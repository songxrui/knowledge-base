## 一、红线规则（不可违反）

### 1.1 禁用词黑名单（13 词）

以下词汇**零容忍**，出现在任何章节中即为 FAIL：

| 禁用词 | 原因 |
|--------|------|
| 赋能 | 企业黑话，空洞无实指 |
| 抓手 | 同上 |
| 闭环 | 同上 |
| 底层逻辑 | 伪深度，通常什么都没说 |
| 综上所述 | AI 三段式签名 |
| 众所周知 | 虚假设定共识 |
| 值得注意的是 | 填充式过渡 |
| 在这个时代 | 空洞宏大叙事 |
| 本质上 | 伪哲学腔 |
| 不难发现 | 假装推导出结论 |
| 随着……的发展 | 模板化开头 |
| 首先/其次/最后 | 三段式骨架 |
| 空壳排比 | 三个以上无信息增量的并列 |

### 1.2 AI 味模式（5 种）

以下模式出现在章节中即触发 AI 味告警：

1. **三段式结构**：首先→其次→最后，或 问题→分析→解决 的机械三段
2. **升华结尾**：结尾段落用"总而言之""展望未来""在这个时代"等拔高
3. **"现在"滥用**：以"现在"开头的过渡句密度过高
4. **-ing 结尾句**：highlighting / underscoring / emphasizing / reflecting / showcasing
5. **虚假权威引用**："研究表明""专家认为""业内人士指出" 无具体来源

### 1.3 证据标注规则

- 每条事实/数据/论断必须标注 `来源::` 锚点
- 格式：`来源:: 作者(年) DOI/URL 关键数字`
- 不确定 → 标注 `[推断]` `[待验证]` `[个人经验]`
- 完全无来源 → 标注 `[来源缺失]`（发布前必须补齐或删除）
- 库内交叉引用不算验证——必须库外独立来源

## 二、强建议规则（需有理由才可违反）

### 2.1 品牌语调

- **教练型人格**：用"我"而非"我们"，用"你"而非"大家"
- **直接到刺痛**：不铺垫，不委婉。"你这个不是产品，是你的大脑活动"——这种直白优于"这可能值得重新考虑"
- **金句收尾**：每个重要判断用一句推文式短句收尾
- **不给鸡汤**：不说"你已经很棒了""相信自己"
- **反共识立论**：每章 ≥1 个反共识 + 适用边界（四件套：流行错误 | 为什么错 | 反例 | 适用边界）

### 2.2 加粗密度

- 每 800 字 ≤ 2 处加粗
- 加粗用于"停下来想一想"的关键句，不是用于强调术语
- 禁止全篇高频加粗（AI 写作特征）

### 2.3 句式节奏

- **短句为主**：能一句话说完的不用两句
- **长短交替**：短句制造节奏，长句展开论证。连续 3 句以上同长度 → 重写
- **避免排比**：不用"不是…不是…不是…而是…"；不用"它让你…它让你…它让你…"

### 2.4 证据密度

- 每章 ≥1 条微信读书标注（书+作者）
- 每章 ≥1 个 `来源::` 锚点
- 关键数字（样本量、效应量、年份）必须精确且可查

### 2.5 个人故事

- 所有提及的个人经历必须真实可验证（哈啰实习、9000 培训班、环卫父母——均确认）
- 禁止编造经历来"增强说服力"
- 如不确定细节 → 标注 `[个人经验，细节可能有偏差]`

## 三、风格签名（可调整）

### 3.1 语气温度

- **默认语气**：冷静、犀利、有距离感——像手术刀，不像拥抱
- **允许的例外**：CH05 关系章节可适度升温；CH02 心理健康章节可出现共情语气
- **底线**：不煽情、不制造焦虑、不利用恐惧

### 3.2 隐喻风格

- 偏好：工程/系统/机器类隐喻（"印钞机""SOP""操作系统"）
- 允许：生物/进化类隐喻（"多巴胺基线""进化默认程序"）
- 避免：过度文艺的隐喻、自然/风景类隐喻（AI 味重灾区）

### 3.3 案例偏好

- 优先用个人经历（真实 > 编造）
- 其次用书籍/论文中的可查案例
- 最后用假设性场景（必须标注"假设"）
- 禁止用"某朋友""某学员""某公司"等不可查案例
