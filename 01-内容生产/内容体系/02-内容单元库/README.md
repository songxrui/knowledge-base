# 02-内容单元库

> 创建: 2026-07-02 | 来源: `D:\KnowledgeBase\cards\` 35张深度卡 + topics 子目录

## 这是什么？

内容单元库是从深度思考卡片中提取的、**可独立复用的内容原子**。每个单元是一个 .md 文件，包含：

- **精华内容**：1-3段的浓缩表达，可直接嵌入文章
- **复用提示**：一行说明适合什么场景
- **元数据**：来源卡片、类型、质量评级、话题标签

## 如何使用？

### 1. 写稿前检索
```powershell
# 按话题搜索
rg "topics:.*执行力" 02-内容单元库/

# 按类型搜索（concept / story / method / quote / data）
rg "type: method" 02-内容单元库/

# 按质量筛选（A级优先使用）
rg "quality: A" 02-内容单元库/

# 按来源追溯原始卡片
rg "source: cards/C2-1" 02-内容单元库/
```

### 2. 复用流程
1. **选题确定后**，按话题标签搜索相关单元
2. **优选 A 级**单元作为核心论据
3. **直接引用或改写**单元内容（注意保留论点完整性）
4. **追溯来源**卡片查看完整论证链（如有需要）

### 3. 内容类型说明
| 类型 | 说明 | 适合场景 |
|------|------|----------|
| `concept` | 核心概念/框架 | 作为文章的理论基础 |
| `method` | 可执行方法/步骤 | 作为文章的实操部分 |
| `story` | 案例故事 | 增加可读性和说服力 |
| `quote` | 金句/引用 | 作为文章的点睛之笔 |
| `data` | 数据/统计 | 增强可信度 |

### 4. 质量评级
- **A**：核心模型，论证完整，可直接使用
- **B**：有价值但需补充或结合其他单元
- **C**：初步想法，需大幅改写

## 维护规则

1. **新增单元**：当深度卡有新内容或外部素材需要入库时，按上方模板创建
2. **更新单元**：追溯来源卡片更新后，同步更新对应单元
3. **废弃单元**：不删除，在 frontmatter 加 `status: deprecated` 并注明原因
4. **命名规范**：`UNIT-XXX_[简短中文标题].md`，ID 递增
