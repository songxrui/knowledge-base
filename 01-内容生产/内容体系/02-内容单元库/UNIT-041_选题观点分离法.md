# 选题-观点分离原创法

先建观点库，后看爆款。日常记录自己的思考（每天3-5条），积累1000+条原创观点。看到爆款 → 提取关键词 → 搜自己的观点库 → 原创嫁接。

自创标题三条件：N个观点讲同一话题 + 足够反常识 + 有冲突感。

核心原则：不在看到爆款后才产出观点。观点预制。爆款只是结构启发，不是内容启发。
