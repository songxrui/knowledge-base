# 附录E.8：自媒体新人操作式学习系统 — 最小学习闭环

> **适用对象**: 0基础刚毕业大学生 / 面对 dontbesilent 210篇文章+76KB手册感到"知识过载"的新人
> **核心原则**: dontbesilent反调研主义 + 执行即能力 + dbs-learning交互式学习
> **一句话**: 看了不做 = 没看。学了不测 = 没学。

---

## E.8.1 前言：你为什么会"知识过载"？

你打开这本76KB的手册，看到210篇文章的目录，第一反应是"太多了，我不知道从哪开始"。

然后你做的事情是：继续往下翻，找"更重要的"章节。找到之后标记、收藏、截图。你觉得自己离答案更近了。

但 dontbesilent 在《只要你没在执行，你就是在逃避执行》里给了最精确的诊断：

> 只要你在学习、在筹备、在调研，就没有人能反驳你。这些事情都是为了达成目标而不得不做的事情，那你就立于不败之地了。但箭头应该反着画：**你是为了逃避执行才去学习。**

这才是你"知识过载"的真正原因：不是知识太多，而是你用"继续学习"当成了"已经行动"的替代品。

本附录的核心任务：让你从"看了再说"变成"做一篇才看下一篇"。

## E.8.2 最小学习闭环

### 本质定义

**最小学习闭环 = 学1篇 → 做1件事 → 得到1个反馈 → 决定下一篇学什么**

这不是"先学完再行动"的瀑布模型。这是**操作式学习**：你的下一篇文章由你上一轮实践的结果决定，不是由目录顺序决定。

对比：

| 传统学习（假学习） | 操作式学习（真学习） |
|---|---|
| 先看完手册再动手 | 看完1篇立即动手 |
| 按目录顺序学 | 按卡点精准学 |
| 学完=完成任务 | 做完=完成任务 |
| 没有数据反馈 | 每条数据都是学习信号 |
| 进度=看了多少篇 | 进度=做了多少事 |

### dontbesilent的两个底层支撑

**支撑1: 可行性分析只能排除必败路径，不能保证成功**

don在《don学经典第一集》说：

> 可行性分析只能得出两个结论：这个事不能干，或者这个事可以去尝试。它万万不可能得出第三个结论叫"成功"。凡来找我做可行性分析的，99.99%不靠谱。实践的人问出来的都是特别特别具体的问题——"我这个白板的镜片是什么牌子的？"因为反光。不实践的人问的是"你这种打法能不能迁移到我的行业？"

这意味着：你在动手之前做的所有"研究"和"分析"，上限只是帮你避坑，下限是让你永远不动手。

**支撑2: 不想做 = 不能做**

don在《不想做，就是不能做》里说：

> 一个人的行动等同于这个人的能力。你没有时间做，意味着你没有能力腾出时间去做。你没有机会做，意味着你没有能力给自己创造这个机会。一个产品不是你公司做的，这个客观事实本身就是护城河。

这意味着：你每多学一篇而不做，不是在"储备知识"，是在证明你"没有能力执行"。

### 闭环结构

`
学1篇 → 做1个动作 → 发布/测试 → 得到数据/反馈
   ↑                                      |
   └──────── 根据反馈选下一篇 ──────────────┘
`

这个闭环不是线性的，是**螺旋上升**的。你每一轮的学习对象都在变，因为你每轮都在解决上一轮暴露的真实问题。

## E.8.3 "学一篇做一篇" — 具体操作步骤

### 第0步：选第一篇（5分钟）

不要从第一章第一节开始。第一篇文章必须满足两个条件：

1. 让你"现在就能做点什么"
2. 做完有明确的结果可观察

**推荐的第一篇文章（三选一）**：

| 推荐篇目 | 学习后要做的动作 | 可观察结果 |
|---|---|---|
| 《做内容的核心不是发什么，是卖什么》 | 写下你第一个"商品"的定义（哪怕只是一个想法） | 有一句完整的商品描述 |
| 《从0到1找到属于自己的生意》公开我的表格工作法 | 填完表格第一行 | 表格不再空白 |
| 《做自媒体的基本功是勇气》 | 用手机录一条30秒自拍视频并发布到任一平台 | 有播放量数据 |

**禁止的第一篇文章类型**：
- 纯理论/框架性文章（如"内容资产工程系统"）—— 你还没有足够的实践体感
- 需要前置知识的文章（如"像素级复制"）—— 等你拍了10条视频再回来看
- 超过4000字的深度长文 —— 你的第一次闭环应该控制在30分钟内

### 第1步：读（15分钟）

不是"读一遍就过"，而是读三遍，每遍有不同目标：

**第一遍（3分钟）：扫标题+小标题+加粗句+结尾**

只看结构，不做笔记。目标是回答一个问题：这篇文章想让我做什么？

如果一篇文章看完你不知道它让你做什么动作，说明这篇文章不适合你当前阶段——换一篇。

**第二遍（8分钟）：精读全文，边读边在脑中翻译成"我要做什么"**

每读完一个段落，在空白处写下一句话（不要用"我理解了"这种模糊表述）：

| 错误的笔记 | 正确的笔记 |
|---|---|
| "我理解了经营比内容更重要" | "今晚写出我第一个商品的3句话描述" |
| "我理解了像素级复制的三个维度" | "找3个对标账号，截图他们的封面和标题格式" |
| "我理解了执行力的两个要素" | "把明天的任务拆成≤15分钟的小块" |

**第三遍（4分钟）：写出唯一的行动指令**

格式：我将在 [具体时间] 做 [具体动作]，完成后能看到 [具体结果]

例子：
- 我将在今晚8:00打开抖音，录制并发布一条30秒的自我介绍视频，明天早上8:00查看播放量
- 我将在今天下午2:00，用表格工作法写下我能提供的3种商品可能性，找1个朋友问愿不愿意付钱

如果写不出行动指令，说明这篇文章你没读懂。重读，或者换一篇。

### 第2步：做（时间不限，但必须24小时内完成）

铁的规则：
- 行动指令写出来之后，24小时内必须完成
- 如果24小时内没完成，你的"行动指令"写错了——不是时间不够，是动作太大了，拆成一半再做
- 禁止在"做"的环节查阅其他文章或资料——你只需要此刻的这篇文章，其他都是拖延的借口

### 第3步：记录反馈（5分钟）

做完之后，记录一个"三行反馈"：

`
做了什么：[一句话]
结果是什么：[一个数据或一个观察]
哪个地方和我想的不一样：[一个意外发现]
`

**三行反馈示例**：

`
做了什么：用抖音录了一条30秒视频，"我是xxx，刚毕业，想学做自媒体，接下来30天每天发一条"
结果是什么：播放量23，点赞1（来自我自己）
哪个地方和我想的不一样：原以为"准备充分才能发"，实际发现"准备"是个无底洞，只要按下发布键就已经赢了90%的人
`

这个三行反馈，就是你下一篇学什么的核心线索。

### 第4步：决定下一篇学什么（2分钟）

根据三行反馈，进入手册寻找对应答案：

| 你的三行反馈暴露的问题 | 下一篇学什么 |
|---|---|
| "播放量不到100" | 《为什么你死活没流量》 |
| "不知道发什么内容" | 《做内容的核心不是发什么，是卖什么》 |
| "拍了但不敢发" | 《自媒体的基本功是勇气》 |
| "发了但没人互动" | 《做内容的本质是对观众构建债权》 |
| "不知道对标谁" | 《像素级复制≠抄袭》 |
| "觉得内容很烂" | 《先完成再完美——你的前100条一定是垃圾》 |
| "没人买我的东西" | 《所有教你"先做内容再变现"的都是耍流氓》 |
| "做不下去想放弃" | 《不要把正常的摸索阶段当成绝望》 |

**注意**：如果三行反馈里写着"一切顺利，没问题"，有两种可能：
1. 你真的做对了（恭喜）
2. 你的动作太小了，没有产生有价值的反馈——你的行动指令需要升级

## E.8.4 三步循环：学习 → 实践 → 复盘

### 循环总览

`
┌────────────────────────────────────────────┐
│  学习（15min）    │ 读1篇，产出1条行动指令    │
├───────────────────┼────────────────────────┤
│  实践（24h内）    │ 执行行动指令，拿到数据    │
├───────────────────┼────────────────────────┤
│  复盘（5min）     │ 写三行反馈，决定下一篇    │
└───────────────────┴────────────────────────┘
`

每一轮循环的目标不是"学完一篇"，而是"暴露一个真实的问题，然后精准找到下一篇答案"。don的方法论不是按目录学的，是按你的**卡点**学的。

### 学习阶段检查清单

在进入"读"之前，先过这3道闸：

- [ ] 我上一轮的三行反馈已经写完（如果是第一轮，跳过本条）
- [ ] 我选的文章和上一轮反馈暴露的问题直接相关
- [ ] 这篇文章看完我知道"要做什么动作"（而不是仅仅"理解了"）

在读完进入"做"之前，再查这3项：

- [ ] 我有一条完整的行动指令（时间+动作+可观察结果）
- [ ] 这个动作可以在24小时内完成
- [ ] 这个动作不需要我再查其他资料就能做

### 实践阶段检查清单

实践中段（做到一半时）：

- [ ] 我有没有因为"感觉不对"而停下来去查别的文章？（如果有，立即回来，先把当前动作做完）
- [ ] 我有没有因为"怕做不好"而迟迟不按发布键？（如果有，记住don的话："不想做 = 不能做"）

实践结束：

- [ ] 我的动作已经"出去"了——发布了、发出了、给人看了、收到了反馈（不是"写好了但没发"）
- [ ] 我有一个具体的"结果"——一个数字、一句话、一个反应（不是"我感觉还行"）

### 复盘阶段检查清单

- [ ] 三行反馈写完了，每一行都是"做了什么/结果/意外"
- [ ] 我知道下一篇该学什么（对照反馈路由表）
- [ ] 如果连续3轮反馈都是"没问题/很顺利"，我会把下一轮的行动指令难度翻倍

## E.8.5 学习病诊断：假学习的7种伪装

don在《只要你没在执行，你就是在逃避执行》里揭示了核心机制：

> 只要我在学习、在筹备、在调研，就没有人能反驳我。这些事情都是为了达成目标而不得不做的事情，那你就立于不败之地了。明明半个小时调研的事，我给你调研三四个小时，多出来的那几个小时其实就是逃避。

以下7种"学习病"，每一种都是一种逃避行动的伪装：

### 病#1: 调研型学习

**症状**：在动手之前，必须先"调研清楚"——行业分析、竞品报告、平台规则。不调研完不开始。

**伪装逻辑**："我对这个领域不了解，贸然动手是不负责任的。"

**真相**：你永远无法通过调研获得行动确定性。don的49天从0到月入20万，没有一步是提前调研出来的。可行性分析的上限是排除必败路径，下限是让你永远不动手。

**诊断问题**：你的调研进行到第几天了？如果超过3天，你已经开始逃避了。

**药方**：今天之内，在你的调研文档里挑1个结论，基于这个结论做1个动作。调研文档里剩下的99%结论，等你做出10条内容之后再回来看。

### 病#2: 课程型学习

**症状**：觉得"系统学习"才能开始——报课、报训练营、买课程。一个课学完再报下一个。

**伪装逻辑**："我在投资自己的成长。"

**真相**：don在《不想做，就是不能做》里说：把行动和能力拆成两件事是自我欺骗。报课 = 把"现在开始"推迟到"学完之后"。但你永远学不完，因为市场一直在出新课。

**诊断问题**：你学过的课程里，有任何一个让你赚到超过课程费用本身的钱吗？

**药方**：关掉课程。用你已经知道的1%的知识，做1件事。做完了如果发现有知识缺口，再精准回来找对应的1篇文章，而不是1整门课。

### 病#3: 工具型学习

**症状**：在开始之前必须选好"最优工具"——用什么剪辑软件？什么文案工具？什么数据分析平台？花大量时间对比工具。

**伪装逻辑**："工欲善其事，必先利其器。"

**真相**：don发了一万多条推文，最初用的就是手机+备忘录。工具不会让你产出更好的内容，只有"开始产出"才会。

**诊断问题**：你花在"选工具"上的时间，是不是已经超过了你花在"做内容"上的时间？

**药方**：今天用手机自带的相机和备忘录，做一条内容发出去。等这条内容播放量超过1000之后，再来考虑"升级工具"。

### 病#4: 收藏型学习

**症状**：看到好文章 → 收藏 → 觉得"我已经掌握了" → 从不回看。

**伪装逻辑**："我知道这个东西在哪，需要的时候我能找到。"

**真相**：你永远不会需要它。因为"需要"是在你行动受阻的时候才出现的，而你不行动就没有"受阻"的体验，就没有"需要"的触发。

**诊断问题**：你上个月收藏的文章里，有哪一篇你回去看过并因此做了一件事？

**药方**：收藏前先执行"学一篇做一篇"闭环。只收藏你"做完之后觉得需要回看"的文章。如果一篇文章你不想马上做对应的动作，就不要收藏——它和你没关系。

### 病#5: 笔记型学习

**症状**：把每篇文章做成精美笔记——思维导图、Notion数据库、飞书文档。笔记越来越厚，行动越来越薄。

**伪装逻辑**："我在构建自己的知识体系。"

**真相**：don在《如何借助AI比任何人学得快10倍》里引用了Bloom的2Sigma理论：学习效果的核心是一对一辅导+掌握学习法，不是笔记的厚度。你的精美笔记是你的"安全感毛毯"，让大脑误以为工作已经完成。

**诊断问题**：你的笔记架构建了多久了？里面有多少条目对应的是一次真实的发布/测试？

**药方**：停止做笔记。改成做"三行反馈"。每一篇学习只产出三行，但每一行都对应一个动作。

### 病#6: 对标型学习

**症状**：花大量时间研究对标的全部内容——看完他所有视频、分析他的所有标题、统计他的发布节奏。但自己一条没发。

**伪装逻辑**："我要像素级复制，所以必须先把对标吃透。"

**真相**：don说的"像素级复制"是在你做的时候复制的，不是在你看的时候复制的。复制发生在你打开相机的那一刻，不是发生在你打开别人主页的那一刻。

**诊断问题**：你分析的对标账号有5个以上了吗？你自己发了5条以上了吗？前者数量超过后者，你就是假学习。

**药方**：只分析1个对标的1条内容。分析完之后，立刻模仿这条内容做一个你自己的版本发出去。发出去之后再分析下一条。

### 病#7: 完美型学习

**症状**："我还没准备好"——觉得知识储备不够、技能不够、时机不对。等准备好了再开始。

**伪装逻辑**："我想对自己的内容负责。"

**真相**：don说"自媒体的基本功是勇气"。你永远不会有"准备好"的那一天，因为"准备好"的标准会随着你学得越多而越变越高。这是一个永远追不到的移动靶。

**诊断问题**：如果现在给你10万元，条件是今天之内必须发出5条内容，你能发出来吗？（答案是能——所以你不是"没准备好"，是"给自己留了退路"）

**药方**：承认"没准备好"是逃避。今天发一条你明知道不完美的内容。你会学到10倍于"继续准备"的东西。

### 真学习 vs 假学习对照表

| 维度 | 假学习 | 真学习 |
|---|---|---|
| 起点 | "我先把这些都学完" | "我现在能做什么？" |
| 进度指标 | 看了多少篇/花了多少小时 | 做了几个闭环/拿到几个反馈 |
| 知识状态 | 脑子里有很多概念 | 手里有发布记录和数据 |
| 情绪状态 | 焦虑但充实（"我在进步"） | 偶尔挫败但清晰（"我知道哪里不对"） |
| 下一步 | 继续找下一篇文章 | 根据反馈精准查漏 |
| 对信息的反应 | 收藏、截图、做笔记 | 写行动指令、执行、记录反馈 |
| 3个月后 | 看了很多但什么都没做 | 发了至少30条内容，有一个初步方向 |

## E.8.6 7天"学做结合"示范计划

以下计划每天都在用"学一篇做一篇"闭环。不要求你一天学10篇——每天只学1篇，但必须做1个动作。

### 第1天：克服"发不出去"的心理障碍

| 环节 | 具体内容 |
|---|---|
| **学什么** | 《自媒体的基本功是勇气》（手册第一章内容提炼） |
| **核心概念** | don说：随时随地发，不打草稿，不做准备。勇气不是学会了再有的，是发出来的。 |
| **今天的行动** | 用手机录1条30秒的视频：你是谁 + 为什么想做自媒体 + 接下来7天你会每天发一条。**直接发布**，不剪辑、不加字幕、不管好不好看。 |
| **发布到** | 抖音或小红书（选你最终想做的平台） |
| **三行反馈** | ①做了什么 ②播放量是多少 ③按下发布键那一刻你在想什么 |

**今天的唯一标准**：视频发出去了。播放量是0也算完成。

### 第2天：搞清楚你"卖什么"

| 环节 | 具体内容 |
|---|---|
| **学什么** | 《做内容的核心不是"发什么"，是"卖什么"》 |
| **核心概念** | 内容是达成目的的手段，不是目的本身。先有商品，后有内容。你不知道发什么，是因为你不知道卖什么。 |
| **今天的行动** | 拿出一张纸（或打开备忘录），写下：①你当前能提供的1样东西——可以是知识、技能、服务、甚至"帮人整理资料"的能力；②谁会需要这个东西；③他为什么现在就需要 |
| **发布到** | 不需要发布（这是内部动作） |
| **三行反馈** | ①我写下的商品是什么 ②我在写的过程中最卡的地方是哪里 ③我对"谁能付钱"有没有把握 |

**今天的唯一标准**：你有一句完整的、"可以被人说NO"的商品描述（如果别人说"我不需要"，你至少知道自己卖的是什么）。

### 第3天：第一次"像素级复制"

| 环节 | 具体内容 |
|---|---|
| **学什么** | 《像素级复制，年入百万；搬运抄袭，颗粒无收》 |
| **核心概念** | 观点必须原创，形式和模式可以像素级学。复制一个人的思维方式，不是复制他的内容。 |
| **今天的行动** | ①在抖音/小红书找1个粉丝<5万但内容你很喜欢的博主；②截图他最近3条的封面+标题格式；③分析"他的观众为什么要点进来看"；④用同样的封面格式和标题结构，做一个你自己的版本（内容是你的），发布 |
| **发布到** | 抖音或小红书 |
| **三行反馈** | ①我复制了谁的什么格式 ②我的版本播放量和第1天比有什么变化 ③"复制格式"和"抄袭内容"的边界我在操作中有什么体感 |

**今天的唯一标准**：你发了一条"借鉴了格式但说的是你自己的话"的内容。

### 第4天：用"卖什么"倒推内容选题

| 环节 | 具体内容 |
|---|---|
| **学什么** | 《所有教你"先做内容再变现"的都是耍流氓》 |
| **核心概念** | 内容是商品购买理由的延伸。内容的好坏标准只有一个：能不能让观众对你的商品产生兴趣。 |
| **今天的行动** | 回顾第2天你写下的"商品描述"。围绕这个商品，列出10个内容选题——每个选题都是一条能"让目标观众发现他需要这个东西"的内容。从中选1个最直接的，录视频发布。 |
| **发布到** | 抖音或小红书 |
| **三行反馈** | ①我围绕商品列了10个选题 ②我选的那个选题是什么 ③发布后有没有人问"怎么买/怎么做/能不能教" |

**今天的唯一标准**：你发的内容，是你自己"商品"的自然延伸，不是泛泛的"行业观点"。

### 第5天：面对低数据的心态管理

| 环节 | 具体内容 |
|---|---|
| **学什么** | 《不要把正常的流量变现的摸索阶段当成绝望》 |
| **核心概念** | don说：摸索期的低数据不是"你失败了"，是"你正在走所有人必经的阶段"。把正常的事情误判为失败，才会真的失败。 |
| **今天的行动** | ①打开你前4天发布内容的数据面板；②写下：每条内容你认为"做得好的1个点"和"下次会改变的1个点"；③继续发今天的第5条内容 |
| **发布到** | 抖音或小红书 |
| **三行反馈** | ①前4天哪条数据相对最好 ②那条好在哪（内容/时间/标题/封面）③我有没有因为低播放量而想放弃——如果有，don的哪句话让我继续 |

**今天的唯一标准**：你在低数据面前没有停下发布。这是第5天和第1天唯一的区别。

### 第6天：执行力的两个按钮

| 环节 | 具体内容 |
|---|---|
| **学什么** | 《普通人赚钱第一步：确定性提高执行力的逻辑》 |
| **核心概念** | 执行力的两个要素是能力和能量。能力不足→拆分任务；能量不足→降低难度。两者都可以管理，不是"天生执行力差"。 |
| **今天的行动** | ①回顾前5天：你哪一天最想拖延？是能力问题（不会拍）还是能量问题（不想拍）？②如果是能力问题：把今天要发的内容拆成5个≤3分钟的小步骤；③如果是能量问题：降低标准——今天只发15秒，对着镜头说一句话就行。完成发布。 |
| **发布到** | 抖音或小红书 |
| **三行反馈** | ①我是能力问题还是能量问题 ②拆分/降低难度后完成了吗 ③这个方法明天我还会用吗 |

**今天的唯一标准**：你用"能力/能量拆解法"完成了第6天的发布——哪怕只说了15秒。

### 第7天：7天复盘 + 找到你的节奏

| 环节 | 具体内容 |
|---|---|
| **学什么** | 《不想做，就是不能做。还没做，就是做不了。》 |
| **核心概念** | 行动就是能力。这7天你发了7条内容——这不是"练习"，这就是你的能力本身。7天前"没发过"就是"不会发"；7天后"发了7条"就是"会发"了。 |
| **今天的行动** | ①写下你这7天的完整列表：每天发了什么、播放量多少、最意外的是什么；②挑出你最有感觉的1条方向；③定下第8-14天的计划：每天发1条，全部围绕这个方向 |
| **发布到** | 今天的内容：说说你这7天最大的1个体会（面向你的观众） |
| **三行反馈** | ①7天中我最有感觉的方向是什么 ②我对"学一篇做一篇"体感最深的是什么 ③下一周我不会再犯的1个错误 |

**今天的唯一标准**：你不再需要"先学再做"——你已经开始了"做了再精准学"的循环。

### 7天完成后的状态检查

- [ ] 7天发了7条内容（不是写了7条草稿）
- [ ] 每条内容都有三行反馈记录
- [ ] 你有一个初步的"商品方向"（哪怕还不完整）
- [ ] 你有一个初步的"内容方向"（第7天复盘确定的那个）
- [ ] 你对"学一篇做一篇"的体感是具体的（不是"我理解了"，是"我每天在这样做"）
- [ ] 你的手册不再让你焦虑——你知道怎么用它了（不是从头读到尾，而是按卡点查）

## E.8.8 常见问题速查

**Q: 我一篇文章要看很多遍才懂，15分钟不够怎么办？**

A: 你不需要"全部理解"才行动。don的学习理念是：理解是行动的结果，不是行动的前提。你只需要看懂"它让我做什么"这一件事。剩下的理解会在你做完之后自动出现。

**Q: 我做完一条内容，觉得太烂了，不想发了怎么办？**

A: don说过"你的前100条内容一定是垃圾"。你不是在等"不烂的那一条"——你是在积累"让第101条不烂"的前100条。发出去，数据告诉你"哪里烂"，下一篇就不烂了。不发出去，你连"哪里烂"都不知道。

**Q: 我的三行反馈里"结果"没有任何数据（0播放0互动），怎么办？**

A: 0播放本身就是数据。它告诉你：①发布时间/平台有问题 ②标题/封面需要换 ③你的账号还没有被算法认识。这三个任何一个都是下一篇的学习方向。

**Q: 我连续几天的反馈都是"没问题"，要继续吗？**

A: 如果连续3天反馈都是"没问题/很顺利"，说明你的行动指令太安全了。把难度翻倍：从"录15秒"升级到"录1分钟"，从"发抖音"升级到"同时发两个平台"。

**Q: 我是文科生，表格工作法那种东西我搞不懂怎么办？**

A: 你的"文科生"身份不是不能做自媒体的理由。don在《赚钱最大的弯路是找一个自己擅长的事》里说：天赋是干出来的，不是找出来的。表格只要求你填"我想要谁的什么钱"——这不需要理科思维。

**Q: 7天之后我还是一分钱没赚到，这正常吗？**

A: 太正常了。don的49天从0到20万，7天只是前1/7。7天的目标不是赚钱——是让你从"纯学习者"变成"操作者"。你赚到的第一个东西叫"体感"：发布是什么感觉？低播放量是什么感觉？"做了再说"是什么感觉？这个体感是你接下来所有变现的基础。
