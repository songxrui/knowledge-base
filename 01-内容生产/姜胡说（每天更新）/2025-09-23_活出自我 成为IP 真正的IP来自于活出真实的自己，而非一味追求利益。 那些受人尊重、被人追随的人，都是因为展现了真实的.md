# 活出自我 成为IP 真正的IP来自于活出真实的自己，而非一味追求利益。

我在短视频中做什么？不过是活出自我，然后分享给大家。
通过这种方式，我获得了更大的影响力，有了更多自由做喜欢的事情，不必为生计而妥协。
这就是正向循环的力量。
我相信你们也能做到。
