# 你为什么赚不到钱的原因 任何数乘以0都等于0。
无论你的能力多强，如果不采取行动，结果为0；
无论你多有才华，没有用户，收入也是0。 
收益 = 价值 × 用户数。 
大多数人收入有限的真正原因是：
- 创造的价值有限
- 服务的用户太少
- 或两者兼有
打工族通常只有一个"用户"（雇主），这就是为什么即使能力出众，收入仍然受限的原因。 
如何提升收益？方法很简单：
- 提高价值：学会创造；发现问题，解决问题。
- 扩大用户：写作、拍视频、做自媒体，让更多人知道你。
这是一个非常明确的方向。 
有人说这是鸡汤。
鸡汤明明大补之物，怎么到你那儿就没用了呢？
原因很可能就是你太虚了！虚不受补。
