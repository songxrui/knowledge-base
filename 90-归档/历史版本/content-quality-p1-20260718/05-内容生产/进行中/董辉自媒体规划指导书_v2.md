# 第一篇：品牌与人设 —— "董辉的认知引擎"从何而来？

## 第 1 章：个人品牌定位（融合 v2.0 "清晰论"）

### 1.1 你的品牌一句话（背下来）

> **品牌句模板**：`为[明确人群]研究[真实问题]，用[可核验证据与运行记录]提供[有限交付]。` 旧版填充值在个人事实确认前停用。

这句话拆开看，每一个词都是武器：

| 要素 | 你填了什么 | 为什么这个填法能打 |
|------|----------|-----------------|
| 身份锚 | 当前无已确认公开条目 | 身份不是必填项；有 `PF-IDENTITY` 记录后再决定是否使用 |
| 地理锚 | 当前无已确认公开条目 | 不以学校层级制造真实感或优越/自卑叙事 |
| 故事资产 | 当前无已确认公开条目 | 只从个人事实确认表读取，不由旧稿或 AI 补写 |
| 产品名 | "认知引擎" | 引擎=持续运转、可升级、可复利。这个名字本身就暗示"系统化交付"——不是卖课，是卖一个"跟着你升级大脑"的过程 |

### 1.2 v2.0 核心方法论：你的"债权"是什么？

dontbesilent 在日期命名原稿 `03-资源/创作者素材/dontbesilent-聊赚钱/2026-04-20_做内容赚钱的本质，是对观众构建债权 #自媒体 #内容 #金钱.md` 第 17 行表述：**"做内容赚钱的本质，是对观众构建债权。"**

什么意思？每一条内容 = 你给观众一笔"认知债"。你给了他们一个有用的洞察，他们欠你一次关注/信任/付费。

债权的三种形态（你已经有了前两种）：

| 债权形态 | 你现在有什么 | 还不够 | 怎么补 |
|---------|------------|--------|--------|
| **经历材料** | 当前无已确认公开条目 | 不足 | 先确认记录；没有真实经历时用来源和问题场景，不强行人格化 |
| **认知债权** | 深度卡体系、DBS方法论、三位一体创作法 | 历史质量判断，需按当前清单复核 | 按主张需要引用可定位来源，不设固定卡片数 |
| **结果材料** | 当前无有效后台数据行 | 不足 | 发布后按统一口径记录，不把“未知”写成 0 |

你的独特优势：你不需要等"成功"之后才有资格说话。dontbesilent 说："人们主动制造无知——为了让'不行'合理化而刻意选择'不知'。"你的优势恰恰是你还没成功——所以你的每一点进步都是"债权"的积累。你不是在讲"我做到了"，你是在讲"我跟你们一起往前走"。

### 1.3 你的人设设计：不是打造，是放大

v2.0 方法论的"清晰论"核心洞察：**"一个人的弱都来自于一种模糊的状态。把自己变清晰的过程，就是自媒体唯一的路径。"**

你的人设不需要"设计"。你只需要把你已有的东西"变清晰"：

| 你已有的 | 变清晰的方式 | 内容示例 |
|---------|------------|---------|
| 财务经历 | 只有 `PF-FINANCE` 确认后才可使用 | 从事实中提取检查问题，不承诺已建立有效系统 |
| 游戏经历 | 只有 `PF-GAME` 确认后才可使用 | 不用排名或年限类比复利，除非推理链完整 |
| 身体经历 | 只有 `PF-BODY` 确认后才可使用 | 健身与内容只能作为待验证类比 |
| 身份背景 | 只有 `PF-IDENTITY` 确认并允许公开后才可使用 | 身份提供情境，不作为攻击或权威武器 |

记住 dontbesilent 这句话："你做的内容能不能让你自己满意？" 如果一条内容你自己看完都觉得"这好像不是我说的"——那就重来。真诚不是策略，是唯一正确的路径。

# 第三篇：Hook 策略 —— 董辉专属的 8 种攻击模式

## 第 4 章：认知攻击理论（v2.0 核心）

### 4.0 先理解底层原理

dontbesilent 在日期命名原稿 `03-资源/创作者素材/dontbesilent-聊赚钱/2025-11-22_做短视频的本质是黑掉人的认知系统 #短视频算法 #自媒体流量 #短视频开头.md` 第 17 行表述：

> **"做短视频的本质是黑掉人的认知系统——你要强制中断别人的思考，你要去劫持别人的意识，你要用你的文字去攻击别人的认知系统。"**

四种攻击模式：

| 攻击类型 | 原理 | 你的应用 |
|----------|------|---------|
| **预测中断** | 上半句建立常见解释，下半句给出有证据的新判断 | “一次真实损失后，最该复盘的不是金额，而是当时缺少哪个停止条件” |
| **信息缺口** | 给出问题和可验证线索，不承诺情绪或神经反应 | “一组可比发布记录中，哪个变量与结果同时变化？” |
| **损失厌恶攻击** | 制造稀缺感 + 特殊性 + 损失恐惧 | "这条内容可能很快会删——因为我说的太真实了" |
| **自我认知命名** | 为观众模糊焦虑提供具体名称 → 共情 | "你有没有这种感觉：学了很多但越来越焦虑？我管它叫'认知负债'" |

### 4.1 H1：反常识宣言（历史候选，无固定配比）

原理：用一句话推翻一个行业共识，制造认知冲突。

董辉模板："[你所在领域的常见认知] + 但/其实 + [反常识结论]"

已填好的示例：

1. "刚开始积累资产时，先学投资还是先建立风险边界？"
2. "大学教了你 4 年专业知识——但没教过你一件事：怎么把知识变成钱。这不是教育的问题，是教育本来就只负责一半"
3. "一组身体记录能说明什么，不能说明什么？"
4. "你以为复利是 1.01 的 365 次方？现实中的复利只有三个字：不中断 + 不毁灭 + 正方向"

### 4.2 H2：可定位数字 + 故事（历史候选，无固定配比）

原理：具体数字 = "这是真的"，故事 = "我愿意听下去"。

董辉模板："[数字] + [时间] + [做了什么] + [意外的结果]"

已填好的示例：

1. "完成第一组可比发布后，哪些判断被后台记录推翻？"
2. "一次有原始记录的损失，怎样转化成下一次会使用的检查表？"
3. "某条内容出现真实咨询后，咨询问题能否支持产品假设？"
4. "两组长期记录能否支持健身与内容系统的类比？"

### 4.3 H3：问题场景 + 有限解释（历史候选，无固定配比）

原理：先说出观众正在经历的痛苦，再给诊断——"你说的就是我！"

董辉模板："[描述普遍痛苦] + 但我发现真正的原因是 [反常识诊断]"

已填好的示例：

1. "你每天刷 3 小时抖音，然后说'没时间做自媒体'——不是没时间，是你把'创作时间'用在了'消费时间'里"
2. "学了很多却越来越焦虑？我管它叫'认知负债'——只输入不输出，每一条知识都在向你讨债"
3. "你买了很多课但一个都没看完——问题不在意志力。问题在于：你买课是在买'安全感'，不是在买'改变'"
4. "连续发布遇到阻力时，先区分任务不清、资源不足和目标价值，不做心理诊断"

### 4.4 H4：适用人群与情境（历史候选，无固定配比）

原理："如果你也 X → 那你就是 Y"——给读者一个身份，他们就会自己走进来。

董辉模板："如果你也在 [做某事] / 也有 [某种感觉]，那你可能是 [某类人]"

已填好的示例：

1. "如果同龄人收入内容让你焦虑，先区分信息、比较和现实资源，不把问题归结为‘还没开始’"
2. "如果你也觉得'先准备好再开始'是对的——那你可能已经被这个思维耽误了至少 2 年"
3. "如果一条内容让你准确复述自己的问题，请写下具体场景；不把读者归为优越的少数"

### 4.5 H5：好奇缺口（历史候选，无固定配比）

原理：设置信息缺口，答案在正文。观众不看完就得不到答案。

董辉模板："一个问题 / 一件事 [严重后果]，我花了 [时间] 才搞清楚"

已填好的示例：

1. "一个真实问题改变了原来的解释——关键证据是什么？"
2. "为什么有人第一条就爆了，而你发了 20 条数据纹丝不动？答案不在内容里——在你的'选题结构'里"
3. "预先固定三个变量后运行一组内容实验，结果是否支持原假设？"

### 4.6 H6：叙事 / 场景型（历史候选，无固定配比）

原理：从一个具体场景切入，让读者"看到"一个画面。

董辉模板：从一天的某个时刻开始叙述。

已填好的示例：

1. "[确认的时间与场景]发生了[可定位事件]；当时的判断记录是______"
2. "后台形成可比样本后，原假设与实际结果出现了______差异"

### 4.7 H7：研究发现型（历史候选，无固定配比）

原理：公开可定位材料中的差异，不假装掌握内幕。

董辉模板："给大家揭秘一个 [描述] + 但是又 [反差特征] 的 [事情/规律]"

已填好的示例：

1. "抽样审计一组创作者后，哪些内容公开了方法，哪些公开了可核验数据？"
2. "对多个社群做同口径审计后，哪些交付能被成员独立完成？没有购买记录时不写亲历"

### 4.8 H8：自传叙事型（成熟武器，后期启用）

原理：有确认记录时，用个人时间轴展示判断如何变化；经历不自动产生权威。

董辉模板："在我 [做某事] 的 [时间段] 里，我 [做了 X 件事 / 犯了 X 个错误]"

已填好的示例：

1. "完成一轮发布实验后，把参数变更、原因和结果列成时间线"
2. "从第一条记录到第一轮产品试跑，把原假设和实际结果并列审计"

### 4.9 Hook 的终极哲学（评述直述）

dontbesilent 在日期命名原稿 `03-资源/创作者素材/dontbesilent-聊赚钱/2026-06-27_允许自己的内容曲高和寡，这是人设的一部分 #清晰 #模糊 #成长.md` 第 69 行表述：

> "拉流量的内容我是担心它流量低的……但是讲深度知识的内容，我是担心它流量高的。因为它流量高意味着我整活了，显得我很不专业。"

对你来说意味着什么：前 30 天你可以也需要用强 Hook。但当你建立了信任之后，有些内容最好的 Hook 就是**平铺直叙**——"今天我想讲清楚一件事"。因为你的观众已经信任你了，不需要每一条都炸裂。

# 第五篇：双平台协同策略

## 第 6 章：抖音 + 公众号 —— 不是两个账号，是一个系统

| **内容深度** | 一个观点 × 一个故事 × 一个金句 | 一个观点 × 多层论证 × 多个案例 |
| **变现角色** | 建立"这个人有点东西"的印象 | 建立"这个人值得跟着学"的信任 |

### 6.2 四种协同模式

**模式 1：先抖后号（月1-2 主力模式）**

`
短内容发布 → 观察受众匹配、完成和回复质量 → 选择有继续研究价值的问题 → 扩展为长文
`

示例：某个有来源的问题在一组可比内容中表现较好，再扩展为长文；不能用未确认金额、年龄和“救命”承诺。

**模式 2：先号后抖（月3+ 启用）**

`
公众号深度文章 → 拆成若干只承担一个任务的短内容 → 按发布参数安排
`

示例：公众号"三位一体创作法"→ 拆 3 条抖音：Day6"刷 3 小时"、Day17"自律是骗局"、Day20"3小时写完就发"

**模式 3：社群闭合（月3+ 核心模式）**

`
抖音建立信任+激发好奇 → 公众号深化信任+完整交付 → 社群完成信任变现
`

**模式 4：数据闭环**

`
每一条内容用同一 TOPIC-ID → CSV 记录双平台表现 → 识别"同一选题哪边表现好" → 优化资源分配
`

### 6.3 引流 SOP

抖音 → 公众号：
- 口播结尾："完整版太长抖音放不下——公号同名「董辉的认知引擎」"

- 候选价格只在 `EXP-PRODUCT-001` 中管理，不在引流文案重复维护

# 第九篇：风险预案

## 第 10 章：历史失败场景清单

> 下列天数、条数和平台阈值均为停用的旧版 `experiment-parameter`。实际停止与调整只看 `EXP-STOP-001`、`EXP-STOP-002`；平台算法原因标为未知，不做单因果诊断。

### 场景 1：第一组内容低于自身基线

症状：在一组可比内容中，多个指标持续低于自己的基线。

诊断：可能涉及分发、受众错配、选题、开头、制作或样本不足；当前不能知道平台算法原因。

应对：
1. 不为维持频率跳过证据门禁；发布频率看参数台账
2. 一次只检查一个变量，例如受众问题或开头是否及时进入主题
3. 可以公开复盘，但不声称公开失败“往往数据最好”

### 场景 2：D7-D9 产生"我是不是不适合"的怀疑

症状：每天发布前拖延、想换定位、觉得"别人都比我好"。

诊断：这只是一个待检验解释。还要检查任务是否清楚、资源是否足够、目标是否仍有价值，以及健康和生活约束。

应对：
1. 写下当前最可能的阻力和竞争解释，不做人格判决
2. 缩到最小行动：不是"今天要做一条爆款"，是"今天写 50 个字就行"
3. 回头看 D1：那里有你最初的兴奋。那条视频虽然数据不好，但它证明了"你能做"

### 场景 3：公众号写了没人看

症状：长文连续多轮没有到达预期受众或产生有效反馈。

诊断：检查订阅基线、分发入口、选题匹配和标题，不假设必须从某一平台导流。

应对：
1. 检查抖音引流：最近 3 条抖音有没有在结尾提公众号？没有 → 加上
2. 先抖后号：抖音数据好的选题 → 扩展为公众号 → 抖音评论区放公众号链接
3. 阅读、回复质量、后续使用和咨询分别记录，不用单一数字宣布“值得”

### 场景 4：社群上线后没人付费

症状：社群上线 2 周，0 付费用户。

诊断：可能是问题、交付、价格、触达、信任或支付流程中的任一环节，不做单因果判断。

应对：
1. 不要焦虑——把社群页面隐藏，继续发内容
2. 检查内容是否让目标读者准确描述问题；没有私信不能单独证明内容价值不足或排除定价、分发和受众错配
3. 访谈目标用户并复核问题与交付，不把“公开数据”直接等同信任
4. 重新上线条件由产品参数台账管理；私信只是需求线索

### 场景 5：发布流程中断

症状：已经一周没发了，再打开选题池觉得"距离很远"。

诊断：触发条件只是候选解释，还要检查任务价值、资源、健康和工具故障。

应对：
1. 不要补发——不要试图"今天发 3 条把断更补回来"。从 1 条开始
2. 缩到最小行动：不是"今天要发一条完整的"，是"今天打开备忘录，写 50 个字"
3. 重新设计一个可观察触发条件，时间和工具按实际情境设置
4. 只有中断本身对读者有用且事实可确认时才写复盘，不把所有生活事件变成内容
