## 📋 每日必做（约 2 小时）

| 时间 | 动作 | 用时 |
|------|------|:--:|
| 上午 | 从选题池取 1 条 → 写 300-500 字口播脚本 | 40min |
| 下午 | 公众号日（每周 2 次）→ 写 1500-3000 字 | 2h |
| 傍晚 | HyperFrames 生成视频 → 写标题 → 发布 | 20min |
| 晚上 | 社群互动 + 看数据 | 30min |
| **总计** | — | **~2h** |

## 🪝 Hook 速查

| # | 类型 | 公式 | 我的版本 |
|---|------|------|---------|
| H1 | 反常识 | [常识] + 但 + [反常识] | "所有教你自律的人都在骗你" |
| H2 | 数字故事 | [数字] + [做了什么] | "亏了 5300 块后，我总结出三条铁律" |
| H3 | 痛点诊断 | [观察] + 我发现 | "连线 30 个群友后我发现：不赚钱的都长一个样" |
| H4 | 身份认同 | 如果你也 X | "如果你是二本学生，且想做自媒体" |
| H5 | 好奇缺口 | 一个问题/一件事 | "一个问题毁掉你的执行力，我花了三年才搞清楚" |
| H6 | 认知攻击 | [假设]——[反直觉答案] | "一个人赚不到钱的核心原因——你上班上多了" |
| H7 | 故事开场 | 个人经历 | "22 岁那年我亏了 5300 块" |
| H8 | 自传叙事 | [时间] + [经历] | "在长沙南华大学，从零开始做自媒体" |

## 📝 标题速查

## ✅ 发布前检查

- [ ] Hook 前 3 秒有冲突/好奇？
- [ ] 有没有 emoji 超过 3 个？
- [ ] 有没有"值得注意的是""令人深思的是"？
- [ ] 有没有"你以为...其实..."？
- [ ] 有没有"赋能""抓手""闭环"？
- [ ] 大声念一遍——念得出口吗？
- [ ] 有没有 ≥1 个具体数字/故事？
- [ ] 如果这是唯一被看到的内容，够好吗？
