## 1. 每周节奏总览

`
         周一        周二        周三        周四        周五        周六        周日
        ─────      ─────      ─────      ─────      ─────      ─────      ─────
上午    抛问题      递话筒      抛问题      递话筒      抛问题      沉默日      沉默日
下午    -           -           -           -           -           -           -
晚上    发 M1        -           发 M2        -           -           围炉夜话    发 M4
        决策日志                 认知拆解                            (每周末)     错题本
                                                                              +周报
`

**设计逻辑**：
- 输出集中在周一/周三晚 → 用户形成"这两天群里有好东西"的心理预期
- 周二/周四只做递话筒 → 给群主和成员缓冲
- 周五抛问题 → 为周末围炉预热话题
- 周六日沉默 → 观察群是否自转 + 围炉夜话 + 错题本收尾

**内容类型轮换规则**：

| 类型 | 频次 | 嵌入位置 |
|------|------|---------|
| 深度分享 | 每周 3 次 | 决策日志(周一) + 认知拆解(周三) + 错题本(周日) |
| 问答/抛问题 | 每周 3 次 | 周一/三/五早安 |
| 投票 | 每周 1 次 | 周五（为围炉夜话选主题或社群决策） |
| 案例拆解 | 每两周 1 次 | 周三认知拆解中轮流出现 |
| 资源推荐 | 每两周 1 次 | 周五与投票交替出现 |

## 3. 围炉夜话 4 期主题库

> **形式**：语音直播（20:00-21:30），群主开场 10 分钟 + 成员分享 + 自由讨论
> **规则**：周五发起投票三选一，实际主题以投票结果为准。以下为推荐主题库。

### 第 1 期：破冰——让每个人被看见

| 主题 | 为什么选这个 |
|------|------------|
| **主推荐**："你最近在'做事'这件事上最大的犹豫是什么？" | 低门槛——不需要成功经验，只需要诚实。跟 D1 决策日志呼应 |
| 备选 A："如果只能用一句话告诉别人'我是谁'——你会说什么？" | 更轻松，适合社交型成员 |
| 备选 B："你今年做过的最不后悔的一个决定" | 正向开场，但可能缺乏深度 |

**操作要点**：
- 群主先分享自己的犹豫（不要讲"我已经想清楚了"）
- 每人发言 3-5 分钟，不被打断
- 群主不说"你这个想法很好"——说"你这个点让我想到..."（递话筒，不下结论）

### 第 2 期：深度——直面失败

| 主题 | 为什么选这个 |
|------|------------|
| **主推荐**："亏过钱吗？那笔钱教会了你什么？" | 跟 D14 错题本呼应。群主先讲 5300 的故事 |
| 备选 A："你做过的最丢脸的一件事——但你现在感谢它" | 需要信任基础，第 2 周可能略早 |
| 备选 B："如果回到一年前，你会阻止自己做什么？" | 更容易切入，但不如失败故事有共鸣 |

**操作要点**：
- 群主先引爆——讲亏 5300 的那一个月没有人接住的感受
- 如果有人讲完，允许沉默 10 秒。不要急着填空白
- 结束时说："今晚说的这些，出不了这个群"（建立安全感）

### 第 3 期：互欠——从"听你说"到"互相接"

| 主题 | 为什么选这个 |
|------|------------|
| **主推荐**："你身边有没有'敢跟你说真话'的人？没有的话，怎么办？" | 跟 D18 同行者互问呼应。群主先承认"我也没有很多" |
| 备选 A："如果在这个群里找一个'敢骂你的人'——你会找谁？" | 高风险高回报。只有在群氛围好的时候用 |
| 备选 B："你上一次被人'接住'是什么时候？谁接的？" | 温暖路线，适合氛围还在建立的阶段 |

**操作要点**：
- 核心目标：让成员之间产生"互欠"感——不只欠群主，也欠彼此
- 如果有人提到群里的某个人——群主递话筒："XX，你听到了吗？"
- 围炉结束后私信 2 位成员："今晚 YY 提到你——要不要私信他聊聊？"

### 第 4 期：展望——三个月后会怎样

| 主题 | 为什么选这个 |
|------|------------|
| **主推荐**："三个月后，如果你变成了一个'更敢做事的人'——你觉得变化会从哪里开始？" | 跟 D22 工具共建和月度复盘呼应。这是"债权"的兑现时刻——用户开始思考"我在这里得到了什么" |
| 备选 A："如果下个月你只能做一件事——你会做什么？" | 聚焦行动，适合行动导向的成员 |
| 备选 B："你觉得这个群最'没用'的地方是什么？" | 反向设计——但需要群有足够安全感才能用 |

**操作要点**：
- 这是首月最后一场围炉——要有"仪式感"+ "延续感"
- 群主先回顾自己一个月的变化（诚实，不要包装）
- 结束时预告下月主题 + 工具共建 v0.1 发布
- 最后 5 分钟："每个人用一句话说说——今晚带走了什么"

## 4. 沉默日设计说明

### 4.1 为什么需要沉默日

来自 30 天运营数据的核心洞察：**社群的健康度不是群主多活跃——是群主不在的时候，群会不会死。**

| 沉默日设计 | 说明 |
|-----------|------|
| **时间** | 每周六 + 周日白天（周日 20:00 前） |
| **群主行为** | 完全不主动发言。不抛问题、不递话筒、不发早安 |
| **如果被 @** | 正常回复，但不要让回复变成"发起新话题" |
| **观察什么** | 群在没人驱动的情况下，有没有人自发开话题？有没有人互相 @？ |

### 4.2 沉默日判断标准

| 沉默日发生了什么 | 判断 | 下周调整 |
|-----------------|------|---------|
| 有人自发开话题 + ≥2 人互动 | ✅ 社群开始自转 | 下周一早安抛更开放的问题 |
| 零消息但不焦虑 | ⚠️ 正常——周末大家都忙 | 不调整 |
| 零消息 + 群主觉得"我该说点什么" | ❌ 群主依赖症还在 | 周一把早安改成更具体的问题（不是开放式的） |
| 有人 @ 群主问"怎么这么安静" | ❌ 成员把群主当发动机 | 周二递话筒时解释："周末让大家自己聊聊——群不是广播站" |

### 4.3 沉默日例外规则

- **新成员入群前 3 天**：如果沉默日刚好是新成员 D1-D3，群主在当天做一次欢迎互动（但不在群里开新话题——私信欢迎 + 引导看历史精华）
- **紧急事件**：如果群内出现争议/负面情绪，正常介入
- **围炉夜话日（周六晚）**：晚间 20:00 围炉夜话属于"沉默日例外"——围炉是固定模块，不算"主动发言"

## 5. 新人融入触发点

> **核心理念**：新人不需要"被运营"——新人需要"被看见 + 被需要"。
> 以下触发点按新成员入群后的相对天数执行，不是按日历日期。

### 5.1 融入时间线总览

`
D0    D1    D2    D3    D4    D5    D7         D14
│      │      │      │      │      │      │           │
入群    破冰            价值感知         互动深化      复盘      深度参与
欢迎    观察            "原来这里       "我也想        "第一周    邀请共建
导航                    有用"          说两句"        怎么样"
`

### 5.2 各触发点详细动作

#### D0：入群当天

| 动作 | 内容 | 渠道 |
|------|------|------|
| 群内欢迎 | @ 新人 + 发新人指南。引导自我介绍（城市 / 在做什么 / 想带走什么） | 群内 |
| 私信导航 | 知识库链接 + 新人必读 + "第一周不用有压力，先潜水看看" | 私信 |
| 登记 | 在付费用户登记表录入基本信息 | 飞书/Excel |

#### D3：价值感知触发

| 动作 | 内容 | 说明 |
|------|------|------|
| 认真回复 | 如果新人发过言——群主认真回复一次（不是"很棒"，是有信息增量） | 让新人感到"我说的话被认真对待了" |
| 引导互动 | 引导 1 位老成员回复新人："XX 你也是做这个方向的，你怎么看？" | 不要让新人只跟群主对话 |
| 分享精华 | @ 新人分享一条历史精华（比如上周的决策日志）："这篇你可能有兴趣" | 让新人知道"好东西不只是今天才有的" |

#### D7：首次反馈收集

| 动作 | 内容 | 渠道 |
|------|------|------|
| 私信三问 | ① 这一周的内容对你有帮助吗？（1-10 分）② 你最想了解什么方向？③ 有什么建议给我吗？ | 私信 |
| 观察发言 | D7 前是否至少发言 1 次？ | 登记表标记 |
| 活跃 → | 邀请参与内容共创（贡献选题/案例） | 私信 |
| 未活跃 → | 问"是不是内容不匹配？想了解什么方向？" | 私信（不施压） |

#### D14：深度参与邀请

| 动作 | 内容 | 渠道 |
|------|------|------|
| 邀请互问 | 如果新人已经发言 ≥2 次 → 私信邀请参与"同行者互问"："要不要抛一个问题给群里？两三句话就行" | 私信 |
| 邀请共建 | 如果工具共建正在进行 → "我们最近在做一个 XX，你愿不愿意贡献一条想法？" | 私信/群内 |
| 标记状态 | 登记表更新——D14 是否从"观望者"变成"参与者"？ | 飞书/Excel |

### 5.3 新人融入健康度判断

| 状态 | 指标 | 群主策略 |
|------|------|---------|
| ✅ 成功融入 | D7 前发言 ≥1 次 + D14 前发言 ≥3 次 | 正常递话筒 + 邀请共创 |
| ⚠️ 慢热型 | D7 前零发言但私信反馈"有帮助" | 不催——D14 再私信一次 |
| ❌ 可能流失 | D14 前零发言 + 私信无回复 | D21 前最后一次私信——直接问："是不是这个群不适合你？如果是的话没关系，我可以退款。" |

> **首 30 天是 Day 1-30，续费操作在 Day 76-90 执行。以下为通用模板，也适用于第二季度续费。**

### 6.2 各节点详细操作

#### D-14：本季度回顾（群内）

`
形式：群公告 + 群内长消息
内容：
- 这三个月我们做了什么（决策日志 X 篇 / 围炉 X 次 / 错题本 X 期）
- 群里的 3 个"名场面"（具体对话引用，隐去昵称）
- 你（群主）自己最大的一个变化
- 留白："你们呢？这三个月最大的变化是什么？"

注意：不要提续费。这是纯回顾——先"欠"，后"收"。
`

#### D-10：下季度预告（群内）

`
形式：群内长消息
内容：
- 下季度主题方向
- 新增模块/调整（如果有）
- 下季度第一场围炉话题预告
- 留白："你们下季度最想聊什么？"

注意：仍然不提续费。让用户"想要下一季"。
`

#### D-7：早鸟续费开启（群内 + 私信）

`
群内发布：
"下季度续费通道开了。早鸟价 169（省 30），到下周三截止。
 之后恢复 199。不想续的完全没关系——最后一周我们照常。"

私信（仅活跃成员）：
"下季度续费开了。你的位置我帮你留到周三。
 如果有什么让你犹豫的地方——直接跟我说。"

关键：私信只发给"值得留的人"。潜水但续费的——发群公告就够了。
`

#### D-3：1 对 1 跟进（私信）

`
对象：活跃但未续费的成员
话术：
"看你还没续——没关系，就是想听听你的感受。
 这三个月，群里有帮到你吗？还是说，你觉得差点意思？
 不管续不续，你跟我说实话就行。"

原则：
- 不要施压
- 如果对方说"最近忙"→ 问"要不要帮你暂停，下季度再说？"
- 如果对方沉默 → 不追问第二遍
`

#### D-0：续费截止

`
动作：
- 结算续费名单
- 移出未续费成员（提前私信过，不突然踢）
- 群内公告："下季度咱们继续——人少了一点，但能量更集中了。"

心态：
- 不续费 ≠ 你做得不好
- 有时候只是"对方的人生阶段跟你的内容不再匹配"
- dontbesilent："续费率不是目标——续费率是你产品设计的结果"
`

## 7. 节假日 & 热点借势指南

### 7.1 借势原则

| 原则 | 说明 |
|------|------|
| **相关性 > 时效性** | 不相关的热点不蹭。"群友都在讨论的事" > "微博热搜第一的事" |
| **角度 > 速度** | 不抢首发。用一个"只有这个群才会聊的角度"去切入 |
| **诚实 > 讨巧** | 如果你对热点没感觉——不说。宁可沉默，不说废话 |
| **群内化 > 搬运** | 看到热点 → 不是转发新闻 → 是抛一个"跟群友有关"的问题 |

### 7.2 2026 年 7-8 月可借势节点

| 日期 | 事件 | 借势角度 | 内容类型 |
|------|------|---------|---------|
| 7 月整月 | 暑假 / 毕业季 | "大学最后一个暑假怎么用" / "毕业生最容易踩的 3 个坑" | 深度分享 / 抛问题 |
| 7 月中旬 | 高考志愿填报季 | "如果重选一次专业——你会选什么？"（与年龄群体强相关） | 投票 + 讨论 |
| 8 月 1 日 | 建军节 | 蹭不了——跳过。相关性为零不硬蹭 | - |
| 8 月中旬 | 秋招启动 | "大四那年我最后悔没做的 3 件事" | 决策日志 / 错题本 |

### 7.3 通用热点借势公式

`
看到一个热点 → 问自己三个问题：

① 这个热点跟"20-26 岁、想做事的年轻人"有什么关系？
   → 没关系 → 跳过
   → 有关系 → 进入 ②

② 我能用什么"反常识"角度切入？
   → 大家都在说 A → 我能说"等等，是不是 B？"
   → 如果只能说 A → 跳过

③ 这个角度能变成群里的"抛问题"吗？
   → 能 → 早安抛问题融入
   → 不能 → 做成决策日志或认知拆解

示例：
热点：某大 V 翻车
① 跟群友有关吗？→ 有——群友也在做内容，也会怕翻车
② 反常识角度？→ 大家都在喷 → 我说："翻车不是问题，翻车之后的反应才是"
③ 变成抛问题？→ "如果你突然被很多人骂——你会怎么处理？"
`

### 7.4 节假日运营规则

| 场景 | 动作 |
|------|------|
| **春节/国庆等长假** | 降低频率但不消失。每周 1 条决策日志 + 1 次围炉。其他时间自由讨论 |
| **考试周（成员群体）** | 主动降噪："这周期末考，群节奏放慢。决策日志照常，其他顺延。你们加油。" |
| **群主个人忙** | 执行"最低存活模式"：每周一/三/五各一次早安，只发决策日志，错题本改为邀请成员自发 |
| **突发公共事件** | 如有争议性事件，群主不在群里表态站队。如果群内讨论激烈 → 私信安抚，不公开灭火 |
