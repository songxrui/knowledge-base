# 董辉的认知引擎 — 新成员 Onboarding 指南

> 社群新成员入群后 7 天的完整引导流程
> 目标：让新成员在 7 天内从"观望者"变成"活跃者"

---

## 入群前：付款确认页

用户付款后，自动回复：
```
✅ 付款成功！欢迎加入「董辉的认知引擎」

📮 请添加微信：DongHui_AI（备注：已付款）

入群后你会收到：
1. 📖 新人指南（本群怎么用）
2. 🗂️ 知识库入口（35 张深度卡 + 答案之书）
3. 🎯 7 天破冰计划

有问题随时私信我，咱们群里见 👋
```

---

## Day 0：入群当天

### 动作
- [ ] 群主 @ 欢迎，发新人指南
- [ ] 引导新人做自我介绍（模板见下）
- [ ] 私信发送知识库链接

### 群内消息模板
```
👋 欢迎 @新成员 加入认知引擎！

简单介绍一下你自己：
- 你在哪个城市？
- 你目前在做/想做什么？
- 你希望从这个群里带走什么？

不用有压力，随便聊聊 🎯
```

### 私信内容
```
Hey，欢迎！我是董辉。

这个群的核心价值就一句话：把"搞钱"这件事从模糊变清晰。

给你两个入口：
📂 知识库：{链接}
📖 新人必读：{链接}

第一周不用有压力，先潜水看看。有任何问题直接私信我。
```

---

## Day 1-2：破冰期

### 群主动作
- [ ] 分享一条"新人友好的内容"（没有门槛的洞察）
- [ ] @ 新人问感受

### 推荐分享内容
- "一个人赚不到钱的核心原因——你上班上多了"（高赞内容引发讨论）
- 自己写一条"22 岁亏 5300 块教会我的事"

---

## Day 3-4：价值感知期

### 群主动作
- [ ] 发布本周深度内容（至少 2000 字）
- [ ] 发起一个投票/讨论话题

### 讨论话题示例
- "你最近在'搞钱'这件事上最大的困惑是什么？"
- "如果只能给 20 岁的自己一条赚钱建议，你会说什么？"

---

## Day 5-6：互动深化期

### 群主动作
- [ ] 回答 2-3 个群友的具体问题
- [ ] 分享一条"只有群里才有的内容"（如未发布的方法论片段）

---

## Day 7：复盘 + 引导续费认知

### 群主动作
- [ ] 私信问感受："第一周感觉怎么样？有什么建议？"
- [ ] 如果活跃 → 邀请参与内容共创（贡献选题/案例）
- [ ] 如果不活跃 → 问"是不是内容不匹配？想了解什么方向？"

### 私信模板
```
Hey，入群一周了，想问你感受怎么样？

三个问题：
1. 这一周的内容对你有帮助吗？（1-10 分）
2. 你最想了解什么方向？（赚钱/自媒体/认知/其他）
3. 有什么建议给我吗？（随便说）

不用客气，真实感受最重要 💪
```

## 附：常见问题 FAQ

**Q: 群里有课程吗？**
A: 没有固定课程。这是一个"知识共享空间"，我会持续输出深度内容，群友互相讨论。课程正在准备中。

**Q: 可以退款吗？**
A: 入群 3 天内，如果你觉得不值，无条件退款。

**Q: 群规是什么？**
A: 两条：不广告、不人身攻击。其他随意。

**Q: 什么时候有线下活动？**
A: 等群人数到 100 人，我会组织长沙线下聚会。
