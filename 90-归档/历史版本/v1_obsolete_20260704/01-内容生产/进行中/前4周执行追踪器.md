# 🆘 崩溃预案：如果连续 3 天没发

> ⚠️ 不要自责。自责是二次伤害。以下是重启程序，照做就行。

## 第一步：诊断（30 秒，只选一个）

```
□ 写不出来（选题枯竭）    → 跳到「重启方案 A」
□ 写了但不想发（完美主义）  → 跳到「重启方案 B」
□ 发了没数据，泄气了      → 跳到「重启方案 C」
□ 生活/学业打断了          → 跳到「重启方案 D」
```

## 第二步：执行重启

**方案 A — 写不出来**
1. 打开 `选题管理/30天选题池_第1期.md`，闭眼指一条
2. 用手机备忘录写 200 字（不是 400，是 200。降低门槛）
3. 不润色，直接录，直接发
4. 发完打勾 → 连发 2 天恢复节奏

**方案 B — 写了不想发（完美主义）**
1. 从草稿箱/备忘录随便找一条
2. 降级标准：标题随便写、封面用纯色底+大字、不检查 Hook
3. 发出去 → 告诉自己"这是第 90 篇中的普通一篇，不是代表作"
4. 发完立刻写第二天那篇

**方案 C — 发了没数据，泄气**
1. 看 Day 1 的数据（你的起点）
2. 看最新一条数据 → 问自己：涨了还是跌了？
3. 如果涨了：你在进步。如果跌了：你在收集数据。
4. 记住 dontbesilent 的话："正反馈是做了之后的副产品"
5. 发一条「翻车日记」：把数据最差的那条拿出来复盘 → 这本身就是内容

**方案 D — 被打断**
1. 承认"生活打断了"是正常的，不是你的错
2. 今天只做一件事：发一条（别的什么都不做）
3. 明天恢复正常节奏
