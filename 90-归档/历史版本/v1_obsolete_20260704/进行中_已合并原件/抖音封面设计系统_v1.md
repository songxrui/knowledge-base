## 🎨 一、董辉专属封面视觉 DNA

> 每张封面必须命中至少 3 项 DNA 标记。这不是"好看"，这是"能被认出来"。

### 色彩系统

| 角色 | 色值 | 占比 | 用途 |
|------|------|:--:|------|
| **底色** | `#F5F1EB` 米白 / `#E8E0D9` 暖灰 | 60% | 大面积背景，保证信息透亮 |
| **主色** | `#1A3A5C` 深蓝 | 25% | 标题大字、主图形、底部色条 |
| **强调色** | `#D4A843` 金色 | 10% | 数字高亮、关键词点缀、分割线 |
| **辅助色** | `#2D2D2D` 炭黑 | 5% | 副标题小字、日期标签 |

### 视觉元素

| 元素 | 规则 | 示例 |
|------|------|------|
| **人物** | 22岁男生剪影，173cm/63.7kg 轮廓，无面部细节 | 侧身站立、背对镜头看远方、书桌前剪影 |
| **图形** | 极简几何 — S型曲线、三柱图、杠铃、环形箭头 | 封面背景暗纹用金色细线图形 |
| **场景** | 宿舍书桌微光、电脑屏幕、窗外城市剪影 | 每3条封面至少出现1次场景元素 |
| **文字禁令** | AI生成底图内禁止可读文字 | 所有文字用Canva/醒图叠加层 |

### 风格约束

- **画风**: Flat Illustration 极简平面，禁 3D 写实、禁赛博朋克、禁渐变光污染
- **留白**: ≥40% 画面为纯色背景
- **线条**: 干净几何线，圆角矩形为主
- **情绪**: 理性、温暖、有力量 — 不愤怒、不焦虑、不鸡汤

### DNA 检查清单

```
生成封面后逐项打勾：
☐ 米白/暖灰底色占比 ≥ 60%？
☐ 标题大字为深蓝 #1A3A5C？
☐ 至少 1 处金色 #D4A843 点缀？
☐ 留白 ≥ 40%？
☐ 无 3D 写实 / 无赛博朋克 / 无渐变色块？
☐ 底图无任何可读文字？
☐ 至少含 1 项董辉专属元素（剪影/宿舍/电脑/S曲线/长沙暗影）？
```

## ✍️ 三、封面文字公式

### 大字公式（主标题，深蓝粗体）

```
公式： [核心数字/冲突词] + [结果/反转]
      ≤ 10 字，1-2 行，占画面高度 15-20%
```

| 类型 | 公式 | 示例 |
|------|------|------|
| 数字冲击 | `[数字] + [名词]` | `亏 5300 块` / `30 天数据` |
| 认知冲突 | `[常识] + ?` | `自律在骗你？` / `越学越穷？` |
| 身份宣言 | `[身份] + [动作]` | `二本做自媒体` / `22岁零存款` |
| 反直觉 | `别 + [动作]` | `别再学投资` / `别先涨粉` |
| 痛点直击 | `你 + [状态]` | `你上班上多了` / `你被算法养了` |

### 小字公式（副标题，炭黑常规）

```
公式： [补充信息/反转/承诺]
      1 行，≤ 15 字，占画面高度 5-8%
      必须与大字形成"冲突→解释"或"悬念→揭晓"关系
```

| 大字 | 小字配对 |
|------|---------|
| `亏 5300 块` | → `但这是我最值的学费` |
| `自律在骗你？` | → `真正的高手靠系统不靠意志` |
| `别再学投资` | → `先学会不亏钱` |
| `30 天数据` | → `发现了一条后背发凉的规律` |
| `二本做自媒体` | → `不需要名校光环` |

### 文字版式铁律

```
☐ 大字必须深蓝 #1A3A5C — 不用纯黑、不用白色、不用渐变
☐ 小字必须炭黑 #2D2D2D — 不用灰色（对比度不够）
☐ 大字+小字间距 ≥ 字高的 0.5 倍
☐ 金色分割线在大字和小字之间
☐ 所有文字整体居中或左对齐，禁止右对齐
☐ 手机预览缩略图（拇指大小）必须能认出大字
```

## 🧪 五、封面 AB 测试方案

### 测试原则

```
同一视频，发布时上传 2 张封面，抖音自动轮播。
24 小时后对比点击率，保留高的一方。
连续测 10 条，找到你的"封面爆款公式"。
```

### 测试变量矩阵

| 变量 | 版本 A | 版本 B | 测试目的 |
|------|--------|--------|---------|
| **大字颜色** | 深蓝 `#1A3A5C` | 金色 `#D4A843` | 哪种颜色在信息流中更跳？ |
| **大字措辞** | 数字型 `亏 5300 块` | 冲突型 `最值的亏损` | 数字 vs 情绪哪个更勾人？ |
| **底图类型** | AI 插画底图 | 纯色背景 + 图标 | 复杂 vs 简洁哪个点击高？ |
| **人物有无** | 含 22 岁剪影 | 纯图形无人物 | 人物剪影是否增加亲近感？ |
| **小字策略** | 补充解释 | 制造好奇 | "学到了更值钱的东西" vs "然后呢？" |
| **布局** | 大字居中 | 大字左对齐 + 右图 | 对称 vs 不对称哪个更吸睛？ |

### AB 测试记录模板

```
| 日期 | 视频 | 版本A | 版本B | A点击率 | B点击率 | 胜者 | 结论 |
|------|------|-------|-------|---------|---------|------|------|
| 7/2  | D01  | 深蓝大字+纯色底 | 金色大字+AI底图 | - | - | - | - |
```

### 测试节奏

```
第 1-5 条：固定底图（纯色深蓝底），只测文字（大字措辞 + 配色）
第 6-10 条：固定文字公式，只测底图（纯色 vs AI插画 vs 照片）
第 11-15 条：固定胜出组合，微调字号/间距/分割线位置
第 16-30 条：用胜出版本批量生产，不再AB测试
```

## ⚡ 六、封面生成 SOP（2 分钟）

### 总流程

```
选题确定 → 30s → 10s → 40s → 30s → 10s = 2min
  ↓         ↓      ↓      ↓      ↓      ↓
 选模板   填文字  定底图  出图   预览   导出
```

### 分步详解

```
Step 1 [30s] — 从选题提取封面关键词
  输入：选题标题
  输出：大字（≤10字）+ 小字（≤15字）+ 底图关键概念（1句话）
  工具：大脑 30 秒，不要纠结

Step 2 [10s] — 打开 Canva 模板
  模板名：「董辉抖音封面_主模板_v1」
  一次性设好：底色 #F5F1EB / 字体 / 分割线 / 底部水印条

Step 3 [40s] — 生成底图（二选一）
  方案A「AI 底图」: 用即梦/可灵，粘贴提示词（从封面示例库中取），--ar 9:16，出图
  方案B「纯色底图」: 跳过此步，直接用深蓝几何图形装饰（30s省掉）

Step 4 [30s] — 在 Canva 中叠加文字
  1. 导入底图（如有）→ 调整透明度到 85% 保证文字可读
  2. 替换大字文字 → 检查颜色 #1A3A5C
  3. 替换小字文字 → 检查颜色 #2D2D2D
  4. 微调文字位置 → 确认安全区内

Step 5 [10s] — 手机预览
  导出 PNG → 发到手机 → 缩略图模式查看
  核心检查：拇指大小能否认出大字？

Step 6 [10s] — 导出发布
  PNG / 质量 90% / ≤ 500KB
  命名: cover_D01_亏5300块_v1.png
```

### 快捷操作

| 场景 | 操作 |
|------|------|
| **赶时间（1min）** | 纯色深蓝底 + 白色大字 + 金色分割线 + 小字 → 跳过 AI 底图 |
| **story 型选题** | 优先用 AI 底图（剪影/场景增加代入感） |
| **认知型选题** | 优先用几何图形（S 曲线/对比图/三柱图） |
| **批量做 5 条** | 先在选题池标注每条的"大字+小字"，再一起进 Canva 替换 |

## 🚫 七、封面禁忌

### 六大红线

| # | 禁忌 | 后果 | 正确做法 |
|---|------|------|---------|
| **1** | 大字 < 18pt | 缩略图看不清，等于没封面 | 最小 26pt，推荐 32pt |
| **2** | 颜色 > 3 种 | 信息流中被花哨淹没，像营销号 | 只用 4 色系统（米白+深蓝+金+炭黑） |
| **3** | 信息过载（3 行+文字） | 用户 0.3 秒无法获取信息→划走 | 1 行大字 + 1 行小字，永远不超过 2 行 |
| **4** | 底图文字与叠加文字重叠 | 完全不可读 | 底图内禁止任何文字（用图标代替） |
| **5** | 表情包/贴纸/花字 | 破坏极简风格，显得不专业 | 只用几何图形和剪影 |
| **6** | 抄袭对标账号的配色 | 失去辨识度，混入信息流 | 坚持深蓝+金色 DNA，不做变色龙 |

### 常见翻车案例

```
❌ 大字用白色 + 放在浅色底图上 → 完全看不见
❌ 小字写了 3 行 → 手机缩略图变成一坨灰色
❌ 红底黄字 → 像超市促销海报
❌ 封面放 5 个不同颜色的标签 → 不知道看哪个
❌ 用了别人账号的头像/Logo → 用户困惑"这是谁？"
❌ 底图 AI 生成了乱码文字 → 显得粗糙不专业
```

### 发布前 10 秒检查

```
☐ 拇指大小能读清大字？（拿远手机看）
☐ 画面颜色 ≤ 3 种？
☐ 文字 ≤ 2 行？
☐ AI 底图中无乱码文字？
☐ 底部 280px 无重要信息？
☐ 表情包/贴纸/花字 = 0？
```
