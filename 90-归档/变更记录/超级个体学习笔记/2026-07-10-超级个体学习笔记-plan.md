# 《超级个体学习笔记》实现计划

> **面向 AI 代理的工作者：** 使用 `superpowers-zh:subagent-driven-development` 逐批执行。每个写作批次使用独立文件集，完成后进行规格审查与内容质量审查。

**目标：** 生成一套八万至十二万字、面向中国大陆年轻内容服务创业者的模块化长期手册。

**架构：** 以总纲建立全书北极星和系统关系，十三章分别承担个人、认知、内容、商业、运营和长期演化问题，附录提供启动、检索、复盘、证据和版本能力。章节结构按问题自由生长，正文只使用 `ᵃ ᵇ ᶜ ᵈ` 四种极简证据标记。

**技术栈：** Markdown、PowerShell、ripgrep、pypdf、本地 PDF、公开一手网页资料。

## 文件结构

最终目录：`03-资源/素材库/超级个体学习笔记/`

创建十九个 Markdown 文件：`README.md`、`00-总纲与使用说明.md`、`01-成为超级个体.md` 至 `13-启动与迭代蓝图.md`、`90-快速启动清单.md`、`91-原则索引.md`、`92-复盘与决策模板.md`、`98-证据与来源附录.md`、`99-版本与实验日志.md`。

规划文件位于 `90-归档/变更记录/超级个体学习笔记/`，不进入最终阅读路径。未经用户明确要求，不执行 `git add`、`git commit` 或 `git push`。

## 内容接口

- `README.md` 消费所有章节标题和相对路径，产出唯一阅读入口。
- `00-总纲与使用说明.md` 产出北极星、系统循环、使用方法和证据符号的存在说明，但不解释符号含义。
- `01` 至 `13` 消费来源台账与用户画像，产出主题正文、必要的内部链接和章节原则。
- `90` 至 `92` 消费正文中的行动、原则与复盘问题，产出可复制工具。
- `98-证据与来源附录.md` 消费全书事实性主张，产出 `ᵃ ᵇ ᶜ ᵈ` 的唯一释义和按章节组织的来源。
- `99-版本与实验日志.md` 产出后续个人实验与规则变更接口。
