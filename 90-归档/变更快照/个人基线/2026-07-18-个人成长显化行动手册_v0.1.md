# 个人成长显化行动手册 v0.1

> **显化 = 让一个重要方向在现实中留下可回看的证据。**

`看五域 -> 选一条 -> 降低启动摩擦 -> 在真实机会中行动 -> 留证据 -> 第 7 天改判`

这不是五套习惯。每轮只升级一个领域；其余四个领域只设护栏，平时不打卡、不增加待办。

## 一、本周行动卡

### 1. 只选一条主线

- [ ] 心理状态
- [ ] 身体
- [ ] 事业财富
- [ ] 关系
- [ ] 学习创造

### 2. 锁定六项

1. **本周唯一主线领域**：________
2. **7 天后希望看见的现实证据**：________
3. **启动句**：当 ________ 发生时，我先做 ________。这个动作能在 2 分钟内开始。
4. **本轮锁定剂量**：每次 ________ 分钟（从 5–20 分钟中选一个，默认 15 分钟，7 天内不改）。
5. **完成证据**：________（文件、照片、记录、交付物或有效反馈）。
6. **复盘日与停止条件**：________；如果 ________，立即停止或转向支持。

锁定剂量只是本轮承诺量，不是最佳时长。做完后可以自愿继续，但额外时长不改变完成标准。

### 3. 只降一个摩擦

- [ ] 提前打开或摆好唯一工具
- [ ] 让启动提示出现在必经位置
- [ ] 移除一个最常打断行动的入口
- [ ] 前一次结束时写好下一步

## 二、四条护栏

主线所在行由上面的停止条件管理；其余四行只在信号出现时行动。

| 领域 | 候选红线信号 | 触发后的第一动作 |
| --- | --- | --- |
| 心理状态 | 情绪、睡眠或基本功能明显恶化 | 暂停新增负荷，联系可信支持或专业服务 |
| 身体 | 疼痛、病情或既有照护计划受到影响 | 停止实验，先恢复或接受合适评估 |
| 事业财富 | 必要工作、账单或已承诺交付受到影响 | 暂停主线，先处理事实、期限和必要义务 |
| 关系 | 安全、边界、照护或重要承诺受到影响 | 优先保护安全并联系合适支持 |
| 学习创造 | 无边界输入再次挤占现实行动 | 关闭新输入，回到当前证据或明确退出 |

任一护栏触发后，不再加码主线。高风险、不可逆或超出能力范围的事项不做个人实验。

## 三、七日证据表

有真实机会才行动和留证据；没有机会记 `noOpportunity`，不补做、不算失败。

| 日期 | 有机会？ | 做到哪一步（未开始 / 开始 / 完成） | 证据或最早中断点 |

| Day 1 |  |  |  |

| Day 3 |  |  |  |
| Day 4 |  |  |  |
| Day 5 |  |  |  |
| Day 6 |  |  |  |
| Day 7 |  |  |  |

第一次中断不补偿、不加量。连续两次在有机会时仍未开始，就把锁定剂量降一档，或只调整一个环境参数。

## 四、认知清债规则

1. 本轮不新增课程、方法书、模板、App 或第二成长目标。
2. 新输入只有在暴露出明确能力缺口时才进入，并写下“学到什么程度就返回行动”。
3. 不能服务当前行动的信息，删除、归档或标为纯探索；不要放进待办冒充进展。
4. 不因为中断评价人格，只记录机会、动作、证据和中断点。

## 五、第 7 天只做一次改判

- **真实机会数**：____
- **证据数**：____
- **原来判断**：我原来以为卡在 ________。
- **事实证据**：实际发生了 ________。
- **当前改判**：现在更支持 ________，但仍不能排除 ________。
- **下一轮唯一动作**：________。

只选一个决定：`保留 / 降低门槛 / 补资源 / 有界学习 / 修测量 / 退出 / 求助`。

唯一验收问题：**第 7 天，我能否依据记录，做出一个比第 1 天更具体的下一步决定？**

- 七天没有真实机会：不判失败；修改触发情境或延长观察。
- 有机会但没有开始：使用最早中断点调整动作或环境。
- 有作品但反馈不能改变决定：选择“修测量”，不宣布方法有效。
- 护栏触发：暂停成长实验，优先修复或求助。
