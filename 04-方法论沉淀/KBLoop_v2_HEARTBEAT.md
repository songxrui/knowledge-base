# KBLoop v2.0 — 心跳质检无限创作循环

> 升级: 2026-06-22 | 基于 superpowers-zh verification-before-completion 原则
> v1.0 → v2.0 变更: 加入6项强制心跳质检，杜绝短文章，每篇≥3000中文有效字符

## 循环（无人交互版本）

```
SELECT → RESEARCH → WRITE → HEARTBEAT_CHECK(6项) → FIX/SAVE → LOOP
                                              ↓ FAIL
                                          RETURN WRITE
```

## 心跳质检六项（每篇必须通过，一项不过即返工）

| # | 检查项 | 通过标准 | 检测方式 |
|---|--------|---------|---------|
| 1 | **AI味零容忍** | 禁用词13词零命中 + AI味5模式零命中 | grep扫描 + 人工审读 |
| 2 | **深度引用** | ≥5本书/论文/名人故事引用，≥3条来源::标注 | 手动计数 |
| 3 | **价值耐久** | "三个月后还值得看吗"=YES（反共识+因果链+个人故事） | self-audit |
| 4 | **选题范围** | 必须在DBS三选题范围内（执行系统/内容与一人企业/认知框架） | 选题匹配 |
| 5 | **商业化钩子** | 自然嵌入健康之书/答案之书引用，价值先行非硬推销 | self-audit |
| 6 | **字数底线** | 中文有效字符 ≥ 3000字（标题/引用/标点不计入） | wc -m ≥ 7500 bytes |

## 选题轮转

从DBS三个压缩选题中循环取用，每次取不同角度：

- TOPIC1 执行系统：环境设计/多巴胺/负循环/14天实验/P0/睡眠/运动/饮食
- TOPIC2 内容与一人企业：资产/复利/HKR/100篇/杠铃/平台/产品化
- TOPIC3 认知框架：反依赖/代际错位/游戏能力/元认知/六格复盘/第一性原理

## 禁产红线

- ❌ 有效中文字符 < 3000字（直接返工）
- ❌ 禁用词命中（直接返工）
- ❌ 引用 < 3本书/人物（直接返工）
- ❌ 无个人真实经历（直接返工）
- ❌ 无商业化钩子（直接返工）
