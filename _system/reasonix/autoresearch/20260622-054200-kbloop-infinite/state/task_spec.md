# KBLoop 无限创作循环 — AutoResearch Task Spec

## Goal
在 KBLoop 工程框架下持续产出高质量长文，永不停止。唯一停止条件：用户按下暂停或遇到必须人工交互的阻塞。

## Scope
- 选题范围：DBS三选题（执行系统/内容与一人企业/认知框架重构）+ 健康之书/答案之书交叉
- 产出格式：2000-4000字中文长文，教练型人格，反共识立论
- 质量门禁：禁用词13词零命中、AI味5模式零命中、来源::标注≥3、反共识≥1

## Non-Goals
- 不发布到外部平台（需人工）
- 不记录发布数据（需人工）
- 不修改已完成的终稿

## Success Criteria
- 每篇文章字数 ≥ 2000
- 每篇文章禁用词13词扫描零命中
- 每篇文章 AI 味 5 模式零命中
- 每篇文章 ≥ 1 个反共识 + 适用边界
- 每篇文章 ≥ 3 条来源::标注
- 每篇文章有商业化钩子（健康之书/答案之书）
