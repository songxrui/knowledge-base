## 1. 每日运营动作

### 1.1 每日时间表

| 时间 | 动作 | 时长 | 说明 |
|------|------|------|------|
| **08:00-08:15** | 群早安 + 当日认知碎片 | 15 分钟 | 不是"早上好"，是分享一条当天触发你的东西 |
| **12:00-12:10** | 午间扫描 | 10 分钟 | 快速浏览上午群消息，需要回复的标记一下（不要秒回） |
| **18:00-18:10** | 晚间扫描 | 10 分钟 | 同上 |
| **21:00-21:30** | 深度互动窗口 | 30 分钟 | 这是"高质量在场"时间——认真回复、抛问题、给反馈 |
| **21:30-21:35** | 数据记录 | 5 分钟 | 记录当日 3 个核心指标（见 8.1） |

**每日总投入**：约 70 分钟。不超过 90 分钟。

### 1.2 早安发送模板

**不是**："大家早上好！"（无效社交）
**而是**：一条具体的认知触发 + 开放性问题

```
示例 1（抛问题日——周一/三/五）：
早上好。今天在准备一条抖音，主题是"XX"。写到一半突然卡住了——我不知道是该用"反常识"开头，还是用"故事"开头。你们看了这么多短视频，哪种开头更容易让你停下来？随便说，不需要什么专业分析。

示例 2（递话筒日——周二/四）：
@XX 你昨天说的那个事后来怎么样了？我跟进一下。
```

**核心原则**：
- 早安消息一定要有一个"开口"——让别人有话可接
- 如果没有具体的触发，不发早安（宁可沉默，不说废话）
- 早安消息的字数控制在 100-200 字之间（太长会让人觉得"群主好努力但我不想读"）

### 1.3 三个"不做"

| 不做 | 原因 |
|------|------|
| **不做"秒回"** | 群主秒回 → 其他成员不回了 → 群主变成客服 |
| **不做"干货轰炸"** | 一天发超过 3 条长消息 → 成员麻木 → 信息贬值 |
| **不做"假活跃"** | 不要为了"让群看起来热闹"而发无意义内容 → 透支信任 |

### 1.4 每日数据记录（30 秒版本）

在手机备忘录或飞书表格里记 3 个数字：

```
日期：
- 今日群消息总数（含群主）：___
- 群主发言数：___
- 非群主发起的对话数（不是回复群主的那种）：___
```

**怎么看**：
- 非群主发起的对话数 ≥ 2 → 健康
- 非群主发起的对话数 = 0 → 明天不要发早安，直接抛一个更开放的问题
- 连续 3 天非群主发起的对话数 = 0 → 触发 7.1"沉默应对"流程

## 2. 每周运营节奏

### 2.1 一周节奏表

```
         周一      周二      周三      周四      周五      周六      周日
        ─────    ─────    ─────    ─────    ─────    ─────    ─────
上午    抛问题    递话筒    抛问题    递话筒    抛问题    沉默日    沉默日
下午    -         -         -         -         -         -         -
晚上    发 M1     -         发 M2     -         -         -         发 M4
       决策日志             认知拆解                               错题本
```

**关键设计逻辑**：
- **输出集中在周一/周三晚**：用户形成"这两天群里有好东西"的心理预期
- **周二/周四低强度**：给群主和成员缓冲，只做递话筒（轻量互动）
- **周六/周日沉默日**：群主不主动发言 —— 这是观察群是否自转的窗口
- **周日错题本**：以"不完美"收尾一周，降低下周一开始的心理门槛

### 2.2 各日详细操作

#### 周一：抛问题日 + 决策日志发布

| 时间 | 动作 | 说明 |
|------|------|------|
| 08:00 | 早安抛问题 | 抛一个跟本周决策日志相关的问题（预热） |
| 20:00-21:00 | 发布"决策日志"（M1） | 群公告 + @所有人（一周一次，不要滥用@） |

**决策日志发布后**：
- 不需要催反馈，等自然回复
- 如果 24 小时内零回复 → 周二私信 2 位活跃成员："这周的决策日志看了吗？想听听你的看法"
- 如果有人在群里讨论 → 你的角色是递话筒，不是下结论

#### 周二：递话筒日

| 时间 | 动作 | 说明 |
|------|------|------|
| 08:00 | 早安递话筒 | @一位最近有行动的成员跟进进展 |
| 全天 | 不主动发起新话题 | 让周一的决策日志继续发酵 |

#### 周三：抛问题日 + 认知拆解发布

| 时间 | 动作 | 说明 |
|------|------|------|
| 08:00 | 早安抛问题 | 跟本周认知拆解无关的问题（避免"预热疲劳"） |
| 20:00-21:00 | 发布"认知拆解"（M2） | 直接发群里（不用公告，减轻形式感） |

#### 周四：递话筒日

同周二。换一个成员递话筒。

#### 周五：抛问题日

| 时间 | 动作 | 说明 |
|------|------|------|
| 08:00 | 早安抛问题 | 可以轻松一点，比如"周末准备干嘛"也可以，但要有信息含量 |
| 全天 | 不做长输出 | 周五晚上的注意力竞争太激烈 |

#### 周六/周日：沉默日

| 规则 | 说明 |
|------|------|
| 群主不主动发言 | 除非有人直接@你且需要回应 |
| 观察 3 件事 | ①有没有人自己发起话题？②有没有人互相@？③有没有人翻旧消息回复？ |
| 记录观察结果 | 周日晚复盘时用 |

#### 周日晚：错题本发布 + 数据周报

| 时间 | 动作 | 说明 |
|------|------|------|
| 20:00 | 群主发"错题本"（M4） | 以身作则，先说自己这周做错的一件事 |
| 20:15 | 邀请成员跟帖 | "这周你们有没有什么踩坑的事？随便说，不用长篇大论" |
| 21:00 | 发布本周数据周报 | 精简版：3 个数字 + 1 个亮点（见 2.3） |

### 2.3 每周数据周报模板

每周日晚发在群里（群公告，7 天有效期）：

```
## 认知引擎 · 第 X 周周报

**本周数据**：
- 群消息总数：XXX 条（上周：XXX）
- 群主发言占比：XX%（上周：XX%） → {↑/↓/→}
- 非群主发起对话数：X 次（上周：X）

**本周一个亮点**：
{本周群里发生的一件具体的事——有人分享实践、有人互相接住、有深入讨论}

**下周预告**：
- 下周一决策日志主题：XXX
- 下周三认知拆解主题：XXX
```

**周报原则**：
- 不超过 200 字 —— 读得完才有价值
- 必须有"一个亮点" —— 让成员感到"这群在往前走"
- 数据必须真实 —— 就算群主发言占比回升了也如实写
- 不写"本周不足"—— 周报是给成员看的，不是给自己的复盘笔记。不足私下记。

## 3. 每月运营规划

### 3.1 月度主题节奏

社群不按"自然月"运营，按"社群季度周期"运营。一个季度 = 3 个主题月：

| 月份 | 主题 | 核心交付 | 月度活动 |
|------|------|---------|---------|
| **Month 1** | 认知基建月 | 帮新成员建立"系统思考"的基础框架 | 工具共建：思维模型速查表 |
| **Month 2** | 行动验证月 | 推动成员从"想"到"做" | 语音围炉：成员分享实践 |
| **Month 3** | 复盘迭代月 | 3 个月回顾 + 续费动员 | 工具共建：避坑合集 |

### 3.2 月度复盘模板（群主自己用，不发群里）

```
## 月复盘：X 月（社群第 X 个月）

### 数据
| 指标 | 本月 | 上月 | 变化 | 健康线 |
|------|------|------|------|--------|
| 总成员数 |      |      |      | - |
| 本月新增 |      |      |      | - |
| 本月流失 |      |      |      | <3 人 |
| 月活跃率 |      |      |      | ≥40% |
| 群主发言占比 |      |      |      | ≤25% |
| 语音围炉参与 |      |      |      | ≥8 人 |
| 本月退款 |      |      |      | 0 |
| 错题本参与率 |      |      |      | ≥30% |

### 本月 3 个"做对了"
1.
2.
3.

### 本月 3 个"下次改进"
1.
2.
3.

### 本月最触动我的一个成员故事


### 下月核心调整（不超过 3 项）
1.
2.

```

### 3.3 每月固定节点

| 日期 | 动作 | 产出 |
|------|------|------|
| 每月 1 号 | 发布本月主题 + 启动工具共建项目 | 群公告 |
| 每月 15 号 | 工具共建中期 check-in | 群聊 |
| 每月 25 号 | 发起语音围炉主题投票（3 选 1） | 群投票 |
| 每月最后一个周六 | 语音围炉（20:00-21:00） | 文字精华整理 |
| 每月最后一天 | 工具共建成果发布 + 署名感谢 | 群公告 + 存入常青资产库 |
| 每月最后一天 | 更新付费用户登记表 | 飞书/Excel |
| 每月最后一天 | 月度复盘（群主私用） | Notion / 飞书 |

### 3.4 债权审计（每月一次，群主私用）

**目的**：检查社群是否在"健康欠债"。

| 审计问题 | 健康信号 | 危险信号 |
|---------|---------|---------|
| 这个月群主给成员创造了多少"被欠"的机会？ | ≥4 次（认知拆解+决策日志） | <2 次 |
| 成员之间互欠了多少次？ | ≥5 次互相帮助/接住 | <2 次 |
| 有多少成员从"消费者"变成了"贡献者"？ | ≥3 人参与工具共建或错题本 | 0 人 |
| 新成员入群 7 天内发言了吗？ | 100% 发言 | <70% |

如果任何一个维度出现危险信号 → 下月运营重点放在那个维度。

## 4. 新用户 Onboarding 流程

### 4.1 入群前：付款后立即执行的 3 步

**Step 1：私信确认（付款后 10 分钟内）**

```
模板（根据实际情况调整）：

XX，看到你付款了。欢迎来认知引擎。

你在 XX 之前私信问过我 XX 问题，这个问题群里也有几个同学在讨论。进去之后可以接着聊。

群里有几个跟你背景比较像的，我待会给你们搭个线。

入群之前想先问你一个问题：你最想在这个群里解决的一个问题是什么？（一句话就行，不用长）
```

**Step 2：信息登记（付款后 30 分钟内）**

在付费用户登记表里填入：

| 字段 | 示例 |
|------|------|
| 姓名/昵称 | 张三 |
| 付款时间 | 2026-07-02 14:30 |
| 入群来源 | 公众号文章《XX》/ 抖音视频 XX / 朋友推荐 |
| 一句话需求 | 想搞清楚怎么做抖音选题 |
| 一句话背景 | 大四，计算机专业，实习中 |
| 7 天融入进度 | 0/7 |

**Step 3：拉入群 + @全员介绍（1 小时内）**

```
欢迎 @XX 加入认知引擎。
XX 是大四计算机的，正在实习，对"怎么做抖音选题"特别感兴趣。
群里做自媒体相关的 @AA @BB —— 你们可能有得聊。

XX，群里有几个东西你可以先翻翻：
1. 群公告里的"常青资产库"—— 里面有之前的决策日志和认知拆解
2. 每周日晚 8 点有"错题本"时间，明天就是，欢迎围观
3. 有问题随时在群里问，不用怕
```

### 4.2 入群后：7 天融入计划

这是整个 SOP 中**最重要的流程**。7 天融入质量直接决定 30 天留存率。

| 天数 | 动作 | 执行者 | 目的 |
|------|------|--------|------|
| **Day 1** | 群主私信发"入群导航"（3 句话） | 群主 | 降低信息焦虑 |
| **Day 2** | 群主在群里@新成员问一个"安全且容易回答"的问题 | 群主 | 让新成员开口说第一句话 |
| **Day 3** | 群主在新成员发言下认真回复（≥50 字）+ 引导另一位老成员互动 | 群主 | 让新成员感到"被看见" |
| **Day 4** | 群主在群里分享一篇与新成员兴趣相关的历史精华，@他说"这篇你可能感兴趣" | 群主 | 展示存量价值 |
| **Day 5** | 检查参与度。如果 5 天没说话 → 群主私信："群里节奏还适应吗？有什么需要帮忙的？" | 群主 | 防止沉默流失 |
| **Day 6** | 引导新成员参与回答同行者互问（群主递话筒） | 群主 + 老成员 | 从"被帮"转向"帮人" |
| **Day 7** | 群主私信："这周感觉怎么样？有什么建议吗？" | 群主 | 收集反馈 + 表达重视 |

### 4.3 入群导航模板（Day 1 私信）

```
XX，欢迎入群！

三句话帮你快速上手：
1. 群公告里有"常青资产库"链接——之前的决策日志、认知拆解、工具共建成果都在里面
2. 群里的节奏是：周一/三晚上发深度内容，周日晚上有"错题本"时间
3. 有想问的直接在群里说——群里有几个跟你背景很像的人，不用怕说错

没有"你应该什么时候出现""不能说什么"这种规则。唯一的规则：真实。
```

### 4.4 Day 5 "沉默警报"触发流程

如果新成员入群 5 天还没说过话：

1. **先看数据**：他有没有看过群消息？（微信群没有"已读"功能，但可以推测——如果他回了其他人的私信但没在群里说话，说明在看但不敢开口）
2. **私信内容**（不是质问，是关心）：
   ```
   XX，这几天群里节奏还适应吗？没有催你说话的意思——有的人喜欢潜水，完全没问题。
   就是想确认一下你有没有什么需要我帮忙的。
   ```
3. **根据回复判断**：
   - "还在看，挺好的" → 不催，继续观察，Day 7 再问一次
   - "有点不知道说什么" → 给他一个具体的开口机会：递一个容易接的问题
   - 不回复 → 继续观察，不追问，不给压力
4. **Day 7 如果仍沉默** → 不再私信打扰，接受"他就是潜水型用户"。潜水≠不满意。

## 5. 续费机制设计

### 5.1 续费时间线

一个季度 = 约 90 天。续费倒计时从 Day 76 开始。

```
Day 76 (D-14)：发布"本季度回顾"
Day 80 (D-10)：发布"下季度预告"
Day 83 (D-7) ：开启早鸟续费（169 元，仅 7 天）
Day 87 (D-3) ：私信尚未续费的活跃成员
Day 90 (D-0) ：续费截止。不续费者移出群
```

### 5.2 本季度回顾模板（D-14）

发在群里，群公告：

```
## 认知引擎 · 第 1 季度回顾

3 个月前的今天，30 个人付了 199，进了这个群。

3 个月里：
- 我们一起读了 XX 篇决策日志和认知拆解
- 语音围炉聊了 XX 个深夜
- 错题本上留下了 XX 条"搞砸了"的记录
- XX 个人在这群里第一次开口说话
- XX 个人从"潜水"变成了"接住别人的人"

让我印象最深的 3 件事：
1. {具体故事}
2. {具体故事}
3. {具体故事}

不管下季度续不续——谢谢你们这 3 个月的"围观"。
```

**关键**：
- 不说"请续费"—— 回顾是制造情感连接，不是销售文案
- 用具体故事，不用抽象数字 —— "W 在群里第一次开口"比"活跃率 40%"有力量
- 真诚感谢，不制造焦虑

### 5.3 下季度预告模板（D-10）

发在群里：

```
## 下季度预告

下个季度会有几个新东西：
1. {具体新模块/新活动}
2. {具体改进}

老用户续费价格不变——你在入群时锁定的价格，永远不变。

早鸟续费下周开启，169（85 折），仅 7 天。
```

### 5.4 早鸟续费（D-7 ~ D-1）

**规则**：
- 169 元，仅 7 天（D-7 到 D-1）
- D-0 当天恢复 199
- 早鸟价不公开宣传（只在群里说），防止新用户进来就要求打折

**操作**：
1. D-7 早上发群公告，附付款码
2. D-5 提醒一次（不是催，是"怕有人忘了"）
3. 每收到一笔续费 → 私信回复："收到了。下季度继续一起折腾。"

### 5.5 D-3：私信尚未续费的活跃成员

**前提**：只私信过去 3 个月里至少参与过一次错题本、一次工具共建或一次语音围炉的成员。

**私信模板**：
```
XX，下季度还继续吗？

没别的意思，就是确认一下。不管续不续我都理解。
如果你觉得哪里可以做得更好，也希望能跟我说——你的反馈对我比续费更重要。
```

**如果对方说不续**：
- 不问原因（可以问他"方便说吗，但不说也没关系"）
- 感谢他的参与
- 移出群后私信："以后公众号和抖音会继续更，欢迎继续看。有任何问题随时私信我。"

**如果对方犹豫**：
- 不推销，不降价
- 说："不着急，早鸟价到 D-1，你可以再想想"

### 5.6 D-0：续费截止与移出

**操作**：
1. 确认所有未续费用户已收到提醒
2. 移出群（不要默默踢—— 每个人都要发一条告别私信）
3. 发布群公告："第 1 季度正式结束。第 2 季度开始。"

**告别私信模板**：
```
XX，第 1 季度认知引擎的旅程结束了。谢谢你当初的信任。

这 3 个月的决策日志、认知拆解、错题本——它们还在你的微信聊天记录里，不会消失。

公众号和抖音会继续更新。有任何问题，随时私信我。

董辉
```

**注意**：不要因为别人不续费就有情绪。续不续是用户的自由。你唯一能控制的，是让他在群里的 3 个月觉得"值了"。

## 7. 常见问题应对

### 7.1 沉默问题：群不活跃怎么办

**场景**：群消息量持续下降，连续多天无人主动发言。

**不要做的事**：
- ❌ 群主疯狂冒泡发消息（会拉高群主占比，形成恶性循环）
- ❌ 发"大家怎么都不说话"（给沉默者压力，让他们更不想说）
- ❌ 用红包激活（红包吸引来的人不是你要的人）

**要做的事**：
1. **先看数据**：是所有人沉默，还是只是不@群主了？
   - 如果是"不@群主但成员之间还在聊"→ 这是好事，你在降权，他们在涨权
   - 如果是"所有人都沉默"→ 进入下一步
2. **抛一个"不得不回"的问题**：
   - 不是"你们觉得XX怎么样"（太好敷衍了）
   - 是"我现在有一个具体的问题需要你们的帮助"（展示群主的脆弱和需求）
   - 示例："我在纠结一件事，下一条抖音要不要露脸。两个选项的利弊我都列出来了，但我拿不准。你们帮我看看。"
3. **降低回复门槛**：
   - 不要问需要深度思考的问题
   - 问一个"是/否"或"A/B"就能回答的问题
   - 示例："A 还是 B？说说直觉就行，不需要理由"
4. **如果还是没人回**：接受现状。有些天就是安静的。安静 ≠ 不好。

**沉默的另一种可能**：你的内容太难了。如果你一直在发 3000 字的深度拆解，成员可能觉得"我还没消化完，不敢说什么"。此时应该发一些更"轻"的东西——一条简短的认知碎片，不需要分析，不需要回复。

### 7.2 吵架/冲突问题

**场景**：两个成员在群里产生观点冲突或人身攻击。

**处理流程**：

| 级别 | 场景 | 处理 |
|------|------|------|
| **Level 1：观点争论** | 两人就某话题激烈讨论，但语言尊重 | 不干预。这是健康的。观察即可。 |
| **Level 2：语气摩擦** | 开始出现"你懂什么""你根本没理解"等攻击性言辞 | 私信双方："群里讨论有点热，没事。但我建议你们私聊继续——群里其他人插不进来。" |
| **Level 3：人身攻击** | 出现侮辱性语言、人身攻击 | 1. 立即在群里说："这个话题先停一下。我们先明确一点——这个群里可以不同意任何人（包括我），但不能攻击人。"<br>2. 私信攻击方："这个群的规则是'可以不同意，不能攻击'。如果继续，我会退费请你离开。"<br>3. 如果持续 → 退费 + 移出群 |
| **Level 4：价值观严重冲突** | 涉及政治、歧视、违法内容 | 零容忍。直接移出群，退费，不解释。 |

**核心原则**：你的群，你的规则。不需要"民主讨论"怎么处理——你是群主，你有权决定谁能留下。温和但坚定。

### 7.3 退款问题

**场景**：用户要求退款。

| 时间窗口 | 政策 | 操作 |
|---------|------|------|
| **入群 ≤7 天** | 全额退款，不问原因 | 立即退款 + 私信："钱已经退回去了。如果你以后还想回来，随时欢迎。谢谢你这几天的参与。" |
| **入群 >7 天** | 不退款 | 回复："按照入群说明，7 天后不支持退款。但如果你觉得群里有什么问题，我很想听听你的反馈。" |
| **特殊场景：群主主动清退** | 全额退款 | 违规者被移出群时，必须退款（不退款 = 你欠他） |

**退款后的心态管理**：
- 退款不丢人。kantbesilent 自己说他的社群有 90% 的人买了不看。退款只是提前退了。
- 每一个退款都是产品反馈。记录退款原因（用户说的原因 + 你推测的真实原因）
- 退款率 >5% → 产品有问题，不是用户有问题

### 7.4 挖墙脚问题

**场景**：有成员在群里拉人进自己的群 / 宣传自己的产品。

**处理原则**：
- **如果你的社群足够好**：成员不会走。即使他拉人，也没人走。
- **如果你的社群不够好**：防不住的。堵不如疏。

**具体操作**：
1. **第一次出现**：私信该成员："XX，群里不适合直接拉人。如果你想介绍自己的东西——可以，但先跟我打个招呼，我们在语音围炉或者固定环节来安排。这样对大家都公平。"
2. **第二次出现**：私信："上次我们说好了先打招呼，这次没有。下次再有，我可能要请你离开了。"
3. **第三次出现**：移出群，退款，不解释。

**为什么不需要过度防范**：
- 你的社群核心价值是"你这个人 + 这群人"—— 不是"群里的人谁都可以拉走"
- 如果成员能被随便拉走，说明他对你的社群没有归属感。这不是挖墙脚的问题，是你的产品问题
- 竞争对手进来偷看？没关系。他们能偷内容，偷不走信任。dontbesilent 说过：你可以抄我的内容，但你抄不走我的 IP。

### 7.5 "群主很忙怎么办"

**场景**：考试周 / 实习忙 / 身体不舒服，无法按 SOP 运营。

**SOP 本身就是给"忙的时候"用的**。当你没法做到 100% 的时候，执行"最低存活模式"：

| 正常模式 | 最低存活模式 |
|---------|------------|
| 每日早安 + 认知碎片 | 每周一/三/五各一次早安（不做每日） |
| 每周决策日志 + 认知拆解 | 只发决策日志，认知拆解顺延 |
| 每日在线扫群 3 次 | 每日扫 1 次（21:00） |
| 周末错题本 | 错题本改为群主不发，邀请成员自发 |
| 周报 | 改为两周一报 |

**提前通知机制**：如果知道未来一周会很忙，提前在群里说：

```
这周期末考，群里的节奏会慢一点。周三的认知拆解顺延到下周。
决策日志和错题本照常。

你们该聊的继续聊——我不在的时候，群不会死的。
```

**核心心态**：你不是 24 小时客服。群主也是人。成员会理解——如果他们不理解，说明他们不是你要的人。

### 7.6 "有人一直潜水怎么办"

**场景**：某些用户入群一个月了，从未发言。

**处理原则**：
- 潜水 ≠ 不满意。有些人就是喜欢看，不喜欢说。
- 不要催，不要给压力。
- 唯一需要关心的指标是：他续费了吗？续了 = 他觉得值，不续 = 他觉得不值。

**判断方法**：月底回顾时，列出"从未发言但续费了"的用户。如果他们续了——说明你的内容足够好，好到他们可以不说话也愿意付钱。这是最高的肯定。
