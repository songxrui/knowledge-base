## 1. 产品定位

### 1.1 一句话产品描述

**"董辉的认知引擎"是一个面向20-28岁大学生和职场新人的199元付费社群，核心交付是用系统思维帮你看清赚钱逻辑，让你不再被碎片信息和成功学收割。**

### 1.2 为什么需要这个产品？

知识付费市场存在一个巨大的结构性缺口：

| 现有选项 | 价格 | 问题 |
|---------|------|------|
| 免费短视频/公众号 | 0元 | 碎片化、无深连接、用户看完就忘 |
| 9.9元资料包/星球 | 9.9元 | 信息堆砌、无人运营、价值感知极低 |
| 几千元课程/训练营 | 2000-5000元 | 门槛高、决策成本大、新人不敢买 |
| dontbesilent社群 | 199元 | ✅ 验证了"低门槛高信任"模型可行 |

**你填补的空白**：提供一个有温度的认知社群——不是冷冰冰的资料包，也不是让人焦虑的高价课。199元，刚好是一顿饭+一杯奶茶的钱。决策成本低，但交付价值高。

### 1.3 与 dontbesilent 社群的对标与差异化

| 维度 | dontbesilent 199社群 | 董辉的认知引擎 |
|------|---------------------|-------------|
| **人设标签** | 创业老兵、方法论大师 | 22岁大学生、系统思维者 |
| **内容风格** | 商业实战派、硬核拆解 | 认知科学视角、从底层原理讲起 |
| **核心交付** | 商业判断力方法论 + AI工具 | 系统思维 × 财富认知 × 自媒体实操 |
| **优势** | 已验证的变现模型、行业口碑 | 同龄人视角、低距离感、成长陪伴感 |
| **目标用户** | 想提升商业判断力的创业者 | 想建立认知系统的大学生/职场新人 |
| **差异化锚点** | "我帮你把生意看清楚" | "我和你一起把底层逻辑搭建起来" |

**你的核心差异化**：dontbesilent的用户买的是"方法论"，你的用户买的是"成长伙伴+认知脚手架"。你不是老师，你是走得稍微快一点的同行者。22岁本身就是最好的差异化——同龄人信同龄人。

### 1.4 目标用户画像

**核心用户**（占80%）：
- **年龄**：20-26岁
- **身份**：大二-大四学生 / 毕业3年内的职场新人
- **痛点**：对赚钱有焦虑，被碎片信息轰炸，想系统学习但不知道从哪里开始
- **付费意愿**：月可支配收入≥1000元，199元不会造成经济压力
- **决策心理**："199不贵，大不了就当少吃两顿外卖"

**边缘用户**（占20%）：
- 27-30岁职场人，想转型做自媒体但缺乏认知框架
- 已有一定阅读基础，想找个"有深度"的社群

**非目标用户**（主动筛选掉）：
- 想要"暴富秘籍"的人 —— 你不是教人暴富的
- 想要"保姆级教程"的人 —— 你交付的是认知，不是操作清单
- 月可支配收入<500元的人 —— 请他们看你的免费内容就好

## 2. 产品结构：引-中-高-顶四层

这是 dontbesilent 验证过的知识付费四层模型，适用于所有"以个人IP驱动"的变现路径。

### 2.1 总览

```
        顶层：1v1长期咨询（2万+/年）
      高层：小班深度陪跑（4999-9999元）
    中层：系统课程 / 训练营（999-1999元）
  引流层：199社群"董辉的认知引擎" ← 你现在在这里
基底：免费内容（抖音 + 公众号）
```

### 2.2 各层详解

#### 引流层：免费内容（现在就开始）

| 维度 | 详情 |
|------|------|
| **形式** | 抖音30-90秒不露脸知识口播 + 公众号1500-3000字深度长文 |
| **目的** | 建立认知、积累信任、筛选付费用户 |
| **核心指标** | 不是涨粉，是"看完后有没有人私信你" |
| **发布频率** | 抖音每周3-5条 + 公众号每周1-2篇 |
| **变现逻辑** | 每一条内容都在构建"债权"——当用户从你这里获得了足够的价值，他们欠你一次付费 |

> **dontbesilent 铁律**："第一天就要找一个能赚钱的事。不挣钱的内容发了也白发。不到500粉的账号年纯利润180万，靠的不是粉丝数量，是信任深度。"

#### 中层：199社群（90天内MVP上线）

这是本文档的核心，详见第3章。

#### 高层（规划）：系统课程 / 训练营（999-1999元）

**触发条件**：
- 社群达到150+付费用户
- 你在社群里验证了某套方法论（有≥10人真实应用并反馈有效）
- 用户主动提出"能不能开个课深入讲"

**产品形态选项**：

| 选项 | 价格 | 适合场景 |
|------|------|---------|
| 录播课+社群答疑 | 999元 | 你有一套完整的框架，不需要实时互动 |
| 21天训练营 | 1299元 | 需要每日打卡、作业批改、社群氛围 |
| 60天深度陪跑 | 1999元 | 需要个性化反馈，人数控制在20-30人 |

**什么时候做这个**：等你有100个付费社群用户后。**现在不要想。**

#### 顶层（规划）：1v1咨询（2万+/年）

**触发条件**：
- 你的深度卡从35张扩展到100+张
- 你有50+个真实的咨询案例
- 有企业/创业者主动找你付费

这个层级的核心不是"卖时间"，而是"卖判断"。dontbesilent的线下课就是典型案例：3天2万+，核心交付是一套判断力操作系统。

**现在你需要知道的**：这个层级存在的意义不是让你现在就去做，而是让你的199社群用户知道——"跟着董辉走，他未来能提供的远不止199元的东西。"

## 3. 199社群详细设计

### 3.1 定价逻辑：为什么是199？

这是你产品设计中最关键的决策。定价不是拍脑袋，是算出来的。

#### 3.1.1 三个定价维度

| 维度 | 分析 |
|------|------|
| **筛选门槛** | 199元 = 筛掉99%白嫖党。9.9元的社群会被广告号和"看了就走"的人淹没，你运营100人累死挣不到1000块。199元让进群的人至少认真对待自己的消费。 |
| **支付意愿** | 你的目标用户月可支配收入1000-3000元。199元占比约6-20%，属于"需要想一下但不会肉疼"的区间。超过299就进入了"需要认真考虑"的决策区。 |
| **价值感知** | 你不是在卖"信息"——免费信息到处都是。你是在卖"一个22岁大学生用系统思维帮我看清赚钱逻辑的近距离观察权"。信息的价值≈9.9元，观察权+信任感的组合≈199元。 |

#### 3.1.2 定价的错误选项

| 价格 | 为什么不选 |
|------|-----------|
| 9.9-49元 | 社群一定会被广告和低质量用户淹没，运营成本远大于收入 |
| 99元 | "差100块就能买199"——用户会拿你和dontbesilent比，你比不过（现在还不能） |
| 299-399元 | 对大学生来说决策成本太高，转化率会低到怀疑人生 |
| 499元+ | 那不是引流款，那是中端产品。你现在没有足够的信任资产支撑这个价格 |

#### 3.1.3 涨价规则

```
用户数    价格
0-50      199元（早期用户价）
51-100    249元
101-150   299元
151-200   349元
200+      399元封顶（此后不涨，但关群限制人数）
```

**为什么这么涨**：
1. 早期用户承担最大的不确定性 → 应该付最低价
2. 涨价本身就是信任信号 → "在涨，说明有价值"
3. 制造自然的紧迫感 → 用户不需要你催，价格会催他们

#### 3.1.4 价格背后的奥派逻辑

> "价格不由成本决定，由用户感知价值决定。" —— 奥地利经济学派

你社群的成本是什么？服务器0元。知识资产0元（你已经有了35张深度卡和1543个内容单元）。

那为什么用户愿意付199？因为他们的感知价值不是"获取信息"，而是：
- "一个22岁大学生用系统思维帮我看清赚钱逻辑" = **199元**
- "有人每周带我复盘自己的认知误区" = **再加50元**
- "一群和我一样的同龄人在讨论怎么赚钱" = **再加50元**

总感知价值至少300元。199元定价是**超值定价**。

### 3.2 交付内容

#### 3.2.1 MVP版交付（前3个月）

这是你社群最精简、最可持续的交付内容。不要贪多。

| 交付项 | 频率 | 形式 | 为什么这样设计 |
|--------|------|------|-------------|
| **每周认知日报** | 每周1篇 | 社群专属长文（2000-3000字），不在公众号发布 | 这是社群的"主菜"——用户付费就是为了看别人看不到的东西 |
| **每周语音直播** | 每周1次 | 微信群语音，30分钟，主题式分享+自由Q&A | 语音建立亲近感。30分钟刚好：不短到敷衍，不长到没空听 |
| **每月认知工具包** | 每月1份 | PDF，含1个思维模型+3个应用场景+1个自测清单 | 可复用的"方法论资产"，用户会保存和转发——这就是口碑传播的起点 |
| **精选问答库** | 持续更新 | 群里好问题+回答，整理为飞书/石墨文档 | 让新入群的人一眼看到价值。问答是社群最有复利效应的资产 |
| **董辉的学习笔记** | 不定期 | 最近读了什么书、看了什么文章、拆解了什么案例 | 展现"你是一个在持续学习的人"——这本身就是最大的价值主张 |

#### 3.2.2 不要承诺的内容

| 不要承诺 | 原因 |
|---------|------|
| "每天更新" | 你做不到，用户也不需要。一周1-2次深交付 > 每天敷衍 |
| "一对一咨询" | 199元不配一对一。如果有人问，就说"可以直播间连麦" |
| "保证赚钱/涨粉/成功" | 别说，说了你就完了。你交付的是认知，不是结果 |
| "终身服务" | 说清楚：一次付费 = 一年社群权益。续费看自愿 |
| "私密干货/绝密方法论" | 不要用"秘笈"这类词。你的价值在于系统思考能力，不是藏着掖着 |

#### 3.2.3 3个月后的交付升级路径

当社群达到50+付费用户后，根据反馈逐步增加：

| 升级项 | 触发条件 | 额外成本 |
|--------|---------|---------|
| 月度嘉宾分享 | 你认识了一个在某领域有深度的人 | 人情交换，无现金成本 |
| 每周深度讨论 | 群里有≥3个活跃用户愿意参与结构化讨论 | 你的时间：30分钟/周 |
| 作业+反馈 | 你推出了某个月度认知工具包后，用户自发交作业 | 你的时间：10分钟/份 |

### 3.3 运营节奏

#### 3.3.1 每周运营日历

| 时间 | 动作 | 预计耗时 |
|------|------|---------|
| **周一 20:00** | 发布本周认知日报到社群 | 写稿耗时：提前完成 |
| **周三 12:00** | 抛出本周讨论话题 + 你的初始观点 | 10分钟 |
| **周五 21:00** | 30分钟语音直播：拆解本周话题 + 回答群内问题 | 30分钟 |
| **周日 19:00** | 发布下周预告 + 精选本周群内最佳讨论 | 10分钟 |

**每周总运营时间**：约1小时（不含写稿时间，写稿已包含在你的内容生产管线中）。

#### 3.3.2 每月的"峰值事件"

每周的日常运营是"基本功"，每月的"峰值事件"负责制造惊喜：

| 月份 | 峰值事件 | 目的 |
|------|---------|------|
| 第1月 | 开群仪式：个人自我介绍+社群地图 | 建立归属感 |
| 第2月 | 第一期认知工具包发布 | 让用户觉得"这个月又在进步" |
| 第3月 | 第一次月度复盘直播（公开你的真实数据） | 建立深度信任 |
| 第4月+ | 根据反馈迭代 | 保持新鲜感 |

#### 3.3.3 日常互动原则

- **你不必每条消息都回**。社群不是客服群。
- **高质量问题必答**。什么是高质量？有背景、有数据、有困惑的具体问题。
- **低质量问题引导**。"怎么赚钱？"这种问题 → 引导他去读你的某篇公众号文章。
- **沉默期处理**：如果群里24小时没人说话 → 不要慌。社群不是微信群聊，是异步知识库。抛出话题即可，不必追求时时热闹。
- **恶意/广告**：零容忍，秒踢。不要解释。

### 3.4 社群规则

#### 3.4.1 核心规则（入群即告知）

```
1. 禁止广告、推广、拉人头——一次即踢
2. 禁止人身攻击、政治敏感话题
3. 鼓励提问，但提问前先搜索群内已有的问答库
4. 鼓励分享自己的实践和复盘，不鼓励纯转发文章
5. 如果你想退群，直接退，不用解释——但已付费不退还
```

#### 3.4.2 隐性规则（不写出来但你心里要有数）

- **你不是客服**：不要秒回。设定"早9-晚9"回复窗口，其余时间是你自己的。
- **你不是群管**：不要费力维护"群氛围"。好内容自然有好氛围。
- **你不是圣人**：说错了就承认。用户不会因为你说错一次就退群，但会因为你不认错而失去信任。

### 3.5 入群话术与欢迎流程

#### 3.5.1 付费后自动回复（微信私信版）

```
Hi {name}！

欢迎加入「董辉的认知引擎」199社群。

这是一个用系统思维看清赚钱逻辑的地方。
这里没有暴富秘诀，但有一群愿意深度思考的人。

接下来三件事：

1. 请做一个自我介绍：你是谁 / 在哪个城市 / 目前最大的困惑是什么
   （格式不限，100字以上最好，一句话也行）

2. 我会在今晚拉你进群。进群后先浏览群公告和精选问答库
   （里面有过去所有的精华内容，建议花20分钟先看一遍）

3. 社群运营节奏是：周一认知日报 / 周三讨论话题 / 周五语音直播 / 周日预告
   不需要每天泡在群里，有空来看就行。

期待和你一起成长。
——— 董辉
```

#### 3.5.2 入群后的欢迎仪式

**在群里@新人，发以下内容**：

```
欢迎 @{新人昵称} 加入「董辉的认知引擎」🔥

目前社群 X 人，你是第 X 位。

简单三步上手：
1. 翻一下群公告，了解社群节奏
2. 看精选问答库：[飞书/石墨链接]
3. 按自己的节奏参与，不用有压力

新人专属福利：私信我任意一个你正在纠结的问题，我会在周五的语音直播中回答。
```

**关键设计**：
- 不要让新人在群里被要求"表演式自我介绍"——很多人社恐，强行要求=劝退
- "私信我问一个问题"是低门槛的破冰方式
- 给具体行动（翻群公告/看问答库），而不是"随便看看"

## 4. 内容与产品的协同

### 4.1 内容→社群：抖音/公众号如何为社群导流

这是你整个商业模式的心脏。内容不为涨粉服务，为变现服务。

#### 4.1.1 导流路径

```
抖音口播（免费）→ 钩子：关注公众号看完整版
    ↓
公众号深度文章（免费）→ 钩子：加微信 / 文末CTA
    ↓
微信私域（朋友圈+私信）→ 展示社群价值+日常运营片段
    ↓
199社群（付费）← 用户主动问"怎么加入"
```

#### 4.1.2 不同平台的导流策略

| 平台 | 导流方式 | 具体做法 |
|------|---------|---------|
| **抖音** | 不直接卖社群 | 结尾CTA："想深入理解这个话题？去我公众号看完整版" |
| **公众号** | 文末CTA+关注自动回复 | 每篇文章结尾有固定模板："如果你觉得这篇文章值199块，欢迎加入我的付费社群" |
| **微信朋友圈** | 间接展示 | 晒社群截图、晒用户反馈、晒认知日报片段，配一句个人感受——不是硬广 |
| **私信** | 被动回答 | 有人私信问"怎么加入社群"时，发标准化介绍+付款码 |

#### 4.1.3 dontbesilent的导流启发

dontbesilent几乎不在短视频里直接卖社群。他卖的是"认知冲击"：
- 发一个反常识观点 → 你被震撼了 → 你去搜他公众号 → 你看到更多深度内容 → 你看到了社群入口 → 你付199

你的路径也一样：**不卖社群，卖"看问题的方式"**。社群是结果，不是目标。

### 4.2 社群→内容：社群如何反哺公开内容

社群不是内容的"垃圾桶"（把次等内容放进去），而是内容的"研发中心"。

| 反哺方式 | 具体做法 |
|---------|---------|
| **选题来源** | 群里有人问了一个好问题 → 扩展为公众号文章。注明"这个问题来自社群成员XX"（经对方同意） |
| **案例素材** | 群里有人的真实经历 → 匿名化后作为案例。比编造的案例有说服力100倍 |
| **观点验证** | 你有一个新想法 → 先在群里说 → 看反应 → 反应好就扩成文章 |
| **辩论素材** | 群里出现了不同意见 → 把两种观点都放出来 → 公众号标题："社群里吵翻了：XXX到底是不是伪命题？" |
| **复购钩子** | 社群用户变成你的高层产品的种子用户 → 他们是天然的口碑传播者 |

### 4.3 转化路径：从关注者到付费用户

#### 4.3.1 三层信任阶梯

```
第1层：关注者 ——"这个人讲的东西好像有点意思"
    ↓（需要：持续的内容价值 + 观点独特性）
第2层：读者 ——"我每篇都看，他说的很多观点我确实没想过"
    ↓（需要：一次"被点燃"的瞬间——某篇文章说中了他的痛点）
第3层：付费用户 ——"199不贵，我想近距离看看他怎么想问题的"
```

#### 4.3.2 转化加速器

| 加速器 | 机制 | 为什么有效 |
|--------|------|-----------|
| **"被点燃"瞬间** | 某篇内容精准击中用户当下的困惑 | 情感决策 > 理性决策 |
| **稀缺信号** | "第2批入群即将涨价" | 损失厌恶 > 获得欲望 |
| **社会证明** | 展示社群截图、用户反馈、讨论质量 | 从众心理：别人都加入了 |
| **低门槛试险** | "私信我任意一个问题，我免费回答" | 先尝后买，信任前置 |

#### 4.3.3 用户旅程地图

```
第0天：刷到你的一条抖音 → "有点意思" → 关注
第7天：又刷到一条 → "说的确实不一样" → 去搜公众号
第14天：读了3篇公众号 → "这人的思维方式和别人不一样" → 加了微信
第21天：朋友圈看到你发的认知日报截图 → "群里的讨论质量好像挺高"
第28天：公众号文章末尾看到涨价预告 → "不买下个月就贵了"
第30天：私信"怎么加入" → 付款 → 入群
```

**关键洞察**：用户不是看完一条内容就付款的。从关注到付费平均需要4-6周。你的工作不是催他付钱，是**在4-6周内持续给他看"你值得信任的证据"**。

## 5. MVP上线计划

### 5.1 上线前置条件（不可跳过）

| 条件 | 具体标准 | 为什么是必要条件 |
|------|---------|----------------|
| **公众号阅读量** | 最近10篇平均阅读≥300 | 不足300说明你的内容还没建立足够的信任基础 |
| **主动私信数** | ≥5个读者主动问"你有没有社群/课程" | 这是最真实的付费信号——有人已经准备好给你钱了 |
| **社群独家内容** | 手上有≥10篇未公开的深度内容 | 社群的第一印象靠内容质量，不能用公众号旧文充数 |

> **修改说明**：指导书v1中写的是公众号≥500阅读。重新评估后调整为≥300——因为你的公众号从零起步，500可能过于理想化。300是一个务实的目标：说明你确实有了一批忠实读者，但不会让你等到怀疑人生。

### 5.2 冷启动策略：前10个付费用户怎么来

前10个用户是最难的——没有社会证明，没有口碑传播。你需要"设计"这10个人。

#### 5.2.1 五步冷启动法

| 步骤 | 动作 | 目标 |
|------|------|------|
| **1. 定向邀请** | 从私信过你的人中，挑10个最活跃、问题最有深度的，私信说："我正在筹备一个付费社群，想邀请你做内测用户，价格打92折（183元），作为交换，我需要你入群后给我真实的反馈。" | 前10个付费用户 |
| **2. 老朋友支持** | 把你最信任的3-5个朋友拉进来（让他们真的付钱，不是白送） | 群启动时不会冷场 |
| **3. 开群当天** | 一次发布一篇超高质量的认知日报（2000字+），让刚入群的人立刻感受到"值了" | 第一印象就是峰值体验 |
| **4. 第一周密集运营** | 比正常节奏多一倍——发两篇日报、两次讨论、一次语音直播 | 前7天决定用户会不会续费 |
| **5. 第一周结束后** | 私信每一个用户："这周感觉怎么样？有什么建议？" | 收集真实反馈，迭代产品 |

#### 5.2.2 不要去做的冷启动方式

| 不要做 | 原因 |
|--------|------|
| 朋友圈发硬广 | 太廉价，降低你的IP质感 |
| 求朋友转发 | 带来的用户不精准，入群后也会走 |
| 免费试用30天 | 免费来的不会珍惜，反而对内容更挑剔 |
| 在别人群里拉人 | 毁人品，行业禁忌 |

### 5.3 上线时间线建议

```
        D0（现在）：读完这份文档，心里有数
        ↓
        第1-4周：执行90天计划第1-30天（基础建设期）
        - 发完30条抖音
        - 写出2篇公众号深度文章
        - 建立选题池和素材库
        ↓
        第5-8周：执行90天计划第31-60天（内容管线稳定期）
        - 公众号累计10+篇文章
        - 开始收到私信
        - 同时开始储备社群独家内容（每周写1篇备用）
        ↓
        第9-12周：执行90天计划第61-90天（社群上线期）
        - 检查3个前置条件是否满足
        - 如果满足 → 第10周启动冷启动（定向邀请）
        - 如果不满足 → 再等2-4周，不着急

目标上线窗口：2026年9月底-10月初
```

**一个重要的心态提醒**：如果90天到了前置条件还没满足——**不要硬开**。硬开的结果是你无法给第一批用户好的体验，他们退群后，你的社群口碑就死了。口碑死了比从没开过更糟。

## 6. 数据指标

### 6.1 核心指标（你每周都要看）

| 指标 | 计算方式 | 健康基线 | 危险线 | 为什么重要 |
|------|---------|---------|--------|-----------|
| **付费转化率** | 付费人数 ÷ 加了微信的总人数 | ≥5% | <2% | 转化率低说明你的内容没有构建足够信任 |
| **30天留存率** | 入群30天后还在的人数 ÷ 入群总人数 | ≥85% | <70% | 留存比你想象的更重要——走的人比不来的人伤害大 |
| **月活跃率** | 本月至少有1次互动的用户 ÷ 总用户 | ≥40% | <20% | 沉默用户最终都会流失 |
| **续费率** | 到期后续费人数 ÷ 到期总人数 | ≥60% | <30% | 续费率是产品价值的唯一真实投票 |

### 6.2 健康指标（每两周看一下）

| 指标 | 健康信号 | 危险信号 |
|------|---------|---------|
| **群内提问质量** | 用户问的是"XX场景下我怎么用这个方法" | 用户问的是"你再说一遍XX是什么" |
| **内容打开率** | 认知日报打开率≥60% | 没人讨论日报内容 |
| **语音直播参与率** | 每场≥10人在线（社群50人时） | 连续3场<5人 |
| **用户自发性** | 用户主动分享自己的实践/复盘 | 所有内容都需要你来发起 |
| **退款率** | <3% | >5%（需要立刻排查原因） |

### 6.3 数据记录方式

在 `D:\KnowledgeBase\05-数据统计\` 下创建一个新文件：`社群运营数据.csv`

```csv
日期,总用户数,本月新增,本月流失,月互动人数,月活跃率,认知日报平均打开数,语音直播平均在线,本月退款数,本月续费数,备注
2026-10-01,12,12,0,10,83%,12,8,0,0,MVP上线首月
```

**更新频率**：每月1号更新一次。

### 6.4 数据驱动的关键决策节点

| 数据信号 | 决策 |
|---------|------|
| 50+用户 + 续费率≥70% | 可以开始规划高层产品（999元课程） |
| 连续3个月留存率<75% | 暂停拉新，先修复社群交付质量 |
| 有3个用户主动说"我朋友也想加" | 可以用"老带新优惠"做增长（但不要过早启动） |
| 连续2个月活跃率<30% | 说明你的内容在"贬值"——需要重新设计交付节奏 |
| 退款率突然飙升 | 立刻私信退款用户问原因——然后修复，不要辩解 |
