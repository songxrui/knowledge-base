## 🔟 分钟倒计时

### ⏱️ T-10min：账号最后检查

- [ ] 抖音头像已设置（真实照片，不是 logo）
- [ ] 抖音昵称正确（董辉的认知引擎）

- [ ] 公众号头像已设置
- [ ] 公众号简介已填写
- [ ] 公众号菜单栏已配置

### ⏱️ T-8min：内容最后检查

- [ ] 视频能正常播放
- [ ] 字幕没有错别字
- [ ] 时长 60-90 秒
- [ ] Hook 前 3 秒有冲突/好奇？
- [ ] 有没有 emoji 超过 3 个？
- [ ] 有没有"值得注意的是""令人深思的是"？
- [ ] 大声念一遍——念得出口吗？
- [ ] 有没有 ≥1 个具体数字/个人故事？

### ⏱️ T-5min：标题与封面

- [ ] 标题已写好（15-25 字）
- [ ] 封面已制作（深蓝底+大字标题）
- [ ] 话题标签已添加（#自媒体创业 #赚钱思维 #大学生创业）
- [ ] 定时发布时间正确（建议 19:00-21:00）

### ⏱️ T-2min：深呼吸

- [ ] 接受一个事实：第一条大概率不会爆
- [ ] 记住一句话：第 90 篇 > 第 3 篇 > 第 1 篇
- [ ] 告诉自己：你不是在发布一条视频，你是在启动一个系统

### ⏱️ T-0：发布

- [ ] 🚀 点击发布
- [ ] 关掉抖音 APP
- [ ] 打开 `前4周执行追踪器.md` → Day 1 打勾
- [ ] 打开 CSV → 记录日期和标题
- [ ] 去写第二条
