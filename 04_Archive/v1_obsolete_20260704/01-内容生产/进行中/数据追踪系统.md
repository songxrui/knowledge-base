# 董辉自媒体数据追踪系统

> 每发布一条内容，立即记录。数据是复盘的唯一依据。

---

## 数据记录规范

### 记录时机
- **T+1小时**：记录初步数据（播放/阅读/点赞）
- **T+24小时**：记录稳定数据
- **T+7天**：记录长尾数据
- **每月最后一天**：月度汇总

### 记录方式
- 主表：`D:\KnowledgeBase\05-数据统计\数据统计表.csv`
- 格式：UTF-8 with BOM（Excel 可读）
- 每次发布后立即追加一行，不要攒到周末一起填

---

## CSV 字段规范

```
日期,平台,内容ID,标题,Hook类型,核心观点,播放/阅读量,点赞数,评论数,分享/转发数,收藏数,粉丝增长,发布时间,备注
```

| 字段 | 说明 | 示例 |
|------|------|------|
| 日期 | YYYY-MM-DD | 2026-07-15 |
| 平台 | douyin / wechat | douyin |
| 内容ID | 文件名的日期部分 | 2026-07-15 |
| 标题 | 发布时的标题 | "亏了5300块——但这是我最值的学费" |
| Hook类型 | H1-H8 | H7 |
| 核心观点 | 一句话 | "赔钱是能力的证明" |
| 播放/阅读量 | 数字 | 523 |
| 点赞数 | 数字 | 47 |
| 评论数 | 数字 | 12 |
| 分享/转发数 | 数字 | 3 |
| 收藏数 | 数字 | 8 |
| 粉丝增长 | 当条内容带来的粉丝 | 5 |
| 发布时间 | HH:MM | 19:30 |
| 备注 | 任何值得记录的事 | "第一条，紧张" |
