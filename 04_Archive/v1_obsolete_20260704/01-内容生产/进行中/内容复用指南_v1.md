# 内容复用指南 v1.0：抖音↔公众号双向互转

> **写给董辉**：这套方法的核心就一句话——**同一份认知资产，用两种格式交付，覆盖两类受众。**
> 版本：v1.0 | 2026-07-02 | 基于：规划指导书 v2.0 + 内容生产操作系统 v1.0 + 公众号文章"认知负债陷阱" + 第1批抖音脚本

## 读前必看：为什么要做双向复用？

你现在有两个平台：
- **抖音**：60-90秒口播，300-500字，每天发，目标是"被算法推荐给陌生人"
- **公众号**：1500-3000字长文，每周发，目标是"让已关注的人深度信任你"

如果每次各写各的，你每周要产出：3条抖音脚本（~1500字）+ 1篇公众号（~2500字）= 4000字原创。

但如果你学会了复用，实际产出可以降到 1500-2000字/周。因为**同一份认知资产可以拆成两种形态**。

这就好比：你有一块猪肉，可以做红烧肉（公众号长文），也可以切成肉丝炒青椒（抖音脚本）。猪肉还是那块猪肉，但吃法不同。

本指南教你：怎么切、怎么炒、怎么两盘菜一起上桌。

## 第一章：公众号长文 → 抖音脚本的拆解方法

### 1.1 核心原理

一篇标准公众号文章的结构是：

```
Hook开头 → 问题拆解(多个小节) → 解决方案 → CTA结尾
```

这天然就是 3-5 条抖音脚本的"母体"。你不需要从零想选题——你只需要把长文的每个小节独立成一条视频。

### 1.2 拆解三步法

**Step 1：找"独立论点"**

打开你的公众号文章，找出每个小标题（## 开头的行）。每一个小标题 = 一个独立论点。如果小标题少于 3 个，把长段落中能独立成立的观点也拆出来。

**Step 2：每个论点配一个 Hook**

对照 §5 Hook 调色板（在内容生产操作系统中），给每个独立论点选一个最合适的 Hook 类型：

| Hook 类型 | 适用场景 | 公式 |
|-----------|---------|------|
| H1 反常识宣言 | 观点与大众认知相反 | "大多数人以为X，实际上Y" |
| H3 认知冲突 | 制造"对但没想到"的感觉 | "你有没有这种感觉——X，但其实Y？" |
| H5 痛点共鸣 | 击中共同经历 | "如果你也X，那你一定懂Y" |
| H7 故事开场 | 有个人经历支撑 | "X年前，我做过一件Y的事" |
| H8 威胁警告 | 制造紧迫感 | "如果你还在X，那你已经在Y了" |

**Step 3：压缩 + 口语化 + 加 CTA**

把公众号段落的书面语改成口语，压缩到 300-500 字，确保 ≤3 个核心信息点，结尾加一个 CTA。

### 1.3 拆解比例参考

| 公众号字数 | 可拆出抖音条数 | 每条字数 | 适用场景 |
|-----------|-------------|---------|---------|
| 1500字 | 2-3条 | 300-400字 | 观点密度低的叙事文 |
| 2000-2500字 | 3-5条 | 350-500字 | **标准配置（你的大多数文章）** |
| 3000字+ | 5-7条 | 350-500字 | 深度长文，可做一周选题 |

### 1.4 质量标准

拆出来的每条抖音脚本必须独立通过质检：

- [ ] 不看公众号原文，单独读这条脚本——能懂吗？
- [ ] Hook 前 3 秒有钩子吗？（冲突/好奇/数字）
- [ ] ≤3 个核心信息点？
- [ ] 有"我"的真实经历吗？（至少 1 处）
- [ ] 结尾有 CTA 吗？

## 第二章：抖音爆款 → 公众号长文的扩展方法

### 2.1 什么时候该扩展？

不是每条抖音都值得扩成公众号。触发条件：

- 24h 播放 >5000（说明选题有传播力）
- 评论 >20 条（说明有讨论价值）
- 完播率 >30%（说明观点吸引人）

满足 2/3 → 扩展。只满足 1/3 → 记录数据但不扩展。都不满足 → 这个选题方向放弃。

### 2.2 扩展三步法

**Step 1：找出抖音脚本的"骨架"**

抖音脚本本质上是一个"论点 + 证据 + 金句"。把它拆回三要素：

```
论点：认知负债 = 未经验证的知识持续产生焦虑利息
证据：查理·芒格的话 + 水库隐喻 + Dan Koe 三位一体
金句：你知道的已经够多了，欠的是验证债不是知识债
```

**Step 2：横向扩展——给每个要素加"层"**

公众号的深度来自"层数"：

| 要素 | 抖音版（1层） | 公众号扩展（3-5层） |
|------|------------|-----------------|
| 论点 | 一句话定义 | 定义 + 类比 + 反例 + 边界条件 |
| 证据 | 1个引用 + 1个隐喻 | 3-4个引用 + 2-3个隐喻 + 1个个人案例 |
| 金句 | 结尾1句 | 每个小节1句 + 结尾1句 |

**Step 3：纵向扩展——加"为什么"和"怎么办"**

抖音脚本因为时间限制，只能讲"是什么"。公众号可以加两层：

```
抖音版：这是什么 → 为什么重要 → 一句话怎么办
公众号：这是什么 → 为什么重要 → 深层机制 → 不处理的后果 → 具体方法(3步) → 今天就能做的事
```

### 2.3 扩展对照表

以 Day7 "为什么你学了很多却越来越焦虑" → "认知负债陷阱"为例：

| 维度 | 抖音 Day7（~450字） | 公众号文章（~2200字） |
|------|-------------------|--------------------|
| 论点 | 1句话定义认知负债 | 5节：定义→机制→三笔利息→翻盘方法→三件小事 |
| 引用 | 查理·芒格 + Dan Koe | 查理·芒格 + James Clear + 认知觉醒 + Dan Koe |
| 隐喻 | 水库 | 水库 + 后台程序 + 健身卡 + 遮羞布 |
| 个人经历 | 无（时间不够） | 全文第一段"去年有段时间…" |
| 动作指令 | 1句"挑一个最小的做一次" | 3件具体可做的事 + 每件怎么做 |

## 第三章：选题双向复用——从同一选题池同时产出两种形式

### 3.1 选题池的双平台标注

你的 30 天选题池已经有"双平台协同"设计。当前池中每条选题天然可做两版：

| Day | 选题 | 抖音 Hook | 公众号扩展方向 |
|-----|------|----------|-------------|
| 1 | 22岁亏了5300 | H7 故事开场 | "亏损如何变成资产——一个22岁大学生的风控系统" |
| 2 | 你买的东西在养你还是在吃你 | H3 认知冲突 | "重新定义资产与负债——从衣柜到时间账户" |
| 3 | 一个人就是一家公司 | H8 警告型 | "一人企业实操手册：从0到第一个产品" |
| 7 | 为什么学了很多越来越焦虑 | H3 认知冲突 | "认知负债陷阱"（已完成） |
| 8 | 从游戏宅到每天写300字 | H7 故事开场 | "环境设计：不靠意志力靠系统" |

### 3.2 选题池的双向流动

```
选题池（30条）
    │
    ├──→ 抖音优先（Day1-10）：先发抖音测数据，数据好的→公众号
    │    理由：抖音反馈快，24h就能判断选题是否成立
    │
    └──→ 公众号优先（Day11-20）：先写公众号深度稿，再拆成3条抖音
         理由：深度选题需要完整论证，公众号写完再拆效率更高
```

### 3.3 判断规则：先做抖音还是先做公众号？

| 选题特征 | 先做 | 理由 |
|---------|------|------|
| 反常识/冲击力强 | 抖音 | 这类观点在抖音传播效率更高 |
| 需要层层论证 | 公众号 | 先写清楚逻辑，再提取最锐利的点做抖音 |
| 有个人故事 | 抖音 | 故事类在抖音更打动人 |
| 方法论/操作指南 | 公众号 | 公众号可以放步骤、表格、清单 |
| 不确定能不能火 | 抖音 | 低成本测试，火了再扩 |

## 第四章：时间效率优化——怎么写一次产出两平台内容

### 4.1 理想工作流（推荐）

**周日：公众号日 → 同时产出下周 3 条抖音**

```
周日 09:00-11:00  写公众号长文（2000-2500字）
周日 11:00-11:30  质检 + 配图 + 排版
周日 14:00-15:00  从长文中拆出 3 条抖音脚本骨架
周日 15:00-16:00  扩写每条的 Hook + 口语化 + CTA
周日 16:00-17:00  3 条脚本各念一遍质检
周日 21:00        发布公众号
周一/三/五        各渲染 1 条抖音发布
```

**总耗时**：约 5 小时产出 1 篇公众号 + 3 条抖音（对比各做各的约 8 小时）

### 4.2 备选工作流（时间紧张时）

如果你只有 2 小时：

```
1. 选一个深度卡话题（5min）
2. 对着手机录音，讲 3 分钟（15min）
3. 把录音转文字，这就是公众号初稿（0min，工具自动）
4. 修整公众号（30min）
5. 从公众号里挑 3 个最锐利的段落 → 这就是 3 条抖音脚本（30min）
6. 微调每条脚本的 Hook 和口语（30min）
7. 发布（10min）
```

关键是**先产出长版（公众号），再切割短版（抖音）**。反过来做效率低——因为短版拼接成长版需要大量"补肉"，而长版切割短版只需要"剔骨"。

### 4.3 效率损耗对照

| 做法 | 每周耗时 | 效率比 |
|------|---------|--------|
| 各写各的（3条抖音 + 1篇公众号独立创作） | ~8h | 基准 |
| 先公众号→拆抖音 | ~5h | 1.6x |
| 语音初稿→修公众号→拆抖音 | ~3h | 2.7x |
| 裸写（不检索素材库，从零创作） | ~12h | 0.67x（越写越慢） |

## 第五章：完整示例——"认知负债陷阱"拆解全流程

### 5.1 原文结构分析

公众号文章"认知负债陷阱"共 5 节 + 开头/结尾：

```
开头（个人故事）      — 200字
一、认知负债定义       — 350字  引用：查理·芒格 + James Clear
二、大脑多巴胺机制     — 350字  引用：认知觉醒
三、三笔隐藏利息       — 400字  注意力电池 + 虚假进步感 + 认知失调
四、翻盘方法           — 350字  引用：Dan Koe 三位一体
五、三件小事            — 250字  具体动作
结尾（金句收束）       — 150字
```

### 5.2 拆解方案：1 篇长文 → 4 条抖音

#### 抖音脚本 A：认知负债的定义（拆自第一节 + 开头个人故事）

```
【Hook - H3 认知冲突】
"你有没有过这种感觉——收藏夹里存了两百篇文章，但如果有人问你'学的东西用上了吗'，你会沉默。"

【展开 - 45秒】
这个现象有一个名字，叫"认知负债"。
查理·芒格说过：未经验证的知识就是负债，不是资产。
什么意思？你知道了"复利效应"——但你从来没按复利的逻辑审视过自己的时间分配。这东西在你脑子里就只是"占地方的东西"。
更可怕的是它还在持续产生利息——"我知道但我做不到"的那种焦虑，就是利息。
去年我陷入过这种状态：每天看两小时书、刷方法论帖子，越学越焦虑。后来才发现——我根本不是在学习，我是在用"输入"替代"行动"。

【CTA】
如果你也有这种感觉——关注"董辉的认知引擎"，下一条视频我讲怎么破这个局。
```

**信息点**：定义 → 芒格引用 → 焦虑=利息 → 个人经历 → 悬念CTA
**来源段落**：开头 + 第一节

---

#### 抖音脚本 B：大脑为什么停不下来（拆自第二节）

```
【Hook - H3 认知冲突】
"你以为你在努力学习——其实你的大脑只是在刷另一种抖音。"

【展开 - 45秒】
当你学到新东西的时候，大脑会分泌多巴胺。你会产生一种"我又变聪明了"的快感。
问题是：你分不清这个奖励来自"我变强了"还是"我获得了一个新鲜刺激"。
刷即刻看到一条新方法论，和刷抖音看到一条新段子——对你大脑来说，区别没那么大。都是"新信息→多巴胺→继续刷"。
所以你明知道"我已经学够了"，手还是会点开下一篇。你上瘾的不是学到东西——是"学到新东西的那个瞬间"。
而代价是——行动被无限推迟。

【CTA】
怎么打破这个循环？关注我，下一条讲"翻盘方法"。
```

**信息点**：多巴胺机制 → 分不清进步和新鲜感 → 上瘾的代价
**来源段落**：第二节

---

#### 抖音脚本 C：三笔看不见的利息（拆自第三节）

```
【Hook - H8 威胁警告】
"如果你已经学了三年还没有任何成果——你可能不是不够努力，是你欠了一笔看不见的债，而且利息很高。"

【展开 - 50秒】
认知负债有三笔隐藏利息。
第一笔：占用你的注意力电池。每一个"还没验证的知识"就像一个永远在后台运行的程序——你以为你在专注做事，其实注意力已经比别人薄了一层。
第二笔：制造虚假的进步感。你一直在学、一直记笔记——看起来很勤奋。但勤奋的对象是"输入"不是"输出"。这两件事的差距，等于零和一的差距。
第三笔最阴——积累认知失调的债务。你脑子里装的理论和你的实际能力差距越来越大。你只有两条路：承认自己不行，或者编一个故事——"我还没准备好"。大多数人选了第二条。

【CTA】
怎么翻盘？核心就四个字——"停止借新债"。关注我，下一条讲具体怎么做。
```

**信息点**：三笔利息各讲清楚 → 注意力/虚假进步/认知失调
**来源段落**：第三节

---

#### 抖音脚本 D：今天就能做的三件事（拆自第四节 + 第五节）

```
【Hook - H5 痛点共鸣】
"如果你也知道了很多但还没行动——别焦虑。不是你有问题，是你的'出水口'堵住了。三个动作，今天就能疏通。"

【展开 - 50秒】
翻盘的方法和还债一样——停止借新债，先还旧债。
Dan Koe 说过：不是准备好了再写——是写的过程中，你变成了那个准备好的人。
具体做三件事：
第一，打开收藏夹，找一个"标记了但没回看过"的东西。看完写三百字——用自己的话讲一遍。
第二，删掉三个"以后可能会看"的收藏。你现在不看，以后也不会看。
第三，把你写的三百字发出去——即刻、朋友圈、小红书，随便哪。不需要排版，发就行。
前两条是"还旧债"，第三条是"把负债变资产"。

【CTA】
关注"董辉的认知引擎"，我用南华大学学生的视角，讲最实在的认知方法论。今天就可以开始。
```

**信息点**：Dan Koe引用 → 三件事 → 还债逻辑
**来源段落**：第四节 + 第五节

### 5.3 拆解后的排期

| 日期 | 脚本 | 时长 | 与原文关系 |
|------|------|------|-----------|
| 周一 | A：认知负债定义 | 70s | 第一节 + 开头 |

### 5.4 对照检查：这条拆解是否合格？

| 检查项 | A | B | C | D |
|--------|---|---|---|---|
| 不看原文能独立看懂 | ✅ | ✅ | ✅ | ✅ |
| 前3秒有钩子 | ✅ H3 | ✅ H3 | ✅ H8 | ✅ H5 |
| ≤3个信息点 | ✅ 4个(略多) | ✅ 3个 | ✅ 3个 | ✅ 3个 |
| 有"我"的经历 | ✅ | ❌ | ❌ | ❌ |
| 结尾有CTA | ✅ | ✅ | ✅ | ✅ |
| 串联设计 | 悬念→B | A续集 | B续集 | 系列收尾 |

> ⚠️ B、C、D 缺少个人经历——这是拆解时容易掉的坑。解决方案：在脚本 B 的"多巴胺"部分加一句"我自己就是这样——收藏夹 200 篇，真正用过的不到 5 篇"；脚本 C 加"这三笔利息，每一笔我都交过"；脚本 D 本来就是行动指南，可以不加。

## 附录 A：常见拆解错误 & 修复

| 错误 | 表现 | 修复 |
|------|------|------|
| 直接复制粘贴 | 抖音脚本读起来像念课文 | 大声念一遍→凡拗口处改口语 |
| 信息过载 | 一条抖音塞了5个观点 | 砍到≤3个，多余观点放到下一条 |
| 忘记CTA | 结尾戛然而止 | 每条结尾加一句"关注/下一条/私信" |
| 缺少个人经历 | 纯讲道理没温度 | 每个系列至少1条有"我"的故事 |
| 串联断裂 | 4条脚本之间没有关联 | 设计CTA指向：1→2→3→公众号→4 |
| 公众号扩展太空 | 只是把抖音脚本拉长了3倍 | 必须加"新层"——新引用/新案例/新角度 |
| 不查素材库 | 扩展时自己编案例 | 先检索`structured-content/02-内容单元库/` |

## 附录 B：HyperFrames 批量生产命令

```powershell
# === 一次性创建本周 3 条抖音的项目骨架 ===

# 假设你已经拆好了 3 条脚本，放在 scripts/ 下
$scripts = @("day1-renzhifuzhai", "day2-duobaan", "day3-sanbiliuxi")
foreach ($s in $scripts) {
    npx hyperframes init "videos/douyin/$s" --non-interactive --example=blank
}

# === 渲染本周全部视频 ===
foreach ($s in $scripts) {
    Write-Host "渲染: $s"
    npx hyperframes render --skill=faceless-explainer --quality high --output "renders/${s}.mp4" -- --width=1080 --height=1920
}

# === 批量质检 ===
foreach ($s in $scripts) {
    Write-Host "质检: $s"
    npx hyperframes lint && npx hyperframes validate
}
```
