# 董辉自媒体图片生成集成指南

> 三条路线生成公众号配图和抖音封面，选最快的那条

---

## 路线 A：AI 生成底图 + Canva 加文字（推荐，15 分钟）

### 工具
- 即梦/豆包/可灵（国产 AI 绘图，免费额度）
- Canva（免费模板）

### 流程
1. 从 `配图提示词_完整合集_v2.md` 找到对应文章的 prompt
2. 粘贴到即梦 → 生成 4 张底图 → 选最好的
3. 导入 Canva 模板 → 加文字 → 导出 PNG
4. 时间：15 分钟/张

### 已准备的 prompt
- `配图提示词_完整合集_v2.md`：12 篇文章 × 3 张 = 36 条英文 prompt
- `抖音封面设计系统_v1.md`：8 种 Hook × 1 张 = 8 条封面 prompt
- 全部可直接粘贴到即梦/豆包

---

## 路线 B：纯 Canva 模板（10 分钟，不需要 AI）

### 适用场景
- 预算为零
- AI 绘图工具不可用
- 需要极快出图

### 模板
- Canva 搜索"极简知识科普"模板
- 替换配色为：深蓝(#1A3A5C) + 暖灰(#E8E0D9) + 金色(#D4A843)
- 替换文字为你的标题

---

## 路线 C：使用 imagegen 技能（需 API）

### 前置条件
- OPENAI_API_KEY 已配置
- 安装 Python 依赖

### 单张生成
```powershell
cd C:\Users\董辉\.codex\skills\.system\imagegen
python scripts/image_gen.py generate --prompt "Minimalist flat illustration..." --output output.png
```

### 批量生成
```powershell
python scripts/image_gen.py generate-batch --prompts-file prompts.txt --output-dir output/
```
