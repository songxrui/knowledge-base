## Part 3：发布节奏策略

### 阶段一：前 7 天 —— 密集发布建立账号权重

**目标**：让算法识别账号为「活跃知识创作者」

| 要素 | 策略 |
|------|------|
| 频率 | 每天 1 条，连续 7 天不间断 |
| 时间 | 固定 21:00 发布（培养观众预期） |
| 内容 | 按选题池顺序，不跳号 |
| 互动 | 每条发布后回复评论，主动去同赛道视频下留言 |
| 数据 | 每条 24h 内记录 CSV，不跳过 |

**为什么前 7 天要密集发？**
1. 新账号冷启动：算法需要足够数据点判断账号标签
2. 内容资产积累：7 条 = 7 个 24h 不睡觉的「销售员」
3. 建立创作惯性：每天发->写->发的肌肉记忆
4. 信号强度：连续发布 > 断断续续，算法对活跃账号更友好

### 阶段二：第 8-28 天 —— 稳定节奏 + 观察数据

**目标**：找到可复制的爆款方向，培养第一批忠实观众

| 要素 | 策略 |
|------|------|
| 频率 | 每周 3 条抖音（一/三/五）+ 每周 1 篇公众号（周日） |
| 时间 | 抖音 21:00，公众号 08:00（早间阅读场景） |
| 内容 | 抖音按选题池顺序；公众号从公众号选题池选取 |
| 复盘 | 每周四为固定「数据复盘日」，分析上周数据趋势 |
| 调整 | 完播率 > 40% 的选题 -> 3 天内扩展公众号；完播率 < 20% 的选题 -> 标记方向调整 |

**W2-W4 关键动作**：
- W2：识别 Day1-7 中 Top3 选题方向，W3 做角度变体
- W3：如果 W2 公众号分享率 > 5% -> 立即拆成 2-3 条抖音
- W4：如果某选题双平台都好 -> 标记为「王牌选题」，第 2 个月持续挖掘

## Part 4：紧急情况处理

### 情况 1：视频 0 播放 / 极低播放（< 100）

**可能性排序**（从高到低）：
1. 账号被限流 / 内容审核未通过
2. 标题 / 标签不够精准，算法无法匹配受众
3. 视频格式问题导致推荐池降权

**处理 SOP**：
- [ ] **T+2h**：检查抖音「创作者服务中心」->「作品数据」-> 是否有「不适合继续推荐」标记
- [ ] 如果被标记 -> 检查是否涉及敏感词（投资建议、赚钱承诺等），修改标题重发
- [ ] 如果未被标记 -> 等待 24h，新账号冷启动需要时间
- [ ] **T+24h 仍 < 100 播放** -> 执行以下诊断：
  - [ ] 用 `dbs-diagnosis` 分析选题方向
  - [ ] 对比同赛道热门视频的标题结构
  - [ ] 检查视频前 3 秒是否足够抓人
  - [ ] 考虑更换发布时间（尝试 07:30 早间档）
- [ ] 如果连续 3 条都低 -> 暂停发新，用现有脚本重新做 HyperFrames 模板调整（换配色/换 Frame Preset）后重发
- [ ] **禁止**：删除视频重发（会被算法标记为异常行为）

### 情况 2：负面评论处理

**分类处置**：

| 评论类型 | 识别特征 | 处理方式 |
|---------|---------|---------|
| 建设性批评 | 提出具体问题或不同观点 | ✅ 认真回复，感谢指正，展开讨论 |
| 情绪化攻击 | 人身攻击、无理由谩骂 | 🚫 不回复、不删评、不置顶。冷处理 |
| 广告/引流 | 带链接、二维码、微信号 | 🗑️ 删除 + 拉黑 |
| 质疑真实性 | "22 岁懂什么""又在编故事" | ✅ 用具体细节回应（如"我确实亏了 5300，交易记录还在"），不争吵 |
| 恶意举报威胁 | 声称要举报 | 🚫 不回复。截图保存证据，如举报属实先自查内容 |

**核心原则**：
- 永远不在评论区吵架——吵架 = 给对方热度
- 有价值的质疑是内容灵感来源
- 如果负面评论集中在一个话题 -> 考虑做一期视频正面回应

### 情况 3：内容被抄袭

**发现渠道**：定期用标题关键词搜索，或粉丝私信告知

**处理 SOP**：
- [ ] **确认抄袭程度**：
  - 轻度（借鉴选题角度，内容不同）-> 不处理，属于行业正常现象
  - 中度（脚本结构相似，文案部分雷同）-> 在对方评论区留言"参考了可以标注来源"
  - 重度（逐字搬运 + 不标注来源）-> 截图取证 -> 抖音举报（侵权投诉入口 -> 作品侵权）
- [ ] **反向利用**：
  - 被抄袭 = 内容有传播价值。借势发一条"被抄了说明我方向对了"的回应视频
  - 在公众号做一次"被抄袭的 3 条经验"复盘文章
- [ ] **预防**：
  - 视频加水印（HyperFrames 可配置水印叠加）
  - 公众号声明原创标识
  - 定期在评论区置顶"原创内容，搬运请注明来源"

### 情况 4：HyperFrames 渲染失败

**处理 SOP**：
- [ ] 检查 `audio_request.json` 格式是否正确
- [ ] 检查脚本文件路径：`capture/extracted/visible-text.txt` 是否存在
- [ ] 重新运行 `npx hyperframes doctor --json` 诊断环境
- [ ] 降低渲染质量重试：`--quality draft`
