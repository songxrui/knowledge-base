## 一级对标：dontbesilent（直接对标）

### 基本信息
| 维度 | 数据 |
|------|------|
| 定位 | 商业思维 + 自媒体创业 |
| 粉丝量 | 70 万+（抖音） |
| 产品 | 199 元社群 + 万元级线下课 |
| 核心方法论 | "搞清楚 + 讲清楚"、债权理论、认知攻击理论 |
| 风格 | 犀利攻击型、反常识断言、文字洁癖 |
| 更新频率 | 日更 |

### 五重过滤结果
| 筛子 | 结果 | 说明 |
|------|------|------|
| 1. 赚钱吗？ | ✅ | 年入百万级，利润够高 |
| 2. 能看懂吗？ | ✅ | 商业模式清晰：免费内容 → 社群 → 线下课 |
| 3. 能模仿吗？ | ✅ | 不需要独家资源，内容 + 产品即可 |
| 4. 排除自我 | ✅ | 每一步都能做 |
| 5. 不讨论本质 | ✅ | 直接执行 |

### 我们可以学的
1. **内容策略**：先建立知识博主身份，再自然产品化
2. **Hook 系统**：反常识断言是最高频有效的 Hook 类型
3. **变现节奏**：暗线期（不提产品）→ 显性化（自然提及）→ 产品化（正式上线）
4. **语言风格**：犀利但不刻薄，攻击观点不攻击人
5. **产品设计**：199 低价社群建立信任 → 万元高价课兑现价值

### 我们的差异化
| dontbesilent | 董辉 |
|-------------|------|
| 30+ 岁，多年创业经验 | 22 岁，大学生视角 |
| "我已经年入百万了" | "我正在从零开始" |
| 资深商业 IP | 成长型知识博主 |
| 攻击行业共识 | 记录成长过程 + 方法论分享 |
| 成熟方法论 | "边学边教"的真诚 |

**核心差异化**：董辉不是 dontbesilent 的复制品——他是"一个普通大学生如何用这套方法论从零做起"的活案例。
