# 董辉自媒体能力进化路线图

> 从 0 基础到对标 dontbesilent 的技能树与学习路径
> 适用：22 岁大学生，0 自媒体经验，目标成为知识付费博主

---

## 能力模型：五个核心维度

## 维度一：表达能力（内容创作）

### Level 0：现在的你
- [ ] 能写 300 字以上的连贯文字
- [ ] 说话别人能听懂
- [ ] 能识别好坏内容的区别

### Level 1：基础期（月 1，目标：发布 15 条）
- [ ] 能写 300-500 字的口播脚本（≤30 分钟/条）
- [ ] 能识别 8 种 Hook 类型并套用
- [ ] 大声念自己的文字不尴尬
- [ ] 能用一句话说清楚一个观点

**练习**：每天写 1 条口播脚本，大声念 3 遍，发出去。不判断好坏。

### Level 2：成长期（月 2，目标：找到手感）
- [ ] 能从数据中判断哪种 Hook 适合自己
- [ ] 能写 1500-3000 字的深度文章
- [ ] 能自然地融入个人故事
- [ ] 开头 3 秒能让陌生人停下来

**练习**：复盘月 1 的 Top5 内容，分析"为什么这条有人看"。

### Level 3：成熟期（月 3-6，目标：形成风格）
- [ ] 有自己的语言风格（不是模仿 dontbesilent，是吸收后变成自己的）
- [ ] 能用大白话讲清楚复杂概念（你妈能听懂）
- [ ] 能写出让人想转发的内容
- [ ] 能预判"这句话能不能火"

**练习**：对比自己第 1 条和第 90 条，记录变化。

### Level 4：专家期（6-12 月，目标：被认可）
- [ ] 有人主动引用你的观点
- [ ] 有人因为你的内容来付费
- [ ] 能用一个概念命名一个现象（如 dontbesilent 的"债权理论"）
- [ ] 内容不需要技巧叠加，平铺直叙就有吸引力

## 维度二：商业思维

### Level 0：现在的你
- [ ] 亏过 5300 块（这是资产！）
- [ ] 理解"卖东西才能赚钱"这个基本道理

### Level 1：基础认知（月 1）
- [ ] 理解"内容为产品服务"（不是为流量服务）
- [ ] 理解"垃圾流量没有价值"
- [ ] 理解"涨粉不等于赚钱"

**学习材料**：dontbesilent "为什么账号光涨粉不赚钱"系列

### Level 2：变现意识（月 2）
- [ ] 能识别"有人想付费"的信号（后台私信、评论）
- [ ] 理解三层变现漏斗（免费内容 → 社群 → 高价产品）
- [ ] 理解"定价即产品"

**练习**：记录每次后台私信的内容，分类"只是想聊天""想跟我学""想买产品"

### Level 3：产品思维（月 3-6）
- [ ] 能设计一个最小可卖的社群产品
- [ ] 理解"引流款和利润款价差 10 倍"
- [ ] 能从用户反馈中迭代产品

### Level 4：商业系统（6-12 月）
- [ ] 有多条收入来源（社群 + 课程 + 咨询 + 其他）
- [ ] 理解"从 0 到 1"和"从 1 到 100"是两套不同规则
- [ ] 能做出"高利润"的商业决策（不是高粉丝量）

## 维度三：执行系统

### Level 0：现在的你
- [ ] 诚实：你正在用哪种方式逃避？（A-H 任选其一）
- [ ] 第 90 篇 > 第 3 篇（记住这句话）

### Level 1：启动期（月 1）
- [ ] 能每天产出 1 条内容（不管质量）
- [ ] 不纠结"这条够不够好"
- [ ] "遇事不决，先发 100 条"成为肌肉记忆

**反逃避检查**：每周日晚上自检——这一周有没有用"准备""调研""学习"替代"发布"？

### Level 2：节奏期（月 2-3）
- [ ] 能找到自己的创作节奏（不是"坚持"，是"习惯"）
- [ ] 不为"没灵感"焦虑（有选题池在）
- [ ] 发布前不恐惧，发布后不内耗

### Level 3：系统期（月 4-6）
- [ ] 内容生产已经完全流程化（不动脑子也能产出）
- [ ] 能同时运营 2 个平台不混乱
- [ ] 能在"批量生产"和"深度打磨"间切换

## 维度四：学习能力

### Level 0：现在的你
- [ ] 有 35 张深度卡（资产！）
- [ ] 有答案之书 v7（金句库！）
- [ ] 理解"搞清楚 + 说清楚"是核心工作

### Level 1：输入系统（持续）
- [ ] 每周至少精读 2 篇 dontbesilent 的文章（不是扫读，是拆解结构）
- [ ] 每条学到的内容都能用自己的话复述
- [ ] 建立"概念 → 大白话"翻译表

**练习**：每次读 dontbesilent 的文章，回答三个问题：
1. 他的核心观点能用一句话说清楚吗？
2. 他用了什么 Hook？为什么有效？
3. 如果让我写同一个观点，我会怎么写？差距在哪？

### Level 2：输出系统（月 2+）
- [ ] 能把别人的方法论转化成自己的语言
- [ ] 能从不同领域迁移概念（游戏 → 赚钱、减肥 → 系统）
- [ ] 能创造自己的原创概念

## 维度五：AI 协作能力

### Level 0：现在的你
- [ ] 用过 ChatGPT/Claude
- [ ] 理解"AI 写的东西需要人把关"

### Level 1：基础使用（月 1）
- [ ] 能用 HyperFrames 从文稿生成视频
- [ ] 能用 AI 生成公众号配图
- [ ] 理解"AI 不能替代判断"

### Level 2：深度协作（月 2+）
- [ ] 能训练 AI 按自己的风格写作（不是让 AI 自己写，是你告诉 AI 怎么写）
- [ ] 能用 AI 做内容分析（不是"AI 帮我分析爆款"，是"AI 帮我结构化我的内容"）
- [ ] 能用多个 Agent 并行处理任务

## 第一阶段终点（90 天后）

你不再是"想做自媒体的大学生"，你是：
- 一个能稳定产出内容的人（≥60 条抖音 + ≥20 篇公众号）
- 一个有人愿意付费的人（≥10 个付费社群成员）
- 一个知道自己能力边界的人（知道什么能做、什么要学）
- 一个已经起跑的人（第 90 篇回头看第 1 篇时，发现自己完全不同了）
