## 流程图 1：每日发布全流程

```mermaid
flowchart TD
    A[早上 9:00] --> B{今天是公众号日?}
    B -->|否| C[看周计划表→确定今天写第几条]
    B -->|是| D[上午: 抖音脚本 30min]
    C --> E[写抖音脚本 300-500字 30min]
    D --> E
    E --> F[HyperFrames 生成视频 10min]
    F --> G[制作封面 2min]
    G --> H{质检通过?}
    H -->|否| I[修改→回到F]
    H -->|是| J[定时发布 19:00]
    D --> K[下午: 公众号文章 2h]
    K --> L[配图生成 15min]
    L --> M[HTML排版 10min]
    M --> N[定时发布]
    J --> O[记录到CSV]
    N --> O
    O --> P[前4周追踪器打勾]
    P --> Q[晚上: 社群互动 15min]
    Q --> R[结束]
```

## 流程图 4：内容复用闭环

```mermaid
flowchart TD
    A[公众号深度文章<br/>2000-3000字] --> B[拆解为 3-5 个独立观点]
    B --> C[每个观点配 Hook]
    C --> D[压缩为 300-500 字脚本]
    D --> E[HyperFrames 生成视频]
    E --> F[发布抖音]
    F --> G{数据反馈}
    G -->|某条爆了| H[扩展为公众号续篇]
    G -->|数据差| I[复盘→调整 Hook]
    H --> A
    I --> C
```

## 流程图 7：遇到创作瓶颈怎么办

```mermaid
flowchart TD
    A[今天不想写] --> B{连续第几天?}
    B -->|第1天| C[写 100 字就停<br/>不要求质量]
    B -->|第2天| D[从选题池复制一条<br/>改个开头就发]
    B -->|第3天| E[停止创作<br/>花1天只复盘]
    B -->|第4天+| F{什么原因?}
    C --> G[发了就算赢]
    D --> G
    E --> H[看数据→找方向→明天重启]
    F -->|没灵感| I[换内容类型<br/>做问答/拆解/复盘]
    F -->|完美主义| J[发一条最差的<br/>破除完美幻觉]
    F -->|倦怠| K[休息 2 天<br/>完全不看手机]
    F -->|怀疑自己| L[回头看 Day1<br/>对比今天的进步]
    I --> G
    J --> G
    K --> M[Day3 强制重启<br/>发最简单的一条]
    L --> G
```
