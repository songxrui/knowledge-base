## 复盘数据收集清单

每月最后一周，确保收集以下数据：

### 定量数据
- [ ] 群成员数变化（新增/退出）
- [ ] 我的发言次数和内容类型
- [ ] 群友发言次数（区分提问/讨论/闲聊）
- [ ] 深度分享阅读量（如果有统计）
- [ ] 私信反馈数量

### 定性数据
- [ ] 本月最有价值的 3 条讨论
- [ ] 本月最活跃的 3 位群友
- [ ] 本月收到的最好反馈
- [ ] 本月收到的最差反馈
- [ ] 我自己最满意的一次输出
- [ ] 我自己最不满意的一次输出

### 续费信号
- [ ] 本月有多少人主动问"怎么续费"
- [ ] 本月有多少人邀请朋友
- [ ] 本月有多少人沉默（从未发言且未私信）

---

## 复盘后的行动

| 发现 | 行动 |
|------|------|
| 某类内容讨论热烈 | 下月增加此类内容频率 |
| 某位群友持续活跃 | 私信感谢 + 邀请贡献 |
| 某位群友持续沉默 | 私信了解原因 |
| 有人问续费 | 记录，到期前 14 天提醒 |
| 收到负面反馈 | 24 小时内回复 + 考虑调整 |

## 季度深度复盘（每 3 个月）

在月度复盘基础上，增加：

### 债权审计
- 本月产出了多少"债权"（免费价值输出）
- 本月兑现了多少"债权"（收到了多少付费/续费）
- 债权产出效率：每条深度分享带来多少续费意愿

### 产品迭代
- 社群产品是否需要升级
- 定价是否需要调整
- 交付内容是否需要增减

### 我自己的状态
- 做社群这件事让我更焦虑还是更满足
- 我还能持续输出吗？需要调整节奏吗
- 如果今天重新开始，我会做什么不同的事
