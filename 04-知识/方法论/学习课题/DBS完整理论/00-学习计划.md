# DBS 完整理论与自媒体创业｜学习计划

## 学习目标

完成本课题后，应具备六项可检查能力：

1. 闭卷画出 DBS 的七层理论地图，并说明每层解决什么问题。
2. 区分 DBS 原稿主张、DBS skill 规则、本文综合模型、独立研究和待验证商业断言。
3. 用自己的语言解释问题消解、像素级对标、产品先行、内容债权、五维内容诊断、内容资产工程和决策回填。
4. 为自己设计一条有现金流边界、有真实问题、有最小交付、有内容实验的创作创业路径。
5. 独立完成一次“研究—写作—发布—交付—复盘”闭环，并留下可追溯证据。
6. 识别夸张承诺、操纵性表达、平台投机和幸存者偏差，保留 DBS 的判断力，舍弃不可持续做法。

## 学习路径

1. **证据层**：先分清作者自述、公开原稿、skill 规则、研究证据和个人实验。
2. **语言层**：学会拆概念、说清目标、形成问题说明书、检查事实前提。
3. **行动层**：识别执行模拟、知识上瘾、方向跳跃和完美主义，用现实动作产生信息。
4. **商业层**：分析商业模式、需求后果、产品边界、定价、交付与规模化条件。
5. **内容层**：完成对标、选题、观点、钩子、结构、证据、共鸣、口播和发布复盘。
6. **系统层**：建立内容单元、主题地图、AI 协作、知识库与决策回填。
7. **迁移层**：把 DBS 的方法改造成自己的创作者经营系统。

## 高效学习协议

### 每次学习固定循环

1. **预检索**：阅读前写下自己对本节的现有理解。
2. **小块输入**：一次学习一个理论簇，保持材料边界清晰。
3. **闭卷重建**：合上文档，画出概念关系并回答检索题。
4. **费曼解释**：假设面对刚毕业、零商业经验的朋友，用三分钟讲清核心机制。
5. **对照纠错**：重新打开材料，只补遗漏、误解和边界。
6. **现实生成**：当天完成一个外部产物，如问题卡、对标表、短稿、访谈提纲或产品草图。
7. **置信度校准**：为每项判断标注“已确认、工作性判断、待验证”。

|---|---|

| 第 3 天 | 交错比较对标、原创、产品先行和内容债权 |
| 第 7 天 | 完成一次费曼口述和一次模拟商业问诊 |
| 第 14 天 | 用自己的项目数据改写一项 DBS 主张 |
| 第 30 天 | 闭卷画完整地图，完成一次反方审计 |
| 第 60 天 | 只看问题清单，重建创作创业 SOP |
| 第 90 天 | 用一篇长文或一节课教会另一位新手 |
