## 版本规则

1. 日常学习和执行默认使用 v2.1。
2. 需要追溯完整内容时查归档 v2.0，不把其中未经验证的主张直接当成个人事实。
3. 新版本先进入 05-内容生产/00-缓冲区/，完成来源、真实性和版本差异审查后才能替换当前阅读版。
