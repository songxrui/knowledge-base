# 选题真实性准入表

> 选题必须先证明“问题真实、事实可用、证据够写”，再进入标题和稿件生成。好标题不能修复虚假前提。

## 准入字段

| 字段 | 必填内容 | 失败处理 |
|---|---|---|
| topic_id | 唯一且稳定的选题 ID | 没有 ID 不进入队列 |
| real_question | 一句真实问题，不是预写结论 | 改回问题 |
| question_source | 访谈、评论、本人记录或可定位材料 | 无来源则保持 candidate-needs-source |
| source_path | 原始材料路径或平台链接 | 找不到则阻断 |
| claim_inventory | 准备写入的事实、数字、因果和建议 | 未列清单不写稿 |
| evidence_needed | 每个主张所需来源 | 无法取得则删除或降级 |
| personal_fact_id | 所有第一人称事实对应确认记录 | blocked 时不得写第一人称 |
| product_dependency | 是否涉及价格、用户、收入、留存、退款 | 必须回到产品验证台账 |
| publication_condition | 什么证据齐全时允许发布 | 条件未满足则阻断 |
| status | candidate-needs-source / evidence-ready / draft-ready / published / blocked / archived | 不得跳级 |

## 六道准入门

1. 问题门：能指出是谁在什么场景遇到什么问题。
2. 来源门：问题和材料均可定位，不以旧 AI 稿的重复次数充当证据。
3. 个人事实门：年龄、学校、亏损、身体、连续发布和账号结果必须有 personal_fact_id。
4. 主张门：精确数字、医学心理、金融和平台规律逐条列来源及边界。
5. 产品门：价格、付款、用户、留存、退款和收入只读产品验证台账。
6. 发布门：完成事实检查、表达检查和平台适配，且发布队列未超过3条。

任一道失败，状态保持 blocked 或 candidate-needs-source。

## 高风险题型

- 连续天数加“发现规律”，但没有发布记录和可比数据。
- 亏损金额加“建立铁律”，但没有交易记录和本人公开许可。
- 首位付费用户加引语，但没有付款记录、授权和原始留言。
- 社群上线结果加用户、收入、留存或退款，但产品台账为空。
- 后台数据加确定性因果，但没有平台口径、样本和反例。
- 读者、朋友或成员发生明确变化，但没有授权和原始记录。

这些题型不是禁止写，而是必须先有真实记录。没有记录时只能改成中性问题。

## 改写示例

不合格题型：声称连续发布30天后已经证明粉丝增长与内容质量无关。

可进入取证：新账号的前30天应该记录哪些指标，才能避免用单条数据判断内容质量。

改写后仍不能直接发布；必须补平台口径、实际记录和适用边界。

## 发布前检查

- 问题来源可定位。
- 第一人称事实全部 confirmed 且允许公开。
- 精确数字有原始记录。
- 案例身份是作者经历、公开案例、合成案例或寓言之一。
- 产品数据来自产品验证台账。
- 标题没有提前写入尚未发生的结果。
- 失败和反例没有被删掉。
- 发布后记录 content_id、平台链接和数据行。
