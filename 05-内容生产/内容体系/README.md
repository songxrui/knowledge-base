# 内容结构化系统

把 `03-资源/` 的原始材料加工为可复用、可追溯、可重组的内容单元，再服务 `05-内容生产/` 的选题、草稿和发布。

## 目录

- `00-规则与索引/`：字段、来源、关系、去重和处理规则。
- `02-内容单元库/`：通过人工判断的正式内容单元。
- `03-处理状态/`：处理台账、索引和冲突总览；过程文件进入其 `00-缓冲区/`。
- `04-模板/`：五类内容单元与主题模板。
- `05-主题地图/`：跨单元主题组织。
- `00-缓冲区/`：选题装配稿、批量候选和未确认过程稿。
- `07-脚本与工具/`：索引、抽取、去重和校验脚本。

## 准入流程

1. 在 `03-资源/` 确认原始来源和位置。
2. 在 `03-处理状态/` 登记来源与处理状态。
3. 用模板抽取问题、概念、观点、案例或方案单元。
4. 检查重复、来源、边界和关系，再进入 `02-内容单元库/`。
5. 选题装配先进入 `00-缓冲区/`，通过人工审核后才进入正式草稿或发布流程。
