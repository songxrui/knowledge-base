# 内容体系 Agent 规则

## 目标

将原始资料转成可复用、可追溯、可重组的内容单元，不把整篇原稿或 AI 摘要直接当成知识。

## 目录规则

- 原始资料只读于 `03-资源/`，本工程不复制第二份原始库。
- 正式单元放 `02-内容单元库/`，每个文件只表达一个主要对象。
- 处理台账放 `03-处理状态/`，日志、候选和样本计划放 `03-处理状态/00-缓冲区/`。
- 选题装配、批量生成和未确认输出放 `00-缓冲区/`。
- 规则和模板只能放在 `00-规则与索引/`、`04-模板/`。
- 工具脚本放 `07-脚本与工具/`，不得把脚本输出默认为正式知识。

## 单元准入

正式单元必须具备：来源定位、单一主张、适用边界、人工判断和必要关系。无法满足时，保留在缓冲区或归档，不进入主库。

## 禁止事项

- 不修改 `03-资源/` 中的原始资料。
- 不批量生成无来源、无人工审核的单元。
- 不把装配稿、审计日志、候选清单混入正式单元库。
- 不在 `03-处理状态/` 重建已删除的空表；需要新流程时先说明用途。
