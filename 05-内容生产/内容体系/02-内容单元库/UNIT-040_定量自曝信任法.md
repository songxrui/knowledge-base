# 定量自曝的信任建立法

dontbesilent 最被低估的信任建立技术：精确到个位数地披露个人数据。
- "4月11号，亮马桥Bacon Spice，越南粉"
- "8729条推文，全原创的1228条"
- "每天3次，两月迭代180次"

精确的数字创造"这人是真的在做事"的信号。模糊的数字创造"这人在编"的信号。

对新手：用精确数字替代模糊描述。"我做了很多内容" → "我连续发了15天视频"。"有不少人问我" → "后台收到了23条私信"。精确本身就是信任。
