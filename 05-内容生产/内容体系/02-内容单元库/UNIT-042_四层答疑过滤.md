# 四层答疑过滤框架

答疑样本规模、解答比例和消解比例均待本人补入原始日志；没有日志前，不写任何经营结果数字。

- **分类比例示例**：第1层（10%）：纯信息获取 → AI或经验脱口解决
- 第2层（15%）：情绪宣泄 → 不展开，不是商业问题
- 第3层（75%）：伪问题 → 25%语言陷阱+25%错误假设 → 要求定义或拆假设
- 第4层（0.9%）：真问题 → 真正需要回答（比例待运行日志校准）

关键洞察：大多数"问题"不需要答案，需要的是被识别为"伪问题"。
