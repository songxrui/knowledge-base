# 8020法则——找到20%的动作撬动80%的结果（比例为解释示例，不是普适结果）

帕累托法则常被用作优化启发式；以下 80/20 应用均为分类示例，需要用实际数据验证，不应写成必然结果。

8020 的进阶用法是反复缩小范围寻找杠杆；4% 和 64% 是数学推演示例，不代表任何具体任务一定达到该结果。

关键警告：8020 法则不适用于需要深度积累的领域。20% 的练习时间和顶级钢琴家是反例示例；先建立完整基础能力，再用 8020 优化。
