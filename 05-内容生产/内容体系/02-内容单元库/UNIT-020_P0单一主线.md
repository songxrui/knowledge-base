# P0单一主线——执行瘫痪的最优解

执行瘫痪的核心原因是"选项太多导致启动成本>意志力"。当你只有一个P0（最高优先级主线）时，不需要"选择先做什么"——启动成本为零。游戏容易沉迷就是因为"下一步"永远确定。

P0的选择方法：找到"哪个变量崩溃后会让所有其他变量都跟着崩溃"——那个才是真正的P0。对用户来说，健康=系统的地基。地基塌了，什么创作/财富/关系都是空中楼阁。

关键原则：P0 的表述应具体到可记录。睡眠、运动和饮食数字只是指标示例，80%/20% 只是排程示例；实际阈值必须来自个人记录，不能替代医学建议或被写成普适规则。
