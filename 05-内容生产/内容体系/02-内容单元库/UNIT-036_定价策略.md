# 没有正确的定价，只有合适的定价

定价不是数学题，是人群筛选器；引流款与利润款的价差、苹果价格、白嫖比例和“9.9元陷阱”都只是待来源核验的案例/假设，不是 dontbesilent 的已证实经营数据。

四层定价体系：引流价（建立信任）→ 信任价（深度体验）→ 利润价（核心收入）→ 锚定价（让利润价"可接受"）。

对新产品，价格应作为验证参数；199元/年只是待真实访谈、付款、交付成本与退款数据验证的候选方案，不是当前承诺。
