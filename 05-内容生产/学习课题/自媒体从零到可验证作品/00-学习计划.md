# 自媒体从零到可验证作品｜学习计划

## 学习目标

独立完成一轮可追溯的内容生产：找到真实问题，核对材料，形成自己的判断，做成平台内容，公开发布，记录反馈，再决定下一次改什么。

课程完成度看这些能力：

1. 能用一句话说清谁在什么场景遇到什么问题。
2. 能区分来源事实、作者方法、个人判断和待验证假设。
3. 能把问题装配成问题、概念、观点、案例和方案五类内容单元。
4. 能把同一主张改成公众号文章与抖音口播，不复制同一版文字。
5. 能完成发布记录，并用反馈定位下一处改动。
6. 能在出现重复需求后设计有限交付，同时写清边界、成本和停止条件。

粉丝、播放和收入受到平台分发、题材、时点与外部传播影响，本课程暂不把它们设为学习完成条件。

## 学习方法

每篇课程固定交付四样东西：

| 项目 | 含义 |
|---|---|
| 学习对象 | 本篇只研究一个能力 |
| 练习 | 用当前账号的真实问题练习 |
| 产物 | 留下一张卡、一份稿、一条发布记录或一次交付记录 |
| 验收 | 能指出路径、来源、结果和下一步 |

阅读文章只算开始。完成练习并留下产物，才更新进度。

## 学习路径

后续主题会根据反馈调整，当前梯度如下：

| 序号 | 主题 | 练习产物 | 验收条件 |
|---:|---|---|---|
| 01 | 自媒体应该学什么 | 能力地图与第一次执行单 | 明确当前只推进哪件作品 |
| 02 | 拆解 DBS 候选写作指纹与知识底座 | 论证骨架卡与 90 秒录音 | 能区分结构、表面节奏、证据和不可推断项 |
| 03 | 找到值得持续研究的真实问题 | 问题卡与问题来源 | 能定位具体人、场景、后果和材料 |
| 04 | 从搜索走到研究 | 最小证据卡 | 事实、推断、反例和边界分开 |
| 05 | 形成自己的内容单元 | QST / CON / OPI / CAS / SOL 装配稿 | 五类单元服务同一个问题 |
| 06 | 写成公众号与抖音两种版本 | 一篇文章与一份口播 | 核心判断一致，平台表达不同 |
| 07 | 标题、开头与朗读修改 | 标题候选、开头与朗读记录 | 承诺由正文兑现，口播能顺畅念出 |
| 08 | 发布、反馈与单变量复盘 | 发布链接与复盘记录 | 区分点击、理解、信任和行动反馈 |
| 09 | 从重复问题到有限交付 | 产品假设与交付边界 | 有问题证据、成本记录和停止条件 |
| 10 | 把有效经验沉淀为系统 | 内容单元与规则 | 只沉淀有来源或多次实践支持的部分 |
