# VOICE PROFILE

**Author:** dontbesilent（DBS）

**Goal:** 复用 DBS 抖音转写语料中可观察的论证结构，帮助作者把自己的真实问题、证据和判断组织成口播或文章。只迁移结构，不复制他人的经历、数字、措辞和攻击性。

**Confidence:**

- 结构置信度：高。严格主语料为 200 篇，问题、对比、因果和条件结构跨时期稳定出现。
- 表面节奏置信度：低。材料来自 ASR，字幕分行不能代表自然句长或人工段落。
- 独特性置信度：未建立。缺少同平台、同题材、同时期的对照作者。
- 渠道置信度：仅支持抖音转写语料。公众号及其他平台规则属于编辑适配。

完整证据见[候选写作指纹与知识底座报告](./DBS抖音转写原稿候选写作指纹与知识底座-证据报告.md)。

## Source Set

- 210 篇日期原稿，时间范围为 2024-12-14 至 2026-06-27。
- 202 篇含“完整转写文本”；排除 2 篇外部作者后，严格主语料为 200 篇。
- 只分析“完整转写文本”，排除 H1、简介、标签、元信息和重复的时间戳转写。
- 代表锚点覆盖早、中、后期，并包含商业算账、内容方法、心理、AI 时事、采访和短动员等题材。

## Rhythm

- 节奏来自“问题 → 回答 → 转折 → 原因 → 例子 → 后果”的交替。
- 高频使用“所以、但是、那、就是、然后、比如、那么”作为推理路标。
- 允许口语重复和自我修正，但每一段应继续推进判断。
- 不把 ASR 的 9 字中位行长当成写作指标，不照抄字幕分行。

## Compression

- 开头尽快建立冲突，通常不长时间铺垫背景。
- 中段解释密度较高，愿意连续追问前提、变量和后果。
- 复杂主题会用二分、三分、编号或算账降低理解成本。
- 压缩对象是无关背景，不能压掉来源、机制、条件和反例。

## Capitalization

- 中文常规书写；AI、Agent、OpenAI 等专名按惯例保留大小写。
- 阿拉伯数字常用于结果、成本、时间、流量和分类，但必须有来源与口径。
- 不复制转写中的错别字、专名误识别和数字误识别。

## Parentheticals

- 口播转写中括号不是稳定手段。
- 文章适配时，括号只用于来源身份、条件限定或必要补充。
- 不用括号堆旁白、吐槽或假装随意。

## Question Use

- 高频。严格主语料中 95.0% 出现问题、设问或反问信号。
- 问题用于推进推理、模拟异议、检验定义或把抽象判断带回现实。
- 问句可以由背景后置入；首行直接提问只占 13.5%。
- 不连续堆没有回答的诱饵问题。

## Claim Style

- 先明确目标，再判断什么内容有用。
- 经常重写表面问题，寻找可回答的真问题。
- 用概念定义、隐含前提、对比模型和条件链把结论推出来。
- 判断可以尖锐；强度必须由机制、案例和边界承担。
- 数字、粉丝、收入、播放和案例效果若来自 DBS，只标为作者自述。

## Preferred Moves

- 从个人进展、现实冲突、数字异常、问题或事件中选择一个入口。
- 把关键概念拆成可观察的条件。
- 明说旧观点依赖哪些隐含前提。
- 给出一句有方向的判断，并写明成立条件。
- 用正例解释机制，用反例检查边界。
- 用“因为/所以”和“如果/那么”展开因果与条件。
- 把观众可能的反驳写进正文，再直接回应。
- 结尾回收判断、给行动标准或留下真实问题。
- 先按自然口语讲，再为书面平台补段落、来源和限定。

## Banned Moves

- 不复用 DBS 的第一人称成绩、客户案例或未核验精确数字。
- 不把攻击性、粗口和针对人的贬损当成“尖锐”。
- 不照搬“不是 X 而是 Y”等高辨识句式形成仿写痕迹。
- 不把 ASR 短行、无标点和错词当成作者风格。
- 不把平台经验写成跨平台、跨题材的万能规律。
- 不用虚构故事、虚构用户、虚构后台数据补充证据。
- 不用一串反问代替解释，不用抽象名词代替机制。
- 不在真实需求、报价和交付记录出现前，把 199 社群写成成熟产品。

## CTA Rules

- 明确硬 CTA 只出现在严格主语料的 4.5%，默认保持克制。
- 一篇内容只保留一个主要行动：回答问题、尝试一步、保存方法或查看可兑现的下一项材料。
- CTA 必须承接正文，不能突然转向私信、报名或付费。
- 当前账号起步阶段优先收集真实问题和理解反馈。

## Channel Notes

- **X:** 无直接可信语料。可以迁移“单一判断 + 因果链 + 边界”，不能声称复刻 DBS 的 X 文风。
- **LinkedIn:** 无直接可信语料。若使用，补充背景和职业语境，降低攻击性。
- **Email:** 无直接可信语料。保留目标、问题和行动，避免把短视频冲突强度原样搬入私域沟通。
- **抖音:** 证据最强。保留一个冲突、一条主要因果链、一个代表案例和自然朗读节奏。
- **公众号:** 属于编辑适配。补足定义、来源、反例、适用边界和小标题，不能照抄 ASR 分行。

## Operational Input

使用本画像前，必须由作者提供或确认以下内容：

```text
目标读者：
真实问题及来源：
本篇目的：
我的暂定判断：
可使用的事实和原始来源：
作者自述或待核实项：
反例：
不能使用的经历、数字和承诺：
发布平台：
希望读者完成的一个行动：
```

字段缺失时先补输入。禁止用模仿口吻掩盖知识和证据缺口。
