## §2 选题生成器

### 2.1 运转原理

```
输入层                    处理层                      输出层
┌──────────┐     ┌──────────────────────┐      ┌──────────────┐
│ 深度卡    │ ──→ │                      │ ──→  │ 选题标题      │
│ 内容单元  │ ──→ │  DBS 六步选题法       │ ──→  │ Hook 类型     │
│ 个人经历  │ ──→ │  + 资产交叉匹配       │ ──→  │ 来源卡片      │
│ 对标选题  │ ──→ │                      │ ──→  │ 核心观点      │
└──────────┘     └──────────────────────┘      └──────────────┘
```

### 2.2 DBS 六步选题法

| 步骤 | 操作 | 董辉实操示例 |
|------|------|------------|
| **Step 1** | 列出你的 3 个兴趣领域 | 赚钱 / 自媒体创业 / 认知科学 |
| **Step 2** | 每个领域列出亲身经历或持续观察的问题 | 只从确认表读取；当前可先写“输入很多但无法用于任务”等中性问题 |
| **Step 3** | 每个问题用"为什么 X 其实是 Y"改写 | "为什么你学了很多却越来越焦虑？"→ 输入不输出 = 认知负债 |
| **Step 4** | 决定是否需要个人故事 | 有允许公开的 `personal_fact_id` 才加入；否则跳过 |
| **Step 5** | 筛选：有数据、来源或记录支撑？ | 核对原始记录、后台导出或研究定位，不依据旧稿重复次数 |
| **Step 6** | 排序：理解深度 × 受众关心程度 | 经验最痛 + 受众最想知道 = 排最前 |

│  核心原则：≤3 个核心信息点 | 口语化到极致     │
└────────────────────────────────────────────┘

【基本信息】
选题标题：____________________
Hook 类型：H___ _______________
来源卡片：____________________
核心观点（一句话）：____________________

【Hook · 0:00-0:05 | 约 30 字】
→ 在前 3 秒建立冲突/好奇/认知落差
→ 使用 §5 Hook 调色板选择具体写法
开头文字：

【正文 · 0:05-0:50 | 约 250-350 字】

第 1 层：问题/现象描述（约 80 字）
→ 让观众觉得"这说的就是我"

【收尾 · 0:50-0:60 | 约 30-50 字】
→ 金句总结 + 引导关注
→ 使用答案之书金句或自创金句
收尾文字：

【HyperFrames 标注】
模板选择：□A 白板型 □B 故事型 □C 数据型
关键帧提示：___秒处需要___动效
```

### 3.2 填写指南

| 步骤 | 操作 | 自检 |
|------|------|------|
| 1. 填基本信息 | 从选题池复制对应字段 | 核心观点能用一句话说清吗？ |
| 2. 写 Hook | 从 §5 Hook 调色板选一个类型，填入个人元素 | 前 3 秒能让人停下滑动吗？ |
| 3. 写正文第 1 层 | 用你自己的经历描述问题，不要抽象 | 你妈能听懂你在说什么吗？ |
| 4. 写正文第 2 层 | 给出反常识洞察，配具体数字 | 有 ≥1 个数字/案例吗？ |
| 5. 写正文第 3 层 | 给出一步就能做的行动建议 | 观众看完知道第一步做什么吗？ |
| 6. 写收尾 | 金句 + 自然引导关注 | 金句能让人想截图吗？ |
| 7. 大声念一遍 | 念出声音，听自然度 | 有念不出口的书面语句子吗？ |

### 3.3 完整填写示例

#### 历史示例 1：故事开场型（结构可复用，第一人称事实 blocked）

```
【基本信息】
选题标题："<已确认个人事实对应的真实问题；无记录时改用中性问题>"
Hook 类型：H7 故事开场
来源卡片：C3-5 交易目标
核心观点：亏损金额不重要——你从中提取了多少可复用模型才重要

【Hook · 0:00-0:05】
<仅当 `personal_fact_id` 已确认且允许公开时，写一条可定位的事实；否则用问题场景开场。>

【正文第 1 层：问题描述】
大部分人亏了钱之后只做一件事：想办法把钱赚回来。
正文只写有记录的过程：发生了什么、当时依据什么、哪个判断后来被证据推翻。
没有交易或账单原始记录时，不使用损失故事，直接讨论决策复盘方法。

【正文第 2 层：核心洞察】
亏损本身不是最可怕的。最可怕的是亏完之后你没有提取出一个可复用的模型。
没有模型的教训 = 白交了学费。
从记录中提取检查问题，例如：当前依据是什么？什么证据会推翻它？失败后何时停止？
不能从一个个人事件推出“两个领域底层逻辑完全一样”，也不写无来源倍数。

【正文第 3 层：行动建议】
不管你正在学什么、做什么，下次你犯了一个错——
别急着翻篇。花 10 分钟写下来：我当时怎么想的？如果再遇到，我会怎么做？
这 10 分钟可能比你接下来忙 10 天更有用。

【收尾】
一次损失不会自动变成资产；只有留下可复用记录并在下一次决策中被验证，才形成候选规则。

【HyperFrames 标注】
模板选择：■B 故事型
关键帧提示：0:03 画面切换（"天塌了"→"最值钱"的反转需要画面节奏变化）
```

#### 历史示例 2：认知冲突型（结构可复用，用户案例 blocked）

```
【基本信息】
选题标题："你买的东西在养你，还是在吃你？"
Hook 类型：H3 认知冲突
来源卡片：C3-1 资产 vs 负债
核心观点：资产 = 把钱放进口袋，负债 = 把钱拿走。衣柜里 80% 是负债

【Hook · 0:00-0:05】
你现在打开你的衣柜——里面 80% 的衣服不是你的资产。它们在吃你。

【正文第 1 层】
罗伯特·清崎有一个最简单的定义：资产是把钱放进口袋的东西，负债是把钱拿走的东西。
你用这个定义重新审视你买过的所有东西——
那件只穿了一次的卫衣，那双买了就没穿出去的球鞋，那个"买了等于学了"的课程。
它们不是资产。它们是负债。因为你买它们的那一刻，钱就走了，再也没回来过。

【正文第 2 层】
但真正的危险不是实物负债——是隐性的认知负债。
什么叫认知负债？你花钱买了一个课、收藏了一篇文章、保存了一张图——
你以为你在"投资自己"。但如果你没有把它变成一次输出、一个行动、一个决策，
那它就只是一条躺在你收藏夹里的负债。
若使用用户案例，必须有同意、购买口径和后续行动记录；没有时只提出问题：购买之后发生了什么可观察行动？

【正文第 3 层】
从今天开始，每买一个东西之前，多问自己一句话：
这个东西接下来三个月会往我口袋里放钱，还是把钱往外掏？
如果是后者——不管多便宜，都是负债。

【收尾】
资产让人越来越自由，负债让人越来越焦虑。
区别不在价格标签上——在你用脑子判断的那一刻。
这是一份可填写的个人资产负债表，不依赖作者身份背书。

【HyperFrames 标注】
模板选择：■A 白板型
关键帧提示：0:02 "资产 vs 负债" 左右分屏对比 | 0:25 "收藏夹" 画面堆积效果

#### 历史示例 3：反常识数据型（结构可复用，结果归因 blocked）

```
【基本信息】
选题标题："那个每天进步 1% 的鸡汤，骗了你多久？"
Hook 类型：H6 反常识数据
来源卡片：C3-4 复利 + C4-5 发布
核心观点：1.01^365=37 倍在现实中不成立——中断、方向错误、S 型曲线才是真相

【Hook · 0:00-0:05】
你一定听过这句话：每天进步 1%，一年后你会强大 37 倍。
我现在告诉你——这句话骗了你。而且它骗你的方式非常隐蔽。

【正文第 1 层】
1.01 的 365 次方确实等于 37。这是数学，没毛病。
但把这个公式套到人的成长上，有三个致命的漏洞——
而这三个漏洞，恰恰是你一直"努力但没结果"的真正原因。

【正文第 2 层】
第一个漏洞：方向。如果你每天进步 1%——但方向是错的呢？
你越努力，离目的地越远。
第二个漏洞：中断。你连续坚持了 200 天，然后生了一场病停了一周——
第 201 天你不是从 200 天的基础上继续，你是从第 30 天的水平重新爬。
倒退的速度永远比前进快。
第三个漏洞：非线性的进步。人在学一个新东西的时候，前 30 天可能看起来没有任何进步——
这不是复利失效了，是你还在 S 型曲线的底部。不是说"再坚持一下就会爆发"——
是"坚持到突破点才会爆发"。大多数人停在突破点之前三天。

【正文第 3 层】
忘掉那个 1.01 的公式。改用这个版本：
不管今天状态多差，至少写 100 个字。
不是"每天更好 1%"——是"最差的那天也不能断"。
这才是现实中真正有用的复利。

【收尾】
复利的敌人不是学得慢——是中断。
这只是一个待验证的编辑判断，不引用未确认连续发布经历。

【HyperFrames 标注】
模板选择：■C 数据型
关键帧提示：0:00 画面出现 1.01^365=37 数字动画 | 0:15 三个漏洞用倒计时数字标记
```

### 4.3 历史填写示例（仅展示结构，所有第一人称与结果数字 blocked）

```
【文章元信息】
选题标题："你以为自己在赚钱——其实你在给认知负债打工"
选题 ID：TOPIC-20260705-W1
所属系列：● 财富商业
目标字数：2200 字
内容单元引用（≥3 个）：
  1. 资产 vs 负债基础定义（C3-1-001）
  2. 认知负债概念（C2-2-003）
  3. 三位一体创作法（C4-1-007）
引用源（≥2 个）：
  1. 罗伯特·清崎《富爸爸穷爸爸》资产/负债定义
  2. dontbesilent "输入不输出 = 认知负债" 原话

【第一段：Hook】
收藏、购买和学习投入不等于已经获得能力。需要观察的是：材料是否改变了下一次解释、行动或交付。
这里把“没有转化为使用的输入”暂称为认知负债；它是作者概念，不是财务或心理学事实。

【第二段：问题展开】
罗伯特·清崎用一句话定义了资产和负债：资产是把钱放进口袋的东西，负债是把钱拿走的东西。
这个定义放到今天需要升级——不只是"钱"的流向，还有"注意力""认知""信任"的流向。
你买的那个只看了三节课的付费课程，你收藏的那篇永远不会再打开的文章，
你加入的那个从来不看消息的"高端社群"——它们在财务账上是"支出"，
在你的心理账上却被打上了"投资自己"的标签。这个标签就是认知负债的第一个陷阱：
它让你在亏钱的时候感觉良好。

【第三段：核心洞察】
损失或购买不会自动产生能力。只有当输入被回忆、纠错并用于真实任务时，才有证据说明它转化为可用知识。
“认知负债”可以帮助描述未使用材料带来的维护压力，但不能借这个隐喻诊断焦虑或推断购买动机。

dontbesilent 说得好："输入不转化为输出 = 认知负债。"
写作不是"准备好了再写"——写的过程中你变成那个准备好的人。
你每次把学到的东西用自己的话重说一遍、写成文章、拍成视频——
你都在把一条认知负债变成认知资产。

【第四段：证据或运行记录】
没有已确认个人实验时，使用可定位的学习研究，或明确设计一次小型运行：先闭卷回忆，再对照来源纠错，记录下一次真实使用是否改善。
输出可以暴露理解缺口，但“写过”不等于“已经掌握”，也不承诺改善焦虑。

【第五段：行动框架】
本稿给出三个候选步骤，执行效果需要记录：

第一步：删除。打开你的收藏夹，删掉所有超过 30 天没看的东西。别犹豫——
如果 30 天都没看，你永远不会看。

第二步：转化。剩下的每一条，用你自己的话写一句话总结。
不是划线，不是复制粘贴——是用你自己的话说一遍。

第三步：发布。选一条你今天学到的最有用的东西，用 300 字写出来，发在任何地方。
朋友圈、即刻、抖音——都可以。一旦你公开说清楚了，你就真的懂了。

【第六段：收尾金句】
钱可以再赚，时间不能倒流。但认知负债——你今天就可以开始还。
文末只保留与文章交付一致的行动，不使用未确认身份签名。
如果这篇对你有用，转给一个正在"努力学习但更焦虑"的朋友。

【配图需求】
封面图 prompt：一个年轻人的桌子，左边是堆积如山的书和课程截图（打上灰色滤镜），
    右边是干净的笔记本 + 一支笔（暖光）。画面风格：极简白底 + 高对比度
插图 1 prompt：信息流瀑布，一个人在瀑布下面被冲击
插图 2 prompt：资产负债表插图风格，左栏"资产"右栏"负债"
风格统一为：极简白底插画风，黑 + 红强调色
```

## §5 Hook 调色板

### 5.1 什么是 Hook 调色板

> 不是“想一个开头”，而是从候选类型中选择并测试。旧版比例没有验证；个人元素必须来自确认表。
> 像调色一样：选出类型（色相）→ 填入素材（饱和度）→ 调整节奏（明度）。

### 5.2 八种 Hook 类型全览

| 编号 | 类型 | 机制 | 适用场景 | 状态 | 使用前提 |
|------|------|------|---------|---------|---------|
| **H1** | 反常识宣言 | 用证据指出常见解释的遗漏 | 有明确反证和边界 | 候选 | 不为冲击而夸大 |
| **H2** | 制造悬念 | 先提出问题，再延迟完整答案 | 讲故事、案例拆解、数据揭示 | 候选 | 结尾必须兑现问题 |
| **H3** | 认知冲突 | 比较旧解释与新证据 | 方法论、概念重构 | 候选 | 不制造虚假对立 |
| **H4** | 身份标签 | 说明适用人群与情境 | 精准触达特定问题 | 候选 | 身份已确认且不做优越归类 |
| **H5** | 痛点共鸣 | 描述可观察的困难 | 情绪与行为问题 | 候选 | 不替读者做心理诊断 |
| **H6** | 数据开场 | 用可定位数字提出问题 | 有真实数据的分析 | 候选 | 样本、时间窗和口径完整 |
| **H7** | 故事开场 | 用已确认经历呈现决策 | 失败复盘、转折时刻 | 候选 | 有 `personal_fact_id` |
| **H8** | 风险提醒 | 说明具体下行和停止条件 | 高风险行为 | 候选 | 不放大恐惧或承诺结果 |

### 5.3 Hook 填充公式

每种 Hook 类型都遵循同一个公式：

```
Hook = 候选类型 + 已确认事实或来源 + 有边界的核心判断
```

### 5.4 个人元素接口（不得从旧稿直接填入）

| 类别 | 可用元素 |
|------|---------|
| **身份标签** | 从 `个人事实确认表.md` 读取允许公开的 `PF-IDENTITY` 条目；当前无 |
| **真实经历** | 从 `PF-FINANCE`、`PF-CONTENT` 读取；当前无 |
| **身体数据** | 从 `PF-BODY` 读取；当前无 |
| **游戏背景** | 从 `PF-GAME` 读取；当前无 |
| **社群数据** | 从 `PF-PRODUCT` 读取；当前无 |
| **创作数据** | 账号事实读确认表；库存事实读当前资产清单 |

### 5.5 八种 Hook 的历史填充稿（只复用句法，事实全部 blocked）

#### H1 反常识宣言
**模板**："[一个违反直觉的断言]。但这不是最可怕的——最可怕的是[更深层的反转]。"
**董辉填入**：
> "购买和收藏不等于已经学会；需要检查材料是否进入真实任务。"

#### H2 制造悬念
**模板**："[做了某件事]之后，我发现了一个[意外结果]——但这个结果不是我想要的。我真正发现的是[悬念]。"
**董辉填入**：
> "复盘一项有原始记录的损失后，最需要回答的不是金额，而是哪个判断在当时没有停止条件。"

#### H3 认知冲突
**模板**："大部分人以为[X]。实际上，[Y]。这两个之间的差距，就是[核心洞察]。"
**董辉填入**：
> "数学复利不能直接描述人的成长；方向、反馈、任务变化和中断都需要单独记录。"

#### H4 身份标签
**模板**："[经确认的身份或情境]正在遇到[具体问题]——接下来只分析一个可执行步骤。"
**董辉填入**：
> "如果你也卡在‘想开始但总觉得没准备好’，先看这条最小动作是否真的能在你的场景里发生。"

#### H5 痛点共鸣
**模板**："你有没有这种感受：[描述一个具体场景]？我之前也这样，直到我发现问题不在[表面原因]，而在[真正原因]。"
**董辉填入**：
> "收藏夹持续增长但没有材料进入真实任务时，问题可能不在信息数量，而在缺少使用和清理规则。"

#### H6 反常识数据
**模板**："[一个反直觉的数字/数据]。这个数据背后藏着一个所有人都忽略的事实：[核心洞察]。"
**董辉填入**：
> "后台形成一组可比样本后，再检验‘情绪表达与完播、工具价值与收藏’是否分别相关；没有数据时不写结果。"

#### H7 故事开场
**模板**："[时间]的[具体场景]，我[做了一个具体动作/发生了一件具体的事]。当时我[感受/反应]。但现在回头看，[反转洞察]。"
**董辉填入**：
> "[已确认时间和场景]发生了[有记录的事件]。当时的判断是[原始记录]；后续证据推翻了[具体假设]。"

#### H8 威胁警告
**模板**："如果你还在[做某件事]，那你可能正在[负面后果]。不是危言耸听——我[亲身经历/数据]证明了这一点。"
**董辉填入**：
> "如果购买的材料长期没有进入任何真实任务，先盘点已使用与未使用项目，再决定停止购买或安排一次应用；不要补写消费金额。"

### 5.6 Hook 选择决策树

```
你的素材里有什么？
├─ 有真实故事 + 具体细节？ → H7 故事开场
├─ 有一个反直觉的观点？ → H1 反常识宣言 或 H3 认知冲突
│   ├─ 观点很刺激 → H1
│   └─ 观点有层次 → H3
├─ 有具体数据 + 对比？ → H6 反常识数据
├─ 有一个普遍痛点？ → H5 痛点共鸣
├─ 有紧迫感/风险？ → H8 威胁警告
├─ 有悬念/未解之谜？ → H2 制造悬念
└─ 想精准触达某类人？ → H4 身份标签
```

## §6 标题生成器

### 6.1 运转原理

```
输入：核心观点（一句话）
       ↓
处理：套用 7 种标题公式，每种产生 1-2 个变体
       ↓
输出：7-14 个备选标题 → 人工选择 Top 1
```

### 6.2 七种标题公式

| 编号 | 公式名称 | 结构 | 适用平台 |
|------|---------|------|---------|
| **T1** | 反常识宣言 | "[公认观点]？——[你的反常识]" | 抖音+公众号 |
| **T2** | 数字清单 | "[数字]个[主题关键词]，第[N]个[情绪词]" | 公众号为主 |
| **T3** | 问题 → 答案 | "为什么[问题]？——[一句话答案]" | 抖音为主 |
| **T4** | 身份 + 结果 | "一个[身份]的[结果]：我[做了什么]" | 抖音为主 |
| **T5** | 对比冲突 | "你以为[X]——其实[Y]" | 通用 |
| **T6** | 故事悬念 | "[做了某事]之后，发现[意外结果]" | 通用 |
| **T7** | 金句直给 | 直接把核心金句作为标题 | 公众号为主 |

- [ ] 能被搜到吗？（含 1-2 个核心关键词）

## §7 质检工作台

### 7.1 运转流程

```
成品稿件 → 五维诊断 → 语言净化 → 格式检查 → 通过 / 退回修改
```

### 7.2 DBS 五维诊断（融入 dbs-content）

| 维度 | 诊断问题 | 通过标准 | 常见失败原因 |
|------|---------|---------|------------|
| **情绪准确度** | 情绪词是否对应真实场景？ | 不夸张、不替读者诊断 | 用情绪词填补证据空白 |
| **信息密度** | 读者能否复述核心判断及其边界？ | 一个主任务清楚 | 观点堆叠或只剩口号 |
| **人格可信度** | 是否有明确判断，个人事实是否已确认？ | 不伪个人化 | 为“人设”补写经历 |
| **结构清晰度** | 读完第一段知道这篇文章讲什么？ | 第一段即建立预期 | 开头绕了 300 字还没进入主题 |
| **行动导向** | 读者看完知道下一步做什么？ | 动作、条件和停止规则清楚 | 只有泛泛鼓励 |

### 7.3 语言净化清单

#### AI 味检测（每项强制检查）

| 检查项 | 检测方法 | 发现即修改 |
|--------|---------|----------|
| "值得注意的是"/"令人深思的是" | 全文搜索这些词 | 直接删除，不给引导语 |
| "不仅……而且……"机械重复 | 搜索"不仅" | 只在逻辑确实需要时保留 |
| "赋能""抓手""闭环""底层逻辑" | 搜索黑话词库 | 替换为日常词汇 |
| "请你记住"/"你要明白"/"真相是" | 搜索祈使句 | 替换为"我发现"/"实际上" |
| emoji 堆叠 | 人工扫读 | 按平台与品牌需要决定，不用固定阈值 |
| 段首"首先…其次…最后…" | 搜索"首先" | 用自然过渡替代 |
| "那么""因此""所以"连续使用 | 人工扫读 | 口语中直接跳转 |

#### DBS 语言哲学检查

| DBS 原则 | 检查问题 | 违规示例 |
|---------|---------|---------|
| 宁短勿长 | 有超过 40 字的句子吗？ | "在这个信息爆炸的时代，我们每个人都面临着一个前所未有的挑战……" |
| 宁具体勿抽象 | 有“很多人”“有时候”“一定程度”吗？ | 改为有来源的对象、时间和口径；不能为具体而编数字 |
| 宁口语勿书面 | 大声念，有念不出口的吗？ | "从而使得该策略得以有效实施" |
| 不解释 | 有"也就是说""换句话说"吗？ | 直接说一遍就够了，不解释第二遍 |

### 7.4 分平台终检清单

#### 抖音终检

- [ ] 时长和字数是否符合本轮平台参数？
- [ ] 开头是否尽快交代真实问题？
- [ ] 是否只承担一个主要任务？
- [ ] 数字或案例是否有来源；没有时是否直接给判断与边界？
- [ ] 结尾有金句？
- [ ] 口语化到你能在不看稿的情况下说一遍？
- [ ] 无任何 AI 味词汇？
- [ ] 标题是否完整、准确且不夸大？

#### 公众号终检

- [ ] 长度是否足以完成一个问题，不按固定字数扩写？
- [ ] 核心 claim 是否有精确来源和边界？
- [ ] 引用是否覆盖关键事实，而非只凑数量？
- [ ] 配图是否承担解释任务；不需要时不强加？
- [ ] 排版已通过 dbs-wechat-html？
- [ ] 第一段建立预期了吗？
- [ ] 结尾有行动建议吗？
- [ ] 有引导关注/社群？

### 7.5 质检通过/退回规则

| 结果 | 条件 | 后续动作 |
|------|------|---------|
| **通过** | 事实、个人材料、边界、结构和平台格式均有可核查证据 | 进入发布流程 |
| **修复后重审** | 存在非事实性表达或格式问题 | 修复后重新检查，不自动发布 |
| ❌ **退回** | 五维任一项不达标 / AI 味严重 / 结构混乱 | 退回重写对应段落 |

## 附录 D：关键原则清单

1. **先积累可比样本再下结论** — 候选样本数见 `EXP-CONTENT-001`，不声称存在通用统计门槛
2. **不跳过质量门禁** — AI 味重的内容发出去毁信任
3. **不跳过数据记录** — 没数据就没复利
4. **不裸写** — 每次写稿前先检索素材库
5. **系统服务于可检验目标** — 发布频率只从参数台账读取，粉丝目标当前未设定
6. **内容为产品服务** — 每一篇内容背后都有明确的产品指向
7. **传播与购买信号分开记录** — 私信、付费和内容正确性不能互相替代
8. **宁可用降级方案按时发布，也不因工具问题中断发布节奏**
9. **模仿颗粒度决定质量** — 对标到帧级别
10. **知道做不到 = 不知道** — dontbesilent
