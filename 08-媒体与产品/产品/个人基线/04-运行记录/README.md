# 运行记录

这里只登记真实运行，不保存示范案例、AI 生成结果或为了展示产品而补写的数据。

## 命名

`RUN-YYYYMMDD-主题.md`

例如：`RUN-20260720-晚间写作.md`。文件名只说明主题，不写“成功”“失败”或结论。

## 状态

- `planned`：合同已锁定，尚未写入任何机会观察；
- `running`：已写入第一条机会观察，包括真实发生的 `noOpportunity`；
- `completed`：到达复盘日并完成事实汇总、改判和下一决定；
- `stopped`：触发停止条件或主动终止，并记录停止原因；
- `invalid`：复盘后确认机会、合同或记录不足，无法评价假设。

状态只能按上述方向回写。模拟或监督方式只要事前声明、真实发生并留下记录，也进入本目录；必须保留 `contact_mode`，其结果不能当作直接接触证据。

## 登记表

|---|---|---|---|---|---|---|---|

在第一份真实记录出现前，表格保持为空。空表比虚构案例更准确。

## 更新产品的条件

- 单次记录可以改变个人下一步；
- 多次记录可提出产品修改候选；
- 只有重复出现、边界清楚且没有更合理竞争解释的规律，才申请更新核心模型；
- 更新核心模型前，在 `90-内部治理/01-主张与来源台账.md` 修改对应 claim 状态和证据。
