# 个人成长新增书籍信源筛选

## 筛选结论

只吸收能改变现有行动指令的增量，不因“多一本参考书”增加正文。

| 候选 | 决定 | 真正增量 | 建议落点 |
| --- | --- | --- | --- |
| 《麦肯锡笔记术》 | 吸收 | 连续失败后先定位变量、提出一个假设，再只改一个条件 | 中断路由、七日调参 |
| 《如何有效阅读一本书》 | 吸收 | 新输入先说明要解决的问题，并按目的决定阅读深度 | 学习创造卡、认知清债规则 |
| 《金字塔原理》 | 吸收 | 先给结论，再给读者此刻需要的依据 | 首屏、Codex 每日回复顺序 |
| 《早起的奇迹》 | 不进入操作规则 | 六分钟压缩和个性化已有等价规则；S.A.V.E.R.S. 会引入六项并行任务 | 仅在参考区说明排除边界 |
| 《目的与利润》 | 暂不采用 | 作者明确不提供具体步骤，主题又会把首月引向事业与创业目标 | 底盘稳定后再评估目的层，不进入 v0.2 |

## 1. 《麦肯锡笔记术》：用一个假设替代笼统加码

**原书案例与上下文（E2 author-method）**

- PDF 第 49 页：作者以“为了健康，每晚跑步一小时却难以坚持”为例。候选解释包括时间段、跑法和课程；排除课程与跑法后，把焦点收窄为“加班后疲惫”，再提出把跑步移到早晨，或通勤时提前一两站下车。案例的关键不是推荐晨跑，而是先筛选失败变量，再改变情境。
- PDF 第 84–85 页：作者把解决问题整理为“真正的问题是什么 → 假设是什么 → 验证假设 → 提出解决方案”，并用 Where / Why / How 与“空（事实）—雨（解释）—伞（行动）”区分事实、解释和行动。

**对现行手册的非重复增量（E4 editorial-mapping）**

现行手册已经规定“连续两个真实机会未开始时缩小剂量或改一个环境参数”，但没有规定如何选择参数。可补成：连续两次中断后，由 Codex 找出最早偏离发生在哪里，列出最多两个解释，只选择更贴近原话的一个作为假设；次日只改变时间、入口、环境或剂量中的一个。

**建议直接落点（E5 deployment-parameter）**

- “卡住时”表：把“连续两个真实机会都未开始”升级为“先定位最早中断点，再只验证一个原因”。
- Codex 回复：推断必须写成可推翻的单一假设，例如“推断：通知可见性可能比动作剂量更早造成中断”；次日指令只能检验这个假设。
- 不要求用户自己画三栏或写分析表，分析工作由 Codex 完成。

**边界**

这是大岛祥誉在书中给出的方法与案例，不等同于麦肯锡官方标准，也不证明这种诊断顺序对个人行为改变具有普适因果效力。

## 2. 《如何有效阅读一本书》：让每次输入先服务一个问题

**原书案例与上下文（E2 author-method）**

- PDF 第 45 页：作者用购书清单把“发现一本书就买”改成“先确认为什么读”。他区分了享受故事、了解作者、工作应用、传授他人或立即实践等目的，并指出目的不同，阅读速度和投入深度也不同。
- PDF 第 74 页：读书笔记从一句话开始，只保留“对自己真正重要”的内容，无关内容可以舍弃。
- PDF 第 85–87 页：“葱鲔火锅式”笔记交替区分原文摘抄与自己的评论；作者同时强调它耗时，实用书可以只写自己的要点，精力不足时应简化。

**对现行手册的非重复增量（E4 editorial-mapping）**

现行手册已经禁止用新书、课程和框架替代行动，但“确实暴露能力缺口后如何读”还不够具体。可补成：进入任何新来源前先确定它必须回答的一个现实问题；只读到足以回答该问题的深度，然后用一句自己的话和一个现实动作返回原任务。

其中“先明确阅读目的、按目的调整深度、从一句话开始、区分作者话与自己的话”来自原书；“一个现实问题、读够即停、返回原任务”是本手册的编辑映射与部署参数，不冒充作者原句。

**建议直接落点（E5 deployment-parameter）**

- 学习创造卡新增条件动作：“确认是能力缺口后，带一个具体问题进入来源；得到可执行答案就关闭来源，回到原任务。”
- Codex 负责把用户暴露的缺口改写为问题，并在回复中说明“这次输入结束后返回哪个动作”，用户不填写读书表。
- 参考区只保留上述方法映射，不把购书清单、完整摘抄模板或定期重读变成新习惯。

**边界**

原书是作者的个人笔记读书法，不是学习效果的比较试验。尤其不应把“做完整读书笔记”设为成长证据；对当前手册，现实应用仍优先于笔记完整度。

## 3. 《金字塔原理》：先让人看到下一步

**原书案例与上下文（E2 author-method）**

- PDF 第 17 页：作者把九项采购清单按超市区域归类，用来说明分组比无结构罗列更易理解和记忆。
- PDF 第 19 页：作者明确要求先提出总结性思想，再展开具体思想；否则读者需要自己猜测句子之间的共同关系。
- PDF 第 28 页：切斯特顿“猪应当作为宠物”的例子先给主张，再沿读者的“为什么”逐层回答，展示只在读者产生疑问时提供下一层信息。

**对现行手册的非重复增量（E4 editorial-mapping）**

它不增加个人成长动作，而是改变动作的交付顺序：用户打开手册或收到每日回复时，第一眼应先看到唯一行动与停止条件，事实、推断和方法依据随后展开。相关指令按“现在 / 卡住 / 何时升级”归组，避免用户在多个章节寻找同一答案。

**建议直接落点（E5 deployment-parameter）**

- 首屏保持“今晚、明早、卡住时”，参考文献继续留在末尾。
- Codex 每日回复的可视顺序建议改为：**明天唯一动作 → 停止或升级条件 → 可纠正事实 → 当前推断**。数据身份仍保持事实与推断分离，不因显示顺序而混淆。
- 每个动作只展开用户执行所需的一层理由；理论说明统一进入文末。

**边界**

《金字塔原理》支持的是表达与组织方法，不证明“动作置顶”会提高个人行为完成率。把它用于 Codex 回复顺序属于编辑设计假设。

## 4. 《早起的奇迹》：不把六项晨间例程带入当前系统

**核验到的原书内容（E2 author-method）**

- PDF 第 88–89 页：作者允许调整 S.A.V.E.R.S. 六项的先后，并给出每项一分钟的六分钟压缩版本。
- PDF 第 92 页：作者说明夜班等人群可以按自己的作息调整，“早起”不必发生在通常意义的早晨。
- PDF 第 96 页：作者描述自己在写书期间缩短其他例程，并随演讲、旅行等任务调整方案。

**排除理由**

这些内容能够支持“流程可压缩、时点应适配生活”，但现行手册的“第一个可控窗口、5–20 分钟、低能量缩小剂量”已经覆盖。若引入静心、自我肯定、想象、锻炼、阅读、书写六项，会直接破坏“任何时期只主动调整一个变量”，并增加认知负债。

书中“30 天习惯巩固”、早起带来广泛人生改善等属于作者主张与读者故事，不能用作本手册的固定周期或效果承诺。故本轮不新增操作指令。

## 5. 《目的与利润》：与首月部署阶段不匹配

**核验到的原书内容（E2 author-method）**

- PDF 第 5 页：作者明确说这不是通常意义的实用商业书，不打算提供具体行动步骤；他希望读者用框架形成自己的步骤，并在失效后持续迭代。
- PDF 第 25 页起：内容转向“应该成为什么样的人”、目标层级、事业、价值创造和创业视角。

**排除理由**

“建议必须随个人情境迭代”与当前反馈闭环一致，但没有新增可执行机制。事业、价值创造与创业方向还可能诱发首月启动新项目，违背“30 天只稳底盘”。可在底盘稳定、需要重建事业方向时另行研究，不进入 v0.2。

## 建议给手册的最小改动集

本轮最多加入三处，不增加新章节：

1. **失败诊断**：连续两次中断后，Codex 只提出一个可推翻的障碍假设，次日只改一个条件。
2. **输入门槛**：能力缺口出现后，带一个现实问题进入来源，得到可执行答案后立即返回原任务。
3. **显示顺序**：每日回复先给“明天唯一动作”和阈值，再显示事实与推断；理论继续集中在末尾。

除此之外，不加入六项晨间例程、购书清单、完整读书笔记模板、创业目标或新的每日记录要求。
