# Dan Koe 选题与写作系统研究

> 研究日期：2026-07-15。研究对象包括 Dan Koe 官网文章、Newsletter、官方频道、本地两本书正文及其明确列出的思想来源。官方作者内容统一记为 `E2`：它能证明作者怎样工作，不能证明方法对所有人有效。

## 核心结论

Dan Koe 的系统不是“找到一个热门垂类后持续填满内容日历”。更接近下面这条链：

`理想生活与反愿景 → 当前问题 → 项目和自我实验 → 捕捉一条有张力的想法 → 短内容测试 → 长内容建构 → 产品承接 → 反馈更新`

真正值得借鉴的是问题和项目驱动、长短内容分工、一份研究多次表达，以及内容和产品共用同一组真实问题。最需要补强的是证据：他的个人经历、收入自述、跨学科类比和强断言经常承担了超过材料本身的证明责任。

## 一、选题从哪里来

### 1. 先有方向，再有素材

在 2023 年的 [Topic Tree 文章](https://thedankoe.com/letters/dont-get-replaced-by-ai-how-to-write-authentic-content/) 中，他建议从能帮助自己抵达理想未来的 2-3 个兴趣或技能出发，先向上扩展成更大的市场，再向下拆成主题和子主题。

这一步解决的是“长期写什么”，不是“明天哪篇会爆”。主题树的判断标准是：

- 它是否来自真实兴趣、技能或经历；
- 它是否能服务正在追求的目标；
- 它能否向上连接一个足够广的公共问题；
- 它是否能向下拆成可以单独回答的问题。

### 2. 问题先于解决方案

本地《Purpose & Profit》正文把灵感来源放在正在解决的问题、个人经历、反对意见和外部观点上。相关定位：

- `03-资源/素材库/books/dankoe-mudi/source.txt:1092`：通过记录、阅读、构建和新体验采集问题。
- `03-资源/素材库/books/dankoe-mudi/source.txt:1439`：先识别问题，再谈解决方案。
- `03-资源/素材库/books/dankoe-mudi/source.txt:1451`：记录个人经历、思考过程和外部素材。

这套方法的价值是让内容拥有现实摩擦。它的限制也很明显：我的问题可能只属于我，必须再验证读者是否有同类处境。

### 3. 观点统一多个兴趣

后期文章 [You Don't Need A Niche, You Need A Point Of View](https://thedankoe.com/letters/you-dont-need-a-niche-you-need-a-point-of-view/) 进一步弱化固定 niche，强调目标、价值观和经历形成的观点镜头。

因此，多兴趣账号不是把几个主题并排摆放，而是用同一组问题反复观察不同领域。对 `个人基线`，这组统一问题是：

> 为什么一个人理解了很多，却仍没有形成稳定行动、作品和反馈？

健康、注意力、笔记、学习、写作和内容产品都可以进入，但必须回答这一个统领问题。

## 二、素材系统

Dan Koe 的素材可分为两类。

### 内部素材

- 正在追求的目标和反愿景；
- 自己遇到的问题、失败和改判；
- 项目过程、客户问题和读者反馈；
- 产品使用中出现的阻力；
- 一段经历中“之前怎样、哪里卡住、后来改了什么”。

### 外部素材

- 书、文章、视频和播客中的一条新想法；
- 能解释当前问题的模型、研究、案例或反例；
- 高表现内容的结构，而不是它的具体观点；
- 其他作者的句子、隐喻和概念，保留来源后再重述。

在 [How I Hunt For Viral Ideas](https://thedankoe.com/letters/how-i-read-books-for-maximum-intelligence-5-minute-habit/) 中，他建议遇到真正有用的想法后停下来，思考它怎样联系自己的目标、问题和经历，再用自己的角度重述。可借鉴的是“一条想法进入现实”，不能继承文中缺乏来源的脑科学解释和传播数字。

- `03-资源/创作者素材/Dan-Koe/01-官方内容索引.md`
- `03-资源/创作者素材/Dan-Koe/02-书籍与人物信源.md`
- `03-资源/创作者素材/Dan-Koe/03-方法证据卡.md`

## 三、内容功能，而不是三个垂类

Dan Koe 把一段时间内的内容功能分为增长、真实性和权威性。

| 功能 | 任务 | `个人基线` 的对应内容 |
|---|---|---|
| 增长 | 让更广的人意识到问题 | “为什么笔记越多，行动反而越少” |
| 真实性 | 展示真实过程、限制和改判 | 一轮七天审计的原始记录与字段删改 |
| 权威性 | 给出能被检查的模型和方法 | 状态—瓶颈—接口、提取练习、证据闭环 |

三者不要求一篇文章同时完成。把三种任务硬塞进一篇，会让文章既像教程、又像日记、又像销售页。

## 四、长短内容结构

### 1. 短内容

官方基础结构是 `Hook → Body → Conclusion`。常见的权威内容有三类：

1. 给初学者的可执行原则；
2. 解释一个主题为什么重要；
3. 指出常见错误、坏建议或被忽略的问题。

短内容的目标是测试入口、语言和问题强度。互动好只代表内容触发了传播或认同，不能证明主张正确。

### 2. BPAS Newsletter

在 [The Future Of Creators](https://thedankoe.com/letters/the-future-of-creators-how-to-build-an-audience-in-2025/) 中，BPAS 被用于较短的 Newsletter：

`Big Idea → Problem → Amplify → Solution`

对本产品的改写是：

`核心判断 → 可观察问题 → 代价与旧解释的不足 → 有边界的模型和下一步`

Amplify 只能展开真实代价，不得增加虚假风险或焦虑。

### 3. APAG

[High-Impact Writing](https://thedankoe.com/letters/learn-this-skill-if-you-want-to-survive-the-next-10-years/) 给出的 APAG 是：

- **Attention**：用相关问题、结果或信息差让读者决定继续读。
- **Perspective**：描绘旧视角、问题和代价。
- **Advantage**：提供新的解释、论据、经历或证据。
- **Gamify**：把改变转成步骤、挑战和下一行动。

本产品只借用其叙事职责，不继承“敌人”式极化和未经来源支持的心理学包装。完整适配见 [[../90-内部治理/02-内容与笔记规范]]。

### 4. 金字塔大纲

在 [Master Persuasion](https://thedankoe.com/letters/the-greatest-skill-of-the-21st-century/) 中，Dan Koe 说明自己会在动笔前写出观点、论据和可引用材料，再形成大纲与草稿。这与 Barbara Minto 的金字塔原则一致，但原始规则应回到 Minto，而不是把 Dan Koe 当作来源。

## 五、风格指纹

### 可观察特征

- 标题和开头先给反常识断言、风险或身份冲突，不长铺背景；
- 第二人称、短段落、排比、反问和命令句制造速度；
- 常从个人低谷进入，再放大为公共问题；
- 用游戏、地图、镜头、系统、熵和层级把抽象问题可视化；
- 在哲学段落与清单、步骤之间交替；
- 文末把行动、深度内容和产品 CTA 分层承接；
- 同一核心想法反复跨媒介表达，形成稳定世界观。

### 风格背后的论证路线

`个人经历 → 普遍问题 → 新定义或跨学科框架 → 步骤系统 → 身份和未来愿景`

这条路线很有传播力，也容易产生四类失真：

1. 把个人成功史当因果证明；
2. 把制度和资源问题改写成个人意识问题；
3. 用伪精确数字增加权威感；
4. 为制造冲突，把复杂分歧压成强者/弱者、玩家/NPC 等二元叙事。

## 六、内容飞轮

Dan Koe 早期强调一封 Newsletter 拆成 Thread 和每日短帖，后期更接近双向循环：

`短帖测试 → 胜出主题扩成长文/视频 → 长文拆出新短帖 → 引向邮件与产品 → 产品反馈产生新问题`

本产品采用这个循环，但增加证据门禁：

`真实问题 → 来源与闭卷解释 → 主张台账 → 短内容测试理解 → 长文完整论证 → 七天协议 → 运行记录 → 改判 → 产品更新`

## 七、可借鉴与不可继承

| 借鉴 | 原因 |
|---|---|
| 从真实问题和项目选题 | 内容天然带有对象、情境和反馈 |
| 用观点统一多个兴趣 | 允许跨主题但不失去识别度 |
| 短内容测试、长内容建构 | 降低研究浪费，形成自有资产 |
| 先大纲再草稿 | 把思考和措辞分开 |
| 一份母内容跨媒介复用 | 降低重复研究成本 |
| 内容与产品共用一组问题 | 内容成为研发和支持系统 |

| 不继承 | 原因 |
|---|---|
| “创业是唯一合理道路” | 忽略职业、资源、照护和风险差异 |
| NPC、洗脑等身份攻击 | 牺牲准确性换冲突 |
| 自述收入和粉丝数作为证明 | 存在幸存者偏差与商业利益 |
| APAG 的“心理学已证明”包装 | 公开文章没有逐项研究来源 |
| 意识、脑科学和宇宙化精确数字 | 来源不稳定或缺失 |
| 把个人经验普适化 | 不能支持产品承诺 |

## 八、对 `个人基线` 的直接决策

1. 长期主题不再是“个人成长”，而是“理解如何变成可观察改变”。
2. 选题由真实运行、读者问题和证据冲突产生，不靠 AI 批量脑暴填表。
3. 每篇只承担增长、真实性或权威性中的一项主任务。
4. 可使用 APAG、BPAS 和强开头，但必须加来源、边界和反证。
5. 没有真实经历时使用公开事实和观察，不补写第一人称故事。
6. 没有运行结果时只写协议和待验证假设，不写“这个方法有效”。
7. 社群和付费产品只能承接已经能独立使用的协议，不销售抽象世界观。
