# 第七天复盘表

复盘的目标是更新领先假设，不是证明自己成功或失败。

## 一、先汇总事实

| 指标 | 计算 |
|---|---|
| 计划情境总次数 | |

| `available` 总数 | |

| 动作完成次数 | |

只在分母大于零时计算：

- **证据完成率**：留下合同证据的 `available` 次数 / 全部 `available` 次数。
- **机会启动率**：动作开始次数 / `available` 次数。
- **开始后完成率**：动作完成次数 / 动作开始次数。
- **质量达标率**：达到质量基准次数 / 已测质量次数。
- **可信反馈率**：可信且达到门槛次数 / 获得反馈次数。

这些比率只描述本轮，不代表长期概率，也不用于与他人比较。

## 二、检查记录是否足以判断

- `available` 少于预期：为什么？
- 是否把有机会但未执行误记成 `noOpportunity`？
- 合同是否在结果出现前锁定，是否被事后改写？
- 开始和未开始是否都被记录？
- 是否在看到结果后临时修改了“成功”标准？
- 反馈是否与目标决定相关且测量有效？
- 是否有明显未记录的外部变化？
- 竞争解释是否仍然无法区分？

如果数据不足，正确输出是“本轮无法判断”，下一轮先修复机会或记录设计。
