## 每次机会

有多次机会时复制本段。

```markdown
### 机会 1

- 机会状态：`noOpportunity` / `available`
- 资源与停止条件允许：否 / 是
- 完成证据出现：否 / 是
- 动作结果：未开始 / 开始未完成 / 完成
- 第一项可观察行为：
- 最早中断点：
- 当时发生的事实：
- 实际用时：
- 质量基准：未测 / 未达 / 达到
- 完成后反馈：无 / 有，内容：
- 反馈有效性：不足 / 可用，原因：
- 下一决定：保持 / 修订 / 有界学习 / 补资源 / 修测量 / 退出 / 寻求支持
```

`noOpportunity` 时，活动用时、完成证据和结果指标均记为 0 或空；机会客观存在但没有执行时必须选择 `available`。

## 可选身心情境快照

只有准备检验“基线影响行动”时才填写，避免把记录变成新的负担。

| 字段 | 记录方式 |
|---|---|
| 睡眠窗口 | 大致入睡与起床时间 |
| 主观清醒度 | 低 / 中 / 高 |
| 最长不受打扰时间块 | 大致时长 |
| 高刺激内容挤占 | 无 / 有，写具体情境 |
| 身体活动 | 无 / 有，不评价强度 |
