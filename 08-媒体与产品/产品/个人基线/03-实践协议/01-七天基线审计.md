# 七天基线审计

## 目的

用一个足够短的周期，记录“机会是否发生、证据合同是否完成、结果是否可信、决定是否更新”，形成当前领先假设。这不是健康挑战，不要求连续七天完美执行，也不能确认真实根因或验证整套理论。

- 相关主张：`PB-003`、`PB-005`
- 术语：[[../02-核心模型/00-术语表]]

## 开始前

选择一项已经反复准备、但七天内有机会接受低风险约束的活动。不要选择“变自律”“建立事业”这类无法在一周内观察的目标。

开始前必须通过 [[00-接口选择表]] 的目标价值、资源权限、风险伦理、知识能力和反馈有效性五道门。直接接触未通过时，可改为模拟或监督方式后重新检查；只有所选接触方式下五道门全部允许测试，才启动运行。若仍未通过，转向退出、补资源、有界学习、修测量或专业支持。

按 [[00-接口选择表#四、证据合同]] 的固定字段写下并锁定：

- **目标决定**：这次证据准备帮助决定什么；
- **任务状态向量**：八项分别填写“未知 / 暂不足 / 当前足够”；
- **本轮焦点状态**：从 K / A / P / R / E / F / Q / H 中只选一个；
- **活动类别**：探索 / 有界学习 / 基础设施 / 约束测试 / 可撤回进展；
- **唯一活动与计划情境**：何时出现机会，做什么；
- **开始标准**：哪一项行为发生才算开始；
- **完成证据**：什么可回看结果算本轮完成；
- **接触方式**：直接 / 模拟 / 监督；
- **结果空间**：可能观察到什么，每种结果改变什么；
- **时间盒与预计机会**：每次 1-20 分钟，七天内预计几次；
- **风险上限、第三方影响、停止条件和支持者**；
- **更新门槛**：一次结果是否足够，需要几次重复或外部评审；
- **领先瓶颈假设**：只能选一个；
- **竞争解释**：至少写一个；
- **合同版本**：锁定后不覆盖，修订新建版本；
- **复盘日期**：第七天后的具体日期。

过去一周发生次数属于可选基线备注，不是合同字段，不得替代 `expected_opportunities`。

如果预计七天内少于三次行动机会，先调整计划情境或延长观察，不急着评价合同。

## 每日记录

使用 [[02-每日记录表]]。最低必填字段是：

- `noOpportunity` 与 `available` 次数；
- 合同版本、完成证据和实际用时；
- 未开始、开始未完成和完成数；
- 最早中断点、质量是否测量、是否获得反馈，以及反馈是否达到更新门槛。

只有本轮准备检验身心情境因素时，才填写睡眠窗口、清醒度、时间块、高刺激挤占和身体活动。

## 第七天复盘

使用 [[03-第七天复盘表]]，先汇总机会、合同证据、质量和反馈，再解释。

### 1. 事实

- `available` 机会发生了几次，`noOpportunity` 有几次；
- 在有机会时留下合同证据几次；
- 质量基准达到几次，反馈可信几次；
- 最常见的中断点；
- 有哪些记录不足或外部变化。

### 2. 改判

- 原领先假设：
- 支持它的证据：
- 反对它的证据：
- 仍未排除的竞争解释：
- 当前证据更支持：

### 3. 下一轮

只能做一个决定：保持、修订、有界学习、补资源、修测量、退出目标或寻求支持。

## 停止与寻求支持

如果实验明显恶化睡眠、情绪、身体状态或日常功能，立即停止。涉及医疗、心理、饮食和训练的问题，不用本协议自行诊断。

完整结果复制 [[../04-运行记录/00-回填模板]] 保存。没有数据时保持空白，不创建示范成功案例。
