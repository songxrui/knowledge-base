# 接口选择表

目的：在开始七天审计前先过安全与资源门，再确定任务状态向量、本轮焦点状态、活动类别和一张证据合同。

## 一、五道门

| 门 | 检查 | 未通过时的路由 |
|---|---|---|
| 目标价值 | 没有展示和身份奖励时仍愿意承担成本吗？ | 修改或退出目标 |
| 资源权限 | 时间、资金、场地、照护、权限和协作存在吗？ | 补资源、协商、集体行动或退出 |
| 风险伦理 | 最大损失可逆吗，是否影响第三方或需要资质？ | 监督模拟、专家复核或停止 |
| 知识能力 | 能否独立提取、示范或通过安全检查？ | 有界学习，写明返回测试的条件 |
| 反馈有效 | 结果与决定相关、有效且达到必要重复吗？ | 修测量或延长观察 |

五门全部允许至少一次合格测试，才进入下一步。

## 二、状态与活动

| 状态 | 当前判断：未知 / 暂不足 / 当前足够 | 对应接口 |
|---|---|---|
| `K` 知识能力 | | 提取、示范、有界学习、监督练习 |
| `A` 动作清晰 | | 情境—动作—证据重写、示例 |
| `P` 资源机会权限 | | 日程、资源、协商、环境调整 |
| `R` 风险伦理 | | 降低暴露、模拟、监督、专家复核 |
| `E` 约束测试 | | 锁定一次低风险证据合同 |
| `F` 反馈有效 | | 指标、重复、盲评或修测量 |
| `Q` 表现质量 | | worked example、反馈练习、质量基准 |
| `H` 稳定与恢复 | | 固定触发、缩小剂量、恢复规则 |

八项都必须填写“未知 / 暂不足 / 当前足够”，记录格式为 `state_vector`。另从中选一个本轮准备改变或观察的 `focus_state`；它不是把其他七项删掉。

活动类别只能选一项作为本轮主任务：探索、有界学习、基础设施、约束测试、可撤回进展。

## 三、选择规则

1. 五道门优先于所有效率建议。
2. 状态不合成总分，只选一个本轮准备改变或观察的状态。
3. 基础设施只有在降低摩擦或提高测量质量时才保留。
4. 约束测试必须事前声明结果空间和更新门槛。
5. 高风险、不可逆或需要专业判断的问题，不用本表自行处理。

## 四、证据合同

以下字段名和含义是唯一合同 schema。[[../04-运行记录/00-回填模板]] 必须原样保留；修订只增加 `contract_version`，不覆盖旧值。

```yaml
contract_version: v1
target_decision:
state_vector:
  K: 未知 | 暂不足 | 当前足够
  A: 未知 | 暂不足 | 当前足够
  P: 未知 | 暂不足 | 当前足够
  R: 未知 | 暂不足 | 当前足够
  E: 未知 | 暂不足 | 当前足够
  F: 未知 | 暂不足 | 当前足够
  Q: 未知 | 暂不足 | 当前足够
  H: 未知 | 暂不足 | 当前足够
focus_state: K | A | P | R | E | F | Q | H
activity_type: 探索 | 有界学习 | 基础设施 | 约束测试 | 可撤回进展
unique_activity:
planned_context:
start_definition:
completion_evidence:
contact_mode: direct | simulated | supervised
result_space:
timebox_minutes: 1-20
expected_opportunities:
risk_cap_and_third_party:
stop_condition:
supporter:
update_threshold:
leading_hypothesis:
competing_explanation:
review_date:
```

五道门按所选 `contact_mode` 重新判断。直接接触不安全但监督模拟安全时，可以把监督模拟作为真实运行登记；它只支持该模拟或监督情境，不能证明直接接触安全。三种方式都无法过门时，不建立运行记录，转向补资源、退出或寻求专业支持。

## 五、解释示例

“锁定合同后仍未留下证据”不能直接说明合同无效。先检查：

- 约定机会是否客观出现；
- 五道门是否判断错误；
- 合同活动和完成证据是否足够清楚；
- 反馈是否真的与决定相关；
- 是否发生了新的资源、风险或权限变化。

`noOpportunity` 不进入证据完成率分母；机会存在但没有留下证据必须如实记为未完成，不能改写成无机会。
