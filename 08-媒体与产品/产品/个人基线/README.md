# 个人基线

> 把理解编译成现实改变。

`个人基线` 是一个长期更新的个人内容产品。它不试图回答“怎样成为最好的人”，只处理一个更窄的问题：当你已经懂了很多，却仍没有发生稳定改变，下一步究竟卡在哪里？

## 产品承诺

使用者完成一次最小周期后，应该得到三样东西：

1. 一张当前基线快照，而不是一份人格评价；
2. 一个由本轮记录支持、仍可被推翻的领先瓶颈假设；
3. 一项能区分竞争解释的下一轮实验。

产品不承诺涨粉、收入、减重、治愈、投资收益或固定行为改变。它提供的是判断框架、记录协议和复盘接口。

## 从这里开始

1. 阅读 [[01-快速开始]]，确认它是否适合你，并把目标改成可观察动作。
2. 用 [[03-实践协议/00-接口选择表]] 选择本轮唯一接口。
3. 用 [[03-实践协议/01-七天基线审计]] 运行第一个周期。
4. 每天填写 [[03-实践协议/02-每日记录表]]，第七天使用 [[03-实践协议/03-第七天复盘表]]。
5. 每轮结束后，只把有来源或真实运行支持的新判断写回产品。

## 产品结构

- [[SOURCE_OF_TRUTH]]：版本、证据身份和冲突规则
- [[00-产品定义]]：用户、问题、承诺与边界
- [[01-快速开始]]：第一次运行的最短路径
- [[01-写作与笔记协议]]：研究、写作与永久笔记的对外摘要
- `02-核心模型/`：长期稳定的判断模型
- `03-实践协议/`：可执行、可停止、可回填的实验
- `04-运行记录/`：只保存真实运行和复盘
- `05-研究与信源/`：Dan Koe 与学习笔记方法的完整研究
- `90-内部治理/`：主张台账、内容规范和产品验证路线图
- [[04-来源地图]]：原始材料与产品模块的追溯关系
- [[05-内容路线图]]：从工作簿到文章、课程和社群的演化顺序
