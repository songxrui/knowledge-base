## 先过五道门

任何心理和效率解释前，按顺序检查：

1. **目标价值**：没有观众、打卡和身份标签时，是否仍愿意承担目标成本？
2. **资源与权限**：时间、资金、场地、照护、组织权限和决策权是否存在？
3. **风险与伦理**：最大可逆损失是什么，是否影响第三方，是否需要监督或专业资质？
4. **知识与能力**：能否通过独立提取、迁移题、示范、监督模拟或安全检查证明已足够起步？
5. **反馈有效性**：结果是否与决定相关、可读、有效，且达到必要重复？

任一门未过，下一步应是修改或退出目标、补资源、降低风险、有界学习或修测量，不进入生产力诊断。

## 状态向量

五道门允许低风险测试后，用八个可跳转、可回退的状态描述当前任务：

`X = (K, A, P, R, E, F, Q, H)`

| 状态 | 含义 |
|---|---|
| `K` | 知识与能力准备度 |
| `A` | 动作是否明确到情境、动作和完成证据 |
| `P` | 资源、机会和权限是否存在 |
| `R` | 风险、伦理和最大可逆损失是否过关 |
| `E` | 是否完成预声明的约束测试 |
| `F` | 反馈是否决策相关、有效并达到更新门槛 |
| `Q` | 目标表现质量是否达到当前基准 |
| `H` | 行为是否在目标情境下可靠发生并能恢复 |

每项只记“未知、暂不足、当前足够”，不合成总分。反馈可能暴露新的知识缺口，稳定执行也可能固化错误动作，所以这里不是线性成熟阶梯。

## 诊断顺序

1. **门禁**：目标、资源、风险、能力和反馈是否允许测试？
2. **状态**：K、A、P、R、E、F、Q、H 中哪一项未知或暂不足？
3. **活动**：当前需要探索、有界学习、基础设施、约束测试，还是正在重复可撤回准备？
4. **接口**：什么外部结构能让下一次证据出现，或让测量变得可信？
5. **决定**：保持、修订、有界学习、补资源、修测量、退出或寻求支持？

可能的接口包括提醒、清单、示例、练习、同伴、教师、环境改造和专业支持。书、摘要与 AI 只是接口的一部分。

正式运行前使用 [[../03-实践协议/00-接口选择表]]。如果没有有效机会、证据合同没有执行、反馈无效或停止条件已触发，不能用该次结果判断方法效果。

## 常见误用

- 把所有失败都诊断成缺少知识；
- 跳过资源、权限和风险，把结构问题道德化；
- 看见一个瓶颈后，同时安装五个接口；
- 用更复杂的系统解决本来只需要一次提醒的问题；
- 把“我能解释”当作“我能独立完成”；
- 把清楚但无效的反馈当作真实证据；
- 为了提高次数拆分动作，或事后修改成功标准。

## 边界

这个模型是现有研究组件约束下的作者综合与 N-of-1 假设族，不是已经整体通过实验检验的心理学理论。它帮助生成下一步路由，不能替代医疗、心理、教育、法律、财务或职业评估。若“可撤回进展”在控制近邻变量后没有增量效度，该名称应撤销。

## 行动接口

选择一个迟迟没有发生的低风险活动，依次填写：目标决定、任务状态向量、本轮焦点状态、活动类别、可能结果、时间与机会、风险上限、更新门槛。完整格式见 [[../03-实践协议/00-接口选择表]]。

若目标价值、资源权限或风险门未过，正确结果可能是退出、补资源或寻求支持，而不是继续优化动作。

## 验证信号

如果完整执行证据合同后，结果没有变得更可解释、反馈仍不能改变决定，或状态编码无法稳定区分任务，就应修改或放弃模型，而不是继续增加接口。单次结果只更新领先假设；模型只有在能改变下一步决定、并且竞争解释得到更好区分时才有用。
