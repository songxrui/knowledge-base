# 创作者书稿

本目录只允许保存能够逐段定位到原始稿件、且明确区分原话、转述和编辑判断的活跃书稿。当前没有通过该门槛的创作者书稿。

- 原始逐字稿：
`
03-资源/创作者素材/
`
- 已归档的 AI 派生书稿：
`
90-归档/历史版本/content-quality-p1-20260718/08-媒体与产品/媒体/创作者书稿/
`
- 归档清单与证据：
`
99-系统/元数据/inventory/CREATOR_DERIVATIVE_BOOK_ARCHIVE_MAP_2026-07-18.md
`

重新生成书稿前，必须先建立“章节段落 -> 原始稿件 -> 时间戳/原文”的来源映射。不得补写创作者没有讲过的故事、数据、经历或结论。
