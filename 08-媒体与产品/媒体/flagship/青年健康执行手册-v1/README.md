## 这本书是什么

本书讨论一个具体问题：一个没有急性重病、但已有睡眠、久坐和未处理风险的年轻人，应先做什么，何时进入医疗系统。

十一章依次处理：安全分级、睡眠、训练、饮食、口腔与日常卫生、紫外线与听力、烟酒与补剂、筛查与过度诊断、疫苗与性健康、最小执行系统和停止自我实验的条件。

## 版本边界

- 完整短书发布候选版，不是出版终稿，没有 ISBN、出版社审校，也**尚未经医学专业审读**。
- 本书提供一般健康行为框架，不诊断疾病、不给处方、不推荐具体药物或补剂剂量。
- 官方指南是人群层面建议，不等于个体最优处方；观察性研究支持关联，不等于个体因果。
- 三套膳食指南之间存在真实分歧（尤其蛋白质口径），本书保留冲突，不做平均。
- 不承诺减重、增肌、寿命或任何健康结果。
- 不披露作者个人医疗信息；书中示例均为一般化场景。

## 阅读路径

| 部分 | 章节 | 解决的问题 |
|---|---|---|
| 安全 | 1、11 | 什么时候自己处理，什么时候就医，什么时候停止 |

| 风险管理 | 6–9 | 不可逆暴露、烟酒补剂、筛查、疫苗与性健康 |
