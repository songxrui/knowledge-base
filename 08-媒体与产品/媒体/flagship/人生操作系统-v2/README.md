## 这一版改了什么

v1 是把九份证据版章节和十二个领域章节装配成的操作手册。v2 收窄为**个人系统的一般理论**：只讲"怎样构建一个能观察、能纠错、能更新的系统"，领域细节交给其他书，避免与第 1 本和健康书重复。

**核心判断：稳定行为的主要杠杆不是意志力，而是系统的默认设置、触发脚本和纠错规则。**

## 结构

**序言　意志力的破产**
1. 默认设置
2. 触发脚本
3. 能量先于时间
4. 区分波动与趋势
5. 删除也是更新
6. 从最小单元开始
7. 五层如何互为条件
8. 系统在运行的标志

**结语　让失败留下信息**
