## 这本书是什么

本书讨论一个具体问题：当资源、家庭控制、健康、低能量和恐惧同时存在时，怎样设计可承担的行动。

十一章依次处理：问题重定义（六层模型）、竞争性解释鉴别、现实约束、五道前置门、四种行为控制故障、全天回路与事件记录、干预排序、自主行动实验、关系与支持、专业分流和六个月行动系统。

## 版本边界

- 完整短书发布候选版，不是出版终稿，没有 ISBN、出版社审校或外部试读。
- **本书不是心理诊断、创伤诊断或治疗方案。** 不诊断抑郁、焦虑、创伤、ADHD、成瘾或睡眠障碍。
- 不要求、也不鼓励在自助环境中强行回忆创伤、暴露、身体释放或恢复“被压抑的记忆”。
- 不把贫困、住房、就业和安全问题心理化。
- 不把名人自传当作可复制的成功路径或治疗证据。
- 六个月行动系统的长期有效性尚未被项目验证。

## 安全边界（不可省略）

出现自伤/自杀想法、计划或行为，无法保证安全，严重失眠伴异常兴奋或冲动，幻觉/妄想/现实检验下降，暴力风险，或游戏/赌博/物质造成即刻重大财务或法律风险时，优先专业支持。
