# 答案之书 v8

## 版本边界

`book-v7` 是冻结的原始汇编。它保留了作者在不同阶段积累的材料、原始章节与合并过程。v8 不修改 v7，而是在保留可追溯关系的前提下重新组织阅读路径，修复章节断层、重复真源、无出处的精确数字和模板化语言。

v8 的四个入口分别承担不同工作。理论版解释问题、证据与适用边界；实践版把可执行动作写成低负荷实验；身体健康章作为个人使用手册，集中处理训练、饮食、睡眠和恢复；证据台账记录每一类主张能支持到什么范围。可以从理论版开始，也可以带着一个具体问题进入实践版。健康实验中若出现持续疼痛、既往疾病限制或药物冲突，先调整或暂停对应动作，再按自己的实际情况安排。

## 内容身份

| 标记 | 含义 |
| --- | --- |
| 研究结论 | 可定位到研究、指南或系统综述的内容 |
| 作者经验 | 作者在个人生活或工作中观察到的结果，不外推为普遍规律 |
| 综合建议 | 基于多个材料整理出的行动方向，需要在个人情境中检验 |
| 待补证 | 原稿存在但暂未找到足够出处的材料，保留问题，不保留结论强度 |

## 文件地图

| 文件 | 功能 |
| --- | --- |
| `01-答案之书_理论版.md` | 从心理、身体、财富、关系到决策的理论框架 |
| `02-答案之书_实践版.md` | 用低负荷实验把理论转成行动 |
| `03-身体健康.md` | 个人健康系统的证据化重写 |
| `90-证据台账.md` | 重要主张、来源、适用范围和待核验项 |

原 v7 的第 1 章正文在合并稿中存在缺口。v8 不凭空补写，理论版从已有材料中能够完整重建的主题开始，并将缺口写入证据台账。
