## 这本书是什么

本书讨论一个完整问题：怎样把人生从意志力管理，改造成可观察、可纠错、可更新的系统。

十二章按“地基—杠杆—生态”排列：元系统、健康、认知、时间能量、财富、创造、学习、决策、AI 个体增长、关系、意义、系统闭环。

## 版本边界

- 完整短书发布候选版，不是出版终稿，没有 ISBN、出版社审校或外部试读。
- 第 1、2、3、5、6、8、9、10、11 章来自既有“证据化派生稿”，带主张编号与原稿来源；第 4、7、12 章与序言、后记为本次新写。
- 所有周期、阈值和指标都是第一轮实验参数，不是普适规律。
- 企业案例（OKR、丰田、桥水）的具体数字本轮未逐条一手核验，只作原则示例，不作因果证明。
- 不承诺收入、健康、关系或任何身份结果；不替代医疗、法律、财务和心理专业判断。
