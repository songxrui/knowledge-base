## 这本书是什么

本书讨论一个狭窄但完整的问题：一个人怎样把有限的注意力，变成愿意承担的方向、可以交付的作品和足以支撑生活的价值，同时不把全部人生交给市场评价。

四部十二章依次处理方向、目的、作品和持续结构。它不是“辞职创业指南”，也不把自由职业、个人品牌或商业变现写成更高等级的人生。

## 版本边界

- 这是完整短书发布候选版，不是出版终稿，也没有 ISBN、出版社审校、外部试读或商业验证。
- 原始开发稿仍保留在 `01-项目/知行转化研究/flagship/`，本版不改写原稿。
- 书中人物为合成场景，只用于承载常见冲突，不是采访记录或效果证明。
- Dan Koe 的材料只证明作者本人提出过相应方法，不证明创业、收入或心理因果；其他研究结论保留原有限制。
- 本稿不能替代投资、职业、法律、心理或医疗建议。
