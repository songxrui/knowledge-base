## 这一版改了什么

v1 是一部证据严谨但不断免责的方法手册。v2 把它改成一部有明确论点的思想著作。

**核心判断只有一句：在生成变便宜的时代，唯一还值钱的东西，是一条能被追溯、被质疑、被追责的主张。**

- 正文不再出现"书中不承诺""本章边界"式的防御写作。
- 减少罗列，增加判断。工具（内容证据契约、Proofline、Quarry、KBLoop）只在论证需要时出现。
- 每章都有一个可以被复述的落点。
