## 这一版改了什么

v1 是一份证据严谨的内部文档：它把该说的都说了，却缺少一个能被复述的核心判断，并且用虚构主人公承载叙事。v2 推翻了这两点。

**核心判断只有一句：可撤回的努力，不产生方向。** 全书的每一章都在推进、检验或限定这一句。

**叙事载体换成真实的书和真实的作者。** 汉娜·阿伦特《人的境况》、薇依与默多克论注意力、克尔凯郭尔《清心即是专一》、萨特（存在先于本质）、弗洛姆《占有还是存在》、鲍曼《液态现代性》、韩炳哲《倦怠社会》、塔勒布《反脆弱》、施瓦茨《选择的悖论》、伯克曼《四千周》、纽波特《优秀到不能被忽视》、伦纳德《Mastery》、丹·科《专注的艺术》、梅多斯《系统之美》、克利尔《掌控习惯》。没有虚构人物。

**正文不做防御性免责。** 来源与边界移到来源说明；正文只下判断。

**作者自己的知识库数据只在序言出现一次**，作为问题的入口，不作为全书主要案例。
