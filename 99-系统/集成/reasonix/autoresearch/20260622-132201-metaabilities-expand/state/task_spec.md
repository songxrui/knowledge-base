# 元能力手册扩展 — Task Spec

## Goal
在现有10章元能力基础上新增3章，每章≥15,000中文字符。渐进式横向纵向扩展，不一次性生成。

## New Chapters
- Ch11: 执行（Execution）— Fogg行为模型，A→B系统设计，习惯自动化
- Ch12: 戒断/自控（Abstinence）— 多巴胺国度，不成瘾，控制不做什么
- Ch13: 自我精神分析（Self-Psychoanalysis）— 原生家庭、童年创伤的心理学解决方案

## Format
费曼解释+寓言故事+训练协议+自测。吸收经典权威书籍精华。

## Scope
逐步扩展，一次一章。先完成11，再12，再13。

## Success Criteria
- 每章≥15,000中文字符（~35,000-40,000 bytes）
- 禁用词13词零命中
- ≥5本经典著作吸收
- 费曼+寓言+协议+自测四件套齐全
