# 元能力长文创作 — Task Spec

## Goal
写一篇至少20,000中文字符的长文，主题是"元能力"——AI时代人类必须优先发展的基础能力（自学、说服、身心健康等）。模仿Dan Koe的语气风格。

## Scope
- 主题：元能力（meta-abilities）的定义、重要性、具体领域、培养方法
- 风格：Dan Koe式——直接、哲学深度、个人叙事、实用框架、精神层面
- 长度：≥20,000中文字符（约8,000-10,000英文词当量）
- 引用：≥10本经典著作/论文/人物故事
- 个人经历：董辉的真实故事贯穿全文

## Non-Goals
- 不写短文章
- 不用AI模板结构
- 不编造经历
- 不含互联网黑话

## Success Criteria
- 字数 ≥ 20,000中文字符
- 禁用词13词零命中
- AI味5模式零命中
- ≥ 10个深度引用
- ≥ 3段个人真实经历
- Dan Koe风格达标（长段、哲学+实践、精神层面、直接对话读者）
- 自然嵌入答案之书/健康之书引用

## 元能力选题框架
1. 自学（Self-Learning）— 如何教会自己任何东西
2. 说服（Persuasion）— 如何让想法在别人脑子里生长
3. 身心健康（Health）— 所有能力的地基
4. 写作（Writing）— 思维的物理形态
5. 决策（Decision-Making）— 在不确定中做选择
