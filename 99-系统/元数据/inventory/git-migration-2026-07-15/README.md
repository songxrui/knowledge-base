# Git 迁移审计清单

> 生成日期：2026-07-15。只记录路径、Git blob 和分类，不记录敏感值。本目录用于审计当前大规模迁移，不代表可以直接执行 `git add -A`。

## 基线结论

| 分类 | 数量 | 含义 |
|---|---:|---|
| HEAD 中已删除文件 | 3,111 | 旧路径在工作树中不存在 |
| 当前未跟踪普通文件 | 3,530 | 排除 `99-系统/alchemist/` 嵌套仓库入口 |
| 唯一精确迁移 | 2,611 | 旧文件与一个新文件的 Git blob 完全一致 |
| 多个精确候选 | 105 | 内容完全一致，但新位置不唯一，不能自动决定 canonical |
| 未匹配删除 | 395 | 可能是修改后迁移、主动删除或遗漏 |
| 精确迁移目标 | 2,738 | 至少对应一个旧路径的未跟踪文件 |
| 新增或已修改 | 792 | 没有与删除文件完全相同的 blob |

对 395 个未匹配删除进一步按文件名比对：274 个有唯一同名候选，属于“修改后迁移”的中等置信候选；17 个同名候选不唯一；104 个没有同名候选，必须人工判断是主动删除还是遗漏。

## 文件说明

- `deleted-to-untracked-exact-matches.csv`：每个旧删除路径的精确 blob 候选。
- `untracked-files-classification.csv`：每个未跟踪文件是否为精确迁移目标。
- `unmatched-deletion-basename-candidates.csv`：未匹配删除的同名候选，仅作人工复核线索。
- `no-candidate-deletions-review.csv`：104 个无同名候选删除的初步分类和待决策栏。
- `sensitive-paths-exclusion.csv`：凭据处置完成前必须排除的路径；不包含任何凭据值。

104 个无同名候选删除中，规则初筛得到：30 个疑似临时或生成文件、6 个孤立 Obsidian 视图、3 个疑似日志或一次性文件、65 个必须人工复核。该分类不是删除授权，所有 `decision` 当前均为 `pending`。

## 安全执行顺序

1. 先处理 `sensitive-paths-exclusion.csv`，轮换并移除有效凭据。
2. 抽查唯一精确迁移，按旧顶层目录分别确认数量与目标职责。
3. 人工复核 105 个重复候选，确定唯一 canonical 或合理镜像。
4. 逐项决定 395 个未匹配删除，禁止把“无候选”默认当作可删除。
5. 将 792 个新增或已修改文件按用户改动、迁移改写、生成产物、第三方镜像分类。
6. 只有上述分类完成后，才按职责区分批暂存和检查 rename/delete diff。

## 当前禁止事项

- 禁止 `git add -A`。
- 禁止把整个知识库作为单次迁移提交。
- 禁止在凭据轮换前暂存敏感路径。
- 禁止自动删除无候选文件或重复候选。
