# 内容准入与精简清理计划

> 目标：降低维护面、提高活跃区平均文件质量，并让中间产物有明确缓冲区。
> 基线：2026-07-15。所有原始稿件先保留，只有高置信度低质物直接删除。

## 准入分级

| 等级 | 判定 | 处理 |
|---|---|---|
| S 原始资料 | 可追溯的原文、逐字稿、书稿来源或外部材料 | 保留，归入 `03-资源/` |
| A 成熟知识/成品 | 有来源、结构完整、可复用或已形成产品 | 保留在 `04-知识/`、`05-内容生产/` 或 `08-媒体与产品/` |
| B 中间产物 | 装配稿、审计、候选清单、测试输出、摘录、日志 | 移入对应二级目录的 `00-缓冲区/` |
| C 低质量 | 空表、重复日志、无信息 JSON、重复短卡、乱码或无独立价值文件 | 删除；有追溯价值的只进 `90-归档/` |

## 终验指标

1. 活跃区不再出现独立的 `02-领域`、`06-运营数据`、`07-已发布` 顶层目录。
2. 中间产物只出现在 `00-缓冲区` 或 `90-归档`。
3. 活跃区原始稿件、成熟知识和可发布成品不被删除。
4. Wiki/Markdown 链接、脚本语法、MOC、旧路径和 Git 空白检查全部通过。
5. 删除项数量、迁移项数量和剩余文件分布写入终验报告。
