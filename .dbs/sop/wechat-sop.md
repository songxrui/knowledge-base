# 公众号发布SOP v1.0 (baoyu配图深度文章)

## Stage 1: 选题与研究 (20分钟)
- [ ] 从选题池认领深度选题
- [ ] 检索内容单元库，收集>=3个相关单元
- [ ] 检索深度卡和答案之书，收集>=2个引用源
- [ ] 确认选题通过6道质量门禁预检

## Stage 2: 撰写 (60-90分钟)
- [ ] 标题采用6种公众号标题公式之一
- [ ] 开头Hook: 制造悬念/认知冲突/具体数字
- [ ] 正文结构: 问题→分析→案例→方法论→行动建议
- [ ] 核心信息点 3-5个
- [ ] 字数 >=2000字
- [ ] 商业化钩子: 自然引出产品/社群入口

## Stage 3: 配图生成 (10分钟)
- [ ] 封面图: 触发 baoyu-cover-image (16:9横版公众号封面)
- [ ] 正文插图: 触发 baoyu-article-illustrator (分析文章，识别3-5个配图点)
- [ ] 信息图卡片: 触发 baoyu-image-cards (核心方法论/步骤可视化)

## Stage 4: 质检 (10分钟)
- [ ] AI味检测: 禁用词扫描 + 5模式检查
- [ ] 深度引用: >=3条来源标注
- [ ] 价值耐久: "3个月后还值得看?"
- [ ] 字数底线: >=2000有效中文字符
- [ ] 口播检测: 读一遍不拗口

## Stage 5: 发布与追踪 (5分钟)
- [ ] 排版: 段落短、配图位置确认
- [ ] 原文链接: 指向历史相关文章
- [ ] 发布后记录数据到CSV
- [ ] 同步文章链接到选题记录表
