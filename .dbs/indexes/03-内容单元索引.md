## 索引说明

内容单元是 DBS 系统的最小可复用内容原子，类型包括：

| 类型代码 | 含义 | 示例 |
|---------|------|------|
| QST | 问题(Question) | 读者常问的问题及回答 |
| CON | 概念(Concept) | 核心概念的定义与拆解 |
| OPI | 观点(Opinion) | 有立场的个人观点 |
| CAS | 案例(Case) | 真实案例或故事 |
| SOL | 解决方案(Solution) | 可操作的方法论 |
| SRC | 来源(Source) | 外部引用来源 |
| DAT | 数据(Data) | 统计数据及解读 |
| GLD | 金句(Gold) | 可直接引用的金句 |

### 按主题检索
使用 `indexes/02-主题索引.md` 定位主题编号 → 在单元库中搜索对应 TYPE 前缀

## 使用规范

1. **优先复用**：写稿前必须检索单元库，至少引用 3 个相关单元
2. **标注来源**：使用 `来源::` 语法标注每个引用的单元
3. **单元更新**：发布后，将新产生的内容拆解为单元回写单元库
4. **质量要求**：每个单元必须包含核心观点 + 论据 + 适用建议
