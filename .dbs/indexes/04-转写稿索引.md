## 转写稿 → 内容单元 流水线

```
转写稿（原始）
    │
    ├── 步骤1：分类 → 归属到 17 主题之一
    │
    ├── 步骤2：去噪 → 移除口语冗余、重复
    │
    ├── 步骤3：结构化 → 提取核心观点/案例/数据/金句
    │
    └── 步骤4：入库 → 保存为内容单元（QST/CON/OPI/CAS/SOL）
```

## 处理优先级

| 优先级 | 条件 | 处理策略 |
|--------|------|---------|
| P0 | 与当前选题直接相关 | 立即提取为内容单元 |
| P1 | 属于高价值主题（财富/认知/创作） | 本周处理 |
| P2 | 属于其他主题 | 按需处理 |
| P3 | 重复或低质量 | 归档/删除 |
