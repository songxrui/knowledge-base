## ⭐ 核心方法论名称、公式、框架

### ⭐ 框架1：一句话方法论（道）
> **"找一个足够大、并且足够有价值、并且没有被同行们研究清楚的领域，把事情搞清楚并且讲清楚，就结束了。"**

| 五个核心问题 | 答案 |
|-------------|------|
| 怎么写好标题？ | "足够大+足够有价值" — 选题决定标题上限 |
| 怎么做好开头？ | "把事情搞清楚" — 真正懂了开头自然有力 |
| 如何让人关注？ | "讲清楚" — 讲不清楚的人不值得关注 |
| 如何让人付费？ | "足够有价值" — 价值感是付费唯一理由 |
| 如何可持续？ | "没被研究清楚" — 竞争壁垒来自持续深挖 |

### ⭐ 框架2：空转词检测法（目标系统）
**测试方法**: 从目标中删掉一个词，句子还成立？成立=空转词。
**14个空转词黑名单**: 更好、真正的、深入、系统性、全面、有价值、有意义、影响力、好好、认真、长期、持续、打造、建立
**7项审计矩阵**（好目标>=5项）: 可指物性、可否证性、有完成态、可测量、可行动、嵌上下文、有时限

### ⭐ 框架3：选项×标准矩阵（决策系统）
列出>=2选项 × >=3标准，打分1-5，加权计算。
来源标签: [本人]、[AI推测]、[AI结论]、[结果回填]、[修正]

### ⭐ 框架4：五重过滤（对标系统）
1. 赚钱吗？→ 2. 能看懂吗？→ 3. 能模仿吗？→ 4. 排除自我 → 5. 不讨论本质
核心信条:
- 排除自我是决策加速器
- 0到1阶段，模仿是正确答案
- 模仿颗粒度决定质量（帧级别对标）
- 高利润是唯一标准

### ⭐ 框架5：内容系统三条铁律
**铁律1: 先有产品后有内容** — "社群只要有一个能发付款链接的页面、一个有价值的交付承诺，就可以上线"
**铁律2: 内容为产品服务** — 每一篇内容背后都有明确产品指向
**铁律3: 垃圾流量没有价值** — "能赚钱的内容，一发言就有人后台私信你"

### ⭐ 框架6：引-中-高-顶四层价格体系
- 引流款(199): 信任建立
- 中端款(999-1999): 系统交付
- 高端款(4999-9999): 深度服务
- 顶端款(2万+): 一对一

### ⭐ 框架7：三位一体创作法
MECE检查(内容排他)、知识存量审计(有资格讲)、平台匹配度评估(适合这个平台吗)

### ⭐ 框架8：六格复盘法
每篇内容后填6格(选题/结构/表达/数据/反馈/迭代)

### 框架9：三个哲学源头
- 维特根斯坦: "语言边界=世界边界"，"意义即使用" → 空转词检测、"讲清楚"
- 阿德勒心理学: 目的论、课题分离 → 目标审计、执行力诊断
- 奥派经济学: 主观价值论、企业家精神 → 定价逻辑、"高利润是唯一标准"

### 框架10："搞清楚"三个检查标准
1. 你自己真懂了吗？（能从第一性原理推导）
2. 你能用一句话说清楚吗？
3. 你能让别人也懂吗？

1. 选题(5min): 从选题池取一条
2. 脚本(15min): 300-500字，<=3个核心信息点
3. HyperFrames制作(10min): 文稿→选风格→生成
4. 质检(5min): Hook够强？信息清晰？无AI味？
5. 发布(5min): 标题+话题+定时

### 公众号发布SOP（约2小时/篇）
1. 选题研究(20min): >=3内容单元+>=2引用源
2. 撰写(90min): 1500-3000字，先小标题后内容
3. 配图(15min): 封面+2-3张插图+信息图
4. 质检(15min): AI味检测+深度引用+价值耐久
5. 排版发布(10min): dbs-wechat-html→公众号编辑器

## ⭐ 所有核心方法论名称、公式、框架

### ⭐ 框架1: 像素级复制三要素
```
复制 = 核心观点 × 内容形式 × 商业模式
       ↑必须原创     ↑可以学      ↑可以学
```
操作步骤: 找对标→拆解核心观点(不能搬)→学内容形式→学商业模式→做二次加工→叠加稀缺性

### ⭐ 框架2: 赚钱三层次（最重要框架之一）
| 层次 | 内容 | 作用 |
|------|------|------|
| 第一性原理(最底层) | 商业绝对真理 | 一切推导的根基 |
| 商业规律(中间层) | 定价、供需、平台逻辑 | 连接理论与实践 |
| 方法技巧(表层) | 标题怎么写、引流款怎么设计 | 日常操作 |

### ⭐ 框架3: 需求五层偏差乘法模型（DBS核心）
从用户说出需求到赚到钱，存在5层偏差，且是乘法关系:
```
Layer 1: 理解偏差 — 用户说的 ≠ 你理解的
Layer 2: 翻译偏差 — 你理解的 ≠ 你做的产品
Layer 3: 触达偏差 — 你做的产品 ≠ 用户看到的
Layer 4: 说服偏差 — 用户看到的 ≠ 用户相信的
Layer 5: 转化偏差 — 用户相信的 ≠ 用户付款的
```
**关键洞察**: 乘法关系意味着中间任何一层为零，结果为零。

### ⭐ 框架4: 流量变现四层金字塔
```
          网络感(顶层: 人格魅力+关系)
        拿捏人性(中层: 心理操控)
      只看钱(下层: 实用价值)
    兼得(底层: 赚不赚钱无所谓)
```

### ⭐ 框架5: 内容电商 vs 货架电商
| 维度 | 货架电商 | 内容电商 |
|------|---------|---------|
| 用户状态 | 带着需求来搜索 | 刷着刷着被种草 |
| 决策路径 | 搜→比价→看评价→买 | 刷→感兴趣→临时决定→下单 |
| 核心竞争力 | 产品好+价格低+客服快 | **内容本身够不够好** |
| 新手门槛 | 极高 | 低 |

### ⭐ 框架6: 内容 > 产品三层认知模型
| 层次 | 认知 | 结果 |
|------|------|------|
| L1(最差) | "产品为王，内容不重要" | 永远赚不到钱 |
| L2(能赚) | "内容 > 产品" | 可以赚到100万 |
| L3(长期) | "好内容源于好产品" | 100万之后阶段 |

### 框架7: 创业 vs 自由职业（两套完全不同的操作系统）
| 维度 | 自由职业 | 创业 |
|------|---------|------|
| 目标 | 稳定，不被拖回职场 | 规模化，高增长 |
| 竞争策略 | 反规模化(非标服务) | 规模化(标准化产品) |
| 收入上限 | 1-3万/月→5-10万/月(顶天) | 无上限 |
| 本质 | 高效出卖自己的时间 | 建立系统 |

### ⭐ 框架8: 第一个100万前后的分水岭
| 阶段 | 拼什么 | 关键动作 |
|------|--------|---------|
| 100万之前 | **执行**力(不是认知) | 做！模仿！测试！迭代！ |
| 100万之后 | 系统构建能力 | 标准化、规模化、团队化 |

### ⭐ 框架9: 直接赚钱 vs 间接赚钱
**直接赚钱**: 卖产品 → 收钱 → 利润（传统模式）
**间接赚钱**: 做内容 → 建立信任 → 卖高阶产品（自媒体模式）
> 大多数人的工资是"直接赚钱"的逻辑，自媒体是"间接赚钱"的逻辑。

### ⭐ 框架10: 真钩子 vs 假钩子
| 类型 | 机制 | 观众反应 | 长期效果 |
|------|------|---------|---------|
| 假钩子 | 骗进来→说别的 | 30秒想拉黑 | 互动率雪崩 |
| 真钩子 | 诱进来→说真的 | "他说的都是真话" | 信任→关注→转发 |

### ⭐ 框架11: 开头五层级（从宽到窄）
| 层级 | 范例 | 可迁移性 |
|------|------|---------|
| L1最广泛 | "今天谁刷到谁幸运" | 高但竞争大 |
| L2个人成长 | "任何人任何年纪都要提防的陷阱" | 高 |
| L3商业认知 | "这个世界是可以作弊的" | 中(替换核心词) |
| L4独家方法论 | "心力不足很难赚到钱" | 低 |
| L5一根针 | "如何在24小时找到生意并盈利" | 极低 |

### ⭐ 框架12: 开头公式 = 话题 + Hook + 可信度
**话题**: 讲什么 / **Hook**: 为什么立刻看 / **可信度**: 凭什么信你
范例: "我去年涨粉700万，靠的就是搞清选题和标题的区别。"
→ 话题: 选题vs标题 / Hook: 700万涨粉 / 可信度: 亲身经历

### ⭐ 框架13: 制造悬念，不要直接给答案
错误(给答案): "李亚鹏10年干黄十几个项目，证明人脉不等于赚钱"
正确(留悬念): "善良的李亚鹏，认识了这么多人的李亚鹏，为什么会把每个公司做到濒临倒闭？"

### ⭐ 框架14: 知识付费产品设计 — 产品梯度
```
引流款(199-299): 社群/小课 → 筛选付费意愿
中端款(999-1999): 系统课程 → 核心利润
高端款(4999-9999): 1v1/小班 → 高利润
```

### ⭐ 框架15: 对标表格工作法（DBS最核心的从0到1的方法）
1. 建立表格(生意名称|收入估算|模仿难度1-10)，最低要求**100行**
2. 收入降序 + 难度升序 = 交叉排序找最优
3. 选前3名开始像素级复制

### ⭐ 框架16: 对标五大标准
1. 商业模式是什么？产品结构如何？
2. 收入结构：多少产品？各多少钱？哪个贡献核心收入？
3. 粉丝转化：你用1/10粉丝量怎么复制他的收入？
4. 内容策略：未来30条短视频的选题规划
5. 转化漏斗：私域→付费怎么设计的？

> **对标检验**: 只有<=3人能回答"TA有多少产品？分别什么价格？哪个贡献核心收入？"

### ⭐ 框架17: 产品化思维 — 内容产品 vs 交付产品
| 内容产品(用户付款前看到的) | 交付产品(用户付款后得到的) |
|---|---|
| **这才是真正的产品** | 只是"产品说明书" |
| 影响决策的一切都是产品 | 说明书当然要写得好 |

### 框架18: 爆款是负反馈理论
- 爆款内容会拉来不精准的泛流量
- 泛流量降低转化率，误导算法标签
- 算法误判后推荐更多不精准用户
- 结论: 精准流量比爆款流量更值钱

### 框架19: 赚钱公式 = 把资源转化为收益的系统性行为
三层目标拆解: 宏观目标→子目标→手段(今天就能做的具体动作)

### ⭐ 框架20: 蜜雪冰城的"知识付费"本质
蜜雪冰城不是饮品公司，是**供应链公司**(90%+收入来自卖原材料给加盟商)
**启示**: 做工具让人赚钱 → 靠卖工具持续收费 → 解决知识付费"无复购"的痛点

### ⭐ 框架21: 项目下滑拐点 = 最佳变现期
1. 赚钱期: 保密，狠捞一笔
2. 下滑拐点: 开始教别人赚钱(还有案例可秀)
3. 崩盘前: 把项目打包卖掉退出
**关键**: 要在业务下滑的拐点(而不是崩盘后)开始教。

### 框架22: 天崩开局识别模型（连线500人后）
| 类型 | 问题本质 | 解决方案 |
|------|---------|---------|
| 反向资产型 | "我家有30年老工厂" — 只有履约能力 | 换新供应链，重走完整链路 |
| 虚假流量型 | "我有好几万粉丝但不知卖什么" — 流量粉≠转化粉 | 重新起号 |

### 框架23: 完整转化链路
媒体内容→种草→从众心理(评论区)→首次转化→私域→沉没成本→多次种草(朋友圈)→信任成交→物流履约
> 缺任何一环都不行。

### ⭐ 框架24: AI三支柱
> **AI时代创作者 = 独特提问 × 价值判断 × 情感连接**
- 信息差部分 → AI可替代
- 观点/情感部分 → 不可替代(你的价值)

### 框架25: AI提问质量 = 领域知识厚度
不懂领域→安全提问→AI回答平庸 / 掌握理论框架→框架引导AI→答案飞跃

### 框架26: 多AI交叉验证法
同一问题发>=3个大模型，再让第4个"管家AI"评估优劣
工具: Genspark(自动3模型+管家)、Chatwise Studio

### ⭐ 框架27: 执行力语义等价（最重要的心理框架）
> **"不想做" = "不能做"**
> **"还没做" = "做不了"**
不存在"我想做但还没做"的状态。这是自我欺骗。

### ⭐ 框架28: 执行力公式
> **执行力 = 能力 + 能量**

### SOP-3: 三步循环学习法
**学习阶段(1道闸门+3道检测)**:
- Q1: 这篇有今天就能做的动作？没有→换一篇
- Q2: 这个动作能在24h内完成？不能→拆更小
- Q3: 做完能得到可观察的结果？不能→换动作

**实践阶段**:
- 中途: 遇到没预料的困难？有→记下来(最有价值的反馈)
- 中途: 想放弃？有→逃避模式激活
- 结束: 完成了？→进入复盘；没完成→分析原因

**复盘阶段(3道标准)**:
- 三行反馈写了吗？没写→现在就写
- 有可观察的结果？没有→这个动作可能不是在学习
- 下篇学什么？不知道→回到反馈路由表

**阶段3: 发布(T-0天)**: 标题12-20字→话题3-5个→定时发布(18:00-21:00)
**阶段4: 互动(T+0-2h)**: 发布后2h内回复评论
**阶段5: 复盘(T+1天)**: 完播率>30%+互动率>5%标记→未达分析原因→记录CSV
