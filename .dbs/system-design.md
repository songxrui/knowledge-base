## 一、系统概览

### 1.1 定位

`.dbs/` 是 DBS 系统的**会话管理与编排层**，位于内容结构化工程（`01-内容生产/内容体系/`）之上，负责：

| 层 | 职责 | 实体位置 |
| --- | --- | --- |
| **资产层** | 深度卡、答案之书、转写稿、内容单元 | `cards/` `media/` `01-内容生产/内容体系/02-内容单元库/` |
| **工程层** | 内容结构化、单元抽取、关系索引 | `01-内容生产/内容体系/` |
| **会话层 (.dbs)** | 会话管理、规则、模板、主题地图、选题装配、发布 SOP | `.dbs/` |
| **产出层** | 发布稿、视频脚本、数据分析 | `01-内容生产/进行中/` `07-已发布/` `05-数据统计/` |

### 1.2 核心原则

1. **.dbs 不重复工程层的结构化能力**：内容单元的主库在 `01-内容生产/内容体系/`，.dbs 负责编排与决策
2. **会话即资产**：每次 DBS 会话产出可追溯的决策记录、方法论提炼、选题方向
3. **规则先于执行**：命名、分类、状态规则稳定后，再进入批量操作
4. **双轨输出**：同一选题 → 抖音口播脚本 + 公众号长文，两条独立装配路径

### 3.3 状态追踪

#### 内容生命周期状态机

```
[选题] → [草稿] → [待发布] → [已发布] → [已归档]
  ↓        ↓         ↓          ↓
 废弃      搁置      驳回       撤回
```

| 状态 | 含义 | 存放位置 | 下一步 |
| --- | --- | --- | --- |
| `选题` | 已记录但未确认 | `01-内容生产/选题管理/` | 确认进入草稿或废弃 |
| `草稿` | 正在撰写中 | `01-内容生产/进行中/` | 完稿进入待发布 |
| `待发布` | 已完成待排期 | `01-内容生产/进行中/` | 排期发布 |
| `已发布` | 已公开发布 | `07-已发布/` | 记录数据后归档 |
| `已归档` | 数据已记录 | `07-已发布/` | 反哺方法论 |
| `搁置` | 暂不推进 | 原位置 | 定期审视 |
| `废弃` | 不再使用 | 可删除或标记 | — |

#### 装配管线状态

```yaml
    queued: 0
```

### 3.4 质量门禁

发布前 6 道门禁：

| 门禁 | 检查内容 | 不通过处理 |
| --- | --- | --- |
| G1: 单元溯源 | 所有引用的内容单元可追溯 | 补全 source_documents |
| G2: 去重检查 | 与已发布内容无同义重复 | 调整角度或合并 |
| G3: AI 味检测 | humanizer 评分 < 2/10 | 人工润色 |
| G4: 事实核验 | 数据/引用可验证 | 标注来源或删除 |
| G5: Hook 审查 | 开头 3 秒有钩子 | 重写开头 |
| G6: 行动号召 | 结尾有 CTA | 补全 CTA |

### 3.5 数据记录规范

CSV 字段定义：
```
发布日期,平台,内容标题,章节来源,内容类型,阅读量,点赞,在看,评论,转发,收藏,新增关注,转化动作,备注
```

- `平台`：公众号 / 抖音 / 小红书
- `内容类型`：深度长文 / 短图文 / 口播视频 / 图文视频
- `转化动作`：付费链接 / 引流微信 / 课程报名 / 无
- 每次发布后 24 小时内追加一行

## 六、选题装配工作流

### 6.1 装配管线总图

```
知识资产                    选题触发                  装配执行                发布
   │                          │                        │                     │
深度卡 ─┐                用户需求 ─┐             选题装配模板 ─┐        抖音口播
答案之书 ─┤              热点事件 ─┤             内容单元调用 ─┤       公众号长文
转写稿 ───┼→ 主题地图 → 选题池 → 装配管线 → 草稿 → 质量门禁 →
内容单元 ─┘              数据反馈 ─┘             表达骨架生成 ─┘      小红书图文
```

### 6.2 选题触发源（5 类）

| 触发源 | 频率 | 装配策略 |
| --- | --- | --- |
| **深度卡扩展** | 每周 1-2 篇 | 选 1 张卡 → 调 3-5 个内容单元 → 装配 |
| **答案之书章节** | 每周 1 篇 | 选 1 章 → 拆 3-5 个观点 → 独立成篇 |
| **转写稿提炼** | 每次研究后 | dontbesilent 转写 → 提取新观点 → 补充内容单元 |
| **热点回应** | 按需 | 热点事件 → 匹配现有观点/概念 → 快速装配 |
| **数据驱动** | 每月 | 分析已发布数据 → 爆款方向 → 深度扩展 |

### 6.3 装配流程（6 步法）

```
Step 1: 定选题
  ├── 从选题池中选择 1 个方向
  ├── 明确目标受众和核心论点
  └── 输出：选题卡（1 句话）

Step 2: 调单元
  ├── 检索内容单元库，匹配 QST + CON + OPI + CAS + SOL
  ├── 优先调用 canonical: true 的主单元
  └── 输出：单元调用清单

Step 3: 搭骨架
  ├── 使用选题装配模板
  ├── 确定 6 段结构：痛点 → 冲突 → 展开 → 案例 → 方法 → 收束
  └── 输出：表达骨架

Step 4: 写草稿
  ├── 基于骨架填充正文
  ├── 标注所有内容单元引用
  └── 输出：完整草稿

Step 5: 平台适配
  ├── 抖音：草稿 → 口播脚本（停顿/重音/语速标注）
  ├── 公众号：草稿 → 配图长文（baoyu 风格）
  └── 输出：双平台稿件

Step 6: 质量门禁
  ├── 过 G1-G6 六道门禁
  ├── 不通过 → 回 Step 4
  └── 通过 → 进入发布队列
```

### 6.4 快速装配命令

```bash
  --question QST-20260611-001 \
  --concept CON-20260611-001 \
  --opinion OPI-20260611-003,OPI-20260611-007 \
  --case CAS-20260611-005 \
  --solution SOL-20260611-002

# 生成关系图
node 01-内容生产/内容体系/07-脚本与工具/generate-link-map.js

# 检查去重
node 01-内容生产/内容体系/07-脚本与工具/generate-duplicate-candidates.js

# 系统总览
node 01-内容生产/内容体系/07-脚本与工具/summarize-system.js
```

### 6.5 内容单元调用优先级

| 优先级 | 单元类型 | 调用策略 |
| --- | --- | --- |
| P0 | 观点单元 (OPI) | 每篇至少 1 个核心观点，最多 3 个 |
| P1 | 概念单元 (CON) | 出现新概念时必须引用，避免重复定义 |
| P2 | 案例单元 (CAS) | 每个观点配 1 个案例，避免空洞 |
| P3 | 方案单元 (SOL) | 结尾必须提供可行动步骤 |
| P4 | 问题单元 (QST) | 开头用，制造共鸣 |

  - 中段 2（400 字）：案例分析
  - 中段 3（400 字）：方法论 / 方案
  - 结尾（200 字）：金句 + CTA
- [ ] 每 300 字插入一个配图点位标记 `[图: 描述]`

  - 风格统一：低饱和 + 留白 + 手写字体点缀
- [ ] 公众号编辑器排版
- [ ] 手机预览检查

#### 阶段 4：发布（T-0 天）

- [ ] 发布时间：工作日 7:00-8:00（早读场景）
- [ ] 标题：20-30 字，制造好奇心缺口
- [ ] 摘要：64 字以内，补充标题未说完的信息
- [ ] 文末 CTA：引导关注/加微信/看更多
- [ ] 同步转发到朋友圈 + 相关微信群

#### 阶段 5：数据复盘（T+1 / T+7 天）

### 7.3 双平台协同 SOP

#### 协同策略

```
同一选题 → 先公众号（深度长文）→ 后抖音（精华口播）
         → 或先抖音（测试热度）→ 达标 → 公众号（深度扩展）
```

#### 协同检查清单

- [ ] 同一选题的双平台稿件使用了相同的内容单元？（保证一致性）
- [ ] 表达角度有差异化？（公众号深度 vs 抖音冲击力）
- [ ] CTA 指向同一转化目标？（统一引导到微信/课程）
- [ ] 发布时间错开？（至少间隔 2 天）
- [ ] 数据关联记录？（CSV 中标注关联选题 ID）

#### 选题复用规则

| 场景 | 策略 |
| --- | --- |
| 抖音视频爆了（完播率 > 40%） | 3 天内扩展为公众号深度长文 |
| 公众号文章分享率高（> 5%） | 3 天内拆成 2-3 条抖音口播 |
| 双平台都表现差 | 标记选题方向需调整，不重复使用 |
| 抖音差但公众号好 | 说明选题偏深度，后续以公众号为主 |
| 公众号差但抖音好 | 说明选题偏冲击力，后续以抖音为主 |
