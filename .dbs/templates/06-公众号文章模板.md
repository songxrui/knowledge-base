# 公众号文章模板

> 深度长文 | ≥2000 字 | baoyu 配图
>

---

## 文章结构

### 1. 标题（20-30 字）
**目的**：在信息流中制造点击欲望

**6 种标题公式（选其一）**：
| 公式 | 结构 | 示例 |
|------|------|------|
| 反共识 | {常识}是错的，{真相}才是对的 | "每天进步 1%是错的——复利的真正前提没有人告诉你" |
| 问题+答案 | 为什么{问题}？因为{答案} | "为什么你总是在晚上失控？因为你的多巴胺基线已经崩了" |
| 具体数字 | {数字}个{方法/习惯/原则}，让你{结果} | "追踪这 5 个数字，就能判断你整个系统的健康度" |
| 身份标签 | 给{身份}的{领域}指南 | "给 22 岁年轻人的第一性原理使用手册" |
| 恐惧+方案 | {问题}不可怕，可怕的是{更深层问题} | "成瘾不可怕，可怕的是你以为这是意志力问题" |
| 故事悬念 | {一个意外发现}，让我重新理解{概念} | "戒手机 10 年失败后，我发现问题不在手机上" |

```
[标题]
{20-30 字，制造好奇心缺口}
```

---

### 2. 摘要（≤64 字）
**目的**：补充标题未说完的信息，强化点击理由

```
[摘要]
{1-2 句话，补充标题的未尽信息，或预告文章的核心价值}
```

---

### 3. 开头 Hook（~150 字）
**目的**：让读者产生"必须读完"的冲动

**开头模式（选其一）**：
| 模式 | 写法 | 适用场景 |
|------|------|---------|
| 悬念故事 | 用个人经历开篇，制造"然后呢？" | 有真实经历的选题 |
| 认知冲突 | 直接推翻读者已有认知 | 反共识类选题 |
| 具体数字 | 用一个震撼数字开场 | 研究/数据类选题 |
| 场景共鸣 | 描述读者熟悉的痛苦场景 | 实用方法类选题 |

```
[开头Hook]
{150 字左右，让读者确信这篇文章会给他一个之前不知道的答案}
```

---

### 4. 正文结构：五段式
**目的**：问题 → 分析 → 案例 → 方法论 → 行动建议

```
[第一部分：锚定问题] (~300 字)
{把读者带入一个他们正在经历的真实问题}
- 描述具体场景和痛苦
- 指出常见的错误解法
- 预告本文将给出的不同答案

[第二部分：深层分析] (~500 字)
{揭示问题的底层机制}
- 引入核心概念或框架（来源:: 标注出处）
- 解释为什么常见解法不work
- 用因果链展示问题的真正根源

[第三部分：案例/故事] (~400 字)
{用真实案例让分析落地}
- 个人经历或读者案例
- 展示"之前"和"之后"的对比
- 用具体细节增强可信度

[第四部分：方法论] (~500 字)
{给出可操作的解决方案}
- 分 3-5 个步骤
- 每步有明确的操作指令
- 配套思维模型或检查清单

[第五部分：行动建议 + CTA] (~300 字)
{告诉读者接下来该做什么}
- 最小可执行的第一步
- 常见坑位提醒
- 自然引出商业化钩子：产品/社群/课程引导
```

---

### 5. 配图计划（4-6 张）

| 位置 | 类型 | 内容 |
|------|------|------|
| 封面 | 16:9 横版 | 标题大字 + 简约背景（baoyu-cover-image） |
| 开头后 | 概念图 | 核心框架可视化（baoyu-image-cards） |
| 分析段 | 数据图 | 关键数据或对比（baoyu-article-illustrator） |
| 案例段 | 场景图 | 故事场景配图 |
| 方法论段 | 步骤图 | 步骤清单或流程图 |
| CTA 前 | 金句卡 | 全文最核心的一句话 |

## 质量检查清单

### AI 味扫描
- [ ] 禁用词 0 命中（更好/真正/深入/系统性/全面/有价值/有意义……）
- [ ] AI 味模式 0 命中（排比堆砌/滥用引用/虚假对比/总结腔/定义开头）
- [ ] "来源::" 标注 ≥3 条

### 深度检查
- [ ] 字数 ≥2000 有效中文字符
- [ ] 至少有 1 个"反共识"观点（读者之前不知道的）
- [ ] 至少有 1 个具体案例（非虚构）
- [ ] "3 个月后还值得看"？

### 商业化检查
- [ ] CTA 自然嵌入（不是硬广）
- [ ] 指向明确的转化目标（微信/社群/课程）

### 排版检查
- [ ] 段落长度：手机屏幕 3-5 行一段
- [ ] 重点加粗：全文 ≤10 处
- [ ] 配图位置：每 300-500 字一张图
- [ ] 原文链接：指向历史相关文章

## 完整示例（前两段）

```
[标题]
追踪这5个数字，就能判断你整个系统的健康度——认知目标函数入门

[摘要]
你不需要追踪100个指标。把这5个数字每周记录一次，3个月后你会看到自己系统的完整画像。

[开头Hook]
我试过很多自我管理工具。Notion、Obsidian、各种习惯追踪App——全都失败了。
不是因为工具不好。是因为我追踪了太多东西。
每天步数、睡眠分数、屏幕时间、番茄钟数、阅读页数、体重、心情评分……
信息变成了噪音。我从"管理自己"变成了"被仪表盘管理"。
直到我学了认知目标函数这个概念。

[第一部分：锚定问题]
你打开手机，习惯性地看一眼屏幕时间——6小时32分钟。
你知道这不是一个好数字，但你不确定它到底意味着什么。
是今天的自控力差？还是这周的项目太忙？还是你最近睡眠不足导致意志力下降？
你不知道。所以你关掉屏幕时间，滑动到下一个 App。
这就是"指标迷雾"——你有数据，但没有函数。
……
```
