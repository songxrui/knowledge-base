# 抖音口播脚本模板

> 基于 DBS Hook 公式 | 30-90 秒 | 300-500 字
> 适用形式：不露脸知识视频（HyperFrames）

---

## 脚本结构

### 1. Hook（0-5 秒，~30 字）
**目的**：制造认知冲突/好奇心缺口，让用户停下滑动

**6 种 Hook 公式（选其一）**：
| 公式 | 示例 |
|------|------|
| 反共识 | "你以为多巴胺让你快乐？它真正的作用是让你痛苦。" |
| 具体数字 | "戒游戏 10 年失败的人，问题不出在自律上。" |
| 问题直击 | "为什么你总是在晚上失控？" |
| 身份认同 | "如果你也是那种知道很多却行动很少的人……" |
| 结果承诺 | "用这个方法，我在 14 天内戒掉了刷手机。" |
| 对比冲突 | "富人买资产，穷人买负债——你的手机是哪个？" |

```
[Hook]
{一句话制造认知冲突或好奇缺口}
```

---

### 2. 核心观点（5-15 秒，~100 字）
**目的**：在 Hook 之后快速交付核心主张

```
[核心观点]
{一句话表达你的核心主张，让观众知道接下来要讲什么}
```

**要求**：
- 一句话说清楚
- 不使用"其实/真正/本质上"等空转词
- 观点必须可验证或可操作

---

### 3. 论证/案例（15-60 秒，~200 字）
**目的**：用 1-2 个论据或案例支撑观点，≤3 个信息点

```
[论证]
{用具体案例、数据或逻辑推演展开观点。信息点不超过 3 个}
```

**论证模式（选 1-2 种）**：
| 模式 | 结构 | 适用场景 |
|------|------|---------|
| 因果链 | A→B→C 层层推导 | 解释"为什么"类观点 |
| 对比法 | 错误做法 vs 正确做法 | 提供方法论的选题 |
| 案例法 | 真实故事 → 提炼原理 | 有个人经历的选题 |
| 数据法 | 具体数字 → 解读含义 | 有研究支撑的选题 |

---

### 4. 行动号召 / CTA（60-90 秒，~50 字）
**目的**：告诉观众接下来做什么

```
[CTA]
{一个清晰的行动指令：关注/私信/看主页/看下一条}
```

**CTA 类型**：
| 类型 | 话术示例 |
|------|---------|
| 关注引导 | "如果你也在重建自己的系统，关注我" |
| 主页引导 | "主页有 35 张深度卡的完整清单" |
| 私信引导 | "私信『多巴胺』获取完整框架" |
| 系列预告 | "下一条讲怎么用 14 天实验验证这个方法" |

---

## 口播检测清单

- [ ] 念一遍不拗口？（口语化，无书面句式）
- [ ] Hook 能在 3 秒内抓住注意力？
- [ ] 核心信息点 ≤3 个？
- [ ] 有具体的案例或数据？
- [ ] 无效词数量：禁用词 0 命中 + AI 味模式 0 命中
- [ ] 字数在 300-500 之间？

---

## 完整示例

```
[Hook]
如果你戒手机戒了 10 年还在失败，问题根本不在你不够自律。

[核心观点]
成瘾的反面不是戒断，是连接。当你和真实世界建立了足够多的连接，手机自然就不香了。

[论证]
我拿自己举例。过去 10 年我试过删 App、设屏幕时间、甚至用老年机——全失败了。
因为我只是在"戒断"，没有建立替代连接。
后来我做了三件事：每天早上先运动 20 分钟、加入了一个线下读书会、把手机充电器挪到了客厅。
三周后，我每天刷手机的时间从 6 小时降到了 1.5 小时。
核心原理是：多巴胺不是快乐分子，它是"想要"分子。你要做的不是消灭"想要"，而是让它指向正确的东西。

[CTA]
如果你也在重建自己的多巴胺系统，关注我，主页有 35 张深度卡的完整索引。
```
