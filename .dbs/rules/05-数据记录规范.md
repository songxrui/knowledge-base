# DBS 数据记录规范 v1.0

## 数据存储位置

| 数据类型 | 存储位置 | 格式 |
|---------|---------|------|
| 发布数据 | `05-数据统计/数据统计表.csv` | CSV |
| 选题记录 | `01-内容生产/选题管理/00-选题记录.md` | Markdown 表格 |
| 会话产出 | `.dbs/sessions/knowledge-base/` | Markdown |
| 质量门禁结果 | `.dbs/rules/04-质量门禁.md` | 检查清单 |

## CSV 数据表字段规范

### 公众号发布记录

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `date` | YYYY-MM-DD | ✅ | 发布日期 |
| `title` | string | ✅ | 文章标题 |
| `theme` | string | ✅ | 主题代码（如 COG-DOP） |
| `topic_id` | string | ✅ | 选题唯一 ID |
| `reading_count` | int | ✅ | 阅读量 |
| `like_count` | int | ✅ | 点赞数 |
| `wow_count` | int | ✅ | 在看数 |
| `comment_count` | int | 选填 | 评论数 |
| `share_count` | int | 选填 | 分享/转发数 |
| `new_followers` | int | 选填 | 新增关注数 |
| `conversion` | string | 选填 | 转化描述 |
| `linked_topic_id` | string | 选填 | 关联抖音选题 ID |
| `notes` | string | 选填 | 备注 |

### 抖音发布记录

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `date` | YYYY-MM-DD | ✅ | 发布日期 |
| `title` | string | ✅ | 视频标题 |
| `theme` | string | ✅ | 主题代码 |
| `topic_id` | string | ✅ | 选题唯一 ID |
| `play_count` | int | ✅ | 播放量 |
| `like_count` | int | ✅ | 点赞数 |
| `comment_count` | int | 选填 | 评论数 |
| `share_count` | int | 选填 | 分享数 |
| `completion_rate` | float | ✅ | 完播率（百分比） |
| `new_followers` | int | 选填 | 新增关注数 |
| `linked_topic_id` | string | 选填 | 关联公众号选题 ID |
| `notes` | string | 选填 | 备注 |

## 数据记录时间线

| 时间点 | 动作 |
|--------|------|
| 发布当天 | 在选题记录中标记"已发布" |
| T+1 天 | 记录初始数据到 CSV |
| T+3 天 | 更新数据（抖音此时数据基本稳定） |
| T+7 天 | 最终数据确认 + 复盘 |

## 数据质量标准

### 数据完整度目标
- 发布后 24h 内记录率：100%
- 必填字段完整度：100%
- 选填字段完整度：≥80%

### 异常数据处理
| 异常 | 处理方式 |
|------|---------|
| 数据为 0 | 确认是否为真实 0，标注确认时间 |
| 数据缺失 | 标记为 `N/A`，记录缺失原因 |
| 数据异常高/低 | 标注 `[异常]`，附简要分析 |
| 数据跨平台不一致 | 在 `notes` 字段中对比说明 |
