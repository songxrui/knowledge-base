# DBS 知识系统使用指南

> 版本：v1.0.0 | 更新：2026-07-01

## 这是什么？

`.dbs/` 是 DBS 知识系统的**会话管理与编排层**，负责：
- 管理 DeepSeek 代理会话的记录与追溯
- 编排内容从选题 → 脚本 → 发布的完整流程
- 提供规则、模板、索引、SOP 四大基础设施

## 目录导航

| 目录 | 用途 | 何时使用 |
|------|------|---------|
| `rules/` | 系统运行规则（命名、分类、状态、质量、数据） | 不确定怎么命名/归类时 |
| `templates/` | 可复用内容模板（深度卡、单元、脚本、文章） | 需要创建新内容时 |
| `indexes/` | 跨资产快速查找（深度卡、主题、单元、转写稿、发布） | 需要定位素材时 |
| `topic-maps/` | 17 主题的完整地图 | 选题或做内容规划时 |
| `assembly/` | 选题装配工作区 + 平台发布队列 | 准备写稿/发布时 |
| `sop/` | 双平台发布标准流程 | 即将发布时逐项检查 |
| `sessions/` | DBS 会话完整记录 | 记录/回顾会话产出时 |
| `archive/` | 历史会话与废弃设计归档 | 内容过期时移入 |

## 快速开始

### 我要写一篇公众号文章

1. 打开 `assembly/wechat/_queue.md`，认领或新建选题
2. 检索 `indexes/01-深度卡索引.md` 和 `indexes/02-主题索引.md` 找素材
3. 使用 `templates/06-公众号文章模板.md` 结构写稿
4. 发布前对照 `rules/04-质量门禁.md` 逐项检查
5. 按 `sop/02-公众号发布SOP.md` 执行发布流程
6. 发布后在 `05-数据统计/数据统计表.csv` 追加数据

### 我要做一条抖音口播

1. 打开 `assembly/douyin/_queue.md`，认领或新建选题
2. 使用 `templates/05-抖音口播脚本模板.md` 写300-500字脚本
3. 按 `sop/01-抖音发布SOP.md` 执行 HyperFrames 制作与发布

### 我要检索素材

1. 先查 `indexes/02-主题索引.md` 确定主题编号
2. 再查 `indexes/01-深度卡索引.md` 找到相关卡片
3. 深入 `indexes/03-内容单元索引.md` 找到可复用内容单元

## 核心规则

1. **.dbs 不重复工程层能力**：内容单元主库在 `01-内容生产/内容体系/`，.dbs 负责编排与决策
2. **会话即资产**：每次 DBS 会话产出可追溯的决策记录
3. **规则先于执行**：命名、分类、状态规则稳定后，再进入批量操作
4. **双轨输出**：同一选题 → 抖音口播脚本 + 公众号长文，两条独立装配路径
