## 一、DBS五维诊断

### 1. 观点层 — 核心论点与认知冲突模式

dontbesilent 的核心观点构建遵循**"反常识三板斧"**模式：

#### 1.1 典型认知冲突类型

| 冲突模式 | 示例 | 代表文章 |
|---------|------|---------|
| **"先X后Y"颠覆** | "先涨粉后变现"是错的 → 先变现后涨粉 | 2025-01-13, 2025-04-16 |
| **"常识=陷阱"反转** | "想清楚再干"是错的 → 越穷越要先干 | 2025-03-24, 2025-04-29 |
| **"你以为的好事其实是坏事"** | 粉丝量没用、涨粉是不务正业 | 2025-06-16, 2025-05-18 |
| **"成功的反面才是真相"** | 打工逻辑和创业逻辑完全相反 | 2025-05-22, 2025-06-20 |
| **"把A说成B"重新定义** | 内耗=心理资本匮乏、货只是内容的赠品 | 2025-05-12, 2025-06-09 |
| **"场景降维打击"** | 蜜雪冰城做知识付费年入百亿 | 2025-04-21 |

#### 1.2 核心论点库（按频率）

1. **"低粉高变现" > "涨粉思维"** — 出现10+次，是最核心论点
   - 一万粉丝月入十万 vs 十万粉丝月入一万
   - 粉丝量是虚荣指标，真正重要的是"信任资产"
   - 强人设 + 自有产品 = 收入差10倍（相比接广告）

2. **"内容即产品" > "先做内容再变现"** — 出现8+次
   - 第一天就做能变现的流量
   - 货只是内容的赠品
   - 在小红书，笔记才是真正的产品

3. **"像素级复制 ≠ 抄袭"** — 出现5+次
   - 复制的不是内容本身，是"观点稀缺性"的生产能力
   - 三段论：核心观点 + 内容形式 + 商业模式
   - 原创是IP生意的必要条件，搬运只能赚短期快钱

4. **"知识付费卖的是情绪/获得感，不是干货"** — 出现4+次
   - 用户买课是为了"爽的获得感"，不是学习
   - 学习反人性 → 买完不看是常态 → 不影响复购
   - 买前靠公域免费内容激发渴望，买后靠好评维持信任

5. **"不挣钱的业务都长一个样"** — 出现3+次
   - 核心特征：1v1咨询模式（卖时间）、无标准化、无复购
   - 做咨询越接单越穷，本质是变相打工

### 2. 结构层 — 文章结构模式

#### 2.1 主导结构："钩子→案例→分析→方法论→收尾金句"

```
[开头 0-5秒] 钩子（数据冲击/颠覆认知/悬念）
    ↓
[5-20秒] 具体案例/故事（自己的或连线遇到的）
    ↓
[20-80%] 逐层分析拆解（通常3个点）
    ↓
[80-95%] 可操作方法论（编号列出）
    ↓
[最后5%] 收尾金句（强化核心论点）
```

#### 2.2 变体结构

| 结构类型 | 特征 | 适用场景 |
|---------|------|---------|
| **案例拆解型** | 完整复述一个连线/案例→逐层拆解→提炼方法论 | 小红书投流卖首饰、直播连麦月入20万 |
| **三段论型** | 规则1→规则2→规则3，并列递进 | 内容变现三大规则、起号三个阶段 |
| **"先破后立"型** | 先推翻一个常识→再建立新认知→给出路径 | 垂直流量账号必死、先涨粉后变现是错的 |
| **个人经历型** | "我花了X年才搞清楚"→回顾踩坑→提炼洞察 | 知识付费的免费vs付费内容问题 |
| **热点借势型** | 抓热点事件→嫁接商业分析→输出观点 | 京东交社保、蜜雪冰城上市 |

#### 2.3 结构规律

- **99%的文章使用"故事引入"开头**，极少直接讲道理
- **"3"是黄金数字**：几乎所有拆解都分3点/3阶段/3规则
- **必须有案例**：要么是连线案例、要么是个人经历、要么是知名品牌
- **结尾必回收论点**：最后一句话必须呼应开头钩子

### 3. 钩子层 — 开头钩子技术

#### 3.1 钩子技术分类

| 钩子类型 | 使用频率 | 典型句式 |
|---------|---------|---------|
| **颠覆认知** | ★★★★★ | "99%的人不知道..." / "所有教你X的人都在耍流氓" / "千万不要X" |
| **数据冲击** | ★★★★ | "一张图片，两小时赚3000" / "一条视频播放千万涨粉6万" / "成本17我卖18" |
| **悬念制造** | ★★★★ | "一个问题毁掉你的知识付费，我花了四年才搞清楚" / "连线几百人之后我发现..." |
| **痛点共鸣** | ★★★ | "有流量又无法变现的人" / "每天都在思考创新的聪明人最不容易赚到钱" |
| **身份展示** | ★★★ | "我全网20万粉丝，输出上百万字" / "去年涨粉70万，我想说..." |
| **问题导向** | ★★ | "为什么你的账号光涨粉不赚钱？" / "赚不到钱是因为上班上多了？" |

#### 3.2 钩子的"前5秒公式"

dontbesilent 自己拆解过他的爆款钩子公式：

```
前5秒 = [结果数据] + [反常识观点]

案例1: "我去年发了篇帖子，两天半从零涨到一万粉丝"（结果数据）
        + "说的是像素级复制别人的生意"（反常识）

案例2: "成本17块我卖18，同行卖3.9"（结果数据/冲突）
        + "但我是怎么赚钱的"（悬念）
```

#### 3.3 关键发现

- **"我"字开头率极高**：几乎每篇文章开头都有"我"——建立身份可信度
- **标题即钩子**：抖音标题本身就是前1-2秒的视觉钩子
- **"骑墙式"对比**：经常用"A和B表面矛盾实为统一"制造张力
- **前置结果**：先告诉你"我做到了X"，再告诉你怎么做到的——用结果换耐心

### 4. 证据层 — 案例来源与可信度构建

#### 4.1 证据来源体系

| 证据类型 | 使用频率 | 可信度 | 典型用法 |
|---------|---------|--------|---------|
| **个人实操案例** | ★★★★★ | 高 | "我在小红书开直播，24人当场付费" |
| **直播连线案例** | ★★★★★ | 中高 | "连线了几百人之后我发现..." |
| **知名品牌类比** | ★★★ | 中 | "蜜雪冰城上市" / "京东交社保" |
| **查理芒格/名人引用** | ★★ | 高 | "查理芒格说过...放到自媒体也一样" |
| **数据截图/后台展示** | ★★ | 极高 | 店铺后台截图：6万粉丝、4000+已售、97.8%好评 |
| **"你去看"实证** | ★★ | 中 | "你去看XX平台上的工具人账号，一个月挣一千都算多的" |

#### 4.2 可信度构建的层级递进

```
第一层：个人结果背书（"我做到了"）
    ↓
第二层：大量样本验证（"连线了几百人"）
    ↓
第三层：理论框架化（"我把它总结为X个规则"）
    ↓
第四层：外部权威嫁接（"查理芒格也说过"）
```

#### 4.3 关键特征

- **"反证据"手法**：先举反面案例再给正面解法，增强说服力
- **"你可以验证"**：经常让观众自己去平台验证他的说法
- **"我的观察是"**：保留一手经验的主观性，不伪装绝对客观
- **数据精确到个位**：31个人付费、97.8%好评率、52%完播率——精确数字比模糊数字可信10倍

### 5. 表达层 — 语言风格特征

#### 5.1 风格标签

| 维度 | 特征 | 评分(1-10) |
|------|------|-----------|
| 口语化程度 | 高度口语化，接近日常对话 | 9 |
| 节奏感 | 短句为主，快节奏切换 | 8 |
| 金句密度 | 每1-2分钟一个可截图的金句 | 8 |
| 个人化程度 | 大量"我"的视角和经历 | 9 |
| 对抗性 | 常使用"所有X都是Y"的绝对化表达 | 7 |
| 逻辑清晰度 | 层层递进，因果链条明确 | 8 |

#### 5.2 语言技术工具箱

1. **"你"字直呼**：句句指向观众，拉近距离
   - "你整天在抖音小红书上发什么婆媳关系..."
   - "你得有多大脸才能拍出一个垃圾..."

2. **"就"字强化**：用"就"制造果断感
   - "你就记住一句话" / "这个事情就不该写" / "你就周末两条"

3. **对比句式**：A vs B 制造张力
   - "像素级复制，年入百万。搬运抄袭，颗粒无收"
   - "流量生意抄面子，品牌生意抄里子"

4. **类比降维**：用日常场景解释商业逻辑
   - "测评"→便利店货架 → 淘宝无限货架 → 小红书信息流
   - "内耗"→心理资本→小时候考试没被夸奖

5. **具体到抽象再回具体**：
   - 具体案例 → 抽象规律 → 可操作步骤

6. **口语化连接词**：
   - "所以也就是说..." / "说的再白一点..." / "OK这个事情其实我说的..."

#### 5.3 节奏控制

- **短句轰炸**（2-5字）: 用于强调观点
- **中句叙事**（8-15字）: 用于案例讲述
- **长句收尾**（15-25字）: 用于总结升华
- **停顿留白**：关键观点前后有明显停顿（听感上）

## 二、可复用的内容模板/套路

### 模板1："从X到Y"四步法

```
第1步：我遇到了什么问题/看到了什么现象
第2步：我尝试了A方法但失败了
第3步：我发现了真正的原因是B
第4步：我把B总结成了可复制的方法
```

### 模板2：连线案例拆解模板

```
① 连线对象的背景/数据（"1000粉丝月入4万"）
② 他们做了什么（具体操作还原）
③ 为什么这个模式有效（底层逻辑拆解）
④ 你能怎么复用（可操作建议）
⑤ 边界条件/适用场景限制
```

### 模板3："反常识三连"

```
常识A → 为什么A是错的 → 正确做法B → B的底层逻辑 → 你的行动清单
```

### 模板4："三个规则"并列模板

```
规则1：XXX（具体解释+案例）
规则2：XXX（具体解释+案例）
规则3：XXX（具体解释+案例）
结尾：三个规则之间的关系/优先级
```

### 模板5："我花了X年才搞清楚"个人进化模板

```
① 几年前的错误认知/做法
② 当时的"成功"（赚到小钱）
③ 后来发现的根本问题
④ 现在的正确认知
⑤ 为什么花了这么久（反思深度）
```

## 三、商业变现方法论

### 3.1 核心变现公式

```
收入 = 信任资产 × 自有产品 × 转化效率

信任资产 > 粉丝数量
自有产品收入 ≈ 广告收入 × 10
高客单价 > 低客单价（但需要更强人设）
```

### 3.2 产品设计原则

| 原则 | 说明 | 来源文章 |
|------|------|---------|
| **先卖再做** | 先验证有人付费，再生产产品（"一张图片赚3000"） | 2024-12-17 |
| **卖情绪不卖干货** | 知识付费的付费动机是"获得感"而非"学习" | 2025-05-07 |
| **课程解决"买后"的问题，公域解决"为什么买"** | 交付质量影响好评率，不影响购买决策 | 2025-06-05 |
| **高价产品卖"人"，低价产品卖"货"** | IP逻辑 vs 卖货逻辑的本质区别 | 2025-04-08 |
| **好评率 > 销量（过冷启动后）** | 97.8%好评率是及格线 | 2025-06-05 |
| **产品不能太"有用"** | 太有用的产品会阻止复购 | 2025-06-10 |
| **总想把产品做得太有用，是在耽误赚钱** | 反直觉：产品的"有用"和"好卖"是两回事 | 2025-06-10 |

### 3.3 定价策略

- **"卖得动就涨价，卖不动就降价"** — 最务实的定价逻辑
- 虚拟资料从99→更高价的阶梯：基础价验证→持续涨价
- 低粉高变现的核心不是粉丝量，是客单价×转化率
- 成本17卖18的案例：靠引流款+利润款复购的组合策略

### 3.4 引流方法论

| 方法 | 核心逻辑 | 来源 |
|------|---------|------|
| **免费资料引流=负债** | 免费送资料引来的不是客户是羊毛党 | 2025-06-01 |
| **公域种草→私域收割** | 四维成本分配：种草/收钱/曝光/复购 | 2025-06-30 |
| **爆款开头搬运法** | 搬别人前15秒爆款开头+自己后段输出 | 2025-03-14 |
| **不投流也可起号** | 靠内容本身完成冷启动 | 2025-06-10 |

### 3.5 私域运营

- **私域不是加微信**：低价产品不值得做私域（获客成本>20元就不做）
- **私域里的顾客 vs 网友**：公域种草要让用户先成为"顾客"而非"网友"
- **四维模型**：种草、收钱、曝光、复购在公私域的不同分配
- **使命愿景价值观在私域讲**：公域不方便说的话，私域来补

### 3.6 1v1咨询的陷阱

- 做1v1咨询本质是"卖时间"，越接单越穷
- 解决方案：标准化 → 产品化 → 规模化
- 如果无法写出SOP，就无法规模化

## 四、平台运营技巧

### 4.1 小红书

| 特征 | 策略 |
|------|------|
| **无电商闭环** | 小红书GMV仅4000亿（抖音3.5万亿），不能"测评" |
| **笔记即产品** | 在小红书赚钱的真正产品是你的笔记内容 |
| **双列信息流** | 封面+标题决定点击率（与抖音单列不同） |
| **图文+视频混排** | 图文能力在小红书比在抖音重要得多 |
| **搜索心智强** | 小红书用户有"搜"的习惯，SEO思维重要 |

### 4.2 抖音

| 特征 | 策略 |
|------|------|
| **前5秒定生死** | 5秒完播率<40%=垃圾, 50%=小爆款, >60%=大爆款 |
| **单列信息流** | 没有封面竞争，全靠前几秒内容 |
| **有电商闭环** | 抖音商城可以"不靠内容只卖货" |
| **投流文化成熟** | 投流讲究"快准狠" |

### 4.3 视频号（蝴蝶号）

| 特征 | 策略 |
|------|------|
| **前3秒定生死** | 比抖音更短，只有3秒窗口 |
| **社交裂变强** | 基于微信生态的传播逻辑 |

### 4.4 跨平台策略

- **"三平台分工"**：抖音拍视频、小红书做图文、蝴蝶号搞直播
- **不要同时起所有平台**：精力是有限的（"哪个都够你喝一壶的"）
- **内容形式因平台而异**：同一观点在不同平台需要不同的"形式盒子"
- **全球冷启动过万粉方法论**：任意内容平台通用（2025-06-10）

## 五、心理/执行/认知框架

### 5.1 心理资本理论

- **核心定义**：内耗 = 心理资本匮乏
- **形成机制**：小时候的努力未得到正向反馈 → 心理资本无法积累 → 长大后不敢做决定、不敢让别人做决定
- **修复路径**：做5-10个副业拿小结果 → 累积心理资本 → 再承受真正的商业打击
- **合伙人筛选**：心理资本低的人不适合合伙创业

### 5.2 执行力框架

| 框架 | 核心观点 |
|------|---------|
| **确定性→执行力** | 执行力差的原因是"不确定性"太高，降低不确定性就能提高执行力 |
| **勇气>能力** | 自媒体时代欠缺的不是能力是勇气 |
| **自媒体煎熬期** | 99%的人在煎熬期被淘汰，熬过去就是竞争壁垒 |
| **"试试就知道了"** | 过度思考不如行动验证 |

### 5.3 认知升级框架

| 框架 | 核心观点 | 来源 |
|------|---------|------|
| **系统性思维** | 赚钱是一个系统，不是单点技能 | 2025-06-28 |
| **逻辑清晰=赚钱前提** | 逻辑混乱的人做不好任何生意 | 2025-06-17 |
| **打工vs创业逻辑相反** | 上班上多了会毁掉创业思维 | 2025-05-22 |
| **"老子时间很贵"** | 摆脱时间换钱的思维枷锁 | 2025-05-18 |
| **逆商=财富上限** | 年入百万的决定要素是逆商 | 2025-04-02 |
| **财务自由倒推法** | 远期目标→当下应该做什么 | 2025-05-14 |
| **判断力操作系统** | 线下课的核心：一套判断力框架 | 2025-05-28 |
| **"语言的边界"** | 你不会表达的东西你就无法思考 | 2025-04-14 |
| **"内容=债权"** | 做内容赚钱的本质是对观众构建债权 | 2025-04-20 |

### 5.4 反内耗工具箱

1. **"搞砸了无非是算法不推流量"** — 降低失败恐惧
2. **"不要当成绝望，只是摸索阶段"** — 重新框架化困难
3. **"允许曲高和寡，这是人设的一部分"** — 接受不完美
4. **"自媒体：光线要差、画面要抖、场景要乱"** — 破除完美主义（2025-06-23）
