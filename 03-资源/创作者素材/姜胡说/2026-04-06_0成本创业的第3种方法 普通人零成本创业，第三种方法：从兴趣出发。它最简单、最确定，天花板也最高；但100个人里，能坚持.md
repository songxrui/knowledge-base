# 0成本创业的第3种方法 普通人零成本创业，第三种方法：从兴趣出发。它最简单、最确定，天花板也最高；但100个人里，能坚持做下去的，可能就1个。不是因为它太难，而是你熬不过早期没结果。 
我之前讲过两种零成本赚钱：
第一种：工作里赚钱。你有信息源，懂别人不懂的。比如搞汽车，周末陪人看车；在酒店上班，知道谁需要摄影师、谁家要结婚，你能做对接。你还能用身份背书，比如你是老师，你推荐的东西，别人更愿意听。
第二种：消费里赚钱。选购前你帮人做决策，购买中你陪同解决问题，还能帮人降低成本。比如你在国内，别人在国外，你帮忙代买。 
第三种：使用里赚钱。买了东西不会装，你来帮装；用完再分享，也有商机。
今天重点说“兴趣变现”。兴趣起步，大概几条路：
1）提供服务/技术；2）做产品；3）做选品；4）做场域连接、做社群；5）做知识变现。 
先讲最小的：服务。你真的喜欢猫、喜欢小动物，就会更细、更耐心，很多细节别人做不到。节假日很多人出门，猫狗带不走，在家谁照顾？这就是缺口。你不出门，又喜欢小动物，就能做上门照看：朋友圈或平台发消息，展示你平时的小动物照片，写清楚一天多少钱；每天怎么照顾，你直播也好、拍照回传也好，都能让对方安心。专业机构不一定比得了你，成本也比不了你。 
我以前也一样。我喜欢鼓捣机器：电脑坏了、系统要重装、复印机出问题，周边很多人都找我，有时也能赚点钱。这种方式有时间成本，但它是最好的入口。 
第二条路：场域连接。互联网越发达，人越需要连接。我年轻时做过“绿野仙踪”，驴友通过论坛认识，约着爬四姑娘山，关系就建立了。我后来做画画社群、玩戏剧、做“跨界疯人院”，最开始全免费，后来人越来越多。为什么我做短视频一上来就有人？我说的不是技巧有多强，而是我之前积累了人。 
第三条路：做产品。你喜欢什么就专注什么，把你的专注放到网上呈现，别人看到就会信任你。因为你更专注，所以东西更好，自然会下单。 
第四条路：精选产品，你不一定自己制作，但是你有品位。你知道什么是好东西。 
第五条路：知识变现。内容/课程/咨询。得到就是一个很典型的案例。 
热情持续投入 → 能力深度积累 → 建立信任溢价 → 多元商业转化 
所有变现的底层是信任。你的热情越深、投入越久，积累的专业度越强，粉丝就越信任你推荐的东西、你建立的社群、你选择的产品。
