# 从 0 到 1 低成本创业 最好的商业灵感来自你的日常痛点。把问题变成机会，这就是创业的开始。 
如何发现商业机会？
随身带本小本子，记录下日常遇到的"烦恼"。都是潜在的商机。
- 今天遇到什么让你不爽的事？
- 拖了很久都没解决的问题是什么？
- 哪些事总是做不好？
- 最近想买却买不到的东西？ 
先列出10个生活中的问题，比如：
1. 睡眠质量差
2. 早上没精神
3. 健身计划总是坚持不了
4. 没时间看书
5. 手机使用过度
6. 写作经常分心 
花3分钟写下这些想法。不用考虑它们是否完美，重要的是开始尝试。没成功？再想20个。 
把纸分两栏：左边写想法，右边写第一步行动。先做第一步，剩下的边走边看。
不要追求完美方案。Airbnb创始人最初只是拍了张床照，写了段文字就开始尝试。
理查德·布兰森就是个好例子。他对航班服务不满意，想："我要开家航空公司。"第一步？他直接打电话给波音，问能不能租架飞机。 
不要纠结想法好坏，重要的是行动。 
普通人：想太多，做太少
成功者：先行动，再完善。
顶尖创业者不是靠读书学习起步。他们先动手做，从实战中学习。这比任何理论都有价值。 
创业三原则：
1. 发现问题就是发现机会
2. 持续试错寻找方案
3. 敢于推销你的产品 
创业没那么复杂。停止过度思考，从小事做起。不懂没关系，边做边学。
关键是：成为一个实验者、学习者、行动者。 
商业的本质很简单：开始、实验、重复。先行动，理解自然会跟上来。 
设个标准：比如你平时请朋友吃饭的钱。如果实验成本低于这个数，直接上。 
把失败当收藏品。定个年度目标：收集100个次失败。因为，每个"失败"都让你离"是"更近一步。实验的好处无限，风险最小。每次失败成本控制在一顿饭钱以内，但成功时收益可能远超付出。这就是非对称博弈的威力。 
创业投资的核心不在于永远正确，而在于控制试错成本。当失败成本极低，而成功收益极高时，你就找到了正确的方向。这是我近年投资最重要的心得。
