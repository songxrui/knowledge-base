## 使用规则

1. 引用作者方法时同时写明文章标题、URL 或本地行号。
2. 个人故事、粉丝数、收入和转化数据一律视为自述。
3. 模仿结构，不复制句子、个人经历或身份冲突。
4. 涉及心理学、神经科学、健康和社会趋势的主张，回到独立来源核验。
5. 只有进入真实项目并产生反馈的方法，才能升级为本产品自己的方法论。
