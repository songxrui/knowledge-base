# 个人健康优先问题：证据账本

> 核验截止：2026-07-20
>
> 对象：接近 22 岁、总体健康、有约 1 年力量训练和 5–6 年业余羽毛球经历，目前主要在家用哑铃与弹力带训练的本人。已知问题为作息显著后移、未处理龋齿、既往“慢性非特异性直肠炎”诊断、稳定期痔疮、轻度痤疮和近视。
>
> 用途：为《个人健康手册》提供可追溯证据；不是诊断、处方或对面诊的替代。
>
> 访问口径：“全文”指本轮或既有原始来源核验中读到论文全文；“指南页”指官方建议、方法或摘要页；“摘要”指 PubMed/Cochrane 结构化摘要；“出版记录”只证明文献存在，不能单独支撑具体建议。

## 先读：五条不可越过的边界

1. **晚睡不是痤疮的确定病因。** 调整睡眠主要针对节律、白天功能和训练恢复；痤疮使用有直接临床证据的治疗。现有孟德尔随机化结果也不能证明“改到午夜入睡即可祛痘”。
2. **“慢性非特异性直肠炎”不等同于溃疡性直肠炎。** 原内镜、病理、感染排查和当时症状未归档前，不套用 UC 的长期用药、监测或年度肠镜路径。
3. **用手指摸到后槽牙凹沟不能诊断龋齿。** 正常窝沟、着色、非洞性龋和已形成洞的龋损需要牙科临床检查，必要时再由牙医选择影像。
4. **儿童近视控制结果不能直接外推给 22 岁成人。** 户外、阿托品、离焦镜片和角膜塑形镜的主要试验证据来自儿童；成人先建立可比较的屈光与眼底基线。
5. **三日家庭训练是证据约束下的个人设计，不是唯一最优。** 指南能规定周活动底线和较可靠的训练变量，不能证明 A/B 动作清单、固定周次或某个 RIR 对每个人最优。

## 证据分级与推断标记

| 标记 | 本账本中的含义 |
|---|---|
| A | 正式指南、权威机构建议或高质量系统综述，方向可靠，但仍需看人群与结局 |
| B | 随机试验或系统综述，结果可量化，但样本、期限或场景限制明显 |
| C | 观察研究、孟德尔随机化、机制或间接证据，适合限定边界，不能直接生成个人疗效承诺 |
| D | 基于多项证据和个人约束的低风险实务推导；不是被单项试验验证的唯一方案 |

| 我识别的限制 | “约 2–3 RIR”是合理操作化，但精确 RIR 目标证据不足；≥10 组是偏肌肥大的相对有利容量，不是最低健康剂量 |
| 能支持 | 家庭哑铃/弹力带可有效；完整幅度、渐进超负荷、每组保留 1–3 次余力；不必练到失败 |
| 不能支持 | A/B 清单是唯一最优；每项都需 ≥80% 1RM；第一周直接堆到高容量；居家训练天然次于健身房 |
| 放入手册位置 | 三日 A/B 交替、进阶规则、RIR 与“动作清单为个人设计”声明 |

**本组综合推断 D4：** `A-B-A / B-A-B`、每次 45–60 分钟、30 分钟时做前四项、连续两次达到次数上限再加最小重量，均是把 WHO 周底线与 ACSM 变量放进现有器械和时间后的执行设计。加入纵跳是为功率与落地能力，但仅在无痛、睡眠正常且动作稳定时进行。痔疮稳定期没有证据要求禁做深蹲、硬拉或跑步；反复极限憋气、失败次数，或动作稳定时诱发出血、疼痛、脱垂，则减量并评估。

## 仍不确定、需要现实信息解决的问题

1. 原“慢性非特异性直肠炎”的内镜范围、病理描述、感染排查和当时症状是什么；没有报告就不能设长期监测方案。
2. 未补龋齿和磨牙凹沟的活动性、深度与牙髓状态；只能由牙科检查，必要时结合影像判断。
3. 双眼当前球镜等效、散光、最佳矫正视力、眼轴/眼底以及近 1–2 年变化；成人近视控制只有在证实仍进展后才有讨论基础。
4. 痤疮是否确为轻度寻常痤疮、皮肤屏障耐受性及当地固定复方产品可及性；严重刺激或诊断不符时应停用并面诊。
5. 哑铃最大重量、弹力带阻力、动作技术和现有心肺量；训练负荷应由次数上限、RIR、动作质量和恢复共同推进。
6. 当前典型起床时间是否确为约 11:30；若不同，14 天表应保持 8 小时窗口整体平移。
