# 超级个体学习笔记

> 版本：v0.1.0（2026-07-10）  
> 状态：总纲与证据台账已建立；其余章节沿用已批准的稳定文件名，链接会随后续任务逐步落地。

## 为谁而写

这套手册只服务一个明确起点：21.8 岁，生活与经营均在中国大陆，刚毕业，全职投入个人事业，已有六个月生存缓冲，以极低固定成本启动；业务范围聚焦内容与服务，不做实体产品，也不把出国、海外平台或海外客户当作默认路径。

## 手册用途

它用于识别当前瓶颈、选择相关章节、设计最小实验、记录结果并修改个人规则。它提供长期判断框架，不提供刚性日程，也不承担道德考核。首次使用先读 [00-总纲与使用说明](./00-总纲与使用说明.md)，需要核对事实与方法边界时查阅 [98-证据与来源附录](./98-证据与来源附录.md)。

## 按问题进入

- **状态和专注失稳**：先读 [02](./02-心力与精力.md)，再按冲突来源进入 [04](./04-工作生活一体化.md) 或 [11](./11-反脆弱与危机协议.md)。
- **方向、身份或项目过多**：从 [01](./01-成为超级个体.md) 与 [08](./08-计划与优先级.md) 开始，长期取舍转到 [12](./12-长期演化与人生复利.md)。
- **学了很多却没有作品**：读 [03](./03-知识与思维系统.md) 与 [09](./09-技能栈与学习元系统.md)。
- **持续发布却没有信任沉淀**：读 [05](./05-内容引擎与个人品牌.md)，涉及平台现实再查 [10](./10-中国内容商业生态.md)。
- **有关注却没有稳定成交**：读 [06](./06-产品化与变现.md) 与 [07](./07-一人公司操作系统.md)。
- **准备启动或重新校准**：先用 [90](./90-快速启动清单.md) 降低启动摩擦，再用 [13](./13-启动与迭代蓝图.md) 和 [92](./92-复盘与决策模板.md) 管理实验；需要快速回查时使用 [91](./91-原则索引.md)。

## 维护方式

先在 [99-版本与实验日志](./99-版本与实验日志.md) 保留原规则、适用条件、观察结果和修改理由，再更新相关章节。平台、支付与合规信息在实际发布、收费或自动化前回到官方入口复核，并保留观察日期。文件名保持稳定；只有导航关系、章节职责或版本状态变化时才更新本页。
