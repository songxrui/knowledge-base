# 90｜快速启动清单

> 这份清单用于建立首轮真实循环，不替代正文判断。遇到状态、产品、平台或风险问题，回到对应章节。未发生的数据保持空白。

## 今天：建立最小底座

- [ ] 写下当前生存缓冲、固定支出、已承诺事项、健康与关系硬边界。
- [ ] 确认基本睡眠、进食、活动与现实联系能够维持；状态明显下降时先读 [02-心力与精力](./02-心力与精力.md)。
- [ ] 建立一个承诺与下一动作清单，包含项目和运行型维护事项。
- [ ] 选择一个能够接触真实对象的具体问题，写清对象、场景、困难、后果与现有替代方案。
- [ ] 选择一个主要公共入口；暂不注册全平台。平台选择回查 [10-中国内容商业生态](./10-中国内容商业生态.md)。
- [ ] 建立一份源内容文件，预留问题、论证、事实、案例授权、适用边界和下一步。
- [ ] 建立空白事件记录：`日期／事实／动作／结果／心力与时间成本／下一步`。
- [ ] 写下停止条件：睡眠和基本功能持续下降、现金触线、重大投诉/退款、平台或数据风险扩散时停止新增承诺。

## 首次一周：接触现实并完成一件作品

- [ ] 收集最近真实发生的情境和原话，把事实、推断与未来购买意愿分开。
- [ ] 将资料只放入当前项目；未进入判断或成品的信息暂不整理。
- [ ] 完成一份可发布源稿，删除虚构经历、无来源数字、算法传闻和无法保持现实一致的隐喻。
- [ ] 在主要入口发布一个平台版本，并保存源稿、版本、发布日期和事实复核日期。
- [ ] 提供一个经对方主动选择后进入的咨询或联系入口；无产品时只收集背景，不暗示结果。
- [ ] 记录具体问题、异议、继续提供材料的行为，以及泛化互动和平台噪声。
- [ ] 复盘制作、发布和回复消耗；影响恢复时缩小格式、频率或并行承诺。
- [ ] 为最明显的能力缺口保留一份基线作品，按 [09-技能栈与学习元系统](./09-技能栈与学习元系统.md) 设计下一轮训练。

## 首次完整周期：跑通内容到反馈

- [ ] 使用同类问题完成一次“研究—表达—发布—对话—下一动作”。
- [ ] 检查合格反馈是否来自目标对象的具体情境，而非只有点赞、播放和称赞。
- [ ] 有重复问题时，设计可以手工完成的小范围诊断或服务。
- [ ] 收款前写清对象、范围、材料、里程碑、验收、修改、退款、退出和异常处理。
- [ ] 只承诺现有能力和容量能够完成的交付；预售不能替代手工能力。
- [ ] 交付后记录实际工时、采用、返工、退款、心力成本和可复用步骤。
- [ ] 把重复步骤先写成清单或模板，人工流程稳定后再测试 AI、自动化或外协。
- [ ] 用 [06-产品化与变现](./06-产品化与变现.md) 判断继续、收窄、改变产品形态或停止。

## 收费前门禁

- [ ] 真实对象和问题已经出现，不依赖想象画像。
- [ ] 能完成手工版本，并有明确完成标准。
- [ ] 报价、付款、退款、延期、材料、隐私与案例授权均有可执行文本。
- [ ] 主体、平台、支付、广告、消费者权益、个人信息和著作权入口已按当期规则核验。
- [ ] 现金、时间和心力容量能够承担最坏合理情形。
- [ ] 无法继续时，有通知、退款、材料交接和人工恢复路径。

## 增加平台、工具或协作者前门禁

- [ ] 当前瓶颈已重复出现并留有事实记录。
- [ ] 输入、步骤和验收足够稳定。
- [ ] 新组件解决明确功能缺口，不只提供新鲜感。
- [ ] 计入学习、迁移、复核、维护和退出后仍有净收益。
- [ ] 已到账现金能够承担试用和撤回成本。
- [ ] 内容、数据和联系路径可以导出，权限可以收回，人工流程可以恢复。
- [ ] 信号消失时，有停止续费、降低频率或退回原流程的决定规则。

## 启动付费社群前门禁

- [ ] 相近对象存在持续实践需求，不只想获取一次资料。
- [ ] 小范围交付已经出现互动、主持或同伴协作的真实价值。
- [ ] 经营者能承担答疑、审核、冲突、退出、退款和资料管理。
- [ ] 成员能说清持续参与的价值；价格未被当作需求证据。
- [ ] 知识星球、小鹅通或其他工具只在功能与成本匹配后选择。
- [ ] 无专用工具时，低成本替代仍能完成履约、退出和数据保护。

## 每轮结束只回答这些问题

- [ ] 发生了什么，哪些仍是推断？
- [ ] 当前瓶颈在状态、注意力、问题、表达、信任、销售、交付、现金还是平台？
- [ ] 哪项资产被再次使用？
- [ ] 哪个承诺、工具或流程应删除？
- [ ] 下一轮只改变哪个主要变量？
- [ ] 什么信号要求停止、减载或寻求帮助？

完整的九十天与一百八十天分支见 [13-启动与迭代蓝图](./13-启动与迭代蓝图.md)；危机与恢复顺序见 [11-反脆弱与危机协议](./11-反脆弱与危机协议.md)。
