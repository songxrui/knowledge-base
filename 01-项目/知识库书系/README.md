# 知识库书系

> 状态：active  
> 建立日期：2026-09-11  
> 目标是形成一组独立、可追溯、可长期维护的书籍，而不是把旧文章换封面后批量出版。

## 书系原则

每一本书只回答一个足够大的问题，拥有自己的读者、核心判断、证据边界与维护触发条件。不同书可以共享研究、案例和写作规范，但不能靠重复章节凑成“新书”。

“完成”定义为形成可直接进入编辑或试读的完整书稿，不等于已经出版。出版、ISBN、真人案例、治疗效果、收入结果和外部推荐都必须由现实事实支持。

## 分工边界

- 第 1 本讲个人事业的整合秩序，并承载“可撤回进展”；不承担心理治疗、医学解释或平台运营大全。
- 第 2 本只处理来源、证据、裁决、验证和知识复用，不写账号增长与产品定价。
- 第 3 本讲跨领域的个人系统，不把每个领域写成专业教材。
- 第 4 本只处理身体、睡眠、训练、饮食、筛查和就医边界，发布前必须有医学专业审读。
- 第 5 本处理现实资源和安全边界，明确区分可执行行动与专业支持；不诊断抑郁、成瘾、ADHD 或睡眠障碍。

“从零到可验证作品”暂不列为主书。真实发布数据、报价、交付和退款案例尚未形成，先作为第 1、2 本的实践章节与独立课程材料，等现实证据足以支撑一本书再立项。

## 单本完成门槛

一本书进入 `v1.0-release-candidate` 前必须同时满足：

1. 有一句可反驳的核心判断，且每章都在推进、限定或检验它。
2. 有完整序言、章节、结语、练习与来源说明，不保留 TODO 或空章。
3. 关键事实可回到原始来源；作者模型、编辑推断和实验参数明确标注身份。
4. 高风险领域写明适用边界、停止条件和专业支持入口。
5. 人物、案例、数字和收入不被虚构或用来承担因果证明。
6. 原稿基线、最终哈希、结构检查、关键词扫描、链接检查和差异审查有记录。
7. 没有冒充出版、真人验证、治疗效果或商业结果。

## 维护规则

- 当前版本只保留一个权威正文；旧版进入 `90-归档/历史版本/`。
- 事实变化时更新来源图，不静默修订正文；材料性变化提升次版本号。
- 新证据推翻核心判断时，缩小结论、增加反例或撤销书名，不靠话术保住房。
- 每本书完成后先进行外部试读；没有试读反馈，不把“可读”写成“已有效”。
