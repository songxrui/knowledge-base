# 知识库书系术语表

> 版本：v2  
> 日期：2026-09-11  
> 用途：统一五本书交叉使用的核心术语。正文首次出现时给定义，之后一致使用。

## 一、《一人事业的内在秩序》

| 术语 | 定义 | 首次定义处 |
|---|---|---|
| 可撤回性 | 一个行动可以在不改变任何他人生活的情况下被取消、删除、改名或放弃的程度 | 第一章 |
| 承担 | 一个行动的后果无法由行动者单方面收回 | 第一章 |
| 撤回测试 | 四问：删掉有人注意吗？改变了谁的哪个决定？之后还要求我承担什么？我推迟的是缺条件的事，还是已有条件、只是不想承担后果的事？ | 第一章 |
| 方向 | 一种长期的、可被他人识别的行动倾向；它是关系属性，不是内在状态 | 第一章 |
| 恰当尺度的承担 | 足够真实能产生方向、足够有界不会毁掉你的不可撤回程度 | 第十二章 |
| 长期问题域 | 一组反复出现的问题、能力和价值取向，而不是一个岗位名称 | 第六章 |

## 二、《可验证的 AI 知识生产》

| 术语 | 定义 | 首次定义处 |
|---|---|---|
| 主张身份 | 每条可独立判断真假的句子的证据属性，共九种：研究支持、历史描述、作者方法、个人事实、库存快照、编辑推断、产品假设、实验参数、阻断 | 第四章 |
| 来源坐标 | 记录位置、版本、内容的引用结构（路径／哈希／定位） | 第五章 |
| 三层引用 | 来源 → 主张 → 作品；用于来源变化时定位受影响范围 | 第五章 |
| 校准 | 确定性程度与现实一致（说 70% 把握，就真的约 70% 发生） | 第二章 |
| 内容不变量 | 一篇文章里必须保住的要素（引用、标题、反例、链接等） | 第八章 |
| 指纹回执 | 绑定仓库、基线提交、内容指纹和处理的审查记录 | 第八章 |

## 三、《人生操作系统》

| 术语 | 定义 | 首次定义处 |
|---|---|---|
| 五层 | 默认层、脚本层、能量层、纠错层、自更新层 | 序言 |
| 默认层 | 当你没有认真思考时，环境把你推向哪里 | 第一章 |
| 脚本层 | 决定行为什么时候启动；用"如果出现某个线索，那么做某个动作"表达 | 第二章 |
| 执行意向 | 把目标改写成"如果 X，那么 Y"的脚本形式 | 第二章 |
| 能量层 | 先记录状态，再选择动作；不制造好听机制，只选低风险、能记录、能停止的恢复动作 | 第三章 |
| 纠错层 | 区分单点与趋势，每轮只改一个主要参数 | 第四章 |
| 自更新层 | 删除不再重要的目标；删除也是更新 | 第五章 |
| 最小可运行单元 | 能在三天内开始、单次不超过十五分钟、只需一个主要工具、完成与否可判断的单元（简称最小单元） | 第六章 |
| 恢复延迟 | 从偏离到回来的时间；比"是否全勤"更能预测系统能否存活 | 第九章 |

## 四、《青年健康执行手册》

| 术语 | 定义 | 首次定义处 |
|---|---|---|
| 三级分级 | 立即急救 / 专业评估 / 低风险自我实验 | 第一章 |
| 欠账 | 已经知道但没处理的病灶，或含义不清的诊断 | 序言 |
| 绝对风险 | 用实际人数的变化描述效果（从千分之二到千分之一），而非百分比 | 第四章 |
| 过度诊断 | 发现了终身不会造成症状或死亡的异常，却带来治疗和焦虑 | 第九章 |
| 最小执行系统 | 每天五件事 + 每周检查 + 每四周复盘 | 第十一章 |

## 五、《受限起点》

| 术语 | 定义 | 首次定义处 |
|---|---|---|
| 六层模型 | 现实条件、发展经历、心理模型、行为策略、维持回路、临床与结构 | 第一章 |
| 五道门 | 目标价值、资源权限、风险伦理、知识能力、反馈有效 | 第四章 |
| 四种控制故障 | 启动失败、维持失败、停止失败、恢复失败 | 第五章 |
| 统一事件记录 | 情境 → 预测 → 反应 → 行为 → 短期收益 → 长期代价 → 替代行为 → 新证据 | 第六章 |
| 竞争性解释 | 对同一现象保留至少三个可区分预测的解释，禁止单一归因 | 第二章 |

## 六、跨书共用与一致用法

- **可撤回 / 不可撤回**：第 1 本的核心概念；第 5 本在讨论"把系统交还给现实"时引用同一概念。
- **最小单元**：第 3 本定义为"最小可运行单元"的简称，其余各书不重复定义。
- **证据身份**：第 2 本称"主张身份"；其他书提到时用同一说法，不改称"可信度"。
- **反馈三层**：出现 / 可信 / 达到更新门槛；五本书统一使用这三分法。
