# 第七章：五个现象的多因素检查

以下现象不共享单一原因。本章只提供观察问题。

| 现象 | 优先记录 | 常见替代解释 |
|---|---|---|
| 晚睡 | 工作结束时间、光照、咖啡因、情绪、睡眠机会 | 失眠、轮班、疾病、照护责任 |
| 关系发火 | 触发事件、表达、责任、修复行为 | 持续冲突、暴力、边界被侵犯 |
| 购买后不使用 | 购买动机、实际需要、首次使用 | 决策错误、时间变化、营销影响 |
| 过度客气 | 场合、权力差、真实感受 | 礼貌规范、安全策略、职业要求 |
| 退出目标 | 新证据、资源、健康和价值变化 | 合理止损，而非心理补偿 |

## 关系责任

压力和疲劳可以解释背景，不能免除伤害责任。造成伤害后应停止伤害、承认影响，并在安全且合适时道歉和修复。存在暴力、威胁或控制时优先寻求安全与专业支持。

## 停止条件

持续失眠、明显戒断反应、进食异常、自伤或伤人风险、关系暴力或功能下降时，不做自我实验。

各模型的反证条件见 [主张与来源台账](../claim-source-ledger.md)。
