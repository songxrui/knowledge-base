# 第六章：跨理论比较的限制

不同作者使用相似比喻，不足以证明他们发现了同一机制。跨理论比较只能生成问题，不能替代来源核验和实证检验。

## 比较表

| 必查项 | 问题 |
|---|---|
| 原始定义 | 作者原文如何定义概念 |
| 测量方式 | 是否存在可观察指标 |
| 适用范围 | 面向什么人群、任务或层级 |
| 替代解释 | 相似语言是否来自翻译或时代背景 |
| 反证条件 | 什么结果会让该理论不适用 |

## 禁止推论

- 哲学、心理学、神经科学和经济学术语不能因措辞相似而合并。
- 动物研究、个案、通俗书和物理公式不能互相充当验证。
- “多位作者都这样说”不是机制证据。
