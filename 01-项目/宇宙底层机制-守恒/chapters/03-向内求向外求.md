# 第三章：内部行动与外部反馈

本章把“向内”和“向外”改成两个可观察维度，不给它们排序。

- 内部行动：本人能够直接执行的行为，例如写作、练习、沟通或休息。
- 外部反馈：他人评价、平台数据、职位、收入或关系回应。

## 待检验假设

当自我评价高度随外部反馈波动时，增加对内部行动的记录，可能帮助区分“我做了什么”和“别人如何回应”。

| 字段 | 内容 |
|---|---|
| 观察指标 | 行动完成情况、自我评价、外部反馈分别记录 |
| 替代解释 | 正常依恋、现实绩效、经济压力、文化规范 |
| 反例 | 外部反馈大幅变化，但自我评价保持稳定 |
| 推翻结果 | 内部行动记录不能增加区分度或改善决策 |

## 边界

外部反馈不是低级需求，内部行动也不保证稳定价值感。关系冲突、抑郁、焦虑或长期功能受损需要专业评估，不能用“向内求不足”解释。
