# 宇宙底层机制-守恒：项目说明

## 项目身份

本项目把“守恒”当作哲学隐喻、观察框架和待检验假设，用来提出问题：一个行为被停止后，是否出现了新的替代行为；一个目标长期没有推进时，是否存在更容易获得反馈的替代活动；一个关系冲突发生前，是否已有可观察的压力、睡眠或沟通变化。

它不是物理守恒定律，不主张人的心理活动服从热力学公式；它不是神经科学定律，不从行为直接推断脑区、神经递质或受体变化；它也不是诊断、治疗、戒断、睡眠、饮食或用药工具。

“能量”在旧稿中混指体力、时间、注意、情绪体验、动机、意志力和意义感。审计后的文本只允许把它当作历史隐喻。实际观察必须把这些变量分开记录，不得相加、换算或声称总量守恒。

## 使用边界

- 章节只用于生成问题，不用于给自己或他人贴病理标签。
- 单次观察不能证明机制。先记录可见行为，再比较替代解释和反例。
- 不用本项目替代医疗、心理咨询、伴侣沟通、危机干预或专业成瘾服务。
- 出现持续失眠、进食异常、明显戒断反应、自伤或伤人念头、关系暴力、持续功能受损时，停止自我实验并联系合格专业人员；紧急危险时使用当地急救资源。
- 造成关系伤害后，应停止伤害、承担责任，并在合适且安全时清楚道歉和修复；“理解压力来源”不能替代问责。

没有可追溯来源的人物故事必须标为“合成案例”。历史或书中案例如缺少精确定位，必须标为“转述未核验”，不能称为真实临床证据。
