# 最强人类认知

> 状态：active，迭代中  
> 建立日期：2026-09-11  
> 定位：一本以"人类认知的最高形式"为对象的合成性著作，目标是尽可能逼近人类已有的最强认知工具与洞见之和。

## 一、这本书在做什么

它不写"如何思考"的入门，也不写某一学科的教材。它做一件事：

**把人类已知的最强认知能力，按能力层级排列成一条上升的阶梯，每一级都用最好的原典、最可信的原始材料、最顶尖实践者的可核查经历来支撑，并给出可训练的接口。**

这里的"最强"不是修辞，是一个可操作的标准：一种认知能力只有在满足以下条件时才被收录——

1. 它被最严格的证据或最长期的实践检验过；
2. 它能解释为什么比它更弱的直觉在这里失效；
3. 它有一个能被普通人练习的接口；
4. 它与阶梯上的其他能力有明确的连接。

## 二、核心判断

> **智力的高低，不由知识的多少决定，而由两件事决定：你构建世界模型的能力，以及你修正这个模型的速度。**

推论的三个层次：

- **表征**：你看见的世界有多真、多细、多结构化。
- **推理**：你能从这个表征里推出多少不被直觉轻易骗到的东西。
- **校准**：现实给出反驳时，你多快、多准地更新。

一切具体的认知工具——注意力、概率、因果、系统、类比、元认知——都是为这三件事服务的。

## 四、方法（这本书如何越iterative越强）

1. **每章五件套**：核心定义 → 最好的原典证据 → 一个顶尖实践者的可核查经历 → 反直觉推论 → 可训练接口。
2. **来源分级**：一手论文/原典（S1）＞权威综述（S2）＞可信公开材料（S3）。S3 不得单独支撑结论。
3. **反例与边界**：每个能力标明它在什么条件下失效。
4. **迭代日志**：每次修订记录"改了什么、依据什么证据、智力表达提升在哪里"。
5. **禁止**：虚构名人经历、无来源精确数字、把流行说法写成共识。

## 五、权威来源池

- **古典原典**：亚里士多德、培根、笛卡尔、休谟、康德、密尔、达尔文、威廉·詹姆斯、杜威（Gutenberg 可得）。
- **推理与科学方法**：波普尔、库恩、拉卡托斯、皮尔士（溯因）。
- **概率与判断**：卡尼曼与特沃斯基、泰特洛克、古德、西尔弗、麦克雷。
- **因果**：珀尔（因果推断）、布拉德福德·希尔。
- **系统**：梅多斯、福瑞斯特、维纳、阿什比、霍兰。
- **创造**：波利亚（数学发现）、根里希、霍夫施塔特、约翰逊（《伟大创意的诞生》）。
- **元认知**：弗拉维尔、邓宁与克鲁格、尼斯贝特与威尔逊。
- **决策**：西蒙、克莱因、杜克、黑斯蒂。
- **智慧**：埃里克森、巴尔特斯、斯坦诺维奇（理性）。
- **可核查的实践者**：芒格（《穷查理宝典》）、纳瓦尔、达尔文（自传中的工作方法）、费曼、马斯克（第一性原理的可核查描述）、奥尔特曼。
