# 90 秒短视频脚本

核心任务：让观众区分“目标相关活动”和“接受约束的测试”。这不是旗舰文章摘要。

| 时间 | 口播 | 画面与节奏 |
| --- | --- | --- |
| 0-3 秒 | 你可能不是没行动。你做的那些事，刚好都能撤回。 | 近景：鼠标把“最终计划_v7”改成“v8”。改名动作结束后停半秒。 |
| 3-15 秒 | 昨晚你又问了一次 AI：怎么早睡，怎么开始写作，怎么把副业跑起来。答案很完整。你保存、分类，还换了一个更顺手的模板。 | 屏幕录制：对话、收藏、拖动卡片。画面不展示品牌，不加夸张提示音。 |
| 15-28 秒 | 这些都和目标有关，所以很容易被记成进展。可它们有一个共同点：你仍然决定什么时候算完成，也可以不让任何结果回来反驳你。 | 画面冻结，三处标记依次出现：可重写、可隐藏、无结果。每个标记停 1 秒。 |
| 28-43 秒 | 我把这种结构叫“可撤回进展”。问题不在学习，也不在计划。具体的 if-then 计划通常能帮人行动。问题是，计划后面有没有一个会留下证据的接口。 | 切到纸面两行：晚点写作；晚饭后 20:10 打开旧稿，写 100 字并保存时间戳。第二行被框住。 |
| 43-58 秒 | 证据也不等于成功。发出一页报价，对方拒绝，仍然是证据。做十分钟训练，发现膝盖不适，也是证据。它们会拿走一点“我其实可以”的想象，换回下一步能用的事实。 | 报价邮件出现“暂不需要”；训练计时器停在 10:00；镜头保持平静，不使用失败音效。 |
| 58-71 秒 | 但先别急着做。没时间、没权限、风险高、真的不会，或者持续情绪和身体问题，都不该被骂成逃避。那时要找资源、学习、监督或专业支持。 | 五个词逐个出现：资源、权限、风险、能力、支持。背景保持静止。 |
| 71-86 秒 | 今天只试一个动作：打开你最近保存的方法，写下它要改变哪个决定；再写一个二十分钟内、低风险、可能让你判断落空的测试。测试没做，就别把这条收藏记成进展。 | 手写四格：决定、测试、证据、截止。最后一格填入今天 20:10。 |
| 86-90 秒 | 你要保留“也许能做到”，还是花掉一点可能，看看结果？ | 正面静帧 2 秒。无音乐上扬，无关注提示。 |

## 拍摄纪律

- 口播约 380 个汉字，按每分钟约 250 字控制；第 28、58、86 秒各留一次可听见的停顿。
- 不使用“你再不行动就晚了”、倒计时、收入损失或人格羞辱。
- 手机画面只承载具体行为，不滚动大量聊天记录。
- 结尾动作必须能在当天验证，但不适用于医疗、投资、法律、危险操作或重大关系决定。

## 这条视频与其他成品的差异

它只解决“如何在一个具体晚上认出可撤回进展”，不解释完整研究、不展示状态向量，也不推销七天产品。
