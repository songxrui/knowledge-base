# 下一步路由器

一个完全本地运行的目标情境路由工具。它检查未来 7 天内一个具体目标的当前瓶颈，允许同时返回多项结果，但不把结果合成单一分数，也不判断用户的人格或疾病。

## 直接使用

双击打开 `index.html`。页面没有外部字体、脚本、接口或分析服务，不需要安装依赖或启动服务器。

基本安全题和支持路由题只保留在当前页面内，默认不会写入 `localStorage`。普通回答会保存为本地草稿；“清除本地数据”会删除该草稿。主动导出的 JSON 会明确标注导出时间与隐私边界。

## 九类结果

| 结果 | 在模型中的位置 | 直接支持的最低条件 |
| --- | --- | --- |
| 真正缺知识 | `K` 结构瓶颈 | 代表性测试未达标，且缺口会改变做法或安全边界 |
| 缺行动定义 | `A` 结构瓶颈 | 缺触发情境、可观察动作、完成证据或无须再选择的入口 |
| 缺环境或权限 | `P` 结构瓶颈 | 真实机会、资源、批准或现实条件明确缺失 |
| 缺反馈 | `F` 结构瓶颈 | 反馈不及时、不相关、无效、不可归因或没有更新规则 |
| 情绪回避 | 候选摩擦 | `K/A/P/R/F` 均足够，且降低暴露赌注会改变行动意愿 |
| 完美主义担忧 | 候选摩擦 | 结构条件足够、外部最低线已达到，但自设门槛继续阻止安全测试 |
| 系统维护成本过高 | `M0` 活动模式 | 维护挤掉真实机会，且无预声明或观察到的测量与表现收益 |
| 目标本身不重要 | 目标价值门 | 无本人认可价值或承诺，删除主要带来释放；建议隔 24 小时复问 |
| 可能需要专业支持参与 | 支持路由 | 仅提示把合适的人工支持加入路线，不作病因判断 |

`U0` 是独立的优先停止规则。无法明确确认基本安全时，工具不会继续生成生产力建议。风险与资质 `R` 也是独立安全门：不可接受的损失或第三方风险会停止直接测试；资质与边界不清时只允许监督、模拟或专家复核。

每类结果只有以下状态：

- `supported`：有直接行为或结构证据；
- `test_needed`：需要一个最小测试核实；
- `not_supported`：当前证据不支持；
- `safety_route`：优先把人工支持加入路线。

未回答、无法确定、不适用和不愿回答都不会被当成“否”。除基本安全停止分支外，九类结果并行计算，因此行动定义、反馈与候选摩擦可以同时显示。

## 合法路线

工具不把“立即行动”设为唯一成功答案。以下结果都是合法路线：

- 删除、改写或重新协商不重要的目标；
- 补足一个可验证缺口的有界学习；
- 争取资源、权限或真实机会；
- 改用监督模拟、专家复核或受保护试点；
- 改善反馈与更新门槛；
- 定义可观察动作；
- 冻结无收益的系统维护；
- 在条件足够后设计小规模约束测试；
- 把合适的专业或社会支持加入路线。

## 文件

- `index.html`：语义结构、内容安全策略和本地入口；
- `styles.css`：响应式界面；
- `logic.js`：浏览器与 Node 共用的纯规则引擎；
- `app.js`：DOM 渲染、本地草稿、导出与清除；
- `tests.mjs`：30 个无依赖规则和安全测试。

## 运行测试

需要 Node.js 18 或更高版本：

```powershell
node tests.mjs
```

预期末行：

```text
30/30 tests passed.
```

测试覆盖单一与多重瓶颈、U0 优先停止、第三方风险、结构条件对情绪和完美主义判断的约束、探索与有界学习边界、支持路由、九类完整性、未知值语义、敏感字段过滤、文本限长、离线策略和安全 DOM 渲染。

## 数据边界

- 无网络请求、云同步、用户账户、追踪器或第三方资源；
- 不保存 U0、S1、S2、S3 的原始回答到默认草稿；
- 所有用户文本经纯文本清洗和长度限制，并通过 `textContent` 渲染；
- 锁定的规则只输出目标情境判断，不输出医学结论、人格标签、排行榜或连续打卡；
- 工具无法定位用户所在地区，因此紧急分支要求用户联系当地紧急服务、可信赖的人或已有支持，不硬编码地区热线。

## 已知边界

这是基于“可撤回进展循环”最终模型实现的工作工具，不是经过目标人群前瞻验证的量表。它不能证明某一心理机制存在，也不能替代组织协商、专业判断或长期观察。一次反馈不足以自动改变策略；探索、深度学习和必要基础设施均可具有独立价值。
