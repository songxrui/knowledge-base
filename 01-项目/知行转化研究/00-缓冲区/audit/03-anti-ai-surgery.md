# 旗舰文章反 AI 味手术

审查对象：flagship/article-v1.md 与 flagship/article.md。  
方法：使用 shuorenhua 的结构、词汇、语气和逻辑特征做人工诊断，同时服从本项目的证据纪律。没有调用或伪造 AI 检测率；此类分数不能证明作者身份，也不是本项目完成标准。

## 诊断

v1 已经避开模板式时代开头、首先/其次/最后、励志收束和连续金句，主要问题不在整篇，而在局部过度整齐：模型收束处连续列出七问，句法长度相近，像产品说明书突然进入文章。它把“证据合同”总结得很完整，却没有让读者看见这张东西如何被写、锁定和废弃。

另外两个缺口是内容性的：实施意图只有元分析结论，没有一个可感知的效应幅度；五道门只有抽象名称，没有展示同一“不发布”行为如何因权限、能力和反馈时滞走向不同路由。终稿只补这两处，不重写已有研究史和结尾。

## 最像 AI 的段落：改写前

> 模型最终留下的东西很小：一张证据合同。
>
> 它只问七件事。这次证据要帮我决定什么？当前瓶颈是知识、动作、权限、风险、反馈、质量还是稳定？我正在做的是有界学习、探索、基础设施、约束测试，还是可撤回进展？可能出现哪些结果？什么时候有真实机会？最大损失和停止条件是什么？证据达到什么程度才允许我改动作？
>
> 这张合同不承诺让人更自律。它只在行动前固定解释规则，避免事后把任何结果都讲成成功。

问题不是观点错误，而是它满足得太快：抽象名词密集、七项结构一次排齐、结尾立刻总结功能。读者能复述概念，却摸不到使用时的摩擦。

## 改写后

> 我最后没有给模型加一套评分表，只留了一张能折起来的纸卡。卡的第一行不是“今天做什么”，而是“这次结果要帮我决定什么”。接着才写当前卡点：知识、动作、权限、风险、反馈、质量，还是稳定性。活动也得如实归类，是有期限的学习、纯探索、必要基础设施、一次约束测试，还是又一轮可撤回准备。
>
> 纸卡背面留给那些很容易事后改口的东西：可能出现哪几种结果，每一种会让决定怎样变化；真实机会何时出现；最大可逆损失、第三方影响和停止条件是什么；一次结果够不够，还是要等三次、等外部复核。写完后把卡锁住。结果难看时可以换决定，不能偷偷换掉当初的结果空间。
>
> 这张卡不会让人更自律。它的用处甚至有点消极：把解释规则固定在结果之前，让“我早就知道会这样”“这次不算”“再优化一点就好”少几个藏身处。若填卡花的时间开始超过那次测试，它也该被丢掉。

改写保留了七个合同字段，没有删除实质。变化是把字段放到纸卡正反面的使用顺序里，加入“锁定后不能改结果空间”和“工具本身成本过高就丢掉”两处真实阻力。结尾不再保证工具有效。

## 其他最小手术

1. 在实施意图段后加入流感疫苗现场实验：日期加时间组相对对照只增加 4.2 个百分点，并明确免费诊所、短暂机会等条件。它校准计划的作用，不把小效应写成魔法。
2. 在五道门后加入数据库迁移、组织权限和慢反馈研究三个对照场景。同一种“继续阅读/尚未发布”因此可能路由到学习、权限协商、延长观察或约束测试。
3. 保留原开头、红队过程、反馈噪声、最脆弱处与有代价的结尾。没有为了“人味”添加无法核验的私人经历。

| 检查项 | 终稿处理 |
| --- | --- |
| 模板式开头 | 从本地命令输出的三个数字和矛盾现场进入 |

| 不必要金句 | 未新增口号式排比；结尾只保留一个代价选择 |
| 作者全知 | 明说模型尚未验证，心理发动机可能被删除 |
| 没有真实代价 | 发布、问价和结果锁定都会损失可想象的可能性 |
| 引用只是装饰 | 每项研究都迫使定义、分类或边界发生变化 |
| 案例过于完美 | 疫苗效应小；Dropbox 只验证继续探索，不证明留存和付费 |
| 媒介重复 | 短视频、轮播、播客各有独立任务和结构 |
| 所有问题被解决 | 结尾与“最可能错在哪里”保留可否定条件 |
