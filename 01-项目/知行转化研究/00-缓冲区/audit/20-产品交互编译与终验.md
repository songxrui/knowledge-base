## 二、产品交互与数据契约验收

| 产品不变量 | 实现与验证证据 | 判定 |
|---|---|---|
| 一次只处理一个目标 | 数据状态只有一个目标；清空后才能开始新目标 | 通过 |
| 合同不可静默覆盖 | 修订创建连续新版本；倒置状态时间线会被导入校验拒绝 | 通过 |
| 无机会不污染分母 | 记录必须有客观原因，分钟、证据和指标清零；当前版本统计不混入旧版 | 通过 |
| 高风险不进入直接测试 | 界面禁用与业务逻辑双层阻断，导入风险快照交叉校验 | 通过 |
| 退出是合法终态 | 二次确认；退出后目标和最近合同关闭，不能继续观察或锁定 | 通过 |
| 导入不静默替换 | 校验、预览、再次确认；错误显示在对话框；失败保持原状态 | 通过 |
| 本地数据不被异常覆盖 | 损坏数据隔离；提交、导入、清空和恢复弃用前比较本地快照 | 通过 |
| 不引入外部依赖和行为操控 | 外部请求为 0；无账号、后端、连续天数、积分、排名或自动惩罚 | 通过 |
