## 验收实际发现的问题

测试不是形式检查，实际捕获并修复了五类问题：

1. 诊断导出使用 schemaVersion 1.0 且结构为 draft + assessment，产品最初只接受虚构的数字 schema 和 app/kind；已改为真实形状并增加普通/紧急载荷测试。
2. 产品 HTML 的账本容器缺少 table-wrap id，应用按 id 查找导致创建目标或修订合同时抛异常；浏览器异常监听定位后已修复。
3. 诊断结果 scrollIntoView 最初被 sticky 顶栏遮住；增加稳定 scroll margin 后重新截图确认。
4. 诊断移动截图中，页面按钮文字会透过半透明 sticky 顶栏形成重影；改为不透明背景，并增加 alpha 回归断言。
5. Chrome 测试 profile 曾写入知识库根目录且有一次清理后被子进程重建；现改用系统临时目录、优先请求浏览器正常退出，并把“目录最终不存在”设为测试后置条件。

- 没有真实用户完成 7 天试验，因此不能声称产品提高行动、决策质量或长期表现。

- 阴性结果、无机会、继续学习、争取权限和退出目标都必须在未来用户研究中保留，不能被改写成成功率。
