# 自控冲突与全天行动失控：低摩擦工作表

> 版本：v0.1
> 日期：2026-08-08
> 用途：个人 7 天、14 天和 30 天行为实验。
> 研究边界：不诊断拖延、ADHD、抑郁、游戏障碍或睡眠障碍；严重功能下降和危险信号优先专业支持。

## 一、先选一个现实结果

今天只选择一个主要现实结果：

```text
今天最重要的一个现实结果：
完成时留下什么外部证据：
最低合格版本是什么：
不做哪些其他目标：
```

运动、早睡、写作、自媒体和赚钱不能同时作为当天最高优先级。其他目标只保留安全和最低维护线。

## 二、六问日记录

每天最多记录一次完整事件，不要求整天写日志。

```text
日期：
今天最重要的一个现实结果：
预计最容易逃避的时刻：
当时我选择了什么：
这个选择短期保护了我什么：
下一次最小替代动作：
今天留下的外部证据：
```

外部证据可以是保存的作品、发出的消息、真实运动记录、实际睡眠时间、退出娱乐的时间、他人回应或明确的决策记录。不能用“我想了很多”“我很有动力”替代。

## 三、四功能诊断

每次偏离只勾一项主要故障，允许附加一项次要故障：

| 功能 | 事实问题 | 最小测试 |
|---|---|---|
| 启动 | 我是否不知道第一步、害怕评价或缺少能量 | 把任务写成一个 5 分钟内可留下证据的动作 |
| 维持 | 是否任务太难、反馈太远、中断太多或睡眠不足 | 只保留一个小时间块并提前写下一步 |
| 停止 | 娱乐/工作是否提供掌控、安慰、连接或完成感 | 在开始前写退出线索和下一项替代活动 |
| 恢复 | 偏离后是否把事件解释成人格事实 | 只记录事实，然后执行一次最小返回 |

## 四、五道门

在把问题解释成“我在逃避”前检查：

| 门 | 当前状态 | 事实 |
|---|---|---|
| 目标价值 | 足够 / 不足 / 未知 | 我为什么要做，是否真的认可 |
| 资源权限 | 足够 / 不足 / 未知 | 时间、钱、地点、资格、支持 |
| 风险伦理 | 足够 / 不足 / 未知 | 最大损失、退出方式、第三方影响 |
| 知识能力 | 足够 / 不足 / 未知 | 能否完成最低版本 |
| 反馈有效 | 足够 / 不足 / 未知 | 结果如何观察、是否能改变下一步 |

任何一门不足时，合法下一步可能是补技能、争取资源、改目标、改善反馈、监督模拟、暂停或求助，不是继续逼自己。

## 六、14天单变量实验

只选一个变量：

- 固定起床锚点；
- 第一段娱乐移出启动窗口；
- 每天只保留一个现实结果；
- 给写作设置一个低风险真实反馈；
- 设置固定共同工作/反馈关系；
- 为娱乐预先写停止线索和替代活动。

```text
实验名称：
我想验证的预测：
只改变的一个变量：
保持不变的条件：
风险上限：
最低行动：
成功定义：完成行动并留下证据，不要求感觉轻松。
失败定义：变量未改变，或功能/安全变差。
停止条件：
每天记录什么：
第7天看什么：
第14天如何更新模型：
```

## 七、30天组合实验

只有 14 天实验产生可读结果，才组合两个接口：

- `启动锚点 + 一个现实结果`；或
- `停止接口 + 恢复接口`。

30 天仍不追求同时修复所有人生模块。每周只问：哪一种功能改善？哪一种仍是瓶颈？是否出现需要专业支持的信号？

## 八、行为控制的四个接口

### 启动接口

```text
当【具体情境】出现，我先做【最小动作】，完成后留下【证据】。
```

### 维持接口

```text
我只做【一个时间块/一个子结果】；如果卡住，我先记录【卡点】再决定补技能、换方法或暂停。
```

### 停止接口

```text
开始【娱乐/工作】前，我写下【退出线索】；退出后立刻进入【低摩擦替代活动】。
```

### 恢复接口

```text
偏离后我只记录事实【发生了什么】，不写人格判断；下一次返回动作是【一个最小动作】。
```

## 九、停止和升级规则

立即停止个人实验并进入专业/急救路径：

- 自伤/自杀想法、计划或行为；
- 无法保证安全；
- 严重失眠伴异常兴奋、冲动、夸大或思维加速；
- 幻觉、妄想、现实检验下降或暴力风险；
- 游戏、赌博、物质或消费造成即刻重大财务/法律风险；
- 记录实验导致持续闪回、解离、恐慌或功能快速恶化。

如果情绪或功能问题持续约两周、反复出现或明显影响学习工作关系，预约合格专业人员。中国大陆可询 `12356` 进行心理援助和服务导航；立即危险拨 `120/110`。
