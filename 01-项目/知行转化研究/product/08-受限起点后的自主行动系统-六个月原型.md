# 受限起点后的自主行动系统：六个月原型

> 版本：v0.1
> 日期：2026-08-07
> 北极星：自主行动能力
> 用途：个人自助研究和行为实验，不是心理治疗或医学诊断。
> 上游报告：[问题重定义与证据研究报告](../research/20-受限起点与自主行动-问题重定义与证据报告.md)

## 一、系统目标

六个月后，不要求“完全不害怕”，而要求在风险可控时能够：

1. 识别自己正在运行的默认策略；
2. 区分现实阻力和心理预测；
3. 做出不依赖家庭许可的部分决定；
4. 采取可逆行动并获得真实反馈；
5. 在失败后恢复并更新判断；
6. 建立不依赖原生家庭的支持和资源路径。

## 二、系统的核心对象

### 2.1 不是改变人格，而是改变默认回路

默认回路：

`重要目标 → 失败/拒绝预测 → 羞耻或身体唤醒 → 回避/冻结 → 短期安全感 → 缺少掌握经验 → 低效能 → 更强预测`

系统不争论“我到底是不是懦弱”，只记录这条回路在什么情境出现，以及哪个环节可以被现实实验改变。

### 2.2 四种问题分流

| 情况 | 优先处理 |
|---|---|
| 不知道做什么 | 问题定义、技能地图和信息补足 |
| 知道但不会做 | 示范、练习、反馈和任务拆解 |
| 会做但不敢接近 | 风险分级、暴露剂量和预测检验 |
| 想做但没有精力 | 功能评估、睡眠/健康、抑郁焦虑和现实负荷 |

不要用同一个“行动力差”标签处理四种不同故障。

## 三、每个问题的标准记录

每次只记录一件真实事件：

| 字段 | 要回答的问题 |
|---|---|
| 情境 | 具体发生了什么，涉及谁，何时发生 |
| 目标 | 我当时真正想完成什么 |
| 自动预测 | 我预期最坏会发生什么 |
| 身体/情绪 | 出现了什么可观察反应 |
| 行为 | 我做了什么或没有做什么 |
| 短期收益 | 这个行为立刻保护了我什么 |
| 长期代价 | 它让未来变得更难的地方是什么 |
| 替代行动 | 一个风险更低但方向相同的动作是什么 |
| 新证据 | 行动后现实发生了什么 |
| 模型更新 | 哪个旧预测被支持、削弱或推翻 |

“短期收益”很重要。回避不是没有功能，它通常提供安全、避免羞耻、避免冲突或暂时节省精力。只有看见它保护了什么，才可能设计替代方案。

## 四、六个月阶段

### 阶段一：基线和安全，前两周

#### 必须完成

- 记录当前收入、住房、负债、家庭依赖和职业状态；
- 列出两个可联系的现实支持来源；
- 记录睡眠、工作/学习、进食、自理和关系功能是否下降；
- 选择三个最典型的“想做但做不到”事件；
- 保存 `12356`、`120` 和 `110` 等当地求助入口。

#### 阶段产物

一页《当前系统状态图》，只写事实，不解释童年。

#### 升级条件

出现自伤/自杀想法、计划或行为，不能保证安全，严重失能，明显躁狂/精神病性症状，严重中毒或暴力风险时，停止个人实验，进入专业或急救路径。

### 阶段二：建立个人机制模型，第一个月

#### 处理三个样本

优先选择：

- 一个职业/赚钱/创作场景；
- 一个关系、求助或边界场景；
- 一个自我评价、失败或公开暴露场景。

每个样本至少写出三个竞争解释。例如“我不敢发布内容”可以来自评价威胁、技能不足、定位不清、资源风险、抑郁性低动力、完美主义担忧或家庭评价内化。

#### 阶段产物

- 三张触发—回避—代价回路图；
- 一张“我必须得到许可才能行动”的证据审计；
- 一张现实阻力与心理阻力分离表；
- 一份尚不能确定的假设清单。

### 阶段三：自主行动实验，第二至第三个月

#### 实验规则

每个实验只验证一个预测，必须满足：

- 风险可控；
- 可以撤回；
- 能观察结果；
- 结果能改变下一步决定；
- 不需要先相信自己。

#### 实验库

| 实验 | 验证的预测 | 最低版本 |
|---|---|---|
| 小范围发布 | “表达后一定会遭到羞辱” | 给一个可控对象发布一个真实观点 |
| 请求帮助 | “求助等于暴露无能” | 向一位可靠的人提出具体、有限请求 |
| 边界实验 | “拒绝会摧毁关系” | 对低风险事项表达一次明确拒绝 |
| 收费实验 | “我没有资格获得交换” | 为一个明确的小结果设定真实价格 |
| 自主决定 | “没有家庭批准就会出事” | 做一个成本上限明确的个人决定 |
| 失败恢复 | “失败后我就无法继续” | 记录失败事实，并在限定周期内完成修正动作 |

#### 每个实验的记录模板

```text
实验名称：
我想验证的预测：
风险上限：
最小行动：
成功不等于感觉好，而是：
实际结果：
哪些事实支持旧预测：
哪些事实削弱旧预测：
下一次如何调整：
```

不要把“我感觉很害怕”当作实验失败。实验要检验的是预测是否准确，以及你是否能在可控范围内完成行动。

### 阶段四：能力、关系和环境重建，第四至第五个月

#### 职业和创作

- 选择一个现实需求，不同时追逐多个身份；
- 建立一项可迁移技能和一组公开作品；
- 计算基本生活跑道和固定成本；
- 把学习连接到真实项目和市场反馈；
- 将“我不配获得收入”拆成能力、价值、定价、市场和羞耻五个问题分别验证。

#### 支持与关系

按功能建立关系地图：

- 可以提供情绪支持的人；
- 可以提供具体信息的人；
- 可以共同工作或学习的人；
- 可以在危机时协助求助的人。

不追求固定人数，不用 AI 猜测他人依恋类型，也不把关系变成绩效表。

#### 环境

优先改变会持续触发旧策略的环境约束：

- 降低不必要的固定成本；
- 减少必须向家庭解释的决策；
- 为高回避任务安排真实反馈者；
- 把作品、合同、收入和学习记录迁移到自己控制的系统；
- 为临床求助、财务支持和职业咨询保留入口。

### 阶段五：整合和复盘，第六个月

复盘不问“我变得自信了吗”，而问：

- 哪些预测被现实推翻；
- 哪些回避仍然准确保护了我；
- 哪些问题其实是技能或资源缺口；
- 哪些问题可能需要专业评估；
- 我是否更能独立做决定、开始行动和承受结果；
- 我的支持来源是否不再全部依赖原生家庭。

## 五、进度与证据指标

不使用“正能量指数”或主观打分作为唯一结果，至少观察以下变化：

- 重要任务从决定到开始的时间是否缩短；
- 回避后是否更快回到任务；
- 是否能记录真实失败而不立刻人格化；
- 是否能在没有家庭许可的情况下完成可逆决定；
- 是否能提出具体求助而不是等待别人猜测；
- 是否能在关系中表达边界并观察真实后果；
- 是否能把学习转化为作品、技能或市场反馈；
- 睡眠、工作、学习、进食和基本自理是否稳定；
- 重大情绪或功能恶化是否及时进入专业支持。

这些是个人纵向指标，不是经过临床验证的量表，也不能替代 PHQ-9、GAD-7 或专业评估。

## 六、停止和升级规则

### 立即停止个人实验

- 自伤/自杀想法、计划或行为；
- 无法保证人身安全；
- 严重失眠伴异常兴奋、冲动或夸大；
- 明显幻觉、妄想或现实检验下降；
- 实验导致持续闪回、解离、恐慌或功能快速恶化；
- 重大财务、关系或职业风险超过预设上限。

### 进入专业支持

- 情绪和功能问题持续约两周、反复出现或明显影响工作学习关系；
- 自助记录反复指向抑郁、焦虑、ADHD、创伤、睡眠、进食或成瘾问题；
- 自我分析变成新的强迫、羞耻和完美主义；
- 需要处理创伤记忆、暴露、解离或复杂关系创伤。

## 七、六个月最终交付

最终应形成一份个人操作手册，包含：

1. 我的现实约束；
2. 我的三条主要触发—回避回路；
3. 我的竞争性解释；
4. 已被验证和推翻的预测；
5. 可独立处理的问题；
6. 需要他人或专业支持的问题；
7. 职业、创作、金钱和关系的下一阶段实验；
8. 我的风险上限和退出条件；
9. 我可以信任的支持路径；
10. 下一次复盘日期和判定标准。

## 八、不可做的事

- 不用“内在小孩”“依恋类型”“神经症”给自己下诊断。
- 不强行回忆创伤，不追求恢复所谓被压抑的记忆。
- 不用名人逆袭故事证明自己必须成功。
- 不把贫困、低教育和住房压力改写成单纯心态问题。
- 不把恐惧消失作为行动前提。
- 不把一次成功当作永久改变，也不把一次失败当作人格真相。
- 不将复杂记录系统变成新的自我控制工具。
