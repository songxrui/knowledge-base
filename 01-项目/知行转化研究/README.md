## 五分钟先知道这些

### 1. 提出了什么

工作名称是**可撤回进展循环**：当目标重要，资源、权限、安全、能力与反馈条件也允许一次合格测试时，一个人仍反复把目标时间投入到容易重写或放弃、没有预声明结果空间、主要增加主观确定而不增加决策相关证据的活动中。

它是**待验证的操作模型与 N-of-1 假设族**，不是学界已验证的新构念。可撤回不等于虚假；探索、有界学习和必要基础设施都有合法位置。

### 2. 为什么不只是旧概念改名

模型没有声称发现新的基础动机。项目层面的新意在三个操作关系：

1. 先过目标价值、资源权限、风险伦理、知识能力、反馈有效性五道门，再允许心理解释。
2. 不按“阅读/计划/输出”的外形分类，而按当前瓶颈、退出条件、结果空间和证据接口，把活动分成探索、有界学习、基础设施、约束测试和可撤回进展。
3. 把“反馈出现、反馈可信、证据达到更新门槛”拆开；合同锁定后只能新建版本，不能事后改写成功标准。

独立原创性审计的底线很明确：若盲评编码不可靠，或控制拖延、完美主义、知识缺口和机会约束后没有增量预测力，就撤销独立名称。

### 3. 最值得先看的三个成果

1. [最终模型](model/04-final-model.md)：定义、五道门、状态向量、证据合同、7 项可证伪预测与撤名条件。
2. [旗舰文章](flagship/article.md)：从这座知识库的 2706/170/92 现场进入，展示初判怎样被反证推翻。
3. [下一步路由器](diagnostic-tool/index.html)：实际区分九类成因，不做总分、人格或医学诊断。

若要看模型如何被红队改变，按顺序读 [初版](model/01-initial-unnamed-model.md)、[十项钢人攻击](model/03-red-team-attack.md)、[最终版](model/04-final-model.md)。

### 4. 哪个成果可以运行

两个静态本地工具都可运行：

- **下一步路由器**：九类多结果诊断，U0 安全停止优先，敏感回答默认不持久化。
- **下一次证据**：一目标、一合同、1–2 个指标、每天不超过 20 分钟；使用单任务工作区、三段合同、移动账本、版本筛选、两阶段 JSON 导入、恢复隔离与退出。

推荐从项目目录启动本地服务器：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory "D:\KnowledgeBase\01-项目\知行转化研究"
```

然后访问：

- `http://127.0.0.1:8765/diagnostic-tool/`
- `http://127.0.0.1:8765/00-%E7%BC%93%E5%86%B2%E5%8C%BA/prototype/`

诊断结果可以导出 JSON；产品只把普通诊断的目标和安全路线说明载入待确认表单。紧急停止或 `canContinue=false` 的结果不会变成生产力目标。

### 5. 理论最可能错在哪里

“可撤回”可能只是拖延、未交付、低约束或低努力的精细改名；现有研究只分别支持组件，没有证明同一人会沿“准备—主观闭合—测试推迟—再次准备”反复形成循环。路由器也可能是一项负责的工程整合，却没有独立理论新意。

这不是附带免责声明，而是模型的撤名条件。详见 [原创性审计](00-缓冲区/audit/02-originality-audit.md) 与 [因果图/决策路由](model/05-causal-map-and-decision-router.md)。

## 证据与隐私

[独立引用核查](00-缓冲区/audit/01-citation-audit.md) 对 24 个唯一 DOI 做了 Crossref 身份核对，并对公开成品使用的高风险数字回到机构页/作者稿。当前访问不到整书的地方没有补页码；创始人自报和回顾案例都保留归属。

公开内容没有使用本地健康、财务、家庭或情绪记录，也没有把模拟“30 天案例”写成真人结果。两个工具本地运行、无外部请求；它们不做医疗诊断，也不替代紧急或专业支持。

## 当前状态

研究和原型已完成本地验证，**尚未完成真实用户的 7 天效果试验，也没有证明模型的因果或增量效度**。产品可运行不等于理论成立；阴性用户结果、合法退出和撤销模型名称都被视为有效产出。
