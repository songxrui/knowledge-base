# 受限起点后的重大问题总图谱与统一研究框架

> 版本：v0.1
> 日期：2026-08-08
> 用途：统一研究游戏、睡眠、自控冲突、注意力、低能量、自卑、情绪、关系、决策、金钱和学习等问题。
> 边界：这是研究与个人行动系统的框架，不是心理诊断、医学建议或治疗替代品。

## 一、总问题

当前要解决的不是“怎样变得更自律”，而是：

> 为什么一个已经拥有较多时间自主权的人，仍然无法稳定启动、维持、停止和恢复重要活动，以至于运动、睡眠、写作、发布和职业推进同时失守？

这个问题需要同时考察：

- 现实资源是否真的足够；
- 身体和心理功能是否处于可执行状态；
- 目标是否具有本人认可的价值；
- 任务是否有明确动作、反馈和退出路径；
- 即时奖励是否持续压过延迟结果；
- 家庭控制、贫困和低支持是否形成了默认预测；
- 游戏、手机、熬夜、回避和学习囤积是否互相强化。

“做不到”不是一种人格，也不是一个病名，而是需要路由的结果。

## 三、统一问题接口

### 3.1 六层机制

所有模块都必须按六层拆解：

1. **现实条件**：钱、住房、工作、教育、时间、权限、照护责任、关系和安全。
2. **发展经历**：照料、控制、忽视、羞辱、冲突、贫困、迁移和其他可观察事件。
3. **心理模型**：对自我、他人、失败、权威、未来和资源的默认预测。
4. **行为策略**：回避、冻结、讨好、反依赖、冲动、过度准备、隐藏、追求即时奖励。
5. **维持回路**：行为如何产生短期收益，又如何减少长期掌握经验或增加现实代价。
6. **临床与结构因素**：抑郁、焦虑、创伤相关症状、ADHD、睡眠、成瘾、身体疾病、贫困和制度约束。

### 3.2 五道前置门

在解释“情绪回避”前，先检查：

| 门 | 问题 | 不通过时的合法路线 |
|---|---|---|
| V 目标价值 | 这是本人真正认可的目标吗 | 澄清、改写、协商或退出 |
| P 资源权限 | 有时间、钱、场所、资格和决策权吗 | 获取资源、协商、暂停或集体行动 |
| R 风险伦理 | 最大损失和第三方风险可接受吗 | 监督、模拟、专家复核或停止 |
| K 知识能力 | 是否具备完成最低动作的能力 | 有界学习、示范和任务特定测试 |
| F 反馈有效 | 结果是否相关、可读、可归因 | 改善测量、增加重复或延长观察 |

只有五道门均达到当前足够，才允许把阻力暂时标为候选情绪回避或完美主义担忧。

### 3.3 统一事件记录

```text
具体情境 → 自动预测 → 身体/情绪反应 → 行为选择 → 短期收益
→ 长期代价 → 替代行动 → 新证据 → 模型更新
```

短期收益不能省略。游戏可能立即提供掌控和低评价环境；熬夜可能提供自主时间；学习可能提供确定感；回避可能避免羞耻。看见功能，才能设计替代物。

## 四、关键交叉回路

### 4.1 数字娱乐—睡眠—低能量—拖延

```text
白天任务回避 → 晚间内疚与未完成感 → 用游戏/刷屏恢复掌控
→ 入睡延迟 → 次日睡眠不足/节律后移 → 启动能力下降
→ 更难面对任务 → 再次回避
```

这个回路不是唯一原因。需要同时排除昼夜节律障碍、失眠、抑郁、躁狂、ADHD 和现实任务过载。

### 4.2 羞耻—公开回避—作品缺失—自我效能下降

```text
想到公开表达/收费 → 预测羞辱或暴露无能 → 隐藏、继续学习或删除作品
→ 缺少市场反馈和掌握经验 → 对能力判断更差 → 下一次暴露更可怕
```

低风险公开实验只能在现实权力风险可接受时使用，不能对受强制控制或暴力环境的人强行安排。

### 4.3 控制内化—许可依赖—决策减少

```text
自主决定 → 预测拒绝、惩罚或关系破裂 → 等待许可/反复征询
→ 决策机会消失 → 自主经验不足 → 更相信自己无法独立决定
```

可逆、小成本、无需家庭参与的决定，才适合作为首轮实验。

### 4.4 贫困—短期奖励偏好—长期规划困难

```text
迫近的现金/家庭责任 → 注意力被短期问题占用 → 长期目标的主观价值下降
→ 选择即时回报或低风险动作 → 长期资产和技能积累不足 → 资源约束持续
```

这条回路要求同时做现金流和职业结构工作，不能只要求“延迟满足”。

### 4.5 孤独—数字替代—情绪调节—真实支持减少

```text
缺少可求助关系 → 数字娱乐提供低风险刺激与陪伴感 → 真实互动减少
→ 支持网络更薄 → 压力时更依赖数字娱乐
```

孤独、客观隔离和关系质量必须分开记录。

### 4.6 学习囤积—主观进展—现实反馈缺失

```text
任务不确定/评价风险高 → 继续阅读、整理、问 AI → 当下确定感上升
→ 现实接触延后 → 没有作品和反馈 → 能力判断不更新
```

学习也可能是真正补足能力。判断标准不是学习媒介，而是它是否解决当前瓶颈并进入提取、练习和反馈。

## 五、风险与专业分流

### 立即停止自助实验

- 自伤/自杀想法、计划或行为；
- 无法保证安全；
- 严重失眠伴异常兴奋、冲动、夸大或思维加速；
- 明显幻觉、妄想、现实检验下降或暴力风险；
- 游戏、赌博、物质或消费造成即刻重大财务/法律风险；
- 自我暴露导致持续闪回、解离、恐慌或功能快速恶化。

中国大陆心理危机与服务导航可询 `12356`；立即生命危险、中毒、意识异常、抽搐或现场暴力拨 `120/110`。这些入口不能替代专业评估或急救。

### 进入专业评估

- 症状或功能问题持续约两周、反复出现或影响工作学习关系；
- 多个领域同时低动力、睡眠/食欲明显变化或基本自理下降；
- 反复无法控制的游戏、赌博、物质或性行为并造成显著代价；
- 长期入睡困难、白天严重困倦或作息无法通过行为调整改变；
- 需要处理创伤记忆、解离、复杂 PTSD、严重社交焦虑或自伤风险。

## 六、研究和行动质量规则

- 不把“多巴胺基线崩塌”“神经回路锁死”写成未经核实的确定机制。
- 不把高频使用、问题使用和正式障碍混为一谈。
- 不把名人成功故事当治疗证据或可复制路径。
- 不把完成次数、打卡天数和单一主观评分当作结果。
- 每个实验都有风险上限、最低动作、成功/失败定义、退出条件和复盘方式。
- 允许暂停、求助、争取资源、继续学习和退出目标成为合法结果。
- 个人案例只用于排序和验证，不升级为普通人的普遍规律。

## 八、最终目标

这套系统完成后，用户应能回答：

1. 我现在遇到的是健康问题、现实问题、技能问题、价值问题、环境问题还是回避问题？
2. 这个问题的短期收益是什么？
3. 什么证据可以支持或推翻当前解释？
4. 下一步最小可逆实验是什么？
5. 什么情况下我应该暂停自助并寻求专业支持？

如果系统只能让人更会解释自己，却不能改善决策、行动、恢复、关系或求助，它就没有完成任务。
