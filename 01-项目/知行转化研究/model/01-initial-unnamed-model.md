# 未命名理论初版

版本：v0.1，形成于近邻理论审计之前。  
状态：工作假设，不是学界已有共识，也没有被整体检验。

## 一句话现象定义

当一个人已经拥有足够的起步知识，却反复选择可以私下修改、随时撤回、很少暴露于外部否定的目标相关活动，并把这些活动带来的确定感或身份感当成进展时，准备就可能替代下一次真实行动。

## 什么属于，什么不属于

属于这个现象，需要同时出现四个信号：

1. **已有起步知识**：本人能说出一个低风险的下一步，或经简短澄清即可说出。
2. **目标相关活动持续发生**：阅读、收藏、重写计划、换工具、整理系统、反复询问 AI，不是完全躺平。
3. **活动高度可撤回**：结果可以一直私藏、修改、废弃，不让身体、用户、市场、同伴或目标环境形成约束。
4. **现实证据没有增加**：没有新的动作痕迹、表现数据、对方回应、身体记录或真实条件下的错误。

下列情况不属于：初学者真正不知道怎么做；高风险任务必须培训或模拟；已有练习包含目标表现、反馈和纠错；贫困、照护、疾病、睡眠或环境让动作客观不可行；目标本身不重要；探索性阅读的目的就是理解、审美或好奇，而非承诺行为改变。

普通人容易误判，是因为准备活动确实有产物：摘要更清楚了，计划更完整了，工具更顺手了，别人也可能认可自己的认真。这些产物不一定虚假，只是它们和目标结果之间还缺一次能反驳自己的接触。

## 两类活动

### 可撤回活动

阅读、搜索、收藏、私下规划、调整模板、写未交付草稿，都可以是有价值的准备。它们共同的结构特征不是“坐着”或“用脑”，而是本人仍掌握全部解释权：何时算完成、质量如何、是否展示、要不要重来，都可以暂不交给现实决定。

### 现实接触

一次现实接触必须满足四项：

1. 与目标行为或目标结果直接相关，而非只与“认真准备”的形象相关；
2. 留下可回看的痕迹，如时间、动作、作品、身体数据、对方回应或环境结果；
3. 结果可能与事前判断冲突；
4. 在目标相似的约束下发生，或在高风险任务中使用能提供有效表现数据的分级模拟。

发出一份草稿、在真实时间关灯、按规定重量完成一组训练、向潜在用户展示演示视频，都可能是现实接触。公开并非必要：身体、计时器和离线测试也能提供外部约束。公开也并非充分：宣布“我要成为作家”没有生成写作表现证据。

## 初版因果链

1. **触发条件**：目标重要、含糊、与身份有关；起步知识已足够；真实反馈标准不清或反馈会威胁自我评价。
2. **内在任务**：降低不确定，保留“我也许能做到”的可能身份，恢复控制感，暂时避免能力被定价。
3. **输入的即时回报**：新解释能提供工具、情绪或认知价值；理解顺畅带来掌握感；选择更多让人觉得仍有退路。
4. **计划的完成感**：写下具体方案能释放被未完成目标占用的注意；被他人看见的身份意图还可能获得提前身份确认。
5. **现实行动的威胁**：它消耗不可退回的时间，减少选项，并可能留下“不够好、目标不重要、方法错误”的证据。
6. **推迟后的再输入**：未解决目标仍制造不确定和自我差距；新的书、方法、提示词或系统再次成为低风险处理手段。
7. **自我强化**：表征能力越来越强，准备产物越来越像进展；系统维护成本上升；缺少基线使本人更难看见现实没有变化。
8. **初版打断点**：给输入加证据义务，把下一步写成 if–then，安排低风险现实接触，记录结果，并允许根据反馈删目标或求助。

## 状态机

```text
S0 真缺知识
  | 决策相关知识 + 独立提取
  v
S1 能解释，但行动未定义
  | 情境线索 + 最小动作 + 完成证据
  v
S2 动作已定义，但尚未接触现实
  | 承担低风险暴露成本
  v
S3 已产生现实结果，但反馈不可读
  | 记录 + 对照预期 + 排除替代解释
  v
S4 反馈能修正下一次尝试
  | 稳定线索 + 重复 + 中断恢复
  v
S5 行为进入环境或身份结构
```

每次从 S1 或 S2 转向更多可撤回活动，都会暂时增加理解、控制或身份感，却不自动提供下一状态缺少的变量。更多知识可以帮助 S0→S1，但不能单独提供 S1→S2 的动作定义、S2→S3 的暴露、S3→S4 的可读反馈或 S4→S5 的稳定重复。

## 可观察指标

这些指标只用于个人前后比较，不设人类统一阈值。

1. **现实接触率** `RCR = C / (C + R)`：观察窗口内，以合格现实接触结束的目标活动次数 `C`，除以现实接触与仅生成可撤回产物的活动次数总和。
2. **证据延迟** `EL`：从保存一条准备改变行为的新信息，到第一次用它产生可反驳结果的时间。
3. **维护占比** `MS = 系统维护分钟 / 目标相关总分钟`：维护包括换工具、重分类、重写规则；若维护本身直接生成目标表现数据，则不计入分子。
4. **反馈更新率** `UR = 改变下一动作的接触次数 / 全部接触次数`：用于发现“有反馈但不纠错”的低水平重复。

指标不能证明心理动机。低现实接触率也可能来自疾病、资源、照护、危险或目标不重要，诊断必须先排除这些条件。

## 输入的证据义务

每条准备改变行动的新信息，至少回答四个问题：

- 它准备改变哪个具体判断？
- 下一次现实接触是什么？
- 会留下什么完成证据？
- 什么日期前发生；若不发生，信息进入探索区还是直接淘汰？

这不是禁止探索。探索区可以没有即时行动义务，但不能在复盘时冒充已发生的目标进展。

## 初版可证伪预测

### P1｜无证据义务的新增资源可能降低近期接触

- **预期观察**：在起步知识已足够且身份相关的任务中，获得大量可选资源但不写证据义务的人，下一周现实接触率低于资源相同但预先写下接触和证据的人。
- **替代解释**：选择过载，而非替代性进展。
- **验证**：随机分配同一资源包，只操纵证据义务；记录实际接触。
- **失败**：两组无差异，或无义务组稳定更高且不能由其他变量解释。

### P2｜公开意图与公开证据方向相反

- **预期观察**：公开身份意图可能降低高度承诺者的行动强度；公开时间戳行为证据则提高接触率。
- **替代解释**：问责强度、观众关系不同。
- **验证**：同一目标随机分为私下、公开身份意图、公开可核验结果三组。
- **失败**：两类公开在匹配问责条件后方向和大小没有差别。

### P3｜长篇阅读的效果取决于当前瓶颈

- **预期观察**：真缺知识或需要形成复杂模型时，长篇阅读加提取会提高后续表现；动作已明确时，无限续读不提高接触率。
- **替代解释**：读者能力、兴趣和材料质量。
- **验证**：先测知识状态，再比较任务相关阅读、阅读加提取、直接尝试三组。
- **失败**：瓶颈不调节阅读效果，或续读在所有状态都稳定改善行为。

### P4｜维护占比只在不产生表现数据时有害

- **预期观察**：高维护占比与低接触率相关，但自动记录、错误分析等直接生成表现数据的维护不呈同样关系。
- **替代解释**：困难任务本来就需要更多维护。
- **验证**：按维护是否生成目标表现数据分层，控制任务复杂度。
- **失败**：两类维护关系相同，或维护占比完全不预测后续接触。

### P5｜反馈可读性决定接触后是纠错还是退回输入

- **预期观察**：模糊、延迟、噪声高的反馈后，人更容易再次搜索方法；具体且可归因的反馈后，更容易修改一个动作变量。
- **替代解释**：负面情绪或反馈强度本身。
- **验证**：在表现相同的任务中操纵反馈可读性，记录下一次选择。
- **失败**：可读性不改变“继续尝试/回到输入”的选择。

### P6｜若动机机制不出现，理论需要删除心理解释

- **预期观察**：控制真正知识缺口、环境、时间、资源和健康后，不确定缓解、身份确认或控制感至少有一项中介可撤回活动与推迟接触的关系。
- **替代解释**：纯粹习惯、界面诱因或机会成本。
- **验证**：纵向日记加行为日志，测活动前后状态与实际接触。
- **失败**：心理功能不预测选择，只有环境或资源稳定解释结果。届时保留行为分类，删除身份/不确定机制。

## 初版边界

- 不能解释 ADHD、抑郁、焦虑障碍、成瘾、慢性疼痛、睡眠障碍等造成的执行困难；疑似情况应寻求专业评估。
- 不能把贫困、工时、照护、歧视、组织权力和信息路由问题个人化。
- 新手、医生、飞行员、工程师、投资者等高风险情境需要先学习、监督和模拟。
- 科学、写作、数学、语言与专业技能需要长期知识积累；现实接触可以是分级练习，不必等于立即公开或商业化。
- 低质量反馈会训练错误；接触现实不保证接触到真相。
- 快速行动可能固化低水平重复；更新率与反馈质量和接触率同样重要。
- 目标不重要时，停止而不是优化执行，可能是更好的结果。

## 初版最脆弱处

“可撤回”与“现实接触”可能只是给“准备替代行动”换了更精细的名字。当前证据分别支持意图差距、流畅错觉、象征性完成、计划闭合和进度反馈，却没有直接验证这些机制会在同一个人身上形成稳定循环。近邻审计必须证明该模型能提出不同预测和不同干预；否则应放弃命名。
