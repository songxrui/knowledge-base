# private-product-line · 私人产品线

> 为董辉一人定制的私有化软件产品组合：把知识库里已经写成的三套操作系统（人生操作系统 / DBS 内容闭环 / 第二大脑）编译成会自己转的软件。本 README 与全部规格为 **AI 起草稿（evidence_level: B）**，未经用户确认不得视为 canonical。

## 定位

- **服务目标层**：`01-项目/`（工程交付类项目）。未来代码仓库直接落在本目录（沿用 `proofline`/`mingxi` 的"根 README + 代码 + docs/specs"惯例）。
- **责任人**：董辉（一切取舍、验收、发布由人决定）。
- **平台约束**：Windows 桌面 + 安卓（6.74 英寸，1080×2400，设计基准 360×800dp）。不做 iOS/macOS/Web 公开版。
- **设计语言**：AQUA —— 以 Apple HIG 与苹果工业设计审美为基准的自建设计系统（见 `docs/specs/02-设计语言-AQUA.md`）。
- **AI 接入**：全产品共享一套 LLM 设置层，中转站与国产模型官网均可，设置页手动填写（见 `docs/specs/03-技术底座与LLM接入.md`）。
- **退出条件**：三个产品 v0.1 全部上线并连续真实使用 30 天后，本项目转为维护模式；或连续 30 天无动作则按规归档。
