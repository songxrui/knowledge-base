# 02 · AQUA 设计语言（苹果风格设计系统）

> AQUA 是本产品线唯一的视觉与交互语言，致敬 Apple Aqua 与 Human Interface Guidelines。目标：在 Windows 与安卓上做出"苹果设计工作室出品"的质感——克制、通透、有深度、有呼吸。三个产品共用一个组件包 `packages/design-system`，禁止各产品私造样式。

## 一、气质总纲

1. **内容即界面**： chrome 退后，正文与数据是主角；装饰性的东西一概没有。
2. **材质分层**：真实的空间深度——底板、面板、卡片三层，靠毛玻璃与投影区分，不靠粗黑分割线。
3. **克制的色彩**：大面积中性色，色彩只用于状态、重点与品牌瞬间；一个屏幕上强调色不超过一种。
4. **物理感动效**：所有运动都是弹簧，不是匀速直线；一切过渡都回应手指与滚轮。
5. **中文即一等公民**：字重、留白、标点按中文排版规范执行，绝不套用英文排版凑合。

## 二、字体

| 层级 | 中文 | 西文/数字 | 说明 |
|---|---|---|---|
| 主字体 | HarmonyOS Sans SC（个人使用免费授权，字重最接近苹方） | Inter | Windows 与安卓统一打包内置，不依赖系统字体 |
| 等宽/数据 | — | JetBrains Mono / tabular-nums | 曲线图坐标、金额、Token 账本 |
| 回退 | 苹方(若有) → Segoe UI Variable → 微软雅黑 | SF Pro(若有) → Segoe UI Variable | |

## 三、色彩

系统色（浅色 / 深色）：

| 语义色 | 浅色 | 深色 |
|---|---|---|
| Blue（主行动/链接） | #007AFF | #0A84FF |
| Green（完成/正向） | #34C759 | #30D158 |
| Red（警示/红线门禁） | #FF3B30 | #FF453A |
| Orange（等待/超期） | #FF9500 | #FF9F0A |
| Teal（能量/身体） | #30B0C7 | #40C8E0 |
| Purple（LLM/智能） | #AF52DE | #BF5AF2 |

中性色：浅色底 `#FFFFFF` / 分组底 `#F2F2F7`；深色底 `#000000` / 浮起层 `#1C1C1E → #2C2C2E → #3A3A3C` 随层级变亮。分隔线一律 1px、黑色 6% 透明度（hairline），深色下用白 8%。

用法纪律：红=门禁失败与红线（对应 faith-humanizer 红线语义）；橙=超期与待复核；紫=任何 LLM 生成内容的水印色（用户必须一眼分辨"这是模型说的"）；绿只给"完成"，不给"涨粉"（防数据情绪化）。

## 四、材质与层级

| 层 | 材质 | 实现 |
|---|---|---|
| 底板 | 浅色 #F2F2F7 / 深色纯黑；桌面端可用 Mica 质感的静态噪点 | 纯色优先，禁用花哨渐变壁纸 |
| 面板 | 毛玻璃：`backdrop-filter: blur(40px) saturate(180%)`，白 72% / 黑 55% | 底部 Tab 栏、侧栏、Sheet 头部、命令面板 |
| 卡片 | 浮起表面：白 #FFFFFF / 深色 #1C1C1E，圆角 16，投影 `0 1px 2px rgba(0,0,0,.06), 0 8px 24px rgba(0,0,0,.08)`；深色下取消投影改用提亮 | 内容承载最小单元 |
| 浮层 | Sheet（自底部/右侧滑入，顶部圆角 20）与 Popover（圆角 12） | 录入、详情、确认 |

深度纪律：同屏不超过三层浮起；投影只给卡片与浮层，不给按钮（按钮靠填充色与按压反馈）。

## 五、形状与动效

- 圆角阶梯：8（小控件）/ 12（按钮、输入框）/ 16（卡片）/ 20（Sheet 顶角）/ 28（大模态）；全部使用连续曲率（squircle），实现可用 `border-radius` + 大圆角内嵌近似，关键位（图标、大按钮）用 SVG 连续圆角。
- 动效一律弹簧：标准弹簧 `stiffness 380 / damping 30`（≈0.35s 稳定），Sheet `0.45s`，列表入场自下而上 stagger 60ms；按压缩放 0.97 并配 10ms 触感（安卓 `vibrator` 轻击）。
- 转场：列表→详情用共享元素（卡片放大为页面）；Tab 切换淡入淡出 + 8px 位移；任何动效尊重系统"减弱动态效果"设置。
- 时长纪律：≤400ms；连续操作时动效立即让位（可打断）。

## 六、组件基准（12 个 M0 必交付）

大标题导航头、毛玻璃底部 Tab 栏、分段控件（Segmented Control）、卡片、大主按钮（蓝色胶囊，高 50）/次按钮（灰填充）、开关与滑块（iOS 规格）、下拉刷新、Sheet 表单、空态（细线插画 + 一句话）、徽章（质量分级 S/A/B/C 专用样式）、图表（曲线用 2px 圆头描边 + 渐变填充 12% 透明度）、命令面板（毛玻璃、居中 1/3 高度）。

## 七、安卓（6.74 英寸）专属规范

- 设备基准：1080 × 2400 px，~3x 密度，**设计画布 360 × 800 dp**；四周边距 16dp，卡片间距 12dp。
- 单手优先：高频操作（打卡、记录、勾选）全部落在屏幕下 1/3；顶部只放浏览内容。
- 底部 Tab：毛玻璃、5 个以内、图标 24dp + 文字 10sp；选中态用系统色填充图标，不用标签动画喧宾夺主。
- Large Title 折叠：滚动时 34→17 并吸顶为毛玻璃小标题。
- 系统融合：尊重安卓返回手势（左缘右缘滑动=返回）；深色模式跟随系统；小组件（Widget）第一优先做"能量四字段打卡 4×2"，让打卡发生在桌面而不是 App 内。
- 字号下限：正文不小于 16sp（6.74 英寸 ~387ppi 下的可读性红线）；对比度 ≥ 4.5:1。

## 八、Windows 桌面专属规范

- 窗口：默认 1280×800，最小 960×640；自绘标题栏（58px），左侧红绿灯改为一枚品牌圆点 + 菜单，右上保留最小化/最大化/关闭（贴合 Windows 用户肌肉记忆）。
- 布局骨架：左侧栏 232px（毛玻璃、可折叠至 68px 图标态）+ 内容区；内容区按任务分两种网格：阅读类最大 720px 居中（知行复盘、文章），看板类全宽 24px 边距（DBS 看板、数据舱）。
- 键盘优先：`Ctrl+K` 命令面板全产品统一；列表 `↑↓` 导航、`Enter` 进入、`Esc` 逐层返回；DBS 看板支持 `J/K` 移卡。
- 滚轮与触控板：滚轮滚动必须带惯性阻尼；`Ctrl+滚轮` 缩放仅用于数据舱图表。
- 多窗口：只允许"主窗口 + 速记 Popover"两态，不做 MDI。

## 九、图标与插画

- 图标：SF Symbols 语义的自绘集（1.5px 描边、圆头、24dp 网格），随字重变粗细；不用彩色多色图标。
- 插画：仅在空态出现，单色细线 + 一处强调色，风格是"工程图纸"而非"可爱贴纸"。
- 品牌瞬间：每产品只保留一处仪式性设计——知行的"回来"按钮（见 04 规格）、DBS 的发布完成页、Cortex 的呼出面板展开动画。其余一律克制。
