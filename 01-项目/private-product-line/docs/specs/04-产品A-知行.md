# 04 · 产品 A：知行（zhixing）· 人生操作系统 App

> 把《人生操作系统 v2》（副标题：意志力不是杠杆）变成软件。全书五层系统 + 《答案之书》决策工具 + 阶级跃迁月检，编译成一个每天打开 3 次、每次 3 分钟的私有 App。

## 一、定位与对标

- 一句话：**不管理待办，管理"系统本身"——默认设置、脚本、能量、纠错规则、以及系统的自我更新。**
- 对标：Things 3（交互与质感标杆）、Apple Journal（低摩擦记录）、Streaks（小组件打卡）。
- 刻意不像的部分（源自 `知行转化研究/product/04` 调研结论）：没有连续天数、没有断签红点、没有金钱惩罚、没有公开打卡。**唯一被奖励的指标是"回来的速度"**（v2 原文："回来的速度是一项指标"）。

## 二、五层系统 → 五个模块（认知出处：人生操作系统 v2）

### 2.1 默认层 · 今日默认
- 概念：环境替你做决定。软件里的"环境"就是首屏本身——**打开知行，看到的不是待办清单，而是今天已排好的默认动作**，由脚本层自动生成，无需选择。
- 首屏结构（自上而下）：Large Title「今天」→ 能量四字段打卡卡（未填时置顶、10 秒完成）→ 今日默认动作卡（每张：动作名 + 锚点时间 + 完成勾选 + "降级为低配版"按钮）。
- 勾选语义：完成 = 打勾；没做 = **不出现任何红色惩罚**，只在晚间复盘进入"波动/趋势"判断。

### 2.2 脚本层 · 脚本库
- 概念：if-then 执行意向挂锚点（出处：第二章触发脚本，B=MAP）。
- 每条脚本三要素：`锚点（时间/地点/前置事件）→ 动作 → 低配版`。**低配版是必填字段**（v2："每条保留低配版本"），表单不给低配版就存不了。
- 锚点类型：固定时间 / 事件后（如"午饭后"）/ 地点。桌面端到点弹 8px 位移的轻提示；安卓走系统通知 + 桌面小组件。
- 脚本卡片上有一个"状态点"：运行中 / 观察中（新脚本前 14 天）/ 已停用（停用即自更新层的删除账本）。

### 2.3 能量层 · 四字段
- 概念："能量先于时间"，每天只记四个字段：**睡眠 / 身体 / 情绪 / 负荷**（v2 原文），四档计数（1-4），10 秒完成，绝不多加字段。
- 视图：90 天四条曲线 + 一张"能量 × 执行"周矩阵（哪几天能量低且默认动作也没跑，一眼看出结构问题而非意志问题）。
- 纪律：曲线旁永远显示 v2 那句话——"不要把你的解释当成证据"。软件不做任何"情绪分析"AI 表演。

### 2.4 纠错层 · 波动与趋势
- 概念："一次不等于结论"；"每轮只改一个主要参数"（第四章）。
- 机制：某默认动作第 3 次未跑（可配置阈值 3-5），才升级为"趋势待归因"，进入归因流程：三选一——**动机 / 能力 / 结构**（v2 把自律拆成这三件事）。
- 参数轮盘（本产品的招牌约束）：归因为"结构"后进入改参数界面，**界面上同时只能激活一个参数修改提案**，上一个提案未复核（改后满 7 天看趋势）前，不能再改第二个。软件用硬约束实现"每轮只改一个"。
- 波动视图：未达趋势阈值的单次偏离全部归入"波动"折叠区，颜色中性灰。

### 2.5 自更新层 · 更新仪式
- 概念："删除也是更新"；目标也会腐烂（第五章）。
- 季度更新仪式（引导式全屏流程，约 20 分钟）：①列出所有脚本/目标 → ②逐条问"更新四问"（v2）→ ③决定：保留 / 改参数 / 删除 → ④删除项进入"删除账本"永久留痕（仪式感设计：删除页有唯一一处品牌瞬间动效）。
- 腐烂检测：目标/脚本创建满 90 天自动进入"待审视"角标，不自动删除，只提醒。

## 三、两个附属模块

### 3.1 决策簿（出处：答案之书 CH07）
- 新建决策表单：情境 → 选项 → 预期结果 → 置信度（50-95%）→ 复核日期（默认 30/60/90 天三选）→ **预验尸**（"如果这个决策半年后失败了，最可能死在哪？"必填）。
- 到期复核推送 → 复盘页固定显示："决策质量 ≠ 结果质量"（防结果绑架），并要求先给"当时信息下的决策过程"打分，再对照实际结果。
- LLM 红军审查（可选按钮）：模型扮演反方，攻击决策的理由（详见 LLM 节）。

### 3.2 月检 · 跃迁仪表盘（出处：阶级跃迁路线图）
- 每月 1 日推送五项月检表单：**现金跑道（<2 个月触发提示）、有效问题数（<10 条提示继续访谈）、付费验证、获客来源、健康与关系**。
- 五阶段命题验证视图（30 天/90 天/12 个月/24 个月/5 年+ 的"要验证的命题 + 可观测指标"），只显示当前所处阶段的指标，其余隐藏。
- 产品禁令：**没有"1 亿"字段，没有远期资本目标输入框**——"一亿元不应该出现在日常待办里"（路线图原文）。仪表盘只装月度可操作指标。

## 四、14 天启动协议（新建目标的准入门）

任何新目标/新脚本创建时必须通过"最小可运行单元四条件"表单（v2 第六章）：①三天内能开始 ②单次 ≤15 分钟 ③只需一个主要工具 ④能用"是否"判断完成。任一不满足 → 表单拒绝保存，并提示改小。创建后进入 14 天观察期，期间只统计三个数：**机会出现次数、启动率、未启动阻力属于哪一层**——不显示完成率百分比。

## 五、信息架构

### 5.1 安卓（6.74 英寸，360×800dp，底部 Tab 5 个）

| Tab | 名称 | 内容 |
|---|---|---|
| 1 | 今天 | Large Title + 能量打卡卡 + 今日默认动作卡列 |
| 2 | 脚本 | 脚本库（按锚点分组），新建/编辑含低配版必填 |
| 3 | 复盘 | 晚间 5 分钟引导流程（事实→波动/趋势→归因→参数提案）；周矩阵 |
| 4 | 决策 | 决策日志列表 + 复核到期；预验尸表单 |
| 5 | 系统 | 月检、14 天协议统计、删除账本、模型设置、导出 |

- 桌面小组件（优先级最高）：4×2 能量四字段快捷打卡；2×1 今日默认动作第一条勾选。
- 通知策略：全天最多 1 条主动通知（晚间复盘，时间自定），脚本锚点提示不计入。

### 5.2 Windows 桌面

- 左侧栏：今天 / 能量 / 脚本 / 复盘 / 决策 / 月检 / 系统。
- 主区特色视图：①周矩阵大图（能量 × 执行）②参数轮盘（当前唯一激活提案 + 复核倒计时）③季度更新仪式全屏模式 ④决策簿时间线。
- 桌面独占：`Ctrl+K` 命令面板支持"打卡/记录一个偏离/新建决策"三个快动作。

## 六、数据模型（SQLite，表前缀 `zhixing_`）

```
zhixing_script      脚本：anchor_type, anchor_value, action, low_version, status, created_at
zhixing_default_run 每日默认执行：script_id, date, done(bool), degraded(bool 低配完成), note
zhixing_energy_log  date, sleep(1-4), body(1-4), mood(1-4), load(1-4)
zhixing_deviation   script_id, date, layer_hint(动机/能力/结构/未归因), escalated(bool 是否升级为趋势)

zhixing_decision    situation, options, expectation, confidence, review_date, premortem
zhixing_decision_review  decision_id, process_score, outcome_note, lesson
zhixing_monthly_check  month, runway_months, valid_questions, paid_validation, acquisition, health_relation
zhixing_archive     删除账本：entity_type, entity_json, deleted_at, reason(更新四问答案)

```

## 七、LLM 能力（角色：教练，不是管家）

| 能力 | 触发 | 约束 |
|---|---|---|
| 复盘教练 | 复盘页"陪我聊聊"按钮 | 苏格拉底式提问，**上下文只有本机四字段与偏离记录**；引用必须可回溯；无记录就说没有 |
| 归因助手 | 归因三选一界面 | 只列三类的历史证据（哪几条偏离、当时能量值），**不给结论** |
| 红军审查 | 决策簿手动触发 | 只攻击不夸奖；输出前先复述决策原文；不允许给"建议你做什么"，只允许"指出这会怎么死" |
| 更新四问陪跑 | 季度仪式 | 逐问引导，引用该脚本 90 天运行数据 |
| 明确禁止 | — | 自动生成待办、安慰性话术、给情绪打标签、预测未来成绩 |

## 八、v0.1 边界（M1-M2 交付）

做：五层模块全量（但季度仪式可先只做删除账本+简单引导）、14 天协议表单、决策簿、月检表单、安卓打卡与速记、复盘教练。
不做：Widget 小组件（M2.5）、局域网同步（M2 后）、健康数据接入、日历集成、任何图表动画炫耀。

## 九、完成标准

- M1：桌面端连续 14 天真实记录（本人数据，非测试数据）——启动协议本身即验收。
- M2：安卓端独立使用 7 天；复盘教练 20 次对话抽检，幻觉引用 = 0。
